# The Swift Performance Lite plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'REQUEST\_URI \(gated by \$\_GET\['force\-\.\.\.

- **ID**: CVE\-2026\-119153
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP, Swift
- **公開**: 2026-11-26

## 原文

The Swift Performance Lite plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'REQUEST\_URI \(gated by \$\_GET\['force\-cache'\]\)' parameter in all versions up to, and including, 2\.3\.7\.5 due to insufficient input sanitization and output escaping\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\. The payload is planted via a single unauthenticated GET request to any URL with ?force\-cache\=1 and a URL\-encoded HTML payload in the path, which the plugin decodes and creates as a literal filesystem directory name; the script fires the next time an administrator opens the Swift Performance dashboard\.
