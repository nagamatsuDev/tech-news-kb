# In the Linux kernel, the following vulnerability has been resolved\: tcp\: Fix potential UAF in reqsk\_timer\_handler\(\)\.

- **ID**: CVE\-2026\-99270
- **危険度**: High（重要） (CVSS 8.1)
- **OS**: Linux
- **公開**: 2026-11-03

## 原文

In the Linux kernel, the following vulnerability has been resolved\:
  
tcp\: Fix potential UAF in reqsk\_timer\_handler\(\)\.
  
When TCP socket migration fails at inet\_ehash\_insert\(\) in  
reqsk\_timer\_handler\(\), we jump to the no\_ownership\: label  
and free the new reqsk immediately with \_\_reqsk\_free\(\)\.
  
Thus, we must stop the new reqsk's timer before jumping to the  
label, but the timer might be missed since the cited commit,  
resulting in UAF\.
  
As we are in the original reqsk's timer context, we can safely  
call timer\_delete\_sync\(\) for the new reqsk\.
  
Let's pass false to \_\_inet\_csk\_reqsk\_queue\_drop\(\) to stop  
the new reqsk's timer\.
