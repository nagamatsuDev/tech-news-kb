- **危険度**: High（重要） (CVSS 7.3)
- **言語**: PHP
- **公開**: 2026-11-26

## 原文

A vulnerability was determined in projectworlds Online Jewellery Shopping System 1\.0\. The affected element is the function Dashbord\_model\.searchAdvance of the file /jewllary\-shop/application/models/dashbord\_model\.php of the component Advanced Search\. This manipulation of the argument from/to causes sql injection\. The attack can be initiated remotely\. The exploit has been publicly disclosed and may be utilized\.
