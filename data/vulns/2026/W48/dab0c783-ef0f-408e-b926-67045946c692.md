# A security vulnerability has been detected in TRENDnet TEW\-751DR and TEW\-733GR 1\.03B01\.

- **ID**: CVE\-2026\-138004
- **危険度**: Critical（緊急） (CVSS 10.0)
- **公開**: 2026-11-27

## 原文

A security vulnerability has been detected in TRENDnet TEW\-751DR and TEW\-733GR 1\.03B01\. Affected is the function soapcgi\_main of the file /soap\.cgi of the component UPnP Igd Control Endpoint\. Such manipulation of the argument service leads to os command injection\. The attack may be performed from remote\. The exploit has been disclosed publicly and may be used\.
