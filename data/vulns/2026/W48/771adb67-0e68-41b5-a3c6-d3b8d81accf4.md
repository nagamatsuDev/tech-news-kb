# OneDev before 17\.2\.4 contains an argument injection vulnerability in commit query handling that allows authenticated attackers to inject \.\.\.

- **ID**: CVE\-2026\-136920
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-25

## 原文

OneDev before 17\.2\.4 contains an argument injection vulnerability in commit query handling that allows authenticated attackers to inject git options through branch or tag names\. Attackers can push a branch named like \-\-output\=&lt;path&gt; and query it via the commits page or REST API to overwrite server\-writable files, causing denial of service\.
