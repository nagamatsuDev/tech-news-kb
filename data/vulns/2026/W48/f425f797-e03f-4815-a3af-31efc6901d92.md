# Weblate before 2026\.11 contains an account takeover vulnerability in the reset\_password view that allows unauthenticated attackers to res\.\.\.

- **ID**: CVE\-2026\-134838
- **危険度**: High（重要） (CVSS 7.4)
- **公開**: 2026-11-22

## 原文

Weblate before 2026\.11 contains an account takeover vulnerability in the reset\_password view that allows unauthenticated attackers to reset victim passwords by abusing case\-insensitive Unicode e\-mail matching\. Attackers controlling a lookalike mailbox using a dotless i or other case\-folding variant receive the victim's reset link, since it is sent to the typed address, and set a new password\.
