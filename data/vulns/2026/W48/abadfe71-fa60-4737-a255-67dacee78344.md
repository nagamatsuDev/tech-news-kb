## 原文

Dell PowerProtect Data Domain Management Center, Feature Release versions 7\.7\.1\.0 through 8\.8, LTS2024 release versions 7\.13\.1\.0 through 7\.13\.1\.80, LTS2025 release versions 8\.3\.1\.0 through 8\.3\.1\.40, LTS2026 release versions 8\.6\.1\.0 through 8\.6\.1\.20, contain an Authentication Bypass by Spoofing vulnerability\.
