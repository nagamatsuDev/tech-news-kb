# Lightdash before 3\.212\.0 contains an insufficiently protected credentials vulnerability in getGitlabInstallationRepoReadAccess that sends\.\.\.

- **ID**: CVE\-2026\-134827
- **危険度**: High（重要） (CVSS 7.7)
- **公開**: 2026-11-22

## 原文

Lightdash before 3\.212\.0 contains an insufficiently protected credentials vulnerability in getGitlabInstallationRepoReadAccess that sends the organization GitLab app token to unverified hosts\. Project developers can set the dbt connection host\_domain to an attacker\-controlled server and capture the token when the AI agent reads the repository, gaining access to every reachable repository\.
