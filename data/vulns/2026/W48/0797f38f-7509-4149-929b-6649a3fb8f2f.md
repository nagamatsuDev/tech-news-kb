# erxes before 3\.4\.14 contains a missing authentication vulnerability in the insurance\_api plugin that allows unauthenticated attackers to \.\.\.

- **ID**: CVE\-2026\-134826
- **危険度**: High（重要） (CVSS 7.3)
- **公開**: 2026-11-22

## 原文

erxes before 3\.4\.14 contains a missing authentication vulnerability in the insurance\_api plugin that allows unauthenticated attackers to create, overwrite or delete contract templates via GraphQL mutations\. Attackers can inject HTML into templates rendered by headless Chromium during generateContractPDF to pull internal network content into PDFs and exfiltrate customer fields\.
