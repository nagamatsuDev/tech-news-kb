# Bold pagos en linea WordPress plugin before 3\.5\.1 contains an improper signature verification vulnerability in the bold\_co webhook that a\.\.\.

- **ID**: CVE\-2026\-135446
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-23

## 原文

Bold pagos en linea WordPress plugin before 3\.5\.1 contains an improper signature verification vulnerability in the bold\_co webhook that allows unauthenticated attackers to forge payment notifications\. Attackers can set metadata\.reference to begin with 'test' and sign the body with the empty test\_secret\_key HMAC, marking any unpaid WooCommerce order as paid\.
