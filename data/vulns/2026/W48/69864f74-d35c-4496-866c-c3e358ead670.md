# AutoGPT is a workflow automation platform for creating, deploying, and managing continuous artificial intelligence agents\.

- **ID**: CVE\-2026\-132264
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-24

## 原文

AutoGPT is a workflow automation platform for creating, deploying, and managing continuous artificial intelligence agents\. In versions 0\.6\.63 through 0\.10\.0, an external API key or OAuth token that has only the EXECUTE\_BLOCK permission can run AutoPilotBlock through the external API and receive a full, unattended AutoPilot turn\. This lets the holder use the account owner's stored third\-party credentials, library agents, and workspace files, and run AutoPilot's sandboxed shell, which the same key is refused when it requests those directly\. This issue is fixed in version 0\.11\.0\.
