# Softaculous Virtualizor before 3\.2\.9 contains an SQL injection vulnerability in enduser/auth\_callback\.php that allows unauthenticated att\.\.\.

- **ID**: CVE\-2026\-135174
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-23

## 原文

Softaculous Virtualizor before 3\.2\.9 contains an SQL injection vulnerability in enduser/auth\_callback\.php that allows unauthenticated attackers to bypass authentication via OAuth\-returned email addresses\. Attackers can register an OAuth provider account with an email containing SQL syntax to complete social login as the administrator account\.
