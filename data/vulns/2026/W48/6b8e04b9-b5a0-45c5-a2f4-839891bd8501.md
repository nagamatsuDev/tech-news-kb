# GitHub CLI gh codespace jupyter may allow code execution via unvalidated URLs from malicious Codespaces

- **ID**: CVE\-2026\-59831 / GHSA\-8cg3\-r6g9\-fpg2
- **危険度**: Medium（警告） (CVSS 4.4)
- **言語**: Go
- **パッケージ**: Go/github\.com/cli/cli/v2 &gt;\= 2\.10\.0, &lt; 2\.96\.0 → 2\.96\.0
- **公開**: 2026-11-24

## 原文

\#\#\# Summary A security vulnerability has been identified in GitHub CLI that could allow remote code execution when users connect to a malicious Codespace using the \`gh codespace jupyter\` command\. The command opens JupyterLab by launching a URL in the user's browser, but that URL is supplied by a process running inside the Codespace and the CLI opens it without validating it\. The browser launcher accepts \`vscode\://\` and \`vscode\-insiders\://\` links, so a malicious Codespace can return a crafted \`vscode\://\` URL\.
