# The Ninja Tables – Responsive Table Builder for Data, Pricing &amp; Product Tables plugin for WordPress is vulnerable to SQL Injection via th\.\.\.

- **ID**: CVE\-2026\-124211
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-26

## 原文

The Ninja Tables – Responsive Table Builder for Data, Pricing &amp; Product Tables plugin for WordPress is vulnerable to SQL Injection via the 'dateFormat' column metadata parameter in versions up to, and including, 5\.5\.1 This is due to insufficient escaping on the stored 'dateFormat' value in DefaultProvider\:\:orderByJsonQuery\(\); convertDateFormatToMysql\(\) only performs str\_replace on date\-format tokens and leaves SQL metacharacters \(including single quotes\) intact, after which the value is concatenated directly into an orderByRaw\(\) ORDER BY clause inside single quotes\. This makes it possible for unauthenticated attackers to append additional SQL queries into already existing queries that can be used to extract sensitive information from the database; the payload is stored in the \_ninja\_table\_columns post meta and executed on every unauthenticated request to the wp\_ajax\_ninja\_tables\_public\_action AJAX endpoint when the table uses sorting\_type\='by\_column' with a date column\.
