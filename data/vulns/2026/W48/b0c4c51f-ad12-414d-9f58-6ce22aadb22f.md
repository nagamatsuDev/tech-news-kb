- **ID**: CVE\-2026\-134887
- **危険度**: High（重要） (CVSS 7.3)
- **言語**: PHP
- **公開**: 2026-11-23

## 原文

A vulnerability was found in osCommerce 4\.14\.63493\. This impacts the function get\_address\_book\_data of the file lib/common/helpers/Customer\.php of the component Account Address List Widget\. The manipulation of the argument customers\_id results in sql injection\. The attack can be launched remotely\. The vendor was contacted early about this disclosure but did not respond in any way\.
