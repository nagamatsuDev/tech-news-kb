# pgjdbc, the PostgreSQL JDBC Driver, does not enforce TLS for some settings that ask for it\.

- **ID**: CVE\-2026\-134845
- **危険度**: High（重要） (CVSS 7.4)
- **公開**: 2026-11-23

## 原文

pgjdbc, the PostgreSQL JDBC Driver, does not enforce TLS for some settings that ask for it\. When sslmode is not set, an ssl value such as 1, on, yes or verify\-full gives sslmode\=prefer, or no TLS before 42\.2\.5\. A service given in the Properties instead of the URL is ignored, so the sslmode of its pg\_service\.conf entry is lost\. BaseDataSource\.setUrl\(\) keeps an sslmode, channelBinding or gssEncMode that was set before it\. An attacker on the network path can then read and change the traffic\. Versions 9\.4\.1208 through 42\.7\.14 are affected, and 42\.7\.15 fixes the problem\.
