# Joomla Extension \- regularlabs\.com \- PHP code injection via content inserted during article preparation in Sourcerer extension &lt; 18\.0\.0 \-\.\.\.

- **ID**: CVE\-2026\-129425
- **危険度**: High（重要） (CVSS 7.7)
- **言語**: PHP
- **公開**: 2026-11-24

## 原文

Joomla Extension \- regularlabs\.com \- PHP code injection via content inserted during article preparation in Sourcerer extension &lt; 18\.0\.0 \- Sourcerer decided whether PHP may run based on the author or last editor of the host article and applied that decision to complete code blocks that other extensions, such as Users Anywhere, inserted into the article while it was prepared\. A user able to edit a value rendered by such an extension, for example the display name in their own user profile, could therefore have PHP executed in the context of a trusted article\. Sourcerer 18\.0\.0 authorizes each executable block against its own source; Users Anywhere 3\.1\.0, ReReplacer 16\.4\.0 and Snippets 11\.2\.0 supply the source information needed to keep executing eligible saved content\.
