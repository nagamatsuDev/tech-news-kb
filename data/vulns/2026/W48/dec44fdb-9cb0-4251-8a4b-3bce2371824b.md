# ExAws\.S3\.Utils\.build\_lifecycle\_rule/1 in ex\_aws\_s3 interpolates caller\-supplied lifecycle rule fields \(the rule id, filter prefix, tag ke\.\.\.

- **ID**: CVE\-2026\-63583
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-24

## 原文

ExAws\.S3\.Utils\.build\_lifecycle\_rule/1 in ex\_aws\_s3 interpolates caller\-supplied lifecycle rule fields \(the rule id, filter prefix, tag key and value, storage class, and noncurrent\-version count\) directly into the PutBucketLifecycleConfiguration XML body without escaping XML metacharacters\. An application that populates any of these fields from untrusted input \(for example a tenant\-supplied object tag\) lets an attacker break out of the surrounding element and inject arbitrary XML into the request, including an entirely new lifecycle action such as a delete\-after\-one\-day expiration that destroys the bucket's objects\. The public entry point ExAws\.S3\.put\_bucket\_lifecycle/2 flows directly into this builder\.
  
This issue affects ex\_aws\_s3\: from 2\.3\.0 before 2\.6\.0\.
