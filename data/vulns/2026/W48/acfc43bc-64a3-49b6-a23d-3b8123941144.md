# Scriban before 7\.6\.0 contains a memory exhaustion vulnerability in object\.to\_json that allows template authors to bypass the LimitToStrin\.\.\.

- **ID**: CVE\-2026\-137508
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-26

## 原文

Scriban before 7\.6\.0 contains a memory exhaustion vulnerability in object\.to\_json that allows template authors to bypass the LimitToString string length limit by serializing into an unbounded MemoryStream\. Attackers can repeatedly apply object\.to\_json to escape\-heavy strings in a tiny template, amplifying output to multi\-gigabyte heap allocations and causing denial of service\.
