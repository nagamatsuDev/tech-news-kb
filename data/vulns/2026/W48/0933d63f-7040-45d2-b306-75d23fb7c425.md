# Wing FTP Server before 8\.2\.8 contains a predictable session identifier vulnerability that allows unauthenticated attackers to hijack admi\.\.\.

- **ID**: CVE\-2026\-135171
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-23

## 原文

Wing FTP Server before 8\.2\.8 contains a predictable session identifier vulnerability that allows unauthenticated attackers to hijack administrator sessions by deriving identifiers from process, time, ServerID, and client IP state\. Attackers can enumerate candidate identifiers using the service\_get\_license\.html endpoint as a validity oracle and replay live sessions to gain administrative control including the Lua console\.
