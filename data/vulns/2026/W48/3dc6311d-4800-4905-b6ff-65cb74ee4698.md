# FLTK through 1\.4\.5 contains a heap buffer overflow vulnerability in Fl\_BMP\_Image\:\:load\_bmp\_\(\) that allows attackers to corrupt heap memor\.\.\.

- **ID**: CVE\-2026\-135433
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-23

## 原文

FLTK through 1\.4\.5 contains a heap buffer overflow vulnerability in Fl\_BMP\_Image\:\:load\_bmp\_\(\) that allows attackers to corrupt heap memory by supplying crafted BMP or ICO files\. Attackers can specify very large image dimensions so the 32\-bit row and alpha mask pointer offsets wrap, writing file\-derived pixel bytes out of bounds to crash applications or possibly execute code\.
