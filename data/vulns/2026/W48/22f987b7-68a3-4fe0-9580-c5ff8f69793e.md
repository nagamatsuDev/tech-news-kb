# Leo through 6\.8\.10 contains an insecure deserialization vulnerability that allows attackers to execute code by embedding pickled data in \.\.\.

- **ID**: CVE\-2026\-137994
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-27

## 原文

Leo through 6\.8\.10 contains an insecure deserialization vulnerability that allows attackers to execute code by embedding pickled data in unknown XML attributes of \.leo outlines\. Attackers can place a pickle \_\_reduce\_\_ gadget in a &lt;t&gt; or &lt;v&gt; element attribute that resolveUa passes to pickle\.loads, executing code with user privileges when the outline is opened\.
