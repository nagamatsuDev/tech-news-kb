# FFmpeg before 9\.1 contains a double free vulnerability in the fill\_marker\(\) function of libavformat/imf\_cpl\.c that frees a Marker label w\.\.\.

- **ID**: CVE\-2026\-135723
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-24

## 原文

FFmpeg before 9\.1 contains a double free vulnerability in the fill\_marker\(\) function of libavformat/imf\_cpl\.c that frees a Marker label without clearing the pointer when default scope allocation fails\. Attackers can supply a crafted Composition Playlist with a Marker Label lacking a scope attribute, triggering a second free in imf\_marker\_free\(\) under memory pressure and causing memory corruption or a crash\.
