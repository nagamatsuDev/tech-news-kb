- **ID**: CVE\-2026\-95464

## 原文

In SignalError of logical\_link\.cc, there is a possible use after free due to an error callback that can destroy the object while its channel list is still being iterated\. This could lead to remote \(proximal/adjacent\) code execution with no additional execution privileges needed\. User interaction is not needed for exploitation\.
