# A flaw was found in pam\.

- **ID**: CVE\-2026\-137898
- **危険度**: High（重要） (CVSS 7.3)
- **公開**: 2026-11-27

## 原文

A flaw was found in pam\. When built with libeconf and an unconfigured vendor directory, the pam\_econf configuration handler misinterprets the search path, causing it to look for configuration files in a relative directory within the current working directory\. A local attacker can exploit this by placing crafted environment configuration files in a world\-writable location\. If an administrator executes a privileged command from that directory, the malicious variables are loaded into the privileged process, resulting in local privilege escalation\.
