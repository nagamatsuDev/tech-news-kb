# ToolJet before 3\.21\.96\-LTS contains a hard\-coded credentials vulnerability where the Helm chart values\.yaml sets secret\_key\_base and lock\.\.\.

- **ID**: CVE\-2026\-137963
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-27

## 原文

ToolJet before 3\.21\.96\-LTS contains a hard\-coded credentials vulnerability where the Helm chart values\.yaml sets secret\_key\_base and lockbox\_key to a static published constant\. Unauthenticated attackers can sign session tokens with the known key to impersonate any user and decrypt all stored datasource credentials\.
