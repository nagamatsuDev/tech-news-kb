# metasfresh through 5\.175 contains a SQL injection vulnerability in the stressTest\_massCacheInvalidation handler of DebugRestController, w\.\.\.

- **ID**: CVE\-2026\-67209
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-25

## 原文

metasfresh through 5\.175 contains a SQL injection vulnerability in the stressTest\_massCacheInvalidation handler of DebugRestController, which concatenates the caller\-supplied tableName request parameter into SELECT statements without parameterization or validation and only checks that the caller is authenticated\. Authenticated WebUI users with any role can send GET requests to /rest/api/debug/stressTest/massCacheInvalidation with SQL in the tableName parameter to run time\-based and error\-based blind queries against the PostgreSQL database, extracting sensitive ERP data such as user credentials and financial records while also degrading availability through sleep payloads\.
