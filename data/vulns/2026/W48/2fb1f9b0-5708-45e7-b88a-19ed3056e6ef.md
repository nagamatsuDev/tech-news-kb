# Vulnerability involving the exposure of sensitive information in the ver\_usuarios endpoint\.

- **ID**: CVE\-2026\-133738
- **危険度**: High（重要） (CVSS 7.2)
- **公開**: 2026-11-25

## 原文

Vulnerability involving the exposure of sensitive information in the ver\_usuarios endpoint\. The JSON response includes data that is not required for the query and which should remain restricted, such as Argon2id password hashes, TOTP secrets, internal configuration flags, email addresses, telephone numbers and dates of last access\. An authenticated user querying this resource can access this confidential information, which is sent directly to the web client\.
