# Scriban and Scriban\.Signed before 7\.6\.0 allow template authors to bypass the LimitToString string length limit because the string\.literal\.\.\.

- **ID**: CVE\-2026\-137510
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-26

## 原文

Scriban and Scriban\.Signed before 7\.6\.0 allow template authors to bypass the LimitToString string length limit because the string\.literal, string\.base64\_encode, html\.escape, html\.newline\_to\_br, html\.url\_encode, and html\.url\_escape builtins lack allocation guards\. An attacker who can supply a small template can repeatedly call these builtins under the default TemplateContext to force multi\-gigabyte allocations and exhaust host memory\.
