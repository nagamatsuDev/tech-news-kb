# In ProcessWriteQueue of client\.cc, there is a possible use after free due to a callback that continues to use its object after the object\.\.\.

- **ID**: CVE\-2026\-95445
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-23

## 原文

In ProcessWriteQueue of client\.cc, there is a possible use after free due to a callback that continues to use its object after the object is destroyed during connection shutdown\. This could lead to remote \(proximal/adjacent\) code execution with no additional execution privileges needed\. User interaction is not needed for exploitation\.
