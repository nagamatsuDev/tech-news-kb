# Gammu before 1\.45\.2 contains a stack\-based buffer overflow vulnerability in ReadBackupTextLen\(\) that allows attackers to overwrite stack \.\.\.

- **ID**: CVE\-2026\-138160
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-28

## 原文

Gammu before 1\.45\.2 contains a stack\-based buffer overflow vulnerability in ReadBackupTextLen\(\) that allows attackers to overwrite stack memory via crafted backup files\. Attackers can supply overlong quoted text values decoded into a 10,000\-byte stack array during convertbackup, restore, or GSM\_ReadBackupFile calls, causing crashes or potential code execution\.
