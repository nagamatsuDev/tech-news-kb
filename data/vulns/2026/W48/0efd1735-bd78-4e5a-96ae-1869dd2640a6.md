# XML\:\:Sig versions before 0\.74 for Perl allow code execution via a document's Algorithm attribute that verify resolves to a function name \.\.\.

- **ID**: CVE\-2026\-134880
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-24

## 原文

XML\:\:Sig versions before 0\.74 for Perl allow code execution via a document's Algorithm attribute that verify resolves to a function name and calls\.
  
The text after the last \`\#\` in the DigestMethod and SignatureMethod Algorithm attributes is looked up with Digest\:\:SHA\-&gt;can\. That returns a code reference for any fully qualified function name, Perl builtins in the CORE namespace included\. The digest function is called on the canonical form of the referenced element, so the document picks both the function and its argument\.
  
An attacker who can submit a signed document can run a command as the verifying process\.
