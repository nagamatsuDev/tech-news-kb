# The Advanced Product Fields \(Product Addons\) for WooCommerce plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'w\.\.\.

- **ID**: CVE\-2026\-136519
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-26

## 原文

The Advanced Product Fields \(Product Addons\) for WooCommerce plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'wapf\[field\_&lt;id&gt;\]' parameter in all versions up to, and including, 1\.7\.4 due to insufficient input sanitization and output escaping\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\. The payload survives sanitization via a whitespace\-prefixed tag gadget, is normalized into real HTML elements by wp\_kses\_post\(\) and force\_balance\_tags\(\) at render time, and is then executed by WordPress core's tags\-box\.js when it encounters the forged \#tagsdiv\-post\_tag element on the order screen\.
