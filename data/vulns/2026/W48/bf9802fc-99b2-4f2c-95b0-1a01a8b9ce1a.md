# OpenEXR is the reference implementation and specification for the EXR image format, widely used in the motion picture industry\.

- **ID**: CVE\-2026\-133466
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-25

## 原文

OpenEXR is the reference implementation and specification for the EXR image format, widely used in the motion picture industry\. From versions 3\.4\.0 through 3\.4\.18 and 3\.5\.0 through 3\.5\.2, decoding a crafted HT\-compressed EXR chunk can cause ht\_undo\_impl\(\) to write a 4\-byte pixel value through a pointer that is not 4\-byte aligned\. This happens when the channels sum to a bytes\-per\-scanline stride that is not a multiple of four\. This issue is fixed in versions 3\.4\.19 and 3\.5\.3\.
