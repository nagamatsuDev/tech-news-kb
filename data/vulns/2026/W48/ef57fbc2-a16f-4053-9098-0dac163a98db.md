# FFmpeg before 9\.1 contains a heap buffer overflow vulnerability in recv\_msg\(\) of the zmq and azmq filters that allows unauthenticated net\.\.\.

- **ID**: CVE\-2026\-135742
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-24

## 原文

FFmpeg before 9\.1 contains a heap buffer overflow vulnerability in recv\_msg\(\) of the zmq and azmq filters that allows unauthenticated network attackers to corrupt memory by sending oversized command messages\. Attackers can send a 4 GiB message to the default listening port, truncating the int buffer size so memcpy\(\) writes past the heap allocation and crashes FFmpeg\.
