# pyfda through 0\.9\.5 contains an insecure deserialization vulnerability in load\_filter\(\) that allows attackers to execute code by supplyin\.\.\.

- **ID**: CVE\-2026\-137518
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-26

## 原文

pyfda through 0\.9\.5 contains an insecure deserialization vulnerability in load\_filter\(\) that allows attackers to execute code by supplying crafted \.npz or \.pkl filter files\. Attackers can embed a \_\_reduce\_\_ gadget that runs via np\.load with allow\_pickle\=True or pickle\.load before validation, executing code with the user's privileges\.
