# mcp\-server\-kubernetes before 4\.2\.0 contains an argument injection vulnerability that allows remote MCP clients to inject kubectl flags by\.\.\.

- **ID**: CVE\-2026\-134817
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-22

## 原文

mcp\-server\-kubernetes before 4\.2\.0 contains an argument injection vulnerability that allows remote MCP clients to inject kubectl flags by supplying dash\-prefixed values as positional operands in tools such as exec\_in\_pod, kubectl\_patch, and kubectl\_logs\. Attackers connected over SSE or Streamable HTTP transport can supply values like \-\-filename to make kubectl read files from the server host, bypassing file\-read restrictions\.
