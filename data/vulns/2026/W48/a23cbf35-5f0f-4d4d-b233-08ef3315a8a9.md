# FFmpeg 4\.4 before 9\.1 contains a heap out\-of\-bounds read and write vulnerability in libavfilter/vf\_deband\.c that allows attackers to corr\.\.\.

- **ID**: CVE\-2026\-135736
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-24

## 原文

FFmpeg 4\.4 before 9\.1 contains a heap out\-of\-bounds read and write vulnerability in libavfilter/vf\_deband\.c that allows attackers to corrupt heap memory by sending a runtime coupling command\. Attackers can send a 'deband coupling 1' command via sendcmd or an unauthenticated zmq filter, making chroma planes be processed at luma dimensions to crash the process or potentially execute code\.
