# OpenEMR before 8\.3\.0 contains a broken access control and path traversal vulnerability in the fax/sms module disposeDocument action via a\.\.\.

- **ID**: CVE\-2026\-124450
- **危険度**: Critical（緊急） (CVSS 9.9)
- **言語**: PHP
- **公開**: 2026-11-08

## 原文

OpenEMR before 8\.3\.0 contains a broken access control and path traversal vulnerability in the fax/sms module disposeDocument action via an unvalidated file\_path parameter\. Authenticated low\-privilege users can read sqlconf\.php to recover database credentials and write arbitrary files as the web user, enabling remote code execution\.
