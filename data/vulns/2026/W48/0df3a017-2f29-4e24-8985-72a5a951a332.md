# Denial of Service in DefaultPluginManager in Apache JSPWIKI versions prior to the fixed version on all platforms allows an attacker to sp\.\.\.

- **ID**: CVE\-2026\-78102
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-11-25

## 原文

Denial of Service in DefaultPluginManager in Apache JSPWIKI versions prior to the fixed version on all platforms allows an attacker to spawn multiple threads until resource exhaustion or to class load any class on the classpath and creating an instance of it\.  
Users are recommended to upgrade to version 3\.0\.1, which fixes this issue\.
