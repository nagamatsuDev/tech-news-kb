# Nmap before 7\.992 contains a use\-after\-free vulnerability in DNS\:\:ResolverImpl\:\:handle\_write in libnetutil/massdns\.cc that dereferences f\.\.\.

- **ID**: CVE\-2026\-137977
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-27

## 原文

Nmap before 7\.992 contains a use\-after\-free vulnerability in DNS\:\:ResolverImpl\:\:handle\_write in libnetutil/massdns\.cc that dereferences freed request objects after writes complete\. Attackers controlling or on\-path to a DNS server can send timed DNS responses with forged ICMP port\-unreachable messages to crash scans, disclose memory, or hijack execution\.
