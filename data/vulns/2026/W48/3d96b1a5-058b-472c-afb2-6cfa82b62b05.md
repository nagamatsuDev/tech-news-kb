# Detoxify 0\.5\.3 through 0\.5\.4 contains an insecure deserialization vulnerability in load\_checkpoint that allows attackers to execute code \.\.\.

- **ID**: CVE\-2026\-137998
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-27

## 原文

Detoxify 0\.5\.3 through 0\.5\.4 contains an insecure deserialization vulnerability in load\_checkpoint that allows attackers to execute code by supplying a crafted checkpoint file\. Attackers can embed a pickle \_\_reduce\_\_ gadget in a \.ckpt file loaded via torch\.load with weights\_only\=False to run code with the user's privileges\.
