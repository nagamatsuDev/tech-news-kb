# OpenEMR before 8\.3\.0 contains a missing authorization vulnerability in library/ajax/upload\.php that allows any authenticated user to read\.\.\.

- **ID**: CVE\-2026\-124461
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-08

## 原文

OpenEMR before 8\.3\.0 contains a missing authorization vulnerability in library/ajax/upload\.php that allows any authenticated user to read and overwrite document data by supplying an arbitrary doc\_id\. Low\-privilege users can enumerate doc\_id values with the fetch and save actions to disclose patient health information and tamper with medical records across all patients\.
