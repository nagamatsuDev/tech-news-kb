# FFmpeg before 9\.1 contains a heap out\-of\-bounds write vulnerability in the deflicker filter that lets attackers corrupt heap memory via u\.\.\.

- **ID**: CVE\-2026\-135734
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-24

## 原文

FFmpeg before 9\.1 contains a heap out\-of\-bounds write vulnerability in the deflicker filter that lets attackers corrupt heap memory via unclamped high bit depth luma samples\. Attackers can supply crafted video whose luma values exceed the nominal depth, making calc\_avgy16\(\) increment counters past the histogram allocation, causing crashes or possibly code execution\.
