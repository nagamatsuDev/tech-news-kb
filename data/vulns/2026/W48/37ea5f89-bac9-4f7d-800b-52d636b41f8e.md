# rConfig Core 8\.2\.19 before 8\.2\.22 contains a server\-side request forgery vulnerability that allows authenticated users to bypass the Devi\.\.\.

- **ID**: CVE\-2026\-135696
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-24

## 原文

rConfig Core 8\.2\.19 before 8\.2\.22 contains a server\-side request forgery vulnerability that allows authenticated users to bypass the DeviceIpIsValid loopback guard by supplying unresolved hostnames\. Attackers can create a device with a hostname resolving to loopback and device\_port\_override 6379, causing configuration downloads to send Redis inline commands for remote code execution\.
