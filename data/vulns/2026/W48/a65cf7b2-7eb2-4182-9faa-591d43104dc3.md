# Ever Gauzy is an open source business management platform for ERP, CRM, HRM, ATS, and project management\.

- **ID**: CVE\-2026\-135399
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-25

## 原文

Ever Gauzy is an open source business management platform for ERP, CRM, HRM, ATS, and project management\. Prior to 111\.42\.10, RoleGuard authorizes requests using the role claim embedded in an access token instead of the user's current database role in packages/core/src/lib/core/context/request\-context\.ts through RequestContext\.hasRoles\. After an administrator demotes a user, an already\-issued token can continue to pass role checks for up to the token's 24\-hour default lifetime, including on DELETE /api/tenant and other RolesEnum\.SUPER\_ADMIN or ADMIN guarded routes, which can preserve tenant\-destructive and billing privileges after revocation\. This issue is fixed in version 111\.42\.10\.
