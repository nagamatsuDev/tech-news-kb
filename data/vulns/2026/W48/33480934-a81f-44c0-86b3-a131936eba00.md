# paramz through 0\.10\.0 contains an insecure deserialization vulnerability that allows attackers to execute code by supplying crafted model\.\.\.

- **ID**: CVE\-2026\-137060
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-25

## 原文

paramz through 0\.10\.0 contains an insecure deserialization vulnerability that allows attackers to execute code by supplying crafted model files to paramz\.load\(\), which calls pickle\.load\(\) without restrictions\. Attackers can embed objects whose \_\_reduce\_\_ method returns callables like exec or os\.system in shared paramz or GPy model files to run code with the victim's privileges\.
