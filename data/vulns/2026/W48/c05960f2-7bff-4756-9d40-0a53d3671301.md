# smalot/pdfparser before 2\.14\.0 contains an inefficient algorithmic complexity vulnerability that allows remote attackers to cause a denia\.\.\.

- **ID**: CVE\-2026\-134129
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-27

## 原文

smalot/pdfparser before 2\.14\.0 contains an inefficient algorithmic complexity vulnerability that allows remote attackers to cause a denial of service by submitting a crafted PDF with deeply nested unbalanced parentheses in a content\-stream string\. Attackers can exploit the regex\-based string isolation loop in PDFObject\:\:formatContent\(\), which rescans growing content on each pass to produce O\(n\^2\) processing time, causing a small PDF to stall or exhaust PHP worker resources for seconds to minutes\.
