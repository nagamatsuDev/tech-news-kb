# justhtml before 3\.17\.0 contains a denial of service vulnerability in decode\_entities\_in\_text that allows unauthenticated attackers to cra\.\.\.

- **ID**: CVE\-2026\-137513
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-26

## 原文

justhtml before 3\.17\.0 contains a denial of service vulnerability in decode\_entities\_in\_text that allows unauthenticated attackers to crash parsing via non\-ASCII Unicode digits in numeric character references\. Attackers can submit a payload like &amp;\#² in HTML text or attributes, causing an uncaught ValueError from int\(\) that aborts JustHTML\(\) and stream\(\) parsing\.
