# RayLabsHQ gitea\-mirror before 3\.38\.1 contains a server\-side request forgery vulnerability that allows unauthenticated attackers to make t\.\.\.

- **ID**: CVE\-2026\-136177
- **危険度**: High（重要） (CVSS 7.2)
- **公開**: 2026-11-24

## 原文

RayLabsHQ gitea\-mirror before 3\.38\.1 contains a server\-side request forgery vulnerability that allows unauthenticated attackers to make the server send HTTP requests by supplying a url to /api/gitea/test\-connection or /api/github/test\-connection\. Attackers can target internal network services and cloud instance metadata endpoints, reading response content leaked through upstream error messages returned by httpGet\.
