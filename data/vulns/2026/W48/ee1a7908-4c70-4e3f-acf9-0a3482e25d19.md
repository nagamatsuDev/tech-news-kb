# TypiCMS Core before 17\.0\.46 contains an insufficiently protected credentials vulnerability that allows authenticated users with "read use\.\.\.

- **ID**: CVE\-2026\-136159
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-24

## 原文

TypiCMS Core before 17\.0\.46 contains an insufficiently protected credentials vulnerability that allows authenticated users with "read users" permission to view plaintext api\_token values for all users, including superusers, via the GET /api/users endpoint\. Attackers can steal a superuser's non\-expiring, non\-rotatable api\_token from the JSON response and use it to gain full superuser API access, enabling creation and deletion of users, roles, and all content\.
