# In ResolvePendingNotifyRequests of remote\_characteristic\.cc, there is a possible use after free due to a status callback that can destroy\.\.\.

- **ID**: CVE\-2026\-95417
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-23

## 原文

In ResolvePendingNotifyRequests of remote\_characteristic\.cc, there is a possible use after free due to a status callback that can destroy the object while its pending request queue is still being iterated\. This could lead to remote \(proximal/adjacent\) code execution with no additional execution privileges needed\. User interaction is not needed for exploitation\.
