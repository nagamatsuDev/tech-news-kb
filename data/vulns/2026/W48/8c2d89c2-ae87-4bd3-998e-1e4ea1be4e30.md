# c\-icap\-server through 0\.5\.15 and 0\.6\.5 contains an out\-of\-bounds write in process\_encapsulated\(\) that allows unauthenticated attackers to\.\.\.

- **ID**: CVE\-2026\-136126
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-24

## 原文

c\-icap\-server through 0\.5\.15 and 0\.6\.5 contains an out\-of\-bounds write in process\_encapsulated\(\) that allows unauthenticated attackers to corrupt heap memory by sending six Encapsulated entities\. Attackers can send a single ICAP request whose sixth entity overwrites trash\_entities\[0\], triggering use\-after\-free and double free in ci\_request\_destroy\(\) during teardown\.
