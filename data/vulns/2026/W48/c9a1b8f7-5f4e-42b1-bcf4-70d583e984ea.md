# A weakness has been identified in DumbWareio DumbAssets up to 1\.0\.11\.

- **ID**: CVE\-2026\-134789
- **危険度**: High（重要） (CVSS 7.3)
- **公開**: 2026-11-23

## 原文

A weakness has been identified in DumbWareio DumbAssets up to 1\.0\.11\. Affected by this vulnerability is an unknown functionality of the file server\.js of the component Settings API\. Executing a manipulation of the argument appriseUrl can lead to dynamically\-determined object attributes\. The attack can be executed remotely\. The vendor was contacted early about this disclosure but did not respond in any way\.
