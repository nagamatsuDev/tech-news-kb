# In BrEdrSignalingChannel\:\:DecodeRxUnit of bredr\_signaling\_channel\.cc, there is a possible use after free due to a missing object lifetime\.\.\.

- **ID**: CVE\-2026\-95421
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-23

## 原文

In BrEdrSignalingChannel\:\:DecodeRxUnit of bredr\_signaling\_channel\.cc, there is a possible use after free due to a missing object lifetime check in a command processing loop\. This could lead to remote \(proximal/adjacent\) code execution with no additional execution privileges needed\. User interaction is not needed for exploitation\.
