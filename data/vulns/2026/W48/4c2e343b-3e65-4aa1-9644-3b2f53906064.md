# Webmin through 2\.670 contains a cleartext transmission vulnerability in web\-lib\-funcs\.pl and fastrpc\.cgi that sends cluster RPC traffic o\.\.\.

- **ID**: CVE\-2026\-134647
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-25

## 原文

Webmin through 2\.670 contains a cleartext transmission vulnerability in web\-lib\-funcs\.pl and fastrpc\.cgi that sends cluster RPC traffic over raw TCP despite SSL configuration\. Network\-positioned attackers can read the session ID and remote\_eval payloads or alter calls in transit to execute code as root on managed servers\.
