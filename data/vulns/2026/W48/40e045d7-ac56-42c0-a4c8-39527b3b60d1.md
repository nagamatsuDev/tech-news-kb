# FreeRDP from 3\.10\.0 before 3\.33\.0 contains an invalid free vulnerability in rdg\.c because the websocket context pointer shares a union wi\.\.\.

- **ID**: CVE\-2026\-137460
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-26

## 原文

FreeRDP from 3\.10\.0 before 3\.33\.0 contains an invalid free vulnerability in rdg\.c because the websocket context pointer shares a union with chunked transfer\-encoding decoder state\. A malicious RD Gateway answering the data channel with chunked encoding can control the overwritten pointer via chunk sizes, causing rdg\_free to free an attacker\-influenced value and crash the client\.
