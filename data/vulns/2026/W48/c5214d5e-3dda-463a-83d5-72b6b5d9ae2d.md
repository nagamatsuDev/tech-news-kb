# The PDF Invoices &amp; Packing Slips for WooCommerce plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'billing\_addre\.\.\.

- **ID**: CVE\-2026\-130321
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-26

## 原文

The PDF Invoices &amp; Packing Slips for WooCommerce plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'billing\_address\.first\_name / company / address\_1 / address\_2 / city' parameter in all versions up to, and including, 6\.0\.0 due to insufficient input sanitization and output escaping\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\. This requires the E\-Documents feature to be enabled with a UBL PEPPOL BIS 3\.0 format, as that setting is disabled by default and controls whether the vulnerable meta box is registered and rendered\.
