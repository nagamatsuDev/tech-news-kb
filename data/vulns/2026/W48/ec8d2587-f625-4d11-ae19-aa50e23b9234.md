# HyperSpy from 1\.2\.0 before 2\.6\.0 contains a code execution vulnerability that allows attackers to run Python code by embedding malicious \.\.\.

- **ID**: CVE\-2026\-138117
- **危険度**: High（重要） (CVSS 7.8)
- **言語**: Python
- **公開**: 2026-11-28

## 原文

HyperSpy from 1\.2\.0 before 2\.6\.0 contains a code execution vulnerability that allows attackers to run Python code by embedding malicious expression strings evaluated with sympy\.sympify\(\)\. Attackers can craft \.hspy or \.zspy files with malicious axis, Expression component, or twin function expressions that execute when victims call hs\.load\(\) or restore models\.
