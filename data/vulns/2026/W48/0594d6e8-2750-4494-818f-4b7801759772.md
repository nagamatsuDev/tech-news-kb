# Ghostscript before 10\.08\.0 contains a \-dSAFER bypass vulnerability in the \.putgstringcopy procedure in gs\_fonts\.ps, which calls the privi\.\.\.

- **ID**: CVE\-2026\-125396
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-10

## 原文

Ghostscript before 10\.08\.0 contains a \-dSAFER bypass vulnerability in the \.putgstringcopy procedure in gs\_fonts\.ps, which calls the privileged \.forceput operator without checking operand types\. Attackers can supply crafted PostScript or PDF documents that trigger a type error, recover \.forceput via a custom error handler, and cause a use\-after\-free across save/restore to execute arbitrary code\.
