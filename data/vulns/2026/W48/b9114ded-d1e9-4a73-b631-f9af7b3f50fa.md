# A security flaw has been discovered in Tencent RapidJSON up to 1\.1\.0\.

- **ID**: CVE\-2026\-137415
- **危険度**: High（重要） (CVSS 7.3)
- **公開**: 2026-11-26

## 原文

A security flaw has been discovered in Tencent RapidJSON up to 1\.1\.0\. This affects the function Writer\:\:WriteString in the library include/rapidjson/writer\.h\. Performing a manipulation of the argument length results in integer overflow\. The attack may be initiated remotely\. The patch is named 297637bc0a0f00dc504dbc1a47ebdaa577f8ae19\. To fix this issue, it is recommended to deploy a patch\.
