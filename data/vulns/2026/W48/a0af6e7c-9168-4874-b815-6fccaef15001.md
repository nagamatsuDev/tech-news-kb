# OpenEMR before 8\.4\.0 contains a mass assignment vulnerability in the patient portal OnsiteDocument query API that lets request parameters\.\.\.

- **ID**: CVE\-2026\-124444
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-08

## 原文

OpenEMR before 8\.4\.0 contains a mass assignment vulnerability in the patient portal OnsiteDocument query API that lets request parameters set bitwise criteria filters whose values are placed unquoted into the SQL WHERE clause\. Authenticated patient portal users can inject SQL via parameters such as Id\_BitwiseAnd to read any database table, including other patients' records and staff password hashes\.
