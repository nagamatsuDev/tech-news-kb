# Server\-Side Request Forgery \(SSRF\) vulnerability in ex\_aws \(instance metadata token provider\)\.

- **ID**: CVE\-2026\-59697
- **危険度**: High（重要） (CVSS 7.6)
- **公開**: 2026-11-24

## 原文

Server\-Side Request Forgery \(SSRF\) vulnerability in ex\_aws \(instance metadata token provider\)\.
  
This vulnerability is associated with program files lib/ex\_aws/instance\_meta\_token\_provider\.ex and program routines ExAws\.InstanceMetaTokenProvider\.request\_token/1 and ExAws\.InstanceMetaTokenProvider\.get/1\.
  
ex\_aws requests its IMDSv2 session token from the link\-local metadata endpoint \(http\://169\.254\.169\.254/latest/api/token\) with HTTP redirect following enabled\. Because the token request follows 3xx redirects and does not restrict the redirect target to the link\-local range, an attacker who can influence the response to the metadata request \(for example an on\-segment neighbor spoofing the link\-local address\) can answer with a redirect to an arbitrary host\. The library follows the redirect and accepts the arbitrary host's response body as the IMDSv2 session token, caching it and sending it as the x\-aws\-ec2\-metadata\-token header on every subsequent metadata and credential request\.
  
This issue affects ex\_aws\: from 2\.3\.0 before 2\.8\.0\.
