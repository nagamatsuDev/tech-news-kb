# The W3 Total Cache plugin for WordPress is vulnerable to PHP Object Injection in all versions up to, and including, 2\.11\.0 via deserializ\.\.\.

- **ID**: CVE\-2026\-135616
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-27

## 原文

The W3 Total Cache plugin for WordPress is vulnerable to PHP Object Injection in all versions up to, and including, 2\.11\.0 via deserialization of untrusted input that is injected into the Memcached object cache through request Host header key truncation\. This allows authenticated attackers, with subscriber\-level access and above, to inject a PHP Object\. The additional presence of a POP chain \(the bundled Guzzle FileCookieJar, reached through the W3TC\\CdnEngine\_S3 autoload bridge\) allows attackers to write arbitrary files and execute code\. This requires the Object Cache to be enabled with the Memcached method backed by the pecl memcache extension and Minify to be enabled; using the same key collision, the attacker first escalates from Subscriber to Administrator\.
