# FFmpeg before 9\.1 contains a heap buffer overflow vulnerability in modplug\_read\_header\(\) in libavformat/libmodplug\.c that allocates the b\.\.\.

- **ID**: CVE\-2026\-135706
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-24

## 原文

FFmpeg before 9\.1 contains a heap buffer overflow vulnerability in modplug\_read\_header\(\) in libavformat/libmodplug\.c that allocates the buffer using max\_size instead of sz\. When max\_size is set to 0, attackers can supply crafted module files that avio\_read\(\) copies into a zero\-sized buffer, causing memory corruption, crashes, or possible code execution\.
