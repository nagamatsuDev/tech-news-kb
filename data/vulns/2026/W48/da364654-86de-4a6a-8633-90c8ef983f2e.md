# edbrowse through 3\.8\.19 contains an integer overflow in stringAndBytes\(\) that allows malicious servers to write past a heap buffer by sen\.\.\.

- **ID**: CVE\-2026\-138159
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-28

## 原文

edbrowse through 3\.8\.19 contains an integer overflow in stringAndBytes\(\) that allows malicious servers to write past a heap buffer by sending response bodies larger than 2 GB\. When a user browses to an attacker\-controlled HTTP, FTP, or gopher server, the oversized body skips reallocation and corrupts the heap, causing crashes or potentially code execution\.
