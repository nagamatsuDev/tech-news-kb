# FFmpeg before 9\.1 contains a heap out\-of\-bounds write vulnerability in libavfilter/vf\_readeia608\.c because build\_histogram\(\) does not cla\.\.\.

- **ID**: CVE\-2026\-135740
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-24

## 原文

FFmpeg before 9\.1 contains a heap out\-of\-bounds write vulnerability in libavfilter/vf\_readeia608\.c because build\_histogram\(\) does not clamp high bit depth luma samples to the nominal maximum\. Attackers can supply crafted 9, 10, 12 or 14 bit gray or YUV video to corrupt heap memory, causing crashes or possibly code execution\.
