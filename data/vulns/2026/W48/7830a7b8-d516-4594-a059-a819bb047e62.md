# Trilium through 0\.107\.0 contains an sql injection vulnerability in updateNormalEntity\(\) that allows malicious sync partners to inject SQL\.\.\.

- **ID**: CVE\-2026\-135686
- **危険度**: High（重要） (CVSS 7.4)
- **公開**: 2026-11-24

## 原文

Trilium through 0\.107\.0 contains an sql injection vulnerability in updateNormalEntity\(\) that allows malicious sync partners to inject SQL by supplying crafted entity names and column keys\. Attackers can abuse /api/sync/changed or PUT /api/sync/update data to copy sessions, etapi\_tokens and user\_data into synced rows and write arbitrary database rows\.
