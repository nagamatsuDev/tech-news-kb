# The WordPress File Upload plugin for WordPress is vulnerable to Arbitrary File Deletion in versions up to, and including, 5\.3\.1 via the '\.\.\.

- **ID**: CVE\-2026\-134173
- **危険度**: Critical（緊急） (CVSS 9.1)
- **言語**: PHP
- **公開**: 2026-11-26

## 原文

The WordPress File Upload plugin for WordPress is vulnerable to Arbitrary File Deletion in versions up to, and including, 5\.3\.1 via the 'wfu\_ajax\_action\_handshake' and 'wfu\_ajax\_action\_send\_email\_notification' AJAX Actions\. This is due to the unauthenticated handshake accepting a 'sid' parameter sanitized only with sanitize\_text\_field\(\), which does not strip '\[', '\]', '\{', or '\}', allowing the sid to be crafted as an item name containing embedded delimiter pairs that plant forged records for arbitrary other item names — including the per\-session file path list and the consent flag — in the plugin's shared concatenated user\-state option store, combined with the notification handler being gated only by a nonce freely minted by the same nopriv handshake\. This makes it possible for unauthenticated attackers to delete arbitrary files on the affected site's server which may make remote code execution possible\.
