# A vulnerability was identified in Tenda RX3 16\.03\.13\.11\.

- **ID**: CVE\-2026\-136548
- **危険度**: Critical（緊急） (CVSS 10.0)
- **公開**: 2026-11-25

## 原文

A vulnerability was identified in Tenda RX3 16\.03\.13\.11\. The affected element is an unknown function of the file /bin/auto\_discover of the component GBK\-to\-UTF\-8 Conversion\. The manipulation of the argument Hostname leads to stack\-based buffer overflow\. Remote exploitation of the attack is possible\. The exploit is publicly available and might be used\.
