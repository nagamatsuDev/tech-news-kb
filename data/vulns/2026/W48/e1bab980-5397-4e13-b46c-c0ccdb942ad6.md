# Gammu before 1\.45\.2 contains a buffer overflow vulnerability in LoadBackup\(\) that allows attackers to corrupt memory by supplying an over\.\.\.

- **ID**: CVE\-2026\-138161
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-28

## 原文

Gammu before 1\.45\.2 contains a buffer overflow vulnerability in LoadBackup\(\) that allows attackers to corrupt memory by supplying an overlong MD5 value in a crafted backup file\. Attackers can overwrite adjacent phonebook and calendar entry pointers via strcpy\(\) into MD5Original when files are loaded with convertbackup or restore, causing crashes or potential code execution\.
