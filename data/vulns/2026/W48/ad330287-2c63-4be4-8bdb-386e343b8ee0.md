# A vulnerability was identified in dayrui XunRuiCMS up to 4\.7\.4\.

- **ID**: CVE\-2026\-136692
- **危険度**: High（重要） (CVSS 7.3)
- **言語**: PHP
- **公開**: 2026-11-25

## 原文

A vulnerability was identified in dayrui XunRuiCMS up to 4\.7\.4\. The impacted element is the function down of the file dayrui/Fcms/Library/Api\.php of the component Attachment Download API\. Such manipulation of the argument ID leads to unrestricted upload\. The attack may be performed from remote\. The exploit is publicly available and might be used\. The vendor was contacted early about this disclosure but did not respond in any way\.
