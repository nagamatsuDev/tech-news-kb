# Jenkins Warnings Plugin 13\.10251\.va\_452d3553728 through 13\.10365\.v85cd7a\_c8110b\_ \(both inclusive\) allows defining inline Groovy parsers w\.\.\.

- **ID**: CVE\-2026\-136837
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-25

## 原文

Jenkins Warnings Plugin 13\.10251\.va\_452d3553728 through 13\.10365\.v85cd7a\_c8110b\_ \(both inclusive\) allows defining inline Groovy parsers whose Groovy scripts are compiled on the Jenkins controller without sandbox protection, allowing attackers able to define inline Groovy parsers to execute arbitrary code in the context of the Jenkins controller JVM\.
