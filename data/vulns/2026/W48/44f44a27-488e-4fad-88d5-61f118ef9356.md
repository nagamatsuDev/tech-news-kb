# Bagel \(bagel\-mcp\) before 2\.5\.5 exposes unsandboxed DuckDB SQL execution through the read\-only annotated query\_messages MCP tool, allowing\.\.\.

- **ID**: CVE\-2026\-138027
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-27

## 原文

Bagel \(bagel\-mcp\) before 2\.5\.5 exposes unsandboxed DuckDB SQL execution through the read\-only annotated query\_messages MCP tool, allowing file access and network requests\. Attackers who prompt\-inject the driving LLM via recorded logs or topics can invoke read\_csv\_auto, COPY TO, or httpfs to read and write files and perform server\-side request forgery\.
