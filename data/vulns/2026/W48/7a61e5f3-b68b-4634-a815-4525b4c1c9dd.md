# Dell Virtual Storage Integrator for VMware vSphere Web Client, versions prior to 10\.12\.0\.0, contains a Use of Hard\-coded Credentials vuln\.\.\.

- **ID**: CVE\-2026\-82168
- **危険度**: High（重要） (CVSS 7.7)
- **公開**: 2026-11-24

## 原文

Dell Virtual Storage Integrator for VMware vSphere Web Client, versions prior to 10\.12\.0\.0, contains a Use of Hard\-coded Credentials vulnerability in ssl\_config\.properties\. An unauthenticated local attacker could potentially exploit this vulnerability, leading to credential exposure\.
