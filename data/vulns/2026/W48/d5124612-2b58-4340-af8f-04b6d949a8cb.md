# HyperSpy from 1\.4\.0 before 2\.6\.0 contains an insecure deserialization vulnerability that allows attackers to execute arbitrary Python cod\.\.\.

- **ID**: CVE\-2026\-138118
- **危険度**: High（重要） (CVSS 7.8)
- **言語**: Python
- **公開**: 2026-11-28

## 原文

HyperSpy from 1\.4\.0 before 2\.6\.0 contains an insecure deserialization vulnerability that allows attackers to execute arbitrary Python code by supplying crafted stored\-model data in \.hspy or \.zspy files\. Attackers can embed a malicious pickle payload in a component's \_class\_dump or a 'fn'\-flagged \_whitelist entry, which cloudpickle\.loads\(\) \(dill in 1\.x\) runs when the victim restores the model\.
