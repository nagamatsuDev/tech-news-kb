# Hermes Agent is an open\-source autonomous AI agent built by Nous Research for running tool\-using workflows across CLI, desktop, and messa\.\.\.

- **ID**: CVE\-2026\-130164
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-23

## 原文

Hermes Agent is an open\-source autonomous AI agent built by Nous Research for running tool\-using workflows across CLI, desktop, and messaging interfaces\. From 0\.21\.6 to 0\.23\.1, when Bot Desktop is hosted inside a non\-local terminal backend, the agent process reads a backend\-writable screen environment file without validating keys or values and merges its entries into the environment of processes started on the agent machine\. Specifically, when terminal\.backend is set to docker or ssh \(or a plugin backend declaring supports\_streams\) with placement auto or terminal, \_published\(\) in tools/bot\_desktop/sandbox\_host\.py accepts arbitrary KEY\=VALUE lines from the hermes\-bot\-desktop env file and propagates them via tools/bot\_desktop/runtime\.py into the browser harness, computer\-use helpers, and local terminal children\. Code running inside the terminal backend can therefore set variables such as LD\_PRELOAD, DYLD\_INSERT\_LIBRARIES, or PATH and gain code execution on the agent machine as the gateway user upon a subsequent browser or computer\-use spawn, exposing credentials, tokens, and session history under the Hermes home directory\. The default local backend, backends that cannot host a screen \(Modal, Daytona, and Vercel\), and Hermes Cloud in its default configuration are not affected\. This issue is fixed in version 0\.23\.2\.
