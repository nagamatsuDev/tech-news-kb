# Webmin through 2\.670 contains a path traversal vulnerability in minecraft/minecraft\-lib\.pl that allows unauthenticated game players to ov\.\.\.

- **ID**: CVE\-2026\-134644
- **危険度**: High（重要） (CVSS 7.4)
- **公開**: 2026-11-25

## 原文

Webmin through 2\.670 contains a path traversal vulnerability in minecraft/minecraft\-lib\.pl that allows unauthenticated game players to overwrite arbitrary files as root via crafted chat messages\. Attackers can send chat messages mimicking logged in lines so the root check\_playtime\_limits cron job rewrites attacker\-chosen files, destroying their contents\.
