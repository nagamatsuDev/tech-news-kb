# LaraDashboard before 1\.5\.2 contains a server\-side request forgery vulnerability that allows authenticated users to reach internal service\.\.\.

- **ID**: CVE\-2026\-137543
- **危険度**: High（重要） (CVSS 7.7)
- **公開**: 2026-11-26

## 原文

LaraDashboard before 1\.5\.2 contains a server\-side request forgery vulnerability that allows authenticated users to reach internal services by abusing the unvalidated ai\_ollama\_base\_url setting\. Once a settings\.edit user points the Ollama base URL internally, any post\.create user can call /admin/ai/generate\-seo with provider\=ollama to fetch internal data reflected in SEO fields\.
