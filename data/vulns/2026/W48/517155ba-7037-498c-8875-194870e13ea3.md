# The AI Engine – MCP Server &amp; AI Chatbot for WordPress, with Claude, ChatGPT &amp; Gemini plugin for WordPress is vulnerable to Limited Arbitr\.\.\.

- **ID**: CVE\-2026\-131589
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: JavaScript/TypeScript, PHP
- **公開**: 2026-11-26

## 原文

The AI Engine – MCP Server &amp; AI Chatbot for WordPress, with Claude, ChatGPT &amp; Gemini plugin for WordPress is vulnerable to Limited Arbitrary File Upload in all versions up to, and including, 3\.9\.4 via the \`url\` parameter of the \`/mwai/v1/helpers/create\_image\` REST API endpoint\. The vulnerability exists because the \`add\_image\_from\_url\(\)\` function applies the \`get\_allowed\_mime\_types\(\)\` extension allow\-list only on the custom\-filename branch; when the request omits a \`filename\` value, the empty\-filename branch derives the stored file's extension directly from the URL basename via \`sanitize\_file\_name\(\)\` without any MIME or extension validation, then writes the downloaded response body verbatim to the WordPress uploads directory via \`file\_put\_contents\(\)\`\. This makes it possible for authenticated attackers with Editor\-level access and above to place attacker\-controlled HTML, SVG, or JavaScript files into \`wp\-content/uploads/YYYY/MM/\` under an attacker\-chosen extension, enabling stored cross\-site scripting against any administrator who opens the resulting attachment URL\. The download routine accepts any HTTP response whose \`Content\-Type\` header begins with \`image/\`, a value freely controlled by the attacker\-owned origin server, meaning the written content need not be a valid image\.
