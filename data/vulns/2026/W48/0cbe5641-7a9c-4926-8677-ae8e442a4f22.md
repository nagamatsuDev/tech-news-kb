# An use of hard\-coded cryptographic key vulnerability has been reported to affect Hybrid Backup Sync\.

- **ID**: CVE\-2025\-62841
- **危険度**: High（重要） (CVSS 8.7)
- **公開**: 2026-10-29

## 原文

An use of hard\-coded cryptographic key vulnerability has been reported to affect Hybrid Backup Sync\. If exploited, the vulnerability could allow remote attackers to compromise the security of the system\.
  
We have already fixed the vulnerability in the following version\:  
Hybrid Backup Sync 26\.4\.0\.521 and later  
Hybrid Backup Sync 26\.4\.1\.563 and later
