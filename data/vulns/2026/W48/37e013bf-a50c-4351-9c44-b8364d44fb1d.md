# A flaw was found in libslirp in icmp\_forward\_error\(\)\.

- **ID**: CVE\-2026\-120830
- **危険度**: High（重要） (CVSS 7.4)
- **公開**: 2026-11-03

## 原文

A flaw was found in libslirp in icmp\_forward\_error\(\)\. When building an ICMP error response, the length of the quoted original IPv4 packet was taken from the IP header without clamping it to the actual buffer length\. A truncated or malformed packet could cause an out\-of\-bounds heap read, leaking host memory into the ICMP error packet returned to a guest or container\.
