# Ettercap before 0\.8\.5\.1 contains a use\-after\-free vulnerability in func\_pcre\(\) in src/ec\_filter\.c that reads the PCRE2 ovector after free\.\.\.

- **ID**: CVE\-2026\-125400
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-10

## 原文

Ettercap before 0\.8\.5\.1 contains a use\-after\-free vulnerability in func\_pcre\(\) in src/ec\_filter\.c that reads the PCRE2 ovector after freeing match data\. Network\-adjacent attackers can send packets matching a loaded pcre\_regex\(\) substitution filter to corrupt memory and potentially execute code as root\.
