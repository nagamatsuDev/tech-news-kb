# The FreeRDP proxy in FreeRDP before 3\.33\.0 dereferences a NULL backend client context in pf\_server\_refresh\_rect and pf\_server\_suppress\_ou\.\.\.

- **ID**: CVE\-2026\-137455
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-26

## 原文

The FreeRDP proxy in FreeRDP before 3\.33\.0 dereferences a NULL backend client context in pf\_server\_refresh\_rect and pf\_server\_suppress\_output, which are guarded only by a debug\-only WINPR\_ASSERT, when a REFRESH\_RECT or SUPPRESS\_OUTPUT data PDU arrives before connection activation\. An unauthenticated remote client that completes licensing without sending Confirm Active can crash the proxy process, terminating all hosted sessions\.
