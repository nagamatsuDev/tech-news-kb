# Gammu before 1\.45\.2 contains a stack\-based buffer overflow vulnerability in ALCATEL\_EncodeString\(\) that allows attackers to overwrite sta\.\.\.

- **ID**: CVE\-2026\-138162
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-28

## 原文

Gammu before 1\.45\.2 contains a stack\-based buffer overflow vulnerability in ALCATEL\_EncodeString\(\) that allows attackers to overwrite stack memory via oversized encoded phonebook text\. Attackers can supply a crafted backup restored with gammu restore or addnew to an attached Alcatel phone, using GSM extension characters to crash Gammu or potentially execute code\.
