# SolarWinds Serv\-U is affected by an Insecure Direct Object Reference \(IDOR\) vulnerability that allows a domain group administrator to byp\.\.\.

- **ID**: CVE\-2026\-82322
- **危険度**: Critical（緊急） (CVSS 9.1)
- **OS**: Windows
- **公開**: 2026-11-24
