# ToolJet before 3\.21\.96\-LTS contains an insufficient session expiration vulnerability that allows attackers to reuse expired JWTs because \.\.\.

- **ID**: CVE\-2026\-137538
- **危険度**: High（重要） (CVSS 7.3)
- **公開**: 2026-11-26

## 原文

ToolJet before 3\.21\.96\-LTS contains an insufficient session expiration vulnerability that allows attackers to reuse expired JWTs because the passport\-jwt strategy sets ignoreExpiration to true\. Attackers holding a leaked tj\_auth\_token can keep sessions alive through auto\-extended expiry and two\-year cookies to persistently access victim accounts\.
