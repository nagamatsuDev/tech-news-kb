# A security vulnerability has been detected in TOTOLINK N350RT 9\.3\.5u\.6468\_B20250827/9\.3\.5u\.6466\_B20250825\.

- **ID**: CVE\-2026\-137043
- **危険度**: Critical（緊急） (CVSS 10.0)
- **公開**: 2026-11-26

## 原文

A security vulnerability has been detected in TOTOLINK N350RT 9\.3\.5u\.6468\_B20250827/9\.3\.5u\.6466\_B20250825\. The affected element is the function setLanguageCfg of the file /cgi\-bin/cstecgi\.cgi\. Such manipulation of the argument lang leads to authorization bypass\. The attack can be executed remotely\. The exploit has been disclosed publicly and may be used\.
