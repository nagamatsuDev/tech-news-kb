# @waline/client vulnerable to stored XSS through unsanitized comment edit previews

- **ID**: CVE\-2026\-64670 / GHSA\-crj3\-q72p\-ggqm
- **危険度**: Critical（緊急） (CVSS 9.3)
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/@waline/client &lt;\= 3\.16\.2
- **公開**: 2026-11-25

## 原文

\#\#\# Summary \`@waline/client\` renders the comment editor's live preview with \`marked\` and no sanitizer \(\`utils/markdown\.ts\`\), and the preview is injected with \`v\-html\`\. When a comment is edited, the editor is seeded with the comment's raw, un\-sanitized body \(\`orig\`\)\. Only administrators and the comment owner can edit\.
