# The Nexter Extension – Security, Performance, Code Snippets &amp; Site Toolkit plugin for WordPress is vulnerable to Stored Cross\-Site Script\.\.\.

- **ID**: CVE\-2026\-136459
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-26

## 原文

The Nexter Extension – Security, Performance, Code Snippets &amp; Site Toolkit plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'comment' parameter in all versions up to, and including, 4\.9\.1 due to insufficient input sanitization and output escaping\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\. This requires the site administrator to have enabled the plugin's SEO module \(available via a persistent admin notice\), after which the nofollow\_comments option is on by default; with comments open, a single unauthenticated POST to wp\-comments\-post\.php is sufficient to plant the payload\.
