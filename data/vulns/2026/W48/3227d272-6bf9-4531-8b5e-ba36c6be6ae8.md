# openIMIS before 2026\-10 contains an information disclosure vulnerability in the core export mixin \(openimis\-be\-core\_py, core/gql/export\_m\.\.\.

- **ID**: CVE\-2026\-82491
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: Python
- **公開**: 2026-11-25

## 原文

openIMIS before 2026\-10 contains an information disclosure vulnerability in the core export mixin \(openimis\-be\-core\_py, core/gql/export\_mixin\.py\) that allows authenticated users with a single ordinary read right to traverse arbitrary foreign key relations by supplying caller\-controlled dotted field paths that are rewritten into Django ORM syntax without an allow\-list\. Attackers can exploit this to export another user's JWT signing key via a path such as user\_created\.i\_user\.private\_key, enabling them to forge valid authenticated sessions for other accounts, including administrators, without detection through failed\-login events or invalidation by password reset\.
