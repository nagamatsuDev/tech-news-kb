# A vulnerability was identified in Volans NGFW Next\-Generation Firewall r5\.1\.

- **ID**: CVE\-2026\-135797
- **危険度**: Critical（緊急） (CVSS 10.0)
- **言語**: PHP
- **公開**: 2026-11-24

## 原文

A vulnerability was identified in Volans NGFW Next\-Generation Firewall r5\.1\. Impacted is the function exec of the file sslvpn/sslvpn\_client\.php of the component SSLVPN Client\. Such manipulation of the argument img leads to os command injection\. The attack can be executed remotely\. The exploit is publicly available and might be used\. The vendor was contacted early about this disclosure but did not respond in any way\.
