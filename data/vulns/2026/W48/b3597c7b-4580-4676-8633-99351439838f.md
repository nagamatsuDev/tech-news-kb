# Iceburg CRM through 5\.0\.0 contains an authorization bypass vulnerability that allows authenticated low\-privileged users to modify any use\.\.\.

- **ID**: CVE\-2026\-137577
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-26

## 原文

Iceburg CRM through 5\.0\.0 contains an authorization bypass vulnerability that allows authenticated low\-privileged users to modify any user record by supplying arbitrary record\_id values to POST /data/save\. Attackers can submit a save request for the ice\_users module with the administrator's record\_id to change their password or email and take over the account\.
