# Pelican 4\.12\.0 contains an OS command injection vulnerability in pelican\-import\.

- **ID**: CVE\-2026\-122090
- **危険度**: High（重要） (CVSS 8.4)
- **言語**: PHP
- **公開**: 2026-11-23

## 原文

Pelican 4\.12\.0 contains an OS command injection vulnerability in pelican\-import\. An attacker\-controlled wp\:post\_name from a WordPress XML export is used in an output filename that is interpolated into a Pandoc command passed to subprocess\.call with shell\=True\. On POSIX systems, command substitution in the slug is evaluated when a user imports the crafted export\.
