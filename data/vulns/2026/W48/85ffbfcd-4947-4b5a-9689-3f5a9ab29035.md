# Dreamweaver Desktop is affected by a Dependency on Vulnerable Third\-Party Component vulnerability that could result in arbitrary code exe\.\.\.

- **ID**: CVE\-2026\-132876
- **危険度**: High（重要） (CVSS 7.7)
- **公開**: 2026-11-27

## 原文

Dreamweaver Desktop is affected by a Dependency on Vulnerable Third\-Party Component vulnerability that could result in arbitrary code execution in the context of the current user\. An attacker could exploit this vulnerability to execute arbitrary code\. Exploitation depends on conditions beyond the attacker's control and requires user interaction in that a victim must open a malicious file\. Scope is changed\.
