# The PDF Invoice for WooCommerce \+ Drag and Drop Template Builder plugin for WordPress is vulnerable to PHP Object Injection in all versio\.\.\.

- **ID**: CVE\-2026\-136240
- **危険度**: Critical（緊急） (CVSS 9.1)
- **言語**: PHP
- **公開**: 2026-11-26

## 原文

The PDF Invoice for WooCommerce \+ Drag and Drop Template Builder plugin for WordPress is vulnerable to PHP Object Injection in all versions up to, and including, 7\.2\.0 via deserialization of untrusted input \. This makes it possible for unauthenticated attackers to inject a PHP Object\. No known POP chain is present in the vulnerable software, which means this vulnerability has no impact unless another plugin or theme containing a POP chain is installed on the site\. If a POP chain is present via an additional plugin or theme installed on the target system, it may allow the attacker to perform actions like delete arbitrary files, retrieve sensitive data, or execute code depending on the POP chain present\. The incomplete remediation in version 7\.2\.0 applied escape\_pdf\_note\(\) only to the customer\_note path; the billing address path at woocommerce/shortcodes\.php\:975–978 remains unpatched, and exploitation requires guest checkout to be enabled along with a payment method that transitions orders to on\-hold status \(such as the stock WooCommerce Direct Bank Transfer option\)\.
