# WPC Linked Variation plugin for WordPress, all versions before 4\.6\.1, contain a stored cross\-site scripting vulnerability that allows aut\.\.\.

- **ID**: CVE\-2026\-136128
- **危険度**: High（重要） (CVSS 8.7)
- **言語**: JavaScript/TypeScript, PHP
- **公開**: 2026-11-24

## 原文

WPC Linked Variation plugin for WordPress, all versions before 4\.6\.1, contain a stored cross\-site scripting vulnerability that allows authenticated attackers with Contributor\-level access to inject arbitrary HTML attributes by submitting an unvalidated wpclv\_link\[source\] value that is echoed into an attribute\-name position within a select element on the edit screen\. Attackers can craft a source value containing onfocus and autofocus attributes to execute arbitrary JavaScript in the wp\-admin session of an administrator or editor who views the edit screen, enabling privilege escalation from Contributor to Administrator with no user interaction required\.
