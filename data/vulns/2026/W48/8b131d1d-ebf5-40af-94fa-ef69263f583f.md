# A weakness has been identified in Tenda RX3 16\.03\.13\.11\_multi\.

- **ID**: CVE\-2026\-136550
- **危険度**: Critical（緊急） (CVSS 9.1)
- **公開**: 2026-11-25

## 原文

A weakness has been identified in Tenda RX3 16\.03\.13\.11\_multi\. This affects the function fromAdvSetMacMtuWan of the file /goform/AdvSetMacMtuWan\. This manipulation of the argument mac causes command injection\. The attack is possible to be carried out remotely\. The exploit has been made available to the public and could be used for attacks\.
