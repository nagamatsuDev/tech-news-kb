# FFmpeg through 9\.0\.2 contains an integer overflow vulnerability in ff\_prores\_kostya\_encode\_init\(\) that miscalculates frame\_size\_upper\_bou\.\.\.

- **ID**: CVE\-2026\-125259
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-09

## 原文

FFmpeg through 9\.0\.2 contains an integer overflow vulnerability in ff\_prores\_kostya\_encode\_init\(\) that miscalculates frame\_size\_upper\_bound using 32\-bit arithmetic for large frame dimensions\. Attackers can supply a high\-resolution video transcoded with the prores\_ks encoder, causing encode\_frame\(\) to write slices past an undersized packet buffer and corrupt heap memory\.
