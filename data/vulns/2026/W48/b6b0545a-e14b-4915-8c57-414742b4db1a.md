# bigcommerce\-api\-mcp before 1\.0\.1 contains a missing authentication vulnerability that allows remote unauthenticated attackers to invoke M\.\.\.

- **ID**: CVE\-2026\-138034
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-27

## 原文

bigcommerce\-api\-mcp before 1\.0\.1 contains a missing authentication vulnerability that allows remote unauthenticated attackers to invoke MCP tools because the /sse and /messages routes skip the authenticateRequest middleware\. Attackers can open /sse to obtain a session id and POST JSON\-RPC tool calls to /messages to retrieve store product, order and customer records using the operator's BigCommerce API key\.
