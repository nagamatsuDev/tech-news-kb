# A flaw has been found in Panabit Smart Application Gateway TANGr7p10\.

- **ID**: CVE\-2026\-135791
- **危険度**: Critical（緊急） (CVSS 9.9)
- **公開**: 2026-11-24

## 原文

A flaw has been found in Panabit Smart Application Gateway TANGr7p10\. This vulnerability affects the function edit\_data\_pie of the file /cgi\-bin/flowcontrol/ajax\_data\_pie\. This manipulation of the argument Name causes os command injection\. The attack may be initiated remotely\. The exploit has been published and may be used\. The vendor was contacted early about this disclosure but did not respond in any way\.
