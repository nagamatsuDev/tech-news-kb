# Community Store for Concrete CMS before 2\.8\.0 contains a stored cross\-site scripting vulnerability that allows unauthenticated attackers \.\.\.

- **ID**: CVE\-2026\-135689
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-24

## 原文

Community Store for Concrete CMS before 2\.8\.0 contains a stored cross\-site scripting vulnerability that allows unauthenticated attackers to inject script via the order email in single\_pages/dashboard/store/orders\.php\. Attackers can place guest orders with quoted email local parts containing markup to execute script in a store manager's session when viewing the order\.
