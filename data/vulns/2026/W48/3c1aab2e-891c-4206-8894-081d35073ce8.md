# The Simple Membership plugin for WordPress is vulnerable to Privilege Escalation in versions up to, and including, 4\.8\.9 This is due to t\.\.\.

- **ID**: CVE\-2026\-133951
- **危険度**: Critical（緊急） (CVSS 9.1)
- **言語**: PHP
- **公開**: 2026-11-26

## 原文

The Simple Membership plugin for WordPress is vulnerable to Privilege Escalation in versions up to, and including, 4\.8\.9 This is due to the site\-wide signing secret \`swpm\_private\_key\_one\` being generated at install time with PHP's non\-cryptographic \`uniqid\('', true\)\` function in \`SwpmInstallation\:\:installer\(\)\`, whose timestamp\-derived keyspace \(\~10\^15 candidates / \~50 bits\) can be constrained via the public WordPress REST API date of the plugin's auto\-created registration page, combined with a single\-MD5 oracle \(\`md5\(key\|level\)\`\) that the public registration form prints as \`swpm\_level\_hash\` and a non\-constant\-time \`\!\=\` comparison in \`SwpmFrontRegistration\:\:register\_front\_end\(\)\` as the sole authorization gate on which membership level a visitor may register into; \`SwpmUtils\:\:get\_free\_level\(\)\` then honors an attacker\-posted \`level\_identifier\=md5\(level\)\` regardless of the configured free\-membership setting, and \`prepare\_and\_create\_wp\_user\_front\_end\(\)\` creates the WordPress account with whatever role the level is configured to grant \(only the \`administrator\` role is refused\)\. This makes it possible for unauthenticated attackers, after an offline brute\-force recovery of the install\-time secret against the public MD5 oracle, to forge a valid \`swpm\_level\_hash\` for any configured membership level and self\-register into that level, elevating their newly created WordPress account to the level's assigned role — e\. Successful exploitation causes the attacker's own account to receive the complete editor role\.
