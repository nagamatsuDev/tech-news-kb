# A flaw was found in GIMP\.

- **ID**: CVE\-2026\-137941
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-27

## 原文

A flaw was found in GIMP\. The Levels configuration setter does not validate the channel enum before using it to index fixed\-size per\-channel arrays\. A crafted XCF file with a non\-destructive Levels filter can set an out\-of\-range channel \(LUMINANCE or RGB\), causing a heap out\-of\-bounds read and write when the file is opened\. This may lead to a crash or arbitrary code execution\.
