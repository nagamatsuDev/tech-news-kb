# Pydantic Deep 0\.2\.18 before 0\.4\.0 contains a missing authentication vulnerability in the bundled DeepResearch FastAPI app that exposes HT\.\.\.

- **ID**: CVE\-2026\-137953
- **危険度**: High（重要） (CVSS 8.6)
- **公開**: 2026-11-27

## 原文

Pydantic Deep 0\.2\.18 before 0\.4\.0 contains a missing authentication vulnerability in the bundled DeepResearch FastAPI app that exposes HTTP routes and the /ws/chat WebSocket\. Remote attackers reaching the server bound to all interfaces can enumerate sessions, read event logs and workspace files, drive the research agent, and delete sessions\.
