# asar\-py before 0\.1\.4 contains a path traversal vulnerability in AsarArchive\.extract\(\) and extract\_archive\(\) that allows attackers to writ\.\.\.

- **ID**: CVE\-2026\-136923
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-25

## 原文

asar\-py before 0\.1\.4 contains a path traversal vulnerability in AsarArchive\.extract\(\) and extract\_archive\(\) that allows attackers to write files outside the destination directory via crafted archive headers\. Attackers can supply a \.asar archive with '\.\.' path components or malicious symlink targets to write files such as usercustomize\.py, leading to code execution\.
