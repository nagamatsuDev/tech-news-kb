# n8n before 1\.123\.96, 2\.47\.6, 2\.48\.3, and 3\.2\.2 contains a path traversal vulnerability in integration nodes that build API request paths \.\.\.

- **ID**: CVE\-2026\-137957
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-11-27

## 原文

n8n before 1\.123\.96, 2\.47\.6, 2\.48\.3, and 3\.2\.2 contains a path traversal vulnerability in integration nodes that build API request paths from unencoded record, table, or resource ID parameters\. Attackers can supply relative path segments through untrusted input such as webhook bodies to read, modify, or delete unintended resources using the node's stored credential\.
