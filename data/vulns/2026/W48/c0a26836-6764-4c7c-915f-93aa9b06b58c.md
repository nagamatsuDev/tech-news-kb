# Nmap before 7\.992 contains a use\-after\-free vulnerability in DNS\:\:ResolverImpl\:\:process\_request in libnetutil/massdns\.cc that frees still\.\.\.

- **ID**: CVE\-2026\-137978
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-27

## 原文

Nmap before 7\.992 contains a use\-after\-free vulnerability in DNS\:\:ResolverImpl\:\:process\_request in libnetutil/massdns\.cc that frees still\-referenced requests when rescheduling after DNS server disconnects\. Attackers answering for at least two configured DNS servers can force a disconnect and send a precisely timed response to crash the scan, possibly enabling code execution\.
