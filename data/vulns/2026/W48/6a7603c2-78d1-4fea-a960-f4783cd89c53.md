# A security flaw has been discovered in Volans NGFW Next\-Generation Firewall r5\.1\.

- **ID**: CVE\-2026\-135798
- **危険度**: High（重要） (CVSS 7.3)
- **公開**: 2026-11-24

## 原文

A security flaw has been discovered in Volans NGFW Next\-Generation Firewall r5\.1\. The affected element is an unknown function of the file include/sqlite3\.inc of the component Web Management Interface\. Performing a manipulation results in sql injection\. The attack is possible to be carried out remotely\. The exploit has been released to the public and may be used for attacks\. The vendor was contacted early about this disclosure but did not respond in any way\.
