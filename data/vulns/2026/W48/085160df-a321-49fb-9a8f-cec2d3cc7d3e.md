# An externally\-controlled format string vulnerability exists in the authenticated upload\_wireguard action of settings/vpnupload\.cgi in the\.\.\.

- **ID**: CVE\-2026\-120951
- **危険度**: High（重要） (CVSS 8.6)
- **公開**: 2026-11-24

## 原文

An externally\-controlled format string vulnerability exists in the authenticated upload\_wireguard action of settings/vpnupload\.cgi in the ADM\. The CGI takes an attacker\-controlled WireGuard profile name, inserts it into a JSON object, serializes it, and passes the resulting formatted string directly to printf as the format argument without validation or escaping\. An authenticated remote attacker can exploit this vulnerability by sending format string specifiers, or leverage variadic read/write primitives within the non\-PIE, non\-Canary root CGI to potentially achieve arbitrary remote code execution with root privileges\.  
Affected products and versions include\: from ADM 4\.1\.0 through ADM 4\.3\.3\.RY62 as well as from ADM 5\.0\.0 through ADM 5\.1\.4\.RM62\.
