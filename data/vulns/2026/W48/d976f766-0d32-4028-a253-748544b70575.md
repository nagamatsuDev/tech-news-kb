# The Simple Membership plugin for WordPress is vulnerable to Privilege Escalation in all versions up to, and including, 4\.9\.0 This is due \.\.\.

- **ID**: CVE\-2026\-135626
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-27

## 原文

The Simple Membership plugin for WordPress is vulnerable to Privilege Escalation in all versions up to, and including, 4\.9\.0 This is due to the \`SwpmLevelForm\:\:role\(\)\` function applying only \`sanitize\_text\_field\(\)\` to the user\-supplied \`role\` parameter with no allowlist, permitting the \`administrator\` role to be stored verbatim into \`swpm\_membership\_tbl\` and subsequently applied to a member's WordPress account via \`\$user\-&gt;add\_role\(\)\` inside \`update\_wp\_user\_role\(\)\` — also without any role allowlist — when the \`swpm\_membership\_level\_changed\` action fires\. This makes it possible for authenticated attackers with Contributor\-level access and above to create a membership level specifying the \`administrator\` WordPress role, assign themselves to that level, and thereby elevate their own WordPress account to full Administrator, gaining complete site control including the ability to install plugins, edit themes, and manage users\. Exploitation requires that the site owner has lowered the plugin's "Admin Dashboard Access Permission" setting from its default \`manage\_options\` capability to a lesser capability such as \`edit\_posts\`, \`edit\_published\_posts\`, or \`edit\_pages\`, which grants lower\-privileged users access to the SWPM admin dashboard where the vulnerable level\-creation form resides\. Successful exploitation causes the attacker's own account to receive the complete administrator role\.
