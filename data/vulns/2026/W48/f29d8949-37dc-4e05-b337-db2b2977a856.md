# The backend language switch action \(quick\_change\_language\) of the JTL\-Shop administration backend is executed without a CSRF token check,\.\.\.

- **ID**: CVE\-2026\-133938
- **危険度**: Critical（緊急） (CVSS 9.3)
- **言語**: JavaScript/TypeScript
- **公開**: 2026-11-27

## 原文

The backend language switch action \(quick\_change\_language\) of the JTL\-Shop administration backend is executed without a CSRF token check, and the supplied language value is neither validated against the installed backend languages nor encoded on output\. The value is stored in the session and in the account data of the administrator and rendered without output encoding in JavaScript strings and HTML attributes of backend pages\. An unauthenticated remote attacker can thereby cause script code to be executed in the browser of a logged\-in administrator who opens a crafted web page; the code can perform actions with the privileges of that administrator\.
