# A security vulnerability has been detected in D\-Link R95 101B06\.

- **ID**: CVE\-2026\-135789
- **危険度**: Critical（緊急） (CVSS 9.1)
- **公開**: 2026-11-24

## 原文

A security vulnerability has been detected in D\-Link R95 101B06\. Affected by this issue is the function GetBluetoothAdapterSettings/GetBluetoothBloodPressure/GetBluetoothDeviceList/GetBluetoothScanDeviceList/SetBluetoothAdapterSettings/SetBluetoothUnpairDevice/SetTriggerBluetoothScan/SetBluetoothPairDevice of the file /bin/ssi of the component DHMAPI SOAP Handler\. The manipulation of the argument inner\_xml leads to os command injection\. The attack can be initiated remotely\. The exploit has been disclosed publicly and may be used\.
