# fastcore through 2\.2\.44 contains a path traversal vulnerability in the fastcore\.xtras\.untar\_dir\(\) archive extraction helper that allows a\.\.\.

- **ID**: CVE\-2026\-65320
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: Python
- **公開**: 2026-11-24

## 原文

fastcore through 2\.2\.44 contains a path traversal vulnerability in the fastcore\.xtras\.untar\_dir\(\) archive extraction helper that allows attackers who supply a crafted tar archive to write files outside the intended extraction directory\. The internal \_unpack\(\) function passes the archive to shutil\.unpack\_archive\(\) without a tar extraction filter, member path validation, or a containment check, so archive members with absolute paths or \.\./ traversal sequences are written to arbitrary locations writable by the application process when running on Python versions before 3\.14\. Applications that extract untrusted archives with untar\_dir\(\) can have application files, configuration, or importable code overwritten, which can lead to code execution, data modification, or denial of service\.
