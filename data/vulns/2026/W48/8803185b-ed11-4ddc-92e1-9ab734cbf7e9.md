# An access control bypass flaw was identified in Samba's vfs\_ceph\_rgw module in it's openat\(\) function\.

- **ID**: CVE\-2026\-109411
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-10-28

## 原文

An access control bypass flaw was identified in Samba's vfs\_ceph\_rgw module in it's openat\(\) function\. An authenticated user can bypass access controls to read or overwrite restricted files on shares configured with the experimental vfs\_ceph\_rgw module\. When a client requests an existing file using mismatched character casing, the module fails to perform a case\-insensitive lookup correctly, causing the server to treat the operation as creating a new file\. As a result, the server skips standard permission checks on the existing file, allowing the attacker to access or overwrite sensitive data owned by other users\.
