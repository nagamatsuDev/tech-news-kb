# Deserialization of Untrusted Data vulnerability in ash\-project ash allows an unauthenticated attacker to execute arbitrary code or inject\.\.\.

- **ID**: CVE\-2026\-124283
- **危険度**: High（重要） (CVSS 8.9)
- **公開**: 2026-11-24

## 原文

Deserialization of Untrusted Data vulnerability in ash\-project ash allows an unauthenticated attacker to execute arbitrary code or inject SQL through a forged keyset pagination cursor\.
  
Ash\.Page\.Keyset\.filter/4 in lib/ash/page/keyset\.ex decodes the client\-supplied page\[\:after\] or page\[\:before\] cursor from Erlang external term format and rejects decoded expressions with Ash\.Expr\.expr?/1\. That check does not examine the fields of a struct\. The cast of each value against the type of its sort field accepts structs for the \:ci\_string, \:map, \:struct and \:term types\. A struct in the cursor value for such a sort field therefore reaches the data layer\. With AshPostgres, the read passes such a struct to inspect/1, which runs the Inspect implementation of the struct module that the attacker selected\. A chain of struct modules from ecto and db\_connection then calls a function that the cursor names, which permits OS command execution\. An %Ash\.Query\.Function\.Fragment\{\} inside an %Ash\.CiString\{\} value is written into the SQL query as raw text\.
  
This issue affects ash\: from 3\.31\.3 before 3\.38\.0\.
