# Ettercap before 0\.8\.5\.1 contains an integer underflow in ccmp\_decrypt\(\) in src/ec\_encryption\_ccmp\.c that subtracts the 8\-byte CCMP traile\.\.\.

- **ID**: CVE\-2026\-125404
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-10

## 原文

Ettercap before 0\.8\.5\.1 contains an integer underflow in ccmp\_decrypt\(\) in src/ec\_encryption\_ccmp\.c that subtracts the 8\-byte CCMP trailer without checking minimum length\. Attackers on a network whose WPA key is loaded can send a short crafted CCMP frame to overflow a stack buffer in the Ettercap process, which normally runs as root\.
