# The ggml\-rpc server suffers from an uninitialized heap memory disclosure vulnerability where the alloc\_buffer function provides new clien\.\.\.

- **ID**: CVE\-2026\-132615
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-23

## 原文

The ggml\-rpc server suffers from an uninitialized heap memory disclosure vulnerability where the alloc\_buffer function provides new clients with buffers containing stale data from previously freed allocations\. This allows an unauthenticated remote attacker to perform an in\-bounds read via get\_tensor to recover sensitive information, such as model weights or KV\-cache data, belonging to other clients sharing the same server\.
