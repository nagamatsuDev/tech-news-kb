# A flaw has been found in hiyouga LLaMA\-Factory up to 0\.9\.5\.

- **ID**: CVE\-2026\-135800
- **危険度**: High（重要） (CVSS 7.3)
- **公開**: 2026-11-24

## 原文

A flaw has been found in hiyouga LLaMA\-Factory up to 0\.9\.5\. Affected is the function save\_args/load\_args of the file src/llamafactory/webui/runner\.py of the component WebUI\. This manipulation of the argument config\_path causes path traversal\. The attack can be initiated remotely\. The vendor was contacted early about this disclosure but did not respond in any way\.
