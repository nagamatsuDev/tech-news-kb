# ICU4C through 79\.1 contains a use\-after\-free and double free vulnerability in the x11\-compound\-text converter because cloning shares the \.\.\.

- **ID**: CVE\-2026\-137326
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-26

## 原文

ICU4C through 79\.1 contains a use\-after\-free and double free vulnerability in the x11\-compound\-text converter because cloning shares the extraInfo block without a safeClone handler\. Attackers who control the charset name passed to ucnv\_open\(\) in applications calling ucnv\_setSubstString\(\) or cloning converters can corrupt the heap, causing crashes and potentially code execution\.
