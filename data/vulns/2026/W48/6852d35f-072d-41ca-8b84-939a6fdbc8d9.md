# A weakness has been identified in TRENDnet TEW\-751DR 1\.03B01\.

- **ID**: CVE\-2026\-138003
- **危険度**: Critical（緊急） (CVSS 9.0)
- **公開**: 2026-11-27

## 原文

A weakness has been identified in TRENDnet TEW\-751DR 1\.03B01\. This impacts the function FUN\_0040ed90 of the file wfadev\.cgi of the component UPnP/WFA\. This manipulation of the argument SOAPAction causes stack\-based buffer overflow\. The attack is possible to be carried out remotely\. A high degree of complexity is needed for the attack\. The exploitability is said to be difficult\. The exploit has been made available to the public and could be used for attacks\.
