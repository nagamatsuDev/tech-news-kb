# soapbar\: verify\_envelope\_bsp accepts an unauthenticated embedded certificate \(signature forgery / authentication bypass\)

- **ID**: CVE\-2026\-64855 / GHSA\-859w\-52fx\-hcm6
- **危険度**: High（重要） (CVSS 8.2)
- **言語**: Python
- **パッケージ**: PyPI/soapbar &lt; 0\.13\.0 → 0\.13\.0
- **公開**: 2026-11-24

## 原文

\#\#\# Impact \`verify\_envelope\_bsp\(\)\` derived its trust anchor from the message it was verifying\. It read the X\.509 certificate out of the caller\-untrusted \`wsse\:BinarySecurityToken\`, validated \*\*only\*\* that certificate's not\-before / not\-after dates, and then verified the signature against that same certificate\. There was no CA\-chain validation, no issuer/subject allowlist, and no pinning\. A successful \`verify\_envelope\_bsp\(\)\` therefore proved only that the envelope was signed by \*whoever supplied the embedded certificate\* — never that it was signed by a \*trusted\* party\.
