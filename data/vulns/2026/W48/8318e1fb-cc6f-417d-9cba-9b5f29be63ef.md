# KindleEar 3\.0\.0 through 3\.5\.3 contains a remote code execution vulnerability that allows authenticated non\-admin users to run Python code\.\.\.

- **ID**: CVE\-2026\-135436
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: Python
- **公開**: 2026-11-23

## 原文

KindleEar 3\.0\.0 through 3\.5\.3 contains a remote code execution vulnerability that allows authenticated non\-admin users to run Python code by uploading malicious recipes\. Attackers can submit crafted recipe source to the /recipe/upload action, which calibre compile\_recipe executes via exec\(\) without sandboxing, gaining root code execution in the Docker container and access to password hashes\.
