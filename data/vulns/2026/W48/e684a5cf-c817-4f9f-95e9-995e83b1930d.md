# A weakness has been identified in eosphoros\-ai DB\-GPT up to 0\.8\.2\.

- **ID**: CVE\-2026\-136694
- **危険度**: High（重要） (CVSS 7.3)
- **公開**: 2026-11-25

## 原文

A weakness has been identified in eosphoros\-ai DB\-GPT up to 0\.8\.2\. This impacts the function skill\_upload of the file packages/dbgpt\-app/src/dbgpt\_app/openapi/api\_v1/agentic\_data\_api\.py of the component Skill Upload Handler\. Executing a manipulation of the argument filename can lead to path traversal\. It is possible to launch the attack remotely\. The exploit has been made available to the public and could be used for attacks\. Upgrading to version 0\.8\.3 will fix this issue\. This patch is called fc6a5017d5a8509d34700694bbd8a637bde311fb\. It is suggested to upgrade the affected component\. This is a regression of CVE\-2026\-51862 because the fix shipped in 0\.8\.1 was reverted in 0\.8\.2 and the corrected code exists only on the unreleased main branch\.
