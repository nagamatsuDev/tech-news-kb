# A flaw was found in Flatpak’s flatpak\-system\-helper\.

- **ID**: CVE\-2026\-133842
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-11-27

## 原文

A flaw was found in Flatpak’s flatpak\-system\-helper\. When a system\-wide app, runtime, or extension uses the extra\-data mechanism and its apply\_extra logic creates a deeply nested directory tree, permission canonicalization can fail \(for example with EMFILE\)\. Affected Flatpak versions can still report success without clearing setuid/setgid bits, leaving a setuid\-root executable under /var/lib/flatpak\. A local attacker who can install or update such content system\-wide, or who can already execute code as a local user in cooperation with that content, can escalate privileges to root\.
