# Scriban before 7\.6\.0 contains a resource exhaustion vulnerability that allows attackers to bypass LoopLimit by supplying large JSON input\.\.\.

- **ID**: CVE\-2026\-137512
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-26

## 原文

Scriban before 7\.6\.0 contains a resource exhaustion vulnerability that allows attackers to bypass LoopLimit by supplying large JSON input to object\.from\_json\. Attackers can pass a flat JSON array or object with hundreds of thousands of elements, which JsonElementExtensions materializes without loop checks, exhausting CPU and memory\.
