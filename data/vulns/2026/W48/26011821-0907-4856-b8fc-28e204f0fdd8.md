# A vulnerability was identified in philipjscott simple\-thumbnail up to 1\.6\.5\.

- **ID**: CVE\-2026\-136946
- **危険度**: High（重要） (CVSS 7.3)
- **公開**: 2026-11-26

## 原文

A vulnerability was identified in philipjscott simple\-thumbnail up to 1\.6\.5\. This issue affects the function ffmpegExecute of the file index\.js\. The manipulation of the argument seek leads to os command injection\. It is possible to initiate the attack remotely\. The exploit is publicly available and might be used\. The project was informed of the problem early through an issue report but has not responded yet\.
