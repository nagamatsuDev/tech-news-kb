# An Incomplete List of Disallowed Inputs in the namespace onboarding API in Google Cloud GKE Fleet versions prior to 2026\-09\-25 on Google \.\.\.

- **ID**: CVE\-2026\-110739
- **危険度**: Critical（緊急） (CVSS 9.0)
- **公開**: 2026-11-27

## 原文

An Incomplete List of Disallowed Inputs in the namespace onboarding API in Google Cloud GKE Fleet versions prior to 2026\-09\-25 on Google Cloud Platform allows an authenticated attacker to escalate privileges to project owner using a privileged system namespace onboarding request\.
  
This vulnerability was patched on 25 September 2026, and no customer action is needed\.
