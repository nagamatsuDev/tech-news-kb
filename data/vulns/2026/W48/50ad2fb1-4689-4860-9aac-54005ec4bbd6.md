# FFmpeg 3\.0 before 8\.1\.3 contains a heap buffer overflow vulnerability in libavfilter/vf\_boxblur\.c because query\_formats\(\) accepts pixel f\.\.\.

- **ID**: CVE\-2026\-137907
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-27

## 原文

FFmpeg 3\.0 before 8\.1\.3 contains a heap buffer overflow vulnerability in libavfilter/vf\_boxblur\.c because query\_formats\(\) accepts pixel formats deeper than 16 bits while the blur temporary buffers hold only 2 bytes per pixel\. Attackers can supply crafted 32\-bit float media, such as PFM or OpenEXR images, that when processed by the boxblur filter overflow the temporary buffers, crashing applications or possibly executing code\.
