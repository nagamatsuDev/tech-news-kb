# OpenEMR before 8\.3\.0 contains a path traversal vulnerability in the FaxSMS module's RCFaxClient and SignalWireClient disposeDocument func\.\.\.

- **ID**: CVE\-2026\-124446
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-08

## 原文

OpenEMR before 8\.3\.0 contains a path traversal vulnerability in the FaxSMS module's RCFaxClient and SignalWireClient disposeDocument functions that allows authenticated low\-privilege users to read and overwrite arbitrary files via the unsanitized file\_path parameter\. Attackers can request action\=download to retrieve cleartext files like sqlconf\.php database credentials and keys, or use action\=setup to overwrite web\-server\-writable files with ciphertext\.
