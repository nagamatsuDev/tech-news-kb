# In astro\-airflow\-mcp 0\.5\.0 through 0\.9\.1, the af CLI and the MCP server send telemetry from a Python subprocess that can import modules f\.\.\.

- **ID**: CVE\-2026\-133632
- **危険度**: High（重要） (CVSS 7.8)
- **言語**: Python
- **公開**: 2026-11-23

## 原文

In astro\-airflow\-mcp 0\.5\.0 through 0\.9\.1, the af CLI and the MCP server send telemetry from a Python subprocess that can import modules from the current working directory\. If a user runs an af command or an MCP tool call from inside a project that contains an attacker\-supplied json\.py, that file runs with the user's privileges\. Users who only run the tool in projects they trust are not affected\. Fixed in 0\.9\.2; in earlier versions, setting AF\_TELEMETRY\_DISABLED\=1 prevents it\.
