# The Product Input Fields for WooCommerce plugin for WordPress is vulnerable to Arbitrary File Upload in all versions up to, and including\.\.\.

- **ID**: CVE\-2026\-104998
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: PHP
- **公開**: 2026-11-26

## 原文

The Product Input Fields for WooCommerce plugin for WordPress is vulnerable to Arbitrary File Upload in all versions up to, and including, 2\.1\.0 via the process\_file\_input\_field function\. This is due to missing file type validation in the process\_file\_input\_field function, which accepts the client\-supplied multipart Content\-Type header as the sole type gate and writes the uploaded file to the unprotected pif\_temp directory using the verbatim client\-supplied filename\. This makes it possible for unauthenticated attackers to upload files that may be executable, which makes remote code execution possible\. Exploitation requires that an administrator has configured at least one product with a File\-type Product Input Field with the "Show thumbnail" option enabled, which is a standard use of the feature; additionally, the pif\_temp/ upload directory is created without \.htaccess or index\.php restrictions, leaving written files directly web\-accessible and executable on default Apache/mod\_php configurations\.
