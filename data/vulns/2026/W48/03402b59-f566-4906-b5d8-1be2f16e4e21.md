# FFmpeg before 9\.1 contains a heap\-based buffer overflow vulnerability in peak\_init\_writer\(\) and wav\_write\_packet\(\) in libavformat/wavenc\.\.\.\.

- **ID**: CVE\-2026\-135722
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-24

## 原文

FFmpeg before 9\.1 contains a heap\-based buffer overflow vulnerability in peak\_init\_writer\(\) and wav\_write\_packet\(\) in libavformat/wavenc\.c that allows attackers to corrupt heap memory by supplying audio with zero channels\. Attackers can provide a crafted PCM stream declaring no channels for WAV output with peak envelope enabled, causing out\-of\-bounds writes past peak\_maxpos and peak\_maxneg arrays, crashes, and potential code execution\.
