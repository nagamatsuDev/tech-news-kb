# DBHub before 1\.7\.0 contains a read\-only mode bypass vulnerability that allows MCP clients restricted to readonly execute\_sql to run write\.\.\.

- **ID**: CVE\-2026\-134803
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-22

## 原文

DBHub before 1\.7\.0 contains a read\-only mode bypass vulnerability that allows MCP clients restricted to readonly execute\_sql to run write and DDL statements via backslash\-escaped quotes\. Attackers can hide stacked statements that clear transaction\_read\_only or COMMIT inside strings misparsed by scanSingleQuotedString, letting them modify or drop MySQL, MariaDB, or PostgreSQL data\.
