# The ZarinPal Payment Gateway for WooCommerce plugin for WordPress is vulnerable to Insecure Direct Object Reference in versions up to, an\.\.\.

- **ID**: CVE\-2026\-92251
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-26

## 原文

The ZarinPal Payment Gateway for WooCommerce plugin for WordPress is vulnerable to Insecure Direct Object Reference in versions up to, and including, 5\.1\.1 via the \`Return\_from\_ZarinPal\_Gateway\(\)\` handler registered on the \`woocommerce\_api\_wc\_zpal\` \(\`?wc\-api\=wc\_zpal\`\) endpoint\. The handler accepts a \`wc\_order\` parameter from the query string, loads the corresponding WooCommerce order without any authentication, nonce, session, capability, or ownership check, and — when the order is paid — issues a 302 redirect to \`get\_return\_url\(\$order\)\`, whose \`Location\` header embeds the order's secret \`order\_key\`\. This makes it possible for unauthenticated attackers to harvest order keys for arbitrary orders \(regardless of payment method\) and then use those keys against the WooCommerce order\-received, order\-pay and download endpoints to read the associated customer's PII, including billing name, street address, phone number, email, purchased items, and totals\.
