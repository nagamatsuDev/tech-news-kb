# FFmpeg before 9\.1 contains a heap out\-of\-bounds write and read vulnerability in the tmidequalizer filter that allows attackers to corrupt\.\.\.

- **ID**: CVE\-2026\-135737
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-24

## 原文

FFmpeg before 9\.1 contains a heap out\-of\-bounds write and read vulnerability in the tmidequalizer filter that allows attackers to corrupt memory by supplying high bit depth samples exceeding the nominal maximum\. Attackers can craft planar 9, 10, 12 or 14 bit video so compute\_histogram16\(\) and apply\_contrast\_change16\(\) index unclamped samples, crashing applications, corrupting the heap, and leaking heap contents\.
