# The Simple Membership plugin for WordPress is vulnerable to Privilege Escalation in all versions up to, and including, 4\.9\.0 The vulnerab\.\.\.

- **ID**: CVE\-2026\-135627
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-27

## 原文

The Simple Membership plugin for WordPress is vulnerable to Privilege Escalation in all versions up to, and including, 4\.9\.0 The vulnerability exists because the \`bulk\_operation\_menu\(\)\` function accepts the \`swpm\_bulk\_change\_level\_to\` parameter from \`\$\_REQUEST\` with only \`sanitize\_text\_field\(\)\` applied, and passes it to \`SwpmMemberUtils\:\:update\_membership\_level\_and\_role\(\)\` without the \`id \!\= 1\` allowlist exclusion that every other level\-selection path in the plugin enforces — leaving membership level 1, which the installer maps to the WordPress \`administrator\` role on every fresh install, freely selectable as a bulk\-change target\. This makes it possible for authenticated attackers with Contributor\-level access and above to elevate their own WordPress account to the full Administrator role, gaining complete site control including plugin installation, user creation, and all other administrator capabilities\. Exploitation requires that an administrator has first lowered the plugin's "Admin Dashboard Access Permission" setting from its default of \`manage\_options\` to a lesser capability such as \`edit\_posts\` \(Contributor\), \`edit\_published\_posts\` \(Author\), or \`edit\_pages\` \(Editor\), which is a non\-default granted\-access configuration; the bulk screen's nonce protection \(\`swpm\_bulk\_change\_level\_nonce\_action\`\) does not mitigate the issue because the nonce is emitted on the same page the delegated lower\-role user can already reach\. Successful exploitation causes the attacker's own account to receive the complete administrator role\.
