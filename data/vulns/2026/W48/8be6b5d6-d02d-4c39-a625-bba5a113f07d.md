# The JetFormBuilder — Dynamic Blocks Form Builder plugin for WordPress is vulnerable to Stored DOM\-Based Cross\-Site Scripting via the 'f\_b\.\.\.

- **ID**: CVE\-2026\-135666
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-26

## 原文

The JetFormBuilder — Dynamic Blocks Form Builder plugin for WordPress is vulnerable to Stored DOM\-Based Cross\-Site Scripting via the 'f\_body \(mapped to post\_content via fields\_map\)' parameter in all versions up to, and including, 3\.6\.8\.2 due to insufficient input sanitization and output escaping\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\. This requires that at least one form on the site contains a Calculated Field block, ensuring the calculated\.field\.js gadget is enqueued on pages where the stored post content is rendered\.
