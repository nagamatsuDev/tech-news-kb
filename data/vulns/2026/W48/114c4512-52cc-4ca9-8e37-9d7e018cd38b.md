# FreeRDP before 3\.33\.0 contains an integer overflow in the client GDI handling of accumulated drawing\-order bounds\: wrapped INT32 coordina\.\.\.

- **ID**: CVE\-2026\-137456
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-11-26

## 原文

FreeRDP before 3\.33\.0 contains an integer overflow in the client GDI handling of accumulated drawing\-order bounds\: wrapped INT32 coordinates yield a zero\-width clip region that causes clipping to be skipped in gdi\_FillRect\. A malicious RDP server can send many ORDER\_BOUNDS orders followed by an OPAQUE\_RECT order to trigger a heap out\-of\-bounds write past the client's drawing bitmap, potentially leading to code execution\.
