# Pomerium from 0\.30\.0 before 0\.34\.0 contains an authentication bypass vulnerability in the MCP token endpoint that skips client secret ver\.\.\.

- **ID**: CVE\-2026\-135300
- **危険度**: High（重要） (CVSS 7.4)
- **公開**: 2026-11-23

## 原文

Pomerium from 0\.30\.0 before 0\.34\.0 contains an authentication bypass vulnerability in the MCP token endpoint that skips client secret verification for client\_secret\_basic clients\. Attackers holding an intercepted authorization code or refresh token can redeem it at /\.pomerium/mcp/token with any secret to obtain the victim's access tokens\.
