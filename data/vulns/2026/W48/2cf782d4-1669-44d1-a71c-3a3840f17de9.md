# Open5GS WebUI through 2\.8\.0 contains an incorrect authorization vulnerability in webui/server/routes/db\.js that allows authenticated user\.\.\.

- **ID**: CVE\-2026\-135691
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-24

## 原文

Open5GS WebUI through 2\.8\.0 contains an incorrect authorization vulnerability in webui/server/routes/db\.js that allows authenticated user\-role accounts to modify the Account model\. Attackers can send PATCH /api/db/Account/&lt;username&gt; setting roles to admin, overwrite password hashes, delete accounts, and read hashes to gain full administrative control\.
