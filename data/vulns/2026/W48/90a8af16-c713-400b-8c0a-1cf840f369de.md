# OpenEMR before 8\.4\.0 contains a server\-side request forgery vulnerability that allows unauthenticated attackers to make the server send H\.\.\.

- **ID**: CVE\-2026\-124466
- **危険度**: High（重要） (CVSS 7.2)
- **公開**: 2026-11-08

## 原文

OpenEMR before 8\.4\.0 contains a server\-side request forgery vulnerability that allows unauthenticated attackers to make the server send HTTP requests by registering an OAuth2 client with an unvalidated jwks\_uri\. Attackers can trigger the fetch via the token introspection endpoint with an unsigned client\_assertion to probe internal services and reach cloud metadata endpoints\.
