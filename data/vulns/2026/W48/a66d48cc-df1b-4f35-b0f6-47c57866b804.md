# The RSS Aggregator by Feedzy – Feed to Post, Autoblogging, News &amp; YouTube Video Feeds Aggregator plugin for WordPress is vulnerable to St\.\.\.

- **ID**: CVE\-2026\-135675
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-26

## 原文

The RSS Aggregator by Feedzy – Feed to Post, Autoblogging, News &amp; YouTube Video Feeds Aggregator plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'comment' parameter in versions up to, and including, 5\.2\.17 due to insufficient restriction on the wp\_kses\_allowed\_html filter callback\. The feedzy\_wp\_kses\_allowed\_html\(\) method is registered on wp\_kses\_allowed\_html with the loader's default accepted\_args\=1, so the callback never receives the context\-name argument and unconditionally adds &lt;iframe&gt; \(with arbitrary src, width, height, frameborder, allowfullscreen and data\-\* attributes\) to the allowed\-tag array for every context — including pre\_comment\_content, which WordPress uses to sanitize comment bodies submitted by users without the unfiltered\_html capability\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\.
