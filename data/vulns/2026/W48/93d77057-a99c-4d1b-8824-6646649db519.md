# PyBioNetGen 0\.8\.7 contains a code injection vulnerability in ParameterBlock\.add\_item\(\) and ModelBlock\.add\_item\(\) that allows attackers to\.\.\.

- **ID**: CVE\-2026\-136922
- **危険度**: High（重要） (CVSS 7.8)
- **言語**: Python
- **公開**: 2026-11-25

## 原文

PyBioNetGen 0\.8\.7 contains a code injection vulnerability in ParameterBlock\.add\_item\(\) and ModelBlock\.add\_item\(\) that allows attackers to execute Python code by passing parameter expressions to sympy\.sympify\(\)\. Attackers can supply a crafted BNG\-XML model file with Python code in a Parameter expr or value attribute to execute code as the user when loaded with bionetgen\.bngmodel\(\)\.
