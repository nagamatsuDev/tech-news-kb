# pain001\-mcp 0\.0\.72 before 0\.0\.80 contains a path traversal vulnerability in the commit\_payment\_batch MCP tool that allows attackers to wr\.\.\.

- **ID**: CVE\-2026\-136620
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-25

## 原文

pain001\-mcp 0\.0\.72 before 0\.0\.80 contains a path traversal vulnerability in the commit\_payment\_batch MCP tool that allows attackers to write files outside any output directory via output\_file\_path\. Attackers can stage a batch, reuse the self\-issued confirmation\_token, and supply absolute, dot\-dot, or symlinked paths to create or overwrite server\-writable files with generated XML\.
