# Frappe LMS before 2\.65\.0 contains an improper authorization vulnerability that allows Batch Evaluators to modify any evaluation because t\.\.\.

- **ID**: CVE\-2026\-75582
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-24

## 原文

Frappe LMS before 2\.65\.0 contains an improper authorization vulnerability that allows Batch Evaluators to modify any evaluation because the LMS Certificate Evaluation doctype lacks a has\_permission scoping hook\. Attackers can call the whitelisted create\_lms\_certificate method with any evaluation name to issue certificates for unassigned evaluations or learners outside their batches\.
