# AutoGPT is a workflow automation platform for creating, deploying, and managing continuous artificial intelligence agents\.

- **ID**: CVE\-2026\-133448
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-24

## 原文

AutoGPT is a workflow automation platform for creating, deploying, and managing continuous artificial intelligence agents\. In versions 0\.7\.1 through 0\.8\.4, chat and prompt text passed to the Claude Code CLI is pre\-processed before reaching the model, bypassing AutoPilot's tool allow\-list and PreToolUse hooks\. In both AutoPilot's Claude Agent SDK path and the graph orchestrator block's extended\_thinking SDK mode, messages starting with / execute CLI commands or bundled skills, while @&lt;path&gt; mentions read files or list directories on the host and attach the results to the model request\. Signed\-in users, members of linked chat channels, graph authors, or indirect tool output carried into turn history can make the CLI read files accessible to the copilot executor process, whose contents reach the model provider and can be repeated in replies, and run commands that compact or clear the session, switch the model, or modify the CLI's settings\.json file\. This issue is fixed in version 0\.9\.0\.
