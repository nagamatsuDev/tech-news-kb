# Pydantic Deep 0\.2\.18 before 0\.4\.0 contains a server\-side request forgery and local file read vulnerability in the DeepResearch export\_rep\.\.\.

- **ID**: CVE\-2026\-137954
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-27

## 原文

Pydantic Deep 0\.2\.18 before 0\.4\.0 contains a server\-side request forgery and local file read vulnerability in the DeepResearch export\_report handler for /export/pdf\. Attackers can inject raw HTML into reports via the unauthenticated /upload endpoint, causing WeasyPrint to fetch internal URLs and embed local server files into exported PDFs\.
