# OpenEMR before 8\.3\.0 contains a path traversal vulnerability in interface/billing/sl\_eob\_process\.php that allows authenticated users to w\.\.\.

- **ID**: CVE\-2026\-124457
- **危険度**: High（重要） (CVSS 7.6)
- **言語**: PHP
- **公開**: 2026-11-08

## 原文

OpenEMR before 8\.3\.0 contains a path traversal vulnerability in interface/billing/sl\_eob\_process\.php that allows authenticated users to write and read files by supplying unsanitized eraname values\. Attackers without billing privileges can inject \.\./ sequences to create ERA report \.html files anywhere the web user can write and parse arbitrary \.edi files echoed into the report\.
