# GFI HelpDesk before 4\.99\.13 contains an SQL injection vulnerability in the archiver export feature that allows authenticated attackers wi\.\.\.

- **ID**: CVE\-2026\-127224
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-23

## 原文

GFI HelpDesk before 4\.99\.13 contains an SQL injection vulnerability in the archiver export feature that allows authenticated attackers with administrator privileges to execute arbitrary SQL queries by supplying crafted itemid\[\] array values to /admin/index\.php?/archiver/Manager/ExportAll\. The Controller\_Manager\.ExportAll\(\) method joins the itemid values with implode\(\) and GetWhere\(\) concatenates them into an IN\(\) clause without sanitization or parameterization, and DumpTables\(\) executes the resulting query against each ticket\-related table, allowing attackers to read or modify database contents\.
