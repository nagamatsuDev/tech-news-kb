# Authorization bypass through user\-controlled key in the RDM folder duplication endpoint in Devolutions Server 2026\.3\.14\.0 and earlier all\.\.\.

- **ID**: CVE\-2026\-126761
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-23

## 原文

Authorization bypass through user\-controlled key in the RDM folder duplication endpoint in Devolutions Server 2026\.3\.14\.0 and earlier allows an authenticated low\-privileged attacker to overwrite and move arbitrary vault entries and read their history via a client\-supplied entry identifier\.
