# PyTables is a Python package to manage extremely large amounts of data\.

- **ID**: CVE\-2026\-134019
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: Python
- **公開**: 2026-11-24

## 原文

PyTables is a Python package to manage extremely large amounts of data\. In 3\.11\.1 and earlier, tables/attributeset\.py treats a NumPy bytes scalar ending in a period as a pickled Python object and calls pickle\.loads\(\) when the attribute is accessed through AttributeSet\.\_\_getattr\_\_ or AttributeSet\.\_\_getitem\_\_\. Opening an attacker\-controlled HDF5 file and reading an affected metadata attribute can execute attacker\-controlled code in the consumer’s process\. No fixed version is available as of this review\.
