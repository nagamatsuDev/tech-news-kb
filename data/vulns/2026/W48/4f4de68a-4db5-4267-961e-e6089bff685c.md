# A vulnerability was found in Panabit Smart Application Gateway TANGr7p10\.

- **ID**: CVE\-2026\-135793
- **危険度**: Critical（緊急） (CVSS 9.9)
- **公開**: 2026-11-24

## 原文

A vulnerability was found in Panabit Smart Application Gateway TANGr7p10\. Impacted is the function import\_upgrde/upload\_modkey of the file /admin/cgi\-bin/sac/ajax\_sac\_ap of the component CGI Backend\. Performing a manipulation of the argument file/filename results in path traversal\. Remote exploitation of the attack is possible\. The exploit has been made public and could be used\. The vendor was contacted early about this disclosure but did not respond in any way\.
