# Hickory DNS hickory\-recursor 0\.25\.0\-alpha\.3 through 0\.25\.2 and hickory\-resolver 0\.26\.0\-alpha\.1 before 0\.26\.2 contains a query amplificati\.\.\.

- **ID**: CVE\-2026\-123586
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-08

## 原文

Hickory DNS hickory\-recursor 0\.25\.0\-alpha\.3 through 0\.25\.2 and hickory\-resolver 0\.26\.0\-alpha\.1 before 0\.26\.2 contains a query amplification vulnerability in its recursive resolver, which mishandles cyclic sibling name server referrals that lack glue records\. Attackers controlling two zones whose name servers reference each other without glue records can make the recursor loop, sending many upstream queries, amplified further by zero\-TTL NS records\.
