# TwigView FileLoader may allow arbitrary file reads through user\-controlled template paths

- **ID**: CVE\-2026\-59191 / GHSA\-hq9r\-72jq\-2pxp
- **危険度**: Medium（警告）
- **言語**: PHP
- **パッケージ**: Packagist/cakephp/twig\-view &lt; 1\.3\.3 → 1\.3\.3, Packagist/cakephp/twig\-view &gt;\= 2\.0\.0, &lt; 2\.1\.2 → 2\.1\.2
- **公開**: 2026-11-24

## 原文

\#\#\# Impact If \`FileLoader\:\:findTemplate\(\)\` is supplied un\-validated user controlled data, arbitrary files can be read\. \#\#\# Patches 1\.3\.3 and 2\.1\.2 contain a fix for this issue\. \#\#\# Workarounds Don't supply user controlled data to \`include\` and \`extends\` tags\.
