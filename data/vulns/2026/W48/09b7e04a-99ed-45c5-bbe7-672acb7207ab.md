# openIMIS before 2026\-10 contains a broken access control vulnerability in the FHIR R4 module that allows any authenticated attacker to de\.\.\.

- **ID**: CVE\-2026\-82495
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-25

## 原文

openIMIS before 2026\-10 contains a broken access control vulnerability in the FHIR R4 module that allows any authenticated attacker to delete Coverage policy records due to an empty permissions\_delete list being vacuously granted by user\.has\_perms\(\[\]\)\. Attackers can issue a DELETE request to the Coverage/&lt;uuid&gt;/ endpoint to permanently and irrecoverably remove insurance policy records\.
