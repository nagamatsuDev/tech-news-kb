# n8n before 1\.123\.96, 2\.x before 2\.47\.6, 2\.48\.x before 2\.48\.3, and 3\.x before 3\.2\.2 does not verify that the user activating a workflow ca\.\.\.

- **ID**: CVE\-2026\-137959
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-11-27

## 原文

n8n before 1\.123\.96, 2\.x before 2\.47\.6, 2\.48\.x before 2\.48\.3, and 3\.x before 3\.2\.2 does not verify that the user activating a workflow can access the credentials set on its trigger nodes\. An authenticated member who knows another user's credential ID can activate a workflow whose trigger uses it, causing n8n to create or delete webhooks on the connected service with that credential's privileges and deliver events from attacker\-chosen resources to the member's workflow\.
