# The Sneeit Framework plugin for WordPress is vulnerable to Remote Code Execution in versions up to, and including, 8\.7 via the 'callback'\.\.\.

- **ID**: CVE\-2026\-106125
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: PHP
- **公開**: 2026-11-27

## 原文

The Sneeit Framework plugin for WordPress is vulnerable to Remote Code Execution in versions up to, and including, 8\.7 via the 'callback' parameter of the sneeit\_compact\_menu\_mega\_content AJAX action\. The handler sneeit\_compact\_menu\_mega\_content\_callback\(\) is registered on the wp\_ajax\_nopriv\_ hook and passes the attacker\-supplied 'callback' value directly into call\_user\_func\(\) after only a function\_exists\(\) check, with the single argument also attacker\-controlled via a JSON\-decoded 'args' parameter\. There is no authentication, no capability check, no nonce, and no allow\-list of callable functions\. This makes it possible for unauthenticated attackers to execute arbitrary existing PHP/WordPress functions with controlled arguments\.
