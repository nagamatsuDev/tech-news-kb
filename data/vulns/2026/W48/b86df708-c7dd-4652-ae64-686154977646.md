# pgjdbc, the PostgreSQL JDBC Driver, can quote a string parameter for the wrong value of standard\_conforming\_strings when preferQueryMode\=\.\.\.

- **ID**: CVE\-2026\-134842
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-23

## 原文

pgjdbc, the PostgreSQL JDBC Driver, can quote a string parameter for the wrong value of standard\_conforming\_strings when preferQueryMode\=simple is set\. A statement, trigger or configuration reload can turn the setting off during a session\. A parameter value with a backslash and a quote then ends the literal, and the rest of the value runs as SQL\. Before 42\.7\.6 any session with the setting off was affected\. The statement cache can also reuse a parse made under the other setting\. With allowEncodingChanges\=true and the EUC\_JP or SJIS client encoding, the yen sign acts as a backslash\. All versions before 42\.7\.15 are affected, and 42\.7\.15 fixes the problem\.
