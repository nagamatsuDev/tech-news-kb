# InternLM LMDeploy 0\.9\.0 through 0\.18\.0 contains an unbounded resource allocation vulnerability in the DistServe proxy /distserve/connecti\.\.\.

- **ID**: CVE\-2026\-137657
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-26

## 原文

InternLM LMDeploy 0\.9\.0 through 0\.18\.0 contains an unbounded resource allocation vulnerability in the DistServe proxy /distserve/connection\_warmup endpoint that allows unauthenticated attackers to exhaust memory\. While a prefill/decode connection is pending, for example after registering a slow node via /nodes/add, repeated warmup requests spawn unbounded wait\_for\_conn\(\) tasks and sockets until the proxy process is killed\.
