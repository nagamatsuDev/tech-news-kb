# Crypto APIs MCP server packages \(@cryptoapis\-io/mcp\-\*\) before 0\.4\.0, mcp\-blockchain\-events, mcp\-blockchain\-fees, mcp\-broadcast and mcp\-pr\.\.\.

- **ID**: CVE\-2026\-138026
- **危険度**: High（重要） (CVSS 7.3)
- **公開**: 2026-11-27

## 原文

Crypto APIs MCP server packages \(@cryptoapis\-io/mcp\-\*\) before 0\.4\.0, mcp\-blockchain\-events, mcp\-blockchain\-fees, mcp\-broadcast and mcp\-prepare\-transactions before 0\.5\.0, and mcp\-aml before 0\.2\.0 contain a missing authentication vulnerability that allows unauthenticated network attackers to invoke tools using the operator's API key\. When started with Streamable HTTP transport and \-\-api\-key, the server binds 0\.0\.0\.0 and exposes /mcp, letting attackers consume paid credits, read account data, redirect event subscriptions, and delete HD wallet xPubs\.
