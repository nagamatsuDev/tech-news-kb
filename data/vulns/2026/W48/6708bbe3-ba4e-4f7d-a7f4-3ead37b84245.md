# Bazarr 1\.4\.4 before 1\.6\.1\-beta\.29 on Windows contains an unauthenticated path traversal vulnerability in the catch\_all\(\) handler in bazar\.\.\.

- **ID**: CVE\-2026\-137585
- **危険度**: High（重要） (CVSS 7.5)
- **OS**: Windows
- **公開**: 2026-11-26

## 原文

Bazarr 1\.4\.4 before 1\.6\.1\-beta\.29 on Windows contains an unauthenticated path traversal vulnerability in the catch\_all\(\) handler in bazarr/app/ui\.py\. Attackers can append percent\-encoded '\.\.' segments after the 'workbox\-' prefix to read files like config\.yaml containing stored API keys and credentials\.
