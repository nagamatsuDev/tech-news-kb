# A flaw was found in tuned\.

- **ID**: CVE\-2026\-137974
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-27

## 原文

A flaw was found in tuned\. This vulnerability allows local privilege escalation because the spindown\-disk profile script does not properly validate filesystem mount sources before executing remount operations with root privileges\. A local user capable of creating user\-space filesystems can craft a malicious mount entry to execute arbitrary commands as root\.
