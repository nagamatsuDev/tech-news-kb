# A flaw has been found in mealie\-recipes Mealie up to 3\.29\.0\.

- **ID**: CVE\-2026\-136134
- **危険度**: High（重要） (CVSS 7.3)
- **公開**: 2026-11-24

## 原文

A flaw has been found in mealie\-recipes Mealie up to 3\.29\.0\. Affected is the function get of the file mealie/pkgs/i18n/provider\_factory\.py of the component I18n Locale Provider\. Executing a manipulation of the argument Accept\-Language can lead to path traversal\. It is possible to launch the attack remotely\. The exploit has been published and may be used\. Upgrading to version 3\.30\.0 is able to address this issue\. This patch is called 4d074185d0dd1bb2dada7a4470bd04bd91227040\. It is advisable to upgrade the affected component\.
