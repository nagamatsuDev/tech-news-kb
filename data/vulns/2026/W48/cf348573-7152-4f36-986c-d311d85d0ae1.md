# Improper certificate validation in websocket connections in Canonical pylxd before 2\.4\.3 allows a network attacker to read command stdin \.\.\.

- **ID**: CVE\-2026\-127163
- **危険度**: Critical（緊急） (CVSS 9.1)
- **公開**: 2026-11-27
