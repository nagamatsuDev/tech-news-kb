# The GeoDirectory – WP Business Directory Plugin and Classified Listings Directory plugin for WordPress is vulnerable to Stored Cross\-Site\.\.\.

- **ID**: CVE\-2026\-127113
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-26

## 原文

The GeoDirectory – WP Business Directory Plugin and Classified Listings Directory plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'post\_content' parameter in all versions up to, and including, 2\.8\.205 due to insufficient input sanitization and output escaping\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\. Unauthenticated exploitation requires the plugin's "Allow posting without logging in" \(post\_logged\_out\) option to be enabled; on default installs the vulnerability is exploitable by Subscriber\-level users and above\.
