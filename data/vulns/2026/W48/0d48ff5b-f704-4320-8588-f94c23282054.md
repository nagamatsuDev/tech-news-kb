# Dell Secure Connect Gateway \(SCG\) Virtual Edition, versions prior to 5\.36\.00\.16, contains a Path Traversal vulnerability\.

- **危険度**: High（重要） (CVSS 7.3)
- **公開**: 2026-11-25

## 原文
