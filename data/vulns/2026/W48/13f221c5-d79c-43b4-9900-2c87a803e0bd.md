# FFmpeg 4\.3 before 9\.1 contains a heap out\-of\-bounds read and write vulnerability in the dynaudnorm filter because cqueue\_resize\(\) miscalc\.\.\.

- **ID**: CVE\-2026\-135743
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-24

## 原文

FFmpeg 4\.3 before 9\.1 contains a heap out\-of\-bounds read and write vulnerability in the dynaudnorm filter because cqueue\_resize\(\) miscalculates gain history queue element counts when gausssize changes at runtime\. Attackers can send gausssize commands via asendcmd scripts or an unauthenticated azmq filter to corrupt heap memory, crashing the process or potentially executing code\.
