# FFmpeg through 9\.0\.2 contains a heap buffer overflow vulnerability in libavcodec/exrenc\.c that allows attackers to corrupt heap memory wh\.\.\.

- **ID**: CVE\-2026\-125260
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-09

## 原文

FFmpeg through 9\.0\.2 contains a heap buffer overflow vulnerability in libavcodec/exrenc\.c that allows attackers to corrupt heap memory when encode\_scanline\_rle\(\) processes frames taller than the encoder height\. Attackers can supply crafted input whose resolution grows mid\-stream, transcoded to OpenEXR with RLE compression, to write pointers past the scanline array and crash the application\.
