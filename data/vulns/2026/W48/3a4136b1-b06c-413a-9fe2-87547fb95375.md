# Bagel \(bagel\-mcp\) before 2\.5\.5 contains an argument injection vulnerability in RsyncFilesToLocalDirectory that allows attackers to inject\.\.\.

- **ID**: CVE\-2026\-138028
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-27

## 原文

Bagel \(bagel\-mcp\) before 2\.5\.5 contains an argument injection vulnerability in RsyncFilesToLocalDirectory that allows attackers to inject rsync options because only \-\-quiet and \-\-log\-format values are rejected\. Attackers who influence the LLM through prompt\-injected content can trigger run\_pipeline with \-e/\-\-rsh or \-\-rsync\-path options to execute commands as the Bagel server process\.
