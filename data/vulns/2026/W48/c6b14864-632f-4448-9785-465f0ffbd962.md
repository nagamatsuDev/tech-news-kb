# FFmpeg before 8\.1\.3 and 9\.x before 9\.0\.2 contains a heap out\-of\-bounds write vulnerability in the APAC decoder in libavcodec/apac\.c cause\.\.\.

- **ID**: CVE\-2026\-125267
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-09

## 原文

FFmpeg before 8\.1\.3 and 9\.x before 9\.0\.2 contains a heap out\-of\-bounds write vulnerability in the APAC decoder in libavcodec/apac\.c caused by an unreset bitstream index\. Attackers can supply a crafted APAC file whose growing bitstream\_index triggers an integer overflow, bypassing the reallocation check so memcpy\(\) corrupts heap memory or crashes the application\.
