# Kestra before 1\.3\.36 contains a reflected cross\-site scripting vulnerability that allows unauthenticated attackers to execute JavaScript \.\.\.

- **ID**: CVE\-2026\-138119
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: JavaScript/TypeScript
- **公開**: 2026-11-28

## 原文

Kestra before 1\.3\.36 contains a reflected cross\-site scripting vulnerability that allows unauthenticated attackers to execute JavaScript by injecting HTML into the executions page sort parameter\. Attackers can lure logged\-in users to a crafted link whose invalid sort value is rendered unsanitized in an error toast, stealing the non\-HttpOnly BASIC\_AUTH credential cookie to take over the instance\.
