# ToolJet before 3\.21\.96\-LTS contains an authentication bypass in instance\-level Google SSO because the id\_token audience is not verified w\.\.\.

- **ID**: CVE\-2026\-137523
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-26

## 原文

ToolJet before 3\.21\.96\-LTS contains an authentication bypass in instance\-level Google SSO because the id\_token audience is not verified when no Google OAuth client ID is configured, the shipped default\. Unauthenticated attackers can submit a Google\-signed id\_token minted for their own OAuth client to /api/sso/sign\-in/common/google without an organizationId, obtaining a session as any existing user with the matching email\.
