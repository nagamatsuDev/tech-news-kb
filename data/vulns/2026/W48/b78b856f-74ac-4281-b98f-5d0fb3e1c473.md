# isomorphic\-git allows unbounded memory allocation from attacker\-controlled delta target size \(DoS\)

- **ID**: CVE\-2026\-63476 / GHSA\-9x82\-4j54\-863h
- **危険度**: Medium（警告） (CVSS 4.3)
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/isomorphic\-git &lt; 1\.38\.6 → 1\.38\.6
- **公開**: 2026-11-23

## 原文

\#\#\# Summary When applying a delta object from a packfile, isomorphic\-git reads a \*\*server\-controlled\*\* \`targetSize\` and calls \`Buffer\.alloc\(targetSize\)\` with no upper bound\. A single malicious HTTP response to \`git\.clone\(\)\`/\`git\.fetch\(\)\` can force a \~2 GB allocation → memory exhaustion / DoS \(process killed on memory\-constrained hosts\)\. \#\#\# Details \`src/utils/applyDelta\.js\`\: \`\`\`js const sourceSize \= readVarIntLE\(reader\) const targetSize \= readVarIntLE\(reader\) // attacker\-controlled … target \= Buffer\.alloc\(targetSize\) \`\`\` A pack with one \`OBJ\_REF\_DELTA\` whose header declares \`targetSize \= 0x7FF
