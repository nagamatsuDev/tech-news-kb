# In HandleEndTransaction of bearer\.cc, there is a possible use after free due to a missing check that the object still exists after a secu\.\.\.

- **ID**: CVE\-2026\-95444
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-23

## 原文

In HandleEndTransaction of bearer\.cc, there is a possible use after free due to a missing check that the object still exists after a security upgrade callback completes synchronously\. This could lead to remote \(proximal/adjacent\) code execution with no additional execution privileges needed\. User interaction is not needed for exploitation\.
