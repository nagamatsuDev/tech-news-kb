# OpenEMR before 8\.3\.0 contains an insecure direct object reference vulnerability in portal/lib/persist\.php that allows authenticated porta\.\.\.

- **ID**: CVE\-2026\-124453
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: PHP
- **公開**: 2026-11-08

## 原文

OpenEMR before 8\.3\.0 contains an insecure direct object reference vulnerability in portal/lib/persist\.php that allows authenticated portal patients to write settings for other patients\. Attackers can modify the setting\_patient parameter in a JSON POST request to another patient's PID, altering that patient's portal settings such as the portal theme\.
