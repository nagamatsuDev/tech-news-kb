# ToolJet before 3\.21\.96\-LTS contains an authorization bypass in the internal database \(TJDB\) PostgREST proxy, which grants proxy access to\.\.\.

- **ID**: CVE\-2026\-137526
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-26

## 原文

ToolJet before 3\.21\.96\-LTS contains an authorization bypass in the internal database \(TJDB\) PostgREST proxy, which grants proxy access to every logged\-in user and derives the database role and schema from the client\-supplied tj\-workspace\-id header\. Any authenticated workspace member can send requests to /api/tooljet\-db/proxy/&lt;tableId&gt; to read and modify TJDB tables, bypassing app, query, and table permissions, and in SQL\-mode\-disabled \(Cloud\) deployments can access all tenants' tables\.
