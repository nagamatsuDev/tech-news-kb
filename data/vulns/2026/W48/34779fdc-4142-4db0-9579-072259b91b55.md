# A security flaw has been discovered in Tenda RX3 16\.03\.13\.11\_multi\.

- **ID**: CVE\-2026\-136549
- **危険度**: Critical（緊急） (CVSS 10.0)
- **公開**: 2026-11-25

## 原文

A security flaw has been discovered in Tenda RX3 16\.03\.13\.11\_multi\. The impacted element is the function formSetSafeWanWebMan of the file /goform/SetRemoteWebCfg\. The manipulation of the argument remoteIp results in command injection\. The attack can be executed remotely\. The exploit has been released to the public and may be used for attacks\.
