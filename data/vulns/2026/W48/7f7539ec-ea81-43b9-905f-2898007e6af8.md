# llama\.cpp b11450 before b12658 contains an out\-of\-bounds write vulnerability in the ggml RPC server that allows unauthenticated attackers\.\.\.

- **ID**: CVE\-2026\-137567
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-26

## 原文

llama\.cpp b11450 before b12658 contains an out\-of\-bounds write vulnerability in the ggml RPC server that allows unauthenticated attackers to write to arbitrary heap addresses via zero\-element destination tensors\. Attackers can learn buffer bases with BUFFER\_GET\_BASE, then send RPC\_CMD\_COPY\_TENSOR with a destination pointer below the buffer base to crash the server or execute code\.
