# pgjdbc, the PostgreSQL JDBC Driver, uses unqualified operators and functions in the catalog queries of DatabaseMetaData, ResultSetMetaDat\.\.\.

- **ID**: CVE\-2026\-134844
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-23

## 原文

pgjdbc, the PostgreSQL JDBC Driver, uses unqualified operators and functions in the catalog queries of DatabaseMetaData, ResultSetMetaData and TypeInfoCache\. A role with CREATE on a schema of the application's search\_path can add an operator with an exact type match, and the server runs it with the privileges of the application's role\. TypeInfoCache also resolves an unqualified type name such as interval by its own ranking\. A domain with that name in another schema, even the temporary schema of another session, can be used instead, and its CHECK runs in the application's session\. All versions before 42\.7\.15 are affected, and 42\.7\.15 fixes the problem\.
