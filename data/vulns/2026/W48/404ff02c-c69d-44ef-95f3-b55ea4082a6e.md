# OpenEMR before 8\.3\.0 contains missing authorization and insecure direct object reference vulnerabilities in the oe\-module\-prior\-authoriza\.\.\.

- **ID**: CVE\-2026\-124456
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: PHP
- **公開**: 2026-11-08

## 原文

OpenEMR before 8\.3\.0 contains missing authorization and insecure direct object reference vulnerabilities in the oe\-module\-prior\-authorizations module that allow authenticated low\-privilege users to access and modify other patients' records\. Attackers can request public/reports/list\_report\.php to view all patients' names, MRNs, insurance and prior\-auth data, or submit arbitrary id values to public/index\.php to overwrite other patients' prior\-authorization records\.
