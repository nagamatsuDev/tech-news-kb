# borg\-ui before 2\.4\.1 contains a privilege escalation vulnerability that allows a repository\-scoped operator to escalate to full administr\.\.\.

- **ID**: CVE\-2026\-136455
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-24

## 原文

borg\-ui before 2\.4\.1 contains a privilege escalation vulnerability that allows a repository\-scoped operator to escalate to full administrator by exploiting an unrestricted source\_directories field in the backup\-plan API that lacks path allow\-listing\. Attackers can configure a backup plan to archive the application's data directory, download the resulting archive to extract the static HS256 \.secret\_key, and use it to forge a JWT with sub"\:"admin" to access admin\-only endpoints like GET /api/auth/users, achieving full application takeover without admin credentials, XSS, or CSRF\.
