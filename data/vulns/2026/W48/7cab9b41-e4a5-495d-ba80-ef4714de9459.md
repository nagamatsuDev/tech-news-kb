# Webmin through 2\.670 contains an improper certificate validation vulnerability in the http\_download function of web\-lib\-funcs\.pl that ski\.\.\.

- **ID**: CVE\-2026\-134283
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-25

## 原文

Webmin through 2\.670 contains an improper certificate validation vulnerability in the http\_download function of web\-lib\-funcs\.pl that skips TLS chain and hostname verification\. Man\-in\-the\-middle attackers can present any certificate and substitute downloaded modules, themes, or catalog content, leading to root code execution or injected HTML\.
