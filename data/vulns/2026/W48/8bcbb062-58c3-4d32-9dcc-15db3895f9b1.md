# Gogs before 0\.14\.4 on Windows contains a path equivalence vulnerability in isRepositoryGitPath that allows authenticated users with write\.\.\.

- **ID**: CVE\-2026\-134808
- **危険度**: High（重要） (CVSS 7.5)
- **OS**: Windows
- **公開**: 2026-11-22

## 原文

Gogs before 0\.14\.4 on Windows contains a path equivalence vulnerability in isRepositoryGitPath that allows authenticated users with write access to bypass \.git directory protection using NTFS aliases\. Attackers can create, rename or upload files via aliases like git\~1 or \.git\:\:\$INDEX\_ALLOCATION to overwrite \.git/config or hooks and execute commands as the Gogs process\.
