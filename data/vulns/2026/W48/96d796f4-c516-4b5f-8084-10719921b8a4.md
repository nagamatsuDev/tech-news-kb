## 原文

A weakness has been identified in TOTOLINK A7100RU 7\.4cu\.2313\_B20191024\. This issue affects the function exportOvpn of the file /cgi\-bin/cstecgi\.cgi of the component CGI Handler\. This manipulation of the argument Username causes os command injection\. The attack is possible to be carried out remotely\.
