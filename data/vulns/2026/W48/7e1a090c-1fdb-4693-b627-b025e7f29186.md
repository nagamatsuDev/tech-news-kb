# lastversion before 3\.6\.20 contains a path traversal vulnerability in extract\_tar\(\) that allows attackers to write files outside the extra\.\.\.

- **ID**: CVE\-2026\-137539
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-26

## 原文

lastversion before 3\.6\.20 contains a path traversal vulnerability in extract\_tar\(\) that allows attackers to write files outside the extraction directory via tar symlink members\. Attackers controlling a project's release assets can craft a tarball with a symlink followed by a file beneath it, writing files like usercustomize\.py to achieve code execution\.
