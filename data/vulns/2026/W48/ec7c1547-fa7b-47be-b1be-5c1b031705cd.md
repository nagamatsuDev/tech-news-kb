# Vates Xen Orchestra Improper Validation of Specified Type of Input Vulnerability

- **ID**: CVE\-2026\-133469 / GHSA\-2r3w\-c2vx\-fv5g
- **危険度**: Critical（緊急） (CVSS 9.8) / 🔥 悪用確認 (CISA KEV)
- **公開**: 2026-11-23

## 原文

XO \(Xen Orchestra\) is a solution to visualize, manage, backup and delegate your XCP\-ng \(or XenServer\) infrastructure\. Prior to 6\.9\.2 and 6\.10\.1, REST cookie parsing turns authenticationToken\=j\:%7B%7D into \{\}\. REST authentication passes that object to the XO token provider without requiring a string\. The token collection treats \{\} as an unfiltered lookup and returns its first token; the provider authenticates as that token's owner if it is unexpired\. The authenticated /rest/v0/users/me/authentication\_tokens route then returns reusable login token IDs\. This vulnerability is actively exploited in the wild\. This vulnerability is fixed in 6\.9\.2 and 6\.10\.1\.
