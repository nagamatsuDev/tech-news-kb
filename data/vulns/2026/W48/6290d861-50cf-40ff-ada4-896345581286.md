# A vulnerability has been found in Panabit Smart Application Gateway TANGr7p10\.

- **ID**: CVE\-2026\-135792
- **危険度**: Critical（緊急） (CVSS 10.0)
- **公開**: 2026-11-24

## 原文

A vulnerability has been found in Panabit Smart Application Gateway TANGr7p10\. This issue affects the function send\_email\_authcode of the file user\.cgi of the component Email Auth Code Sender\. Such manipulation of the argument Username leads to os command injection\. The attack may be launched remotely\. The exploit has been disclosed to the public and may be used\. The vendor was contacted early about this disclosure but did not respond in any way\.
