# openIMIS before 2026\-10 contains a missing authorization vulnerability in the OpenSearch reporting dashboard proxy, where the nginx auth\_\.\.\.

- **ID**: CVE\-2026\-82490
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-25

## 原文

openIMIS before 2026\-10 contains a missing authorization vulnerability in the OpenSearch reporting dashboard proxy, where the nginx auth\_request only verifies login status without checking the declared right before attaching a hardcoded administrative credential to the proxied request, and the backend OpenSearch cluster has its security plugin disabled via a hardcoded compose setting\. Any authenticated account, including self\-registered or zero\-rights users, can exploit this flaw to gain read, write, and delete access to the OpenSearch cluster\.
