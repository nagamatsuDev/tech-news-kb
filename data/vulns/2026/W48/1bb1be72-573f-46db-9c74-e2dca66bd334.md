# fulgur allows Unbounded string\-set value accumulation causes memory/CPU exhaustion \(denial of service\)

- **ID**: CVE\-2026\-68539 / GHSA\-vw2v\-g4x7\-xcqg
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: Rust
- **パッケージ**: crates\.io/fulgur &gt;\= 0\.4\.4, &lt; 0\.28\.0 → 0\.28\.0
- **公開**: 2026-11-25

## 原文

\`fulgur\` converts untrusted HTML/CSS into PDF, commonly on a server that processes input supplied by many tenants\. In versions from 0\.4\.4 up to \(but not including\) the patched release, the CSS \`string\-set\` named\-string values resolved from a document were accumulated per element with no memory budget, letting a small crafted document amplify into large retained memory \(and the CPU to copy it\) — a denial of service\. A \`string\-set\` value is attacker\-controlled\: it is resolved from an element's own text \(\`content\(text\)\`\), from one of its attributes \(\`attr\(\.\.\.\)\`\), or from a CSS string literal\. ful
