# Deserialization of Untrusted Data vulnerability in lasp\-lang partisan allows an unauthenticated remote attacker to abort the Erlang VM of\.\.\.

- **ID**: CVE\-2026\-118898
- **危険度**: High（重要） (CVSS 8.7)
- **公開**: 2026-11-25

## 原文

Deserialization of Untrusted Data vulnerability in lasp\-lang partisan allows an unauthenticated remote attacker to abort the Erlang VM of a node via Excessive Allocation\. partisan\_peer\_service\_server\:handle\_info/2 decodes every frame that arrives on the peer listener with binary\_to\_term/1, without the safe option, before handle\_inbound/2 interprets the message and before any peer authentication takes place\. TLS is off by default and the listener accepts connections from any host, so one frame that names more atoms than the atom table holds aborts the VM\. partisan\_peer\_service\_client\:handle\_info/2 decodes frames from the server side of a connection the same way\.
  
The decode also materializes funs, ports and references the frame encodes and inflates compressed terms\. The demonstrated impact is denial of service\. partisan does not invoke decoded funs, so code execution was not shown\.
  
This issue affects partisan\: from 3\.0\.0 before 6\.4\.0\.
