# Sandbox protection in Jenkins Pipeline\: Groovy Plugin 4403\.v471713a\_cea\_19 and earlier can be circumvented through interface field initia\.\.\.

- **ID**: CVE\-2026\-136834
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-25

## 原文

Sandbox protection in Jenkins Pipeline\: Groovy Plugin 4403\.v471713a\_cea\_19 and earlier can be circumvented through interface field initializers, allowing attackers with permission to define and run sandboxed Pipelines to bypass the sandbox protection and execute arbitrary code in the context of the Jenkins controller JVM\.
