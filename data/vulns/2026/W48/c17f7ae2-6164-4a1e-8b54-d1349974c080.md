# vedo through 2026\.6\.3 contains an insecure deserialization vulnerability that allows attackers to execute code by supplying crafted \.npy \.\.\.

- **ID**: CVE\-2026\-136167
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-24

## 原文

vedo through 2026\.6\.3 contains an insecure deserialization vulnerability that allows attackers to execute code by supplying crafted \.npy or \.npz files loaded with allow\_pickle\=True\. Attackers can embed an object with a malicious \_\_reduce\_\_ method in mesh, assembly, scene or font files to run code with the victim's privileges when opened\.
