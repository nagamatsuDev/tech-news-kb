# Schmitech ORBIT before 2\.17\.15 contains an improper authorization vulnerability in the permission\_or\_api\_key dependency that allows any v\.\.\.

- **ID**: CVE\-2026\-136189
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-24

## 原文

Schmitech ORBIT before 2\.17\.15 contains an improper authorization vulnerability in the permission\_or\_api\_key dependency that allows any valid API key to access /admin management routes\. Attackers holding a chat inference API key can read other keys in plaintext, rewrite config\.yaml, and manage adapters and prompts to take over server administration\.
