# FFmpeg through 9\.0\.2 contains a heap buffer overflow vulnerability in liboapve\_encode\(\) in libavcodec/liboapvenc\.c that allows attackers \.\.\.

- **ID**: CVE\-2026\-125196
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-09

## 原文

FFmpeg through 9\.0\.2 contains a heap buffer overflow vulnerability in liboapve\_encode\(\) in libavcodec/liboapvenc\.c that allows attackers to corrupt heap memory by supplying frames larger than the configured encoder dimensions\. Attackers can craft videos whose resolution changes mid\-stream so that transcoding to APV without rescaling writes attacker\-controlled pixel data past the imgb plane buffers\.
