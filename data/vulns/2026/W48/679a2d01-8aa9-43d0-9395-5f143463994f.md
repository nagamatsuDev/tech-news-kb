# LiteLLM Pass\-Through Endpoint Code Injection Remote Code Execution Vulnerability\.

- **ID**: CVE\-2026\-136539
- **危険度**: High（重要） (CVSS 7.2)
- **公開**: 2026-11-24

## 原文

LiteLLM Pass\-Through Endpoint Code Injection Remote Code Execution Vulnerability\. This vulnerability allows remote attackers to execute arbitrary code on affected installations of LiteLLM\. Authentication is required to exploit this vulnerability\.
  
The specific flaw exists within the handling of pass\_through\_endpoints\. The issue results from the lack of proper validation of code before it is executed via module import\. An attacker can leverage this vulnerability to execute code in the context of the service account\. Was ZDI\-CAN\-31433\.
