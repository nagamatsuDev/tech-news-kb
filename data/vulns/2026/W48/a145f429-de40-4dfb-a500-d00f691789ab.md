# Deserialization of Untrusted Data vulnerability in woylie flop allows a remote attacker to execute code on the server via a crafted pagin\.\.\.

- **ID**: CVE\-2026\-130411
- **危険度**: Critical（緊急） (CVSS 9.2)
- **公開**: 2026-11-24

## 原文

Deserialization of Untrusted Data vulnerability in woylie flop allows a remote attacker to execute code on the server via a crafted pagination cursor\.
  
Flop\.Cursor\.decode/2 in lib/flop/cursor\.ex decodes the after and before parameters with \:erlang\.binary\_to\_term/2 in \:safe mode\. Its check rejects functions, PIDs, ports and references, but it accepts maps, and therefore structs of any module\. Flop passes the decoded values to Ecto as query parameters\. A cursor value that nests an Ecto\.Query\.DynamicExpr struct with a DBConnection\.Stream struct as its binding fails the Ecto cast\. Ecto then inspects the value for the error message, the Inspect implementation enumerates the stream, and DBConnection calls the module, function and arguments in the \:log option of the stream\.
  
This issue affects flop\: from 0\.8\.0 before 0\.26\.7, from 0\.27\.0 before 0\.27\.3, from 0\.28\.0 before 0\.28\.1, and from 0\.29\.0 before 0\.29\.2\.
