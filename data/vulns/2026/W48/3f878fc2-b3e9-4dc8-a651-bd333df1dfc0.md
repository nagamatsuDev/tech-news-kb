# The CubeWP Forms plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'cwp\_custom\_form\[form\_data\_id\]' parameter in a\.\.\.

- **ID**: CVE\-2026\-131806
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-26

## 原文

The CubeWP Forms plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'cwp\_custom\_form\[form\_data\_id\]' parameter in all versions up to, and including, 1\.1\.13 due to insufficient input sanitization and output escaping\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\. The nonce required by the submission handler is publicly emitted in the inline script data of any page rendering the cwpCustomForm shortcode, making it trivially obtainable by unauthenticated visitors and rendering the nonce check ineffective as an authentication barrier\.
