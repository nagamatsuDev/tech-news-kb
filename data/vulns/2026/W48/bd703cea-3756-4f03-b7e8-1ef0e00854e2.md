# Gammu before 1\.45\.2 contains a heap\-based buffer overflow in ReadWAPSettingsEntry\(\) that allows attackers to corrupt heap memory via craf\.\.\.

- **ID**: CVE\-2026\-138163
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-28

## 原文

Gammu before 1\.45\.2 contains a heap\-based buffer overflow in ReadWAPSettingsEntry\(\) that allows attackers to corrupt heap memory via crafted backup files with excess WAP or MMS settings entries\. Attackers can supply a backup with more than four TitleNN keys in a \[WAPSettings\] or \[MMSSettings\] section, loaded via convertbackup, restore, or GSM\_ReadBackupFile, causing crashes or potential code execution\.
