# Improper access control of a file path in TXOne StellarProtect and Stellar Agent \(Windows\) allows a local attacker to write or overwrite \.\.\.

- **ID**: CVE\-2026\-77670
- **危険度**: High（重要） (CVSS 7.1)
- **OS**: Windows
- **公開**: 2026-11-24

## 原文

Improper access control of a file path in TXOne StellarProtect and Stellar Agent \(Windows\) allows a local attacker to write or overwrite arbitrary files with SYSTEM privileges\. This issue affects StellarProtect\: 3\.3 and earlier; Stellar Agent \(Windows\)\: before 5\.0\.3056\. \*Note\: Stellar Agent \(Windows\) is the new name for StellarProtect\.
