# Assimp through 6\.0\.6 contains an out\-of\-bounds write vulnerability in glTFAsset\.inl that allows attackers to corrupt memory via oversized\.\.\.

- **ID**: CVE\-2026\-134861
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-22

## 原文

Assimp through 6\.0\.6 contains an out\-of\-bounds write vulnerability in glTFAsset\.inl that allows attackers to corrupt memory via oversized glTF 1\.0 accessor elements\. Attackers can supply a crafted glTF 1\.0 file with VEC4 position or VEC3 index accessors to overflow heap or stack buffers during import, crashing applications\.
