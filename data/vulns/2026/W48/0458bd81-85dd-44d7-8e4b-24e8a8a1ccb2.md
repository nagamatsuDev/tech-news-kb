# SiYuan from 3\.8\.0 before 3\.8\.11 contains a lockout bypass vulnerability that allows remote attackers to brute\-force publish passwords by \.\.\.

- **ID**: CVE\-2026\-137468
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-26

## 原文

SiYuan from 3\.8\.0 before 3\.8\.11 contains a lockout bypass vulnerability that allows remote attackers to brute\-force publish passwords by forging client\-computable publish\-auth\-&lt;ID&gt; cookies\. Attackers can compute SHA\-256\(ID \+ candidate\) locally and send it on content requests like /api/filetree/getDoc to guess passwords without throttling and read protected documents\.
