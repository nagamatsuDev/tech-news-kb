# OpenEMR before 8\.4\.0 contains a local file inclusion in the ESign router \(library/ESign/Router\.php\), which passes the unsanitized module \.\.\.

- **ID**: CVE\-2026\-124467
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-08

## 原文

OpenEMR before 8\.4\.0 contains a local file inclusion in the ESign router \(library/ESign/Router\.php\), which passes the unsanitized module parameter into a require\_once of '&lt;module&gt;/Controller\.php', and the fax module's faxProcessUploads writes attacker\-named files to a predictable temp path without extension checks\. Authenticated attackers can upload a PHP file named Controller\.php, then request interface/esign/index\.php with a traversing module parameter to include it and execute arbitrary code\.
