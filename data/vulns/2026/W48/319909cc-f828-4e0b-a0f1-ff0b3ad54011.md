# ToolJet before 3\.21\.96\-LTS contains a command injection vulnerability in its GitHub Actions release workflow, which interpolates the pull\.\.\.

- **ID**: CVE\-2026\-137964
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-27

## 原文

ToolJet before 3\.21\.96\-LTS contains a command injection vulnerability in its GitHub Actions release workflow, which interpolates the pull request title directly into a shell run block\. Attackers can submit a pull request against a release branch with shell metacharacters in its title that, once merged, executes commands with a cross\-repository GITHUB\_TOKEN, enabling unauthorized merges into enterprise repositories\.
