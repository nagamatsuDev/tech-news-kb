# LaraDashboard before 1\.5\.2 contains an information disclosure vulnerability in SettingObserver that writes full Setting models, including\.\.\.

- **ID**: CVE\-2026\-137542
- **危険度**: High（重要） (CVSS 7.7)
- **公開**: 2026-11-26

## 原文

LaraDashboard before 1\.5\.2 contains an information disclosure vulnerability in SettingObserver that writes full Setting models, including plaintext secret option\_value fields, into the action\_logs table\. Users holding only actionlog\.view can read API keys, SMTP passwords, and OAuth client secrets through the action log API without settings permissions\.
