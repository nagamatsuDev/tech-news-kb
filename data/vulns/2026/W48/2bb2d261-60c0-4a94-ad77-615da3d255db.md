# WPC Product Options for WooCommerce before 4\.0\.9 contains a price manipulation vulnerability that allows unauthenticated attackers to pur\.\.\.

- **ID**: CVE\-2026\-135470
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-23

## 原文

WPC Product Options for WooCommerce before 4\.0\.9 contains a price manipulation vulnerability that allows unauthenticated attackers to purchase products at an arbitrary price by submitting crafted wpcpo\-\* option data with a negative price in an add\-to\-cart request\. Attackers can exploit the add\_cart\_item\_data\(\) function in includes/class\-cart\.php, which stores client\-supplied price values without validation and carries them into the order total via before\_calculate\_totals\(\), to checkout products at zero or arbitrary cost\.
