# Cakephp twig\-view unserialize Twig filter allows arbitrary object deserialization

- **ID**: CVE\-2026\-59192 / GHSA\-48qj\-5wxh\-m8hc
- **危険度**: Medium（警告）
- **言語**: PHP
- **パッケージ**: Packagist/cakephp/twig\-view &lt; 1\.3\.3 → 1\.3\.3, Packagist/cakephp/twig\-view &gt;\= 2\.0\.0, &lt; 2\.1\.2 → 2\.1\.2
- **公開**: 2026-11-24

## 原文

\#\#\# Impact The \`unserialize\` filter has no restriction on which classes are allowed\. This can be used as a deserialization remote\-code\-execution gadget\. \#\#\# Patches 1\.3\.3 and 2\.1\.2 contain a fix for this issue\. The fix may impact backwards compatibility if you are relying on deserializing PHP objects in your templates\. \#\#\# Workarounds Don't use the \`unserialize\` filter\.
