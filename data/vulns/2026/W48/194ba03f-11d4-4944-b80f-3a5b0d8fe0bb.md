# FreeRDP before 3\.33\.0 contains a race condition in asynchronous RDPDR IRP processing that allows malicious RDP servers to leak client mem\.\.\.

- **ID**: CVE\-2026\-137452
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-26

## 原文

FreeRDP before 3\.33\.0 contains a race condition in asynchronous RDPDR IRP processing that allows malicious RDP servers to leak client memory through non\-atomic wStream reference count updates\. Attackers can send repeated IRPs, such as smartcard redirection requests, so concurrent Stream\_Release\(\) calls lose decrements and accumulate unreleased streams, exhausting memory and causing denial of service\.
