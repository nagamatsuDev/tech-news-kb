# FreeRDP before 3\.33\.0 contains a heap out\-of\-bounds write in h264\_context\_reset\(\) in libfreerdp/codec/h264\.c, which stores new dimensions\.\.\.

- **ID**: CVE\-2026\-137077
- **危険度**: High（重要） (CVSS 7.4)
- **公開**: 2026-11-25

## 原文

FreeRDP before 3\.33\.0 contains a heap out\-of\-bounds write in h264\_context\_reset\(\) in libfreerdp/codec/h264\.c, which stores new dimensions before the YUV planes are reallocated\. Remote peers can trigger surface height increases so avc420\_compress\(\) writes taller frames past undersized luma and chroma planes, corrupting heap memory or crashing the process\.
