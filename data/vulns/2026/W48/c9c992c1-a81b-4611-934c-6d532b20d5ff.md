# The Music Player for WooCommerce plugin for WordPress is vulnerable to Directory Traversal in all versions up to, and including, 1\.9\.4 vi\.\.\.

- **ID**: CVE\-2026\-135266
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-26

## 原文

The Music Player for WooCommerce plugin for WordPress is vulnerable to Directory Traversal in all versions up to, and including, 1\.9\.4 via the '\_downloadable\_files' parameter parameter\. This makes it possible for unauthenticated attackers to read the contents of arbitrary files on the server, which can contain sensitive information\. Staging the attack requires storing a crafted downloadable file URL against a product, which requires the edit\_products capability \(Shop Manager or above\); however, triggering the file read via the ?wcmp\-action\=play handler is fully unauthenticated once the crafted URL is saved to a published product\.
