# A security vulnerability has been detected in Tenda RX3 16\.03\.13\.11\_multi\.

- **ID**: CVE\-2026\-136552
- **危険度**: Critical（緊急） (CVSS 9.1)
- **公開**: 2026-11-25

## 原文

A security vulnerability has been detected in Tenda RX3 16\.03\.13\.11\_multi\. This impacts the function formSetIPv6status of the file /goform/setIPv6Status of the component multiWAN\. Such manipulation of the argument remoteIP leads to command injection\. The attack may be performed from remote\. The exploit has been disclosed publicly and may be used\.
