# ChargePoint Home Flex wpa\_passphrase Command Injection Remote Code Execution Vulnerability\.

- **ID**: CVE\-2026\-131817
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-25

## 原文

ChargePoint Home Flex wpa\_passphrase Command Injection Remote Code Execution Vulnerability\. This vulnerability allows network\-adjacent attackers to execute arbitrary code on affected installations of ChargePoint Home Flex EV chargers\. Authentication is not required to exploit this vulnerability\.
  
The specific flaw exists within the PSK parameter passed to the wpa\_passphrase endpoint\. The issue results from the lack of proper validation of a user\-supplied string before using it to execute a system call\. An attacker can leverage this vulnerability to execute arbitrary code in the context of root\. Was ZDI\-CAN\-29000\.
