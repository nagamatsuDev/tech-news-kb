# HCIPy through 0\.7\.1 contains an insecure deserialization vulnerability that allows attackers to execute code by supplying crafted \.pkl fi\.\.\.

- **ID**: CVE\-2026\-137997
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-27

## 原文

HCIPy through 0\.7\.1 contains an insecure deserialization vulnerability that allows attackers to execute code by supplying crafted \.pkl files to read\_field, read\_grid or read\_mode\_basis\. Because hcipy/util/io\.py selects pickle by file extension and calls pickle\.load, a \_\_reduce\_\_ gadget in a pupil, apodizer, PSF or mode\-basis file runs code with the user's privileges\.
