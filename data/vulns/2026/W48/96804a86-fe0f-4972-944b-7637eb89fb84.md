# POSTAL 2 before build 26810491 contains a sandbox escape vulnerability that allows malicious Steam Workshop mods to execute code by calli\.\.\.

- **ID**: CVE\-2026\-138154
- **危険度**: High（重要） (CVSS 8.6)
- **OS**: Windows
- **公開**: 2026-11-28

## 原文

POSTAL 2 before build 26810491 contains a sandbox escape vulnerability that allows malicious Steam Workshop mods to execute code by calling ConsoleCommand with a start file URI\. Attackers can ship a batch file in a mod at the predictable workshop install path and launch it via ShellExecuteW, executing commands as the player on Windows\.
