# FFmpeg before 9\.1 contains a stack\-based buffer overflow vulnerability in ff\_rtmp\_packet\_write\(\) in libavformat/rtmppkt\.c that allows mal\.\.\.

- **ID**: CVE\-2026\-135725
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-24

## 原文

FFmpeg before 9\.1 contains a stack\-based buffer overflow vulnerability in ff\_rtmp\_packet\_write\(\) in libavformat/rtmppkt\.c that allows malicious RTMP servers to overflow a 16\-byte header buffer\. Attackers can send a Set Chunk Size packet on a high channel id with an extended timestamp, which handle\_chunk\_size\(\) echoes back, corrupting the publishing client's stack\.
