# Ettercap before 0\.8\.5\.1 contains an out\-of\-bounds read and size\_t underflow vulnerability in sslw\_remove\_sts\(\) in src/ec\_sslwrap\.c, cause\.\.\.

- **ID**: CVE\-2026\-125403
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-10

## 原文

Ettercap before 0\.8\.5\.1 contains an out\-of\-bounds read and size\_t underflow vulnerability in sslw\_remove\_sts\(\) in src/ec\_sslwrap\.c, caused by a stale length and an unchecked memmem\(\) result when stripping Strict\-Transport\-Security headers\. A malicious HTTPS server whose response passes through Ettercap's SSL interception can trigger out\-of\-bounds reads and memory corruption in the Ettercap process, which normally runs as root\.
