# The Warehouse Cargo theme for WordPress is vulnerable to Arbitrary File Upload in versions up to, and including, 2\.7\.4 via the warehouse\_\.\.\.

- **ID**: CVE\-2026\-76075
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-26

## 原文

The Warehouse Cargo theme for WordPress is vulnerable to Arbitrary File Upload in versions up to, and including, 2\.7\.4 via the warehouse\_cargo\_install\_and\_activate\_plugin\(\) AJAX handler\. The handler is registered on wp\_ajax\_ but performs no nonce verification and no capability check, allowing any authenticated user to supply an attacker\-controlled URL that the server fetches, writes into wp\-content/plugins/ with file\_put\_contents\(\), extracts with unzip\_file\(\) \(which does not filter file extensions\), and then activates via activate\_plugin\(\)\. This makes it possible for authenticated attackers, with Subscriber\-level access and above, to upload arbitrary files on the affected site's server which makes remote code execution possible\.
