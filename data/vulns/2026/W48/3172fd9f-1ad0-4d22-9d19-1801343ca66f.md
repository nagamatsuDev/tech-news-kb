# SurrealDB before 4\.0\.0 contains an authorization bypass vulnerability that allows restricted subjects to execute arbitrary queries by cal\.\.\.

- **ID**: CVE\-2026\-137490
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: JavaScript/TypeScript
- **公開**: 2026-11-26

## 原文

SurrealDB before 4\.0\.0 contains an authorization bypass vulnerability that allows restricted subjects to execute arbitrary queries by calling the JavaScript surrealdb\.query\(\) bridge\. Attackers permitted to run a specific script can bypass the Capabilities\:\:allows\_query\(\) gate in the query module to execute unrestricted queries beyond their predefined operations\.
