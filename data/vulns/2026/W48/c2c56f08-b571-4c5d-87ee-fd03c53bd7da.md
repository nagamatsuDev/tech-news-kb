# Interstellar before 6\.3\.0 contains a server\-side request forgery vulnerability that allows unauthenticated attackers to reach internal se\.\.\.

- **ID**: CVE\-2026\-135161
- **危険度**: High（重要） (CVSS 8.6)
- **公開**: 2026-11-23

## 原文

Interstellar before 6\.3\.0 contains a server\-side request forgery vulnerability that allows unauthenticated attackers to reach internal services by enabling allow\_loopback\_ips and allow\_private\_ips in wisp\-js at startup\. Attackers can open a wisp WebSocket that bypasses the Express password middleware and create TCP streams to loopback, internal hosts, or cloud metadata services\.
