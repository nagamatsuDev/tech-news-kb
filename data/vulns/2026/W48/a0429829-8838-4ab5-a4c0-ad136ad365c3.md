# dsniff through 2\.5a2 contains an integer underflow in decode\_sniffer\(\) in decode\_sniffer\.c that allows unauthenticated remote attackers t\.\.\.

- **ID**: CVE\-2026\-134753
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-22

## 原文

dsniff through 2\.5a2 contains an integer underflow in decode\_sniffer\(\) in decode\_sniffer\.c that allows unauthenticated remote attackers to write past the global obuf buffer\. Attackers can send a UDP datagram to port 2001 on a monitored segment with a 4096\-byte string, disabling base64\_pton bounds checks to corrupt memory and crash dsniff\.
