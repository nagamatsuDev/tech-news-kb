# openIMIS before 2026\-10 contains an improper validation vulnerability in the deduplication service \(openimis\-be\-deduplication\_py, dedupli\.\.\.

- **ID**: CVE\-2026\-82492
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-25

## 原文

openIMIS before 2026\-10 contains an improper validation vulnerability in the deduplication service \(openimis\-be\-deduplication\_py, deduplication/services\.py\) that allows a caller holding only the narrow right 170001 to bypass column path validation by exploiting the fact that only the first segment of a dotted relation path is checked before the full unvalidated path is used in the query\. Attackers can supply a crafted dotted column path such as user\_created\_\_i\_user\_\_private\_key to traverse relations and retrieve an administrator's JWT signing key, enabling forgery of a valid administrator session without a password that survives password resets and generates no failed\-login event\.
