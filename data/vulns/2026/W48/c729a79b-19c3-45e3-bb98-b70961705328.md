# FFmpeg 7\.1 before 9\.1 contains an out\-of\-bounds read vulnerability in libavfilter/vf\_scale\.c that allows attackers to read past the filte\.\.\.

- **ID**: CVE\-2026\-135739
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-11-24

## 原文

FFmpeg 7\.1 before 9\.1 contains an out\-of\-bounds read vulnerability in libavfilter/vf\_scale\.c that allows attackers to read past the filter input array by sending width or height commands using ref variables\. Attackers can send such commands via sendcmd scripts or unauthenticated zmq or azmq filters, causing config\_props\(\) to dereference an invalid pointer and crash the process\.
