# A vulnerability was found in projectworlds Online Jewellery Shopping System 1\.0\.

- **危険度**: High（重要） (CVSS 7.3)
- **言語**: PHP
- **公開**: 2026-11-26

## 原文

A vulnerability was found in projectworlds Online Jewellery Shopping System 1\.0\. Impacted is the function searchItem of the file application/models/dashbord\_model\.php of the component Dashbord Search\. The manipulation of the argument q results in sql injection\. It is possible to launch the attack remotely\. The exploit has been made public and could be used\.
