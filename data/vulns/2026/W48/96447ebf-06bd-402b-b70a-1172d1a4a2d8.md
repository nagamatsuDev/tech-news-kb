# A cleartext transmission of sensitive information vulnerability in the ADM Notifications allows network eavesdroppers on the outbound net\.\.\.

- **ID**: CVE\-2026\-120933
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-24

## 原文

A cleartext transmission of sensitive information vulnerability in the ADM Notifications allows network eavesdroppers on the outbound network path to obtain Clickatell service credentials via the SMS\. When executing an SMS test for Clickatell Communicator Central, the backend function Send\_Test\_SMS embeds the sensitive contents directly into an unencrypted HTTP request URL\. An observer on the NAS network egress path can capture the plain text credentials and message payload since the initial request is transmitted without TLS protection or secret redaction\.  
Affected products and versions include\: from ADM 4\.1\.0 through ADM 4\.3\.3\.RY62 as well as from ADM 5\.0\.0 through ADM 5\.1\.4\.RM62\.
