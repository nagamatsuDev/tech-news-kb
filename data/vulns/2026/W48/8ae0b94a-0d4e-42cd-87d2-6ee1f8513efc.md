# During IMPORT FOREIGN SCHEMA, mysql\_fdw copies column metadata returned by the remote MySQL server into the CREATE FOREIGN TABLE statemen\.\.\.

- **ID**: CVE\-2026\-62154
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-25

## 原文

During IMPORT FOREIGN SCHEMA, mysql\_fdw copies column metadata returned by the remote MySQL server into the CREATE FOREIGN TABLE statements it runs locally without quoting it\. The COLUMN\_DEFAULT value is placed directly in the DEFAULT clause, and the name of the generated ENUM type is inserted unquoted\. A malicious or compromised MySQL server, or an attacker who can tamper with the connection, can return crafted information\_schema metadata and run arbitrary SQL in the local PostgreSQL session of the user who runs IMPORT FOREIGN SCHEMA\. The issue is fixed in mysql\_fdw 2\.10\.0\. From mysql\_fdw 2\.10\.0, mysql\_fdw quotes these values before building the statements\.
