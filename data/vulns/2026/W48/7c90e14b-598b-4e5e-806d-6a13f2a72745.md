# GFI HelpDesk before 4\.99\.13 contains an SQL injection vulnerability in the staff group management feature that allows authenticated attac\.\.\.

- **ID**: CVE\-2026\-127223
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-23

## 原文

GFI HelpDesk before 4\.99\.13 contains an SQL injection vulnerability in the staff group management feature that allows authenticated attackers with administrator privileges to execute arbitrary SQL queries by supplying a crafted title parameter to /admin/index\.php?/Base/StaffGroup/InsertSubmit\. The Controller\_StaffGroup\.RunChecks\(\) method concatenates the unsanitized title value directly into a duplicate name lookup query against the staffgroup table, allowing attackers to read or modify database contents\.
