# actix\-multipart \(actix\-web\) before 0\.8\.7 contains a resource exhaustion vulnerability in the MultipartForm extractor that allows unauthen\.\.\.

- **ID**: CVE\-2026\-137504
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-26

## 原文

actix\-multipart \(actix\-web\) before 0\.8\.7 contains a resource exhaustion vulnerability in the MultipartForm extractor that allows unauthenticated attackers to exhaust memory or file descriptors by sending unlimited parts\. Attackers can stream many zero\-byte parts uncounted by total\_limit and memory\_limit, pinning 128 KiB buffers or opening temporary files to crash workers\.
