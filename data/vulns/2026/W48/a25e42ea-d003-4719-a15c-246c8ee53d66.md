# AutoGPT is a workflow automation platform for creating, deploying, and managing continuous artificial intelligence agents\.

- **ID**: CVE\-2026\-130169
- **危険度**: Critical（緊急） (CVSS 10.0)
- **公開**: 2026-11-23

## 原文

AutoGPT is a workflow automation platform for creating, deploying, and managing continuous artificial intelligence agents\. In versions 0\.6\.26 through 0\.7\.4, AutoGPT Platform ships a publicly known, hardcoded default JWT verification key in backend/\.env\.default and autogpt\_platform/\.env\.default\. Because HS256 is symmetric, anyone who knows the secret can forge valid JWTs for any user or for the admin role, bypassing authentication and authorization without user interaction\. This issue is fixed in version 0\.8\.0\.
