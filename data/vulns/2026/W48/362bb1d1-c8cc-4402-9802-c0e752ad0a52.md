# Pyro through 1\.9\.2 contains an insecure deserialization vulnerability in ParamStoreDict\.load\(\) that calls torch\.load with weights\_only\=Fa\.\.\.

- **ID**: CVE\-2026\-136160
- **危険度**: High（重要） (CVSS 7.8)
- **言語**: Python
- **公開**: 2026-11-24

## 原文

Pyro through 1\.9\.2 contains an insecure deserialization vulnerability in ParamStoreDict\.load\(\) that calls torch\.load with weights\_only\=False, unpickling arbitrary Python objects\. Attackers can trick users into loading a crafted parameter file defining \_\_reduce\_\_ to execute code with the privileges of the Python process\.
