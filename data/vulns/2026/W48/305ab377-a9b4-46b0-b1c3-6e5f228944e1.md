# Improper Neutralization of Directives in Dynamically Evaluated Code \('Eval Injection'\) in the HWBridge custom methods command dispatcher \.\.\.

- **ID**: CVE\-2026\-130336
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-25

## 原文

Improper Neutralization of Directives in Dynamically Evaluated Code \('Eval Injection'\) in the HWBridge custom methods command dispatcher \(lib/rex/post/hwbridge/ui/console/command\_dispatcher/custom\_methods\.rb\) in Rapid7 Metasploit Framework versions prior to 6\.5\.10 on all platforms allows a malicious or compromised hardware bridge to execute arbitrary code in the msfconsole process via a crafted method\_name returned by the /custom\_methods endpoint\. The injected code runs automatically when the operator connects to the bridge, without the operator invoking any custom command\.
