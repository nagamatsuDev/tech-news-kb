# Deserialization of Untrusted Data vulnerability in the application/vnd\.hex\+erlang request body parser in hexpm hexpm allows an unauthenti\.\.\.

- **ID**: CVE\-2026\-129514
- **危険度**: Critical（緊急） (CVSS 10.0)
- **公開**: 2026-11-24

## 原文

Deserialization of Untrusted Data vulnerability in the application/vnd\.hex\+erlang request body parser in hexpm hexpm allows an unauthenticated remote attacker to execute operating system commands via a crafted Erlang external term format request body\. This vulnerability was actively exploited against the hex\.pm service on 2026\-11\-23\.
  
HexpmWeb\.ErlangFormat\.decode/1 in lib/hexpm\_web/erlang\_format\.ex decodes the body with Plug\.Crypto\.non\_executable\_binary\_to\_term/2, which accepts maps that have a \_\_struct\_\_ key\. HexpmWeb\.PlugParser\.parse/5 returns the decoded term as the request params\. The parser runs in the endpoint before routing and authentication, so a POST to any route reaches it\. Elixir dispatches protocols on the \_\_struct\_\_ key, so the client selects which Inspect and Enumerable implementations run when error reporting inspects the params\. A chain through Ecto\.Query\.DynamicExpr and DBConnection\.Stream reaches an apply/3 call on a \{module, function, args\} tuple taken from the request body\.
  
This issue affects hex\.pm\: from 2016\-02\-23 before 2026\-11\-23; hexpm/hexpm\: from ab1bbcef7cc8395d1056d3b1aa6a174353492d59 before 379b0a29bcc95164249f38ad7d772a37a8ff9533\.
