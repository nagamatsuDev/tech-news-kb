# JSONSchema2PoPo2 through 3\.0\.3 contains a code injection vulnerability that allows attackers to inject Python code by supplying JSON Sche\.\.\.

- **ID**: CVE\-2026\-137999
- **危険度**: High（重要） (CVSS 7.8)
- **言語**: Python
- **公開**: 2026-11-27

## 原文

JSONSchema2PoPo2 through 3\.0\.3 contains a code injection vulnerability that allows attackers to inject Python code by supplying JSON Schema default or format values that are written unescaped\. Attackers can place a single quote in a string property default to break out of the literal in the generated \_\_init\_\_ signature, executing injected code when the generated module is imported\.
