# CodeSafe is an open\-source Python library for code encryption, decryption, and safe evaluation using Python's AST module\.

- **ID**: CVE\-2026\-133467
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: Python
- **公開**: 2026-11-25

## 原文

CodeSafe is an open\-source Python library for code encryption, decryption, and safe evaluation using Python's AST module\. From versions 0\.0\.1 through 0\.0\.4, the safe\_eval\(\) function can be bypassed with indirect subscript calls such as builtins'exec', because AST validation blocks only direct calls to dangerous built\-ins\. An attacker who controls an expression passed to safe\_eval\(\) can execute arbitrary Python code with the permissions of the host application\. This issue is fixed in version 0\.0\.5\.
