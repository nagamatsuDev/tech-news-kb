# The SumUp Payment Gateway For WooCommerce plugin for WordPress is vulnerable to Insecure Direct Object Reference in versions up to, and i\.\.\.

- **ID**: CVE\-2026\-97345
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-26

## 原文

The SumUp Payment Gateway For WooCommerce plugin for WordPress is vulnerable to Insecure Direct Object Reference in versions up to, and including, 2\.17\.1 via the 'sumup\-validate\-order' query parameter handled by the check\_redirect\_flow\(\) / resolve\_payment\_redirect\_validation\(\) functions\. The template\_redirect handler accepts an arbitrary numeric order ID from an unauthenticated GET request and, without any ownership or capability check, loads the corresponding WooCommerce order and issues a 302 redirect whose Location header is built by get\_return\_url\(\), disclosing the target order's secret order\_key\. This makes it possible for unauthenticated attackers to enumerate order IDs, harvest each order's WooCommerce order\_key, and use those keys against the plugin's create\_checkout endpoint and WooCommerce's own order\-received/order\-pay pages to read customer PII \(name, email, phone, billing address, order total\) for any order in the store\.
