# A flaw has been found in osCommerce up to 4\.14\.63493\.

- **ID**: CVE\-2026\-134885
- **危険度**: High（重要） (CVSS 7.3)
- **言語**: PHP
- **公開**: 2026-11-23

## 原文

A flaw has been found in osCommerce up to 4\.14\.63493\. The impacted element is the function actionSuccess of the file lib/frontend/controllers/MultisafeController\.php of the component MultiSafepay Payment Success Callback\. Executing a manipulation of the argument customer\_id can lead to improper authentication\. It is possible to launch the attack remotely\. The vendor was contacted early about this disclosure but did not respond in any way\.
