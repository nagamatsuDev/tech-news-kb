# FFmpeg before 9\.1 contains an out\-of\-bounds write vulnerability in ogg\_buffer\_data\(\) in libavformat/oggenc\.c because ogg\_buffer\_page\(\) le\.\.\.

- **ID**: CVE\-2026\-135709
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-24

## 原文

FFmpeg before 9\.1 contains an out\-of\-bounds write vulnerability in ogg\_buffer\_data\(\) in libavformat/oggenc\.c because ogg\_buffer\_page\(\) leaves a full page current after failed allocation\. When page allocation fails, a memset with length \(size\_t\)\-1 or an overflowing memcpy writes past the segment table, causing heap memory corruption and crashes when writing Ogg output\.
