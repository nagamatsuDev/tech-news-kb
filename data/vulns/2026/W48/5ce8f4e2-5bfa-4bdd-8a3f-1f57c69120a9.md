# FreeRDP 2\.11\.2 before 3\.33\.0 contains unbounded resource consumption in the Progressive codec because progressive\_decompress\(\) resets the\.\.\.

- **ID**: CVE\-2026\-137459
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-26

## 原文

FreeRDP 2\.11\.2 before 3\.33\.0 contains unbounded resource consumption in the Progressive codec because progressive\_decompress\(\) resets the tile update batch only when frameId changes\. A malicious RDP server can repeat RDPGFX\_CAPROGRESSIVE WireToSurface2 commands with a constant frameId to cause unbounded memory growth, quadratic CPU cost, a heap out\-of\-bounds write on tile\-cache allocation failure, and client crashes\.
