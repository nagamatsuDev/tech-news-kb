# OpenEMR before 8\.5\.0 contains a second\-order SQL injection vulnerability in the IPPF contraceptive issue feature because issue\_ippf\_con\_s\.\.\.

- **ID**: CVE\-2026\-126489
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains a second\-order SQL injection vulnerability in the IPPF contraceptive issue feature because issue\_ippf\_con\_save concatenates layout\_options field\_id values into a REPLACE INTO query as column names\. Authenticated administrators can add a malicious field\_id via edit\_layout\.php, then trigger issue\_ippf\_con\_save through add\_edit\_issue\.php to execute arbitrary SQL\.
