# When using Clang or GCC, building a malicious package that uses cgo could cause unexpected code execution at build time or write files to\.\.\.

- **ID**: CVE\-2026\-97035
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-11

## 原文

When using Clang or GCC, building a malicious package that uses cgo could cause unexpected code execution at build time or write files to arbitrary directories via "\-gen\-\*" or "\-gnat\*" flags in "\#cgo" directives\. The "\-g\*" wildcard in the compiler and linker flag allowlists previously matched Clang's two\-argument "\-gen\-cdb\-fragment\-path &lt;dir&gt;" flag and GCC's two\-argument "\-gnatO &lt;file&gt;" flag, permitting compilation database fragments and sidecar output files to be written to arbitrary directories and desynchronizing flag argument parsing between the go command and the compiler driver so that subsequent arguments could be passed as unvalidated positional inputs to the linker\. "\-gen\-\*" and "\-gnat\*" flags are now disallowed in "\#cgo" compiler and linker flags\.
