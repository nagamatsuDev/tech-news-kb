# Ahime Image Printer WordPress プラグインは、\.NET Core ファイルを作成する前に、名前、拡張子、またはアップロードされたファイルの種類を検証しません。

- **ID**: CVE\-2026\-124833
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: PHP
- **公開**: 2026-11-13

## 概要（機械翻訳）

画像印刷ワードプレスプラグイン 1\.0\.0は、ディスクに書き込む前にアップロードされたファイルの名前、拡張子、タイプを検証しないため、認証されていない攻撃者はPHPを含むHgJ\#aryファイルをアップロードし、サーバー上でコードを実行できます。

## 原文

The Ahime Image Printer WordPress plugin through 1\.0\.0 does not validate the name, extension or type of uploaded files before writing them to disk, allowing unauthenticated attackers to upload arbitrary files, including PHP, and execute code on the server\.
