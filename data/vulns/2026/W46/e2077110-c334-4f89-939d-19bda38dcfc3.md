# IBM ContextForge MCP Gateway 1\.0\.0 through 1\.1\.0 is vulnerable to improper credential handling because the X\-Upstream\-Authorization reque\.\.\.

- **ID**: CVE\-2026\-110279
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-13

## 原文

IBM ContextForge MCP Gateway 1\.0\.0 through 1\.1\.0 is vulnerable to improper credential handling because the X\-Upstream\-Authorization request header can override the gateway\-managed upstream credential for OAuth \(authorization\_code and client\_credentials\), bearer and basic authenticated gateways, which could allow an authenticated user to cause upstream requests to be made with a different credential and bypass per\-user permission and audit attribution\.
