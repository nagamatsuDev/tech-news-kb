# A vulnerability has been identified in ROS\# \(All versions &lt; V2\.3\.1\)\.

- **ID**: CVE\-2026\-109097
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-11-10

## 原文

A vulnerability has been identified in ROS\# \(All versions &lt; V2\.3\.1\)\. Affected systems do not properly escape text of message definition files\. This could allow an attacker that is able to pass a crafted message definition file to the user to inject arbitrary code into the generated program\.
