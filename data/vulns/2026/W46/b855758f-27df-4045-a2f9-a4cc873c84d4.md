# Elextensions ELEX WordPress ヘルプデスク&amp;カスタマーチケットシステムelex\-helpdesk\-custome\.comにおける信頼できないデータの脆弱性のデシリアライズ。

- **ID**: CVE\-2026\-125855
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: PHP
- **公開**: 2026-11-13

## 概要（機械翻訳）

Elextensions ELEX WordPress ヘルプデスク&amp;カスタマーチケットシステムの非信頼データ脆弱性のデシリアライズにより、オブジェクト注入が可能となり、ELEX WordPress ヘルプデスク&amp;カスタマーチケットシステムに影響します。

## 原文

Deserialization of Untrusted Data vulnerability in Elextensions ELEX WordPress HelpDesk &amp; Customer Ticketing System elex\-helpdesk\-customer\-support\-ticket\-system allows Object Injection\.This issue affects ELEX WordPress HelpDesk &amp; Customer Ticketing System\: from n/a through 3\.3\.9\.
