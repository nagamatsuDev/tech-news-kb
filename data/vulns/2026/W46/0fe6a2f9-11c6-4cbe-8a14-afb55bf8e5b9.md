# FrankenPHP Dockerイメージは、1\.11以前に新しいベースイメージタグが作成された時にのみ再構築された。

- **ID**: CVE\-2026\-128027
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: PHP
- **公開**: 2026-11-13

## 概要（機械翻訳）

1\.1\.11以前のFrankenPHP Dockerイメージは、新しいベースイメージタグが作成された場合にのみ再構築されるため、Alpine、PHP、Goが既存のタグの下で適用したセキュリティ修正は伝わらなかった。。リモート攻撃者は、libcrypto3のCVE\-2025\-15467のようなスターシステムライブラリで既知の欠陥を悪用してコードを実行することができる。。は、に攻撃された。

## 原文

FrankenPHP Docker images before 1\.1\.11 were rebuilt only when new base image tags were created, so security fixes that Alpine, PHP, and Go applied under existing tags were not propagated\. Remote attackers could exploit known flaws in the stale system libraries, such as CVE\-2025\-15467 in libcrypto3, to execute code\.
