# Cudy TR3000 before 2\.5\.42 contains a command injection vulnerability that allows authenticated administrators to execute commands as root\.\.\.

- **ID**: CVE\-2026\-75577
- **危険度**: High（重要） (CVSS 7.2)
- **公開**: 2026-11-13

## 原文

Cudy TR3000 before 2\.5\.42 contains a command injection vulnerability that allows authenticated administrators to execute commands as root by storing a malicious WireGuard private key\. Attackers can save a private\_key containing \$\(\) shell substitution and call the vpn\.export\_conf method on the /cgi\-bin/luci/rpc/app JSON\-RPC endpoint, which passes the key to a wg pubkey shell command\.
