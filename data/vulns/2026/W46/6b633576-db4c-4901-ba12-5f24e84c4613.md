# 簡単にDragDropファイルアップロードできるWordPressプラグイン 1\.1\.10以前のプラグインは、ユーザーが提供するパスを削除しないため、不正アクセスを許す。

- **ID**: CVE\-2026\-124822
- **危険度**: Critical（緊急） (CVSS 10.0)
- **言語**: PHP
- **公開**: 2026-11-13

## 概要（機械翻訳）

簡単なDragDropファイルアップロードワードプレスプラグイン 1\.1\.10以前のプラグインは、ユーザが提供するパスを検証せずに削除し、未認証のユーザがwp\-config\.phpのようなサーバー上のZJWRaryファイルやディレクトリを削除できるようにする。

## 原文

The Easy DragDrop File Uploader WordPress plugin before 1\.1\.10 does not validate a user\-supplied path before deleting it, allowing unauthenticated users to delete arbitrary files and directories on the server, such as wp\-config\.php\.
