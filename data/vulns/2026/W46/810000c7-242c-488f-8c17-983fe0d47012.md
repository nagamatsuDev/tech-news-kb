# n8n before 1\.123\.89, 2\.0\.0 before 2\.45\.5, 2\.46\.0 before 2\.46\.1, and 3\.0\.0 before 3\.0\.1 contains an insufficient isolation vulnerability i\.\.\.

- **危険度**: High（重要） (CVSS 7.5)
- **言語**: JavaScript/TypeScript

## 原文

n8n before 1\.123\.89, 2\.0\.0 before 2\.45\.5, 2\.46\.0 before 2\.46\.1, and 3\.0\.0 before 3\.0\.1 contains an insufficient isolation vulnerability in workflow expression evaluation that allows authenticated users to escape the sandbox\.
