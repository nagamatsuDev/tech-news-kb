# FFmpeg through 9\.0\.2 contains an out\-of\-bounds memory access vulnerability in the encode\_frame\(\) function of libavcodec/huffyuvenc\.c, bec\.\.\.

- **ID**: CVE\-2026\-125229
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-09

## 原文

FFmpeg through 9\.0\.2 contains an out\-of\-bounds memory access vulnerability in the encode\_frame\(\) function of libavcodec/huffyuvenc\.c, because encode\_init\(\) never validates minimum frame dimensions for the median predictor\. Attackers can supply a tiny video, such as a 2\-pixel\-wide or 1\-2\-pixel\-tall frame, that causes negative sub\_median\_pred lengths and out\-of\-bounds reads and writes when transcoded to huffyuv or ffvhuff, crashing the encoder\.
