# SQLコマンド\('SQL Injection'\)で使われる特別な要素の不適切な中性化は、WP BASE WP BASE Booking wp\-base\-boo\.\.

- **ID**: CVE\-2026\-124970
- **危険度**: Critical（緊急） (CVSS 9.3)
- **公開**: 2026-11-13

## 概要（機械翻訳）

SQLコマンド\('SQL Injection'\)で使われる特別な要素を、WP BASE WP BASE Booking wp\-base\-booking\-of\-appointments\-service\-and\-eventsで不正に中和すると、Blind SQL Injectionが可能である。この問題はWP BASE Bookingに影響する。

## 原文

Improper Neutralization of Special Elements used in an SQL Command \('SQL Injection'\) vulnerability in WP BASE WP BASE Booking wp\-base\-booking\-of\-appointments\-services\-and\-events allows Blind SQL Injection\.This issue affects WP BASE Booking\: from n/a through 6\.5\.2\.
