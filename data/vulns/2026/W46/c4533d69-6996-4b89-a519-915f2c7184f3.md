# In CommitToBuffer of hal\_override\_options\.bundle\.cc, there is a possible way to retain stale direct memory access mappings to secure memo\.\.\.

- **ID**: CVE\-2026\-56966
- **危険度**: High（重要） (CVSS 8.4)
- **公開**: 2026-11-10

## 原文

In CommitToBuffer of hal\_override\_options\.bundle\.cc, there is a possible way to retain stale direct memory access mappings to secure memory due to a confused deputy\. This could lead to local escalation of privilege with System execution privileges needed\. User interaction is not needed for exploitation\.
