# OpenEMR before 8\.5\.0にはAuthorizations\_full\.phpに不足している認証脆弱性がある。

- **ID**: CVE\-2026\-126458
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-13

## 概要（機械翻訳）

8\.5\.0以前のOpenEMRは、認証に欠落した承認脆弱性を含む\_full\.phpであり、認証されたスタッフユーザーはHbitrary患者の臨床記録を承認することができる。。は、承認された。攻撃者は、攻撃者によって選択されたpidと独自のCSRFトークンでmode\=Authorizeリクエストを送信し、課金、フォーム、pnotes、トランザクションレコードにAuthorized\=1を設定し、プロバイダレビューをバイパスできます。

## 原文

OpenEMR before 8\.5\.0 contains a missing authorization vulnerability in authorizations\_full\.php that allows any authenticated staff user to authorize arbitrary patients' clinical records\. Attackers can send a mode\=authorize request with an attacker\-chosen pid and their own CSRF token to set authorized\=1 on billing, forms, pnotes, and transactions records, bypassing provider review\.
