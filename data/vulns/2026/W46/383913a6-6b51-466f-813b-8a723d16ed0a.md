# JSON\:\:XS versions before 4\.05 for Perl allow memory exhaustion by buffering incremental input past max\_size after a NUL byte in incr\_parse\.

- **ID**: CVE\-2026\-124536
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-14

## 原文

JSON\:\:XS versions before 4\.05 for Perl allow memory exhaustion by buffering incremental input past max\_size after a NUL byte in incr\_parse\.
  
The parser appends each chunk to its buffer and compares max\_size with how far it has progressed, not with the buffer length\. It treats a NUL byte as the end of the input, so a NUL within the first max\_size bytes keeps it short of the limit\. The buffer keeps growing, and incr\_skip cannot remove the NUL\.
  
A peer streaming data to an incr\_parse consumer can exhaust process memory regardless of max\_size\.
