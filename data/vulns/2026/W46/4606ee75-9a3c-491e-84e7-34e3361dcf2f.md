# Ettercap through 0\.8\.4\.1 contains a stack buffer underwrite vulnerability in the telnet dissector in src/dissectors/ec\_telnet\.c that decr\.\.\.

- **ID**: CVE\-2026\-125406
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-10

## 原文

Ettercap through 0\.8\.4\.1 contains a stack buffer underwrite vulnerability in the telnet dissector in src/dissectors/ec\_telnet\.c that decrements the output pointer on backspace without a lower bound check\. Attackers can send a telnet stream with more backspaces than preceding characters to write below the stack buffer, corrupting the stack of the Ettercap process that normally runs as root\.
