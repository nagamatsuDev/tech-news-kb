# Control Web Panel \(CWP\) before webpanel\_version 1\.30\.6 contains a host header injection vulnerability that allows unauthenticated attacke\.\.\.

- **ID**: CVE\-2026\-124020
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-13

## 原文

Control Web Panel \(CWP\) before webpanel\_version 1\.30\.6 contains a host header injection vulnerability that allows unauthenticated attackers to manipulate the password\-recovery reset URL by injecting the HTTP Host header into the /v1/lostpass/ route's token generation process\. Attackers can lure an automated mail\-security scanner into visiting the poisoned reset link to exfiltrate the live recovery token, replay it at /login/index\.php?acc\=newpass to set a new password, and subsequently abuse the File Manager and Crontab modules to achieve command execution as the targeted hosting account\.
