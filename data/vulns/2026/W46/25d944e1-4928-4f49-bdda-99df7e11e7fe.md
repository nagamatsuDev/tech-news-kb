# 脆弱性はCoolerMaster MASTERPLUS\+ 1\.9\.6 に特定された。

- **ID**: CVE\-2026\-129255
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-14

## 概要（機械翻訳）

CoolerMaster MASTERPLUS\+ 1\.9\.6 で脆弱性が確認された。。。これは、コンポーネントデバイスドライブのライブラリWinRing0x64\.sysの関数 sub\_11504 に影響します。HgGument PhysicalAddress の操作は、誤ったデフォルト許可につながります。。

## 原文

A vulnerability was identified in CoolerMaster MASTERPLUS\+ 1\.9\.6\. This affects the function sub\_11504 in the library WinRing0x64\.sys of the component Device Driver\. The manipulation of the argument PhysicalAddress leads to incorrect default permissions\. The attack can only be performed from a local environment\. The vendor was contacted early about this disclosure but did not respond in any way\.
