## 原文

Rucio is a scientific data management framework\. From 1\.14\.0 until 35\.9\.1, 38\.6\.1, 40\.4\.2, and 41\.1\.1, validate\_auth\_token in lib/rucio/core/authentication\.py does not distinguish short\-lived SSH challenge nonces from authentication tokens stored in the same token table\. An unauthenticated attacker can request /auth/ssh\_challenge\_token for an arbitrary account by supplying X\-Rucio\-Account, then present the returned X\-Rucio\-SSH\-Challenge\-Token as X\-Rucio\-Auth\-Token to authenticate to other API endpoints as that account, including an administrative account\. This issue is fixed in versions 35\.9\.1, 38\.6\.1, 40\.4\.2, and 41\.1\.1\.
