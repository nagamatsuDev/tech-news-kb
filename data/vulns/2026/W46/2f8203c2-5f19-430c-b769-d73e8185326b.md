# Heym builds and runs agentic systems and business\-process automations on self\-hosted infrastructure\.

- **ID**: CVE\-2026\-67541
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-11

## 原文

Heym builds and runs agentic systems and business\-process automations on self\-hosted infrastructure\. Prior to version 0\.0\.70, team\-member management \(add / remove / update\) is gated only on team membership, not on the team creator/admin role — and TeamMember has no role column\. Any non\-creator member can seat an attacker account into the team; because credential team\-shares are scoped only by TeamMember\.user\_id, the newly\-added attacker can then decrypt every credential shared into that team \(provider API keys, OAuth tokens\. This issue has been patched in version 0\.0\.70\.
