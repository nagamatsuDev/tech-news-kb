# osコマンド\('os command injection'\)で使われる特殊要素の不適切な中和。

- **ID**: CVE\-2026\-126144
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-11

## 概要（機械翻訳）

osコマンド\('os command injection'\)で使用される特別な要素を不正に中和すると、FortiMail 8\.0\.0から8\.0\.1、FortiMail 7\.6\.0から7\.6\.4\.4\.4\.6、FortiMail 7\.0から7\.6\.2、FortiRecorder 7\.6\.0から7\.6\.2、FortiRecorder 7\.2\.0から7\.2\.12、FortiRecorder 7\.0\.0から7\.0\.6は、承認されていない攻撃者が、特定のHTTPリクエストを通じて、認可されていないコードやコマンドを実行できるようにします。

## 原文

A improper neutralization of special elements used in an os command \('os command injection'\) vulnerability in Fortinet FortiMail 8\.0\.0 through 8\.0\.1, FortiMail 7\.6\.0 through 7\.6\.4, FortiMail 7\.4\.0 through 7\.4\.6, FortiMail 7\.2 all versions, FortiRecorder 7\.6\.0 through 7\.6\.2, FortiRecorder 7\.2\.0 through 7\.2\.12, FortiRecorder 7\.0\.0 through 7\.0\.6 may allow an authenticated attacker to execute unauthorized code or commands via specifically crafted HTTP requests\.
