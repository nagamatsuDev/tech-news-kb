# Firekylin through 2\.18\.1 contains an improper authorization vulnerability that allows editor\-role users to read administrator\-only secret\.\.\.

- **ID**: CVE\-2026\-125750
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-10

## 原文

Firekylin through 2\.18\.1 contains an improper authorization vulnerability that allows editor\-role users to read administrator\-only secrets because the admin API base guard permits all GET actions\. Editors can query options\.js for TOTP secrets, push credentials, and cloud storage keys, or user\.js for other users' app\_key/app\_secret to publish posts as administrators via admin/post\_push\.
