# Cudy TR3000 before 2\.5\.42 contains a command injection vulnerability that allows authenticated administrators to execute commands as root\.\.\.

- **ID**: CVE\-2026\-129103
- **危険度**: High（重要） (CVSS 7.2)
- **公開**: 2026-11-13

## 原文

Cudy TR3000 before 2\.5\.42 contains a command injection vulnerability that allows authenticated administrators to execute commands as root by injecting newlines into reboot\_time\. Attackers can submit a reboot\_time value followed by a newline and crontab line, which /etc/init\.d/autoreboot writes to the root crontab for crond to run\.
