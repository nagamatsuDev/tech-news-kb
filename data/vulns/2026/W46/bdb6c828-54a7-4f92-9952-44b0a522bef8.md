# OpenEMR before 8\.5\.0 contains an improper authorization vulnerability in interface/drugs/dispense\_drug\.php, which checks only for admin/d\.\.\.

- **ID**: CVE\-2026\-126433
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: PHP
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains an improper authorization vulnerability in interface/drugs/dispense\_drug\.php, which checks only for admin/drugs view permission instead of write permission before dispensing medication\. Authenticated users with read\-only drug administration access can send GET requests with drug\_id, quantity, fee, and encounter parameters to create false dispensing records and decrement inventory\.
