# 複数の場所では、整数オーバーフローによる境界外書き込みが可能となる。

- **ID**: CVE\-2026\-58681
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-10

## 概要（機械翻訳）

複数の場所では、整数オーバーフローによる境界外書き込みが可能となる。これにより、追加の実行権限なしでリモートコードを実行することができる。\)。探索にはユーザのインタラクションは必要ない。\)。

## 原文

In multiple locations, there is a possible out\-of\-bounds write due to an integer overflow\. This could lead to remote code execution with no additional execution privileges needed\. User interaction is not needed for exploitation\.
