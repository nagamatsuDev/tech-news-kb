# 重要なリソース脆弱性に対するポイントマルチプロダクト不正な許可割り当ての確認

- **ID**: CVE\-2026\-123039
- **危険度**: High（重要） (CVSS 7.8) / 🔥 悪用確認 (CISA KEV)
- **OS**: Network/Firmware
- **公開**: 2026-11-12

## 概要（機械翻訳）

Gaia OS DynamicCLIデーモンはrootとして実行され、接続プロセスを認証することなく、書き出せるローカルソケット\(/tmp/dynamic\_socket\)でリスンします。。\.\.\.認証されたローカルユーザは、コマンドをソケットに送信して、ルートとして実行することができる。は、ルートとして実行される。は、ローカルのユーザが、実行したコマンドを、ルートとして実行させる。

## 原文

The Gaia OS DynamicCLI daemon runs as root and listens on a world\-writable local socket \(/tmp/dynamic\_socket\) without authenticating connecting processes\. An authenticated local user can send a command to the socket and have it executed as root\.
