# WWBN AVideo through 29\.7\.1 contains an incorrect authorization vulnerability that allows delegated Videos Admin users to obtain video\_id\_\.\.\.

- **ID**: CVE\-2026\-126805
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-11

## 原文

WWBN AVideo through 29\.7\.1 contains an incorrect authorization vulnerability that allows delegated Videos Admin users to obtain video\_id\_hash values bound to any video owner via encoder endpoints like aVideoEncoderStatus\.json\.php\. Attackers can request the hash for an administrator\-owned video and replay it through useVideoHashOrLogin\(\) for password\-less login, gaining plugin upload, configuration, and user management access\.
