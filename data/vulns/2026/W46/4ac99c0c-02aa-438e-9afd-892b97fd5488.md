# Software installed and run as a non\-privileged user may conduct improper GPU system calls to the execution of an error path that triggers\.\.\.

- **ID**: CVE\-2026\-74911
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-13

## 原文

Software installed and run as a non\-privileged user may conduct improper GPU system calls to the execution of an error path that triggers an OOB read &amp; write\.
  
An error can be triggered which causes the index of the array element to be cleaned up by the error path would be outside of the array bounds\.
