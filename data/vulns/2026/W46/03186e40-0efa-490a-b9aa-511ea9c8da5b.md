# 7\.3\.2\-86009 以前の SSOAuth in Synology Disk Station Manager \(DSM\) におけるユーザ制御キー脆弱性の承認バイパス

- **ID**: CVE\-2026\-13672
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-12

## 概要（機械翻訳）

認証バイパスは、7\.3\.2\-86009\-5および7\.4\.1\-90080\-1以前のSSOAuth in Synology DiskStation Manager \(DSM\) において、ユーザが管理するキー脆弱性をバイパスすることで、リモート認証されたユーザがJJKのファイルを読み書きし、サービス拒否攻撃を実行できるようにする。

## 原文

An authorization bypass through user\-controlled key vulnerability in the SSOAuth in Synology DiskStation Manager \(DSM\) before 7\.3\.2\-86009\-5 and 7\.4\.1\-90080\-1 allows remote authenticated users to read or write arbitrary files and conduct denial\-of\-service attacks\.
