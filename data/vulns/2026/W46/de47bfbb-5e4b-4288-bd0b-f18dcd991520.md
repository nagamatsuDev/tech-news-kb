# Dynatrace MCP Server is an MCP server for Dynatrace Observability\.

- **ID**: CVE\-2026\-123811
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-09

## 原文

Dynatrace MCP Server is an MCP server for Dynatrace Observability\. Prior to 2\.0\.0, a server started with the \-\-http option accepts JSON\-RPC tools/call requests without authentication, session validation, or Host and Origin protections before dispatching them under the server's configured Dynatrace credentials\. A network\-reachable caller can invoke execute\_dql to read logs, security events, user sessions, and other Grail data, or invoke create\_dynatrace\_notebook to create tenant\-visible notebooks\. The send\_event path is not affected because its requestHumanApproval gate blocks this attack path, and reset\_grail\_budget only demonstrates dispatch without accessing Dynatrace data\. This issue is fixed in version 2\.0\.0\.
