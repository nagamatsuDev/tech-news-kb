# AIOHTTP\: WebSocket receive queue limits bypassed by small or compressed messages

- **ID**: CVE\-2026\-128132 / GHSA\-5rmc\-48h2\-hvcm
- **危険度**: High（重要）
- **言語**: Python
- **パッケージ**: PyPI/aiohttp &lt;\= 3\.14\.3 → 3\.14\.4
- **公開**: 2026-11-13

## 原文

\#\#\# Summary The WebSocket reader continued parsing frames already received after the receive queue had paused the transport, and empty messages were not counted towards the queue size\. With permessage\-deflate, a single read of compressed frames could add many megabytes of decompressed messages to the queue\. \#\#\# Impact An attacker could cause excessive memory use in a WebSocket server, or a malicious server against a client, by sending many small or compressed messages faster than the application consumes them\. \-\-\- Patch\: https\://github\.com/aio\-libs/aiohttp/commit/0ae507423f681161efa77d20052b40
