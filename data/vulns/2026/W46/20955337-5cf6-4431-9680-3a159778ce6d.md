## 原文

pyLoad is a free and open\-source download manager written in Python\. Prior to 0\.5\.0b3\.dev102, UnTar\.\_safe\_extractall in src/pyload/plugins/extractors/UnTar\.py validates archive member paths and link targets but does not call TarInfo\.isdev to reject special tar member types before calling tarfile\.extractall\. On supported Python 3\.9 through 3\.13 runtimes, tarfile defaults to the fully\_trusted extraction filter, so a user with ADD and STATUS permissions can cause extraction of a crafted archive containing character devices, block devices, or FIFOs\. Python 3\.14 defaults to a safe extraction filter\. When pyLoad runs with operating\-system privileges that permit device creation, including the official root\-based Docker deployment, the archive can expose raw devices and compromise the host\. Non\-root deployments can still create FIFOs that cause hangs or IPC confusion\. This issue is fixed in version 0\.5\.0b3\.dev102\.
