# OS command injection vulnerability in audio messages API in Zenitel Connect before 1\.11\.0 allows remote authenticated users to execute ar\.\.\.

- **ID**: CVE\-2026\-95615
- **危険度**: High（重要） (CVSS 8.7)
- **公開**: 2026-11-13

## 原文

OS command injection vulnerability in audio messages API in Zenitel Connect before 1\.11\.0 allows remote authenticated users to execute arbitrary OS commands as root in the hiatus application container via filename parameter to the /api/system/audio\_messages endpoint\.
