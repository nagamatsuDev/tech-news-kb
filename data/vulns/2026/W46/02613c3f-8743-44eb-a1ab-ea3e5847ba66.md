# Cudy TR3000 before 2\.5\.42 contains a command injection vulnerability that allows authenticated administrators to execute commands as root\.\.\.

- **ID**: CVE\-2026\-129102
- **危険度**: High（重要） (CVSS 7.2)
- **公開**: 2026-11-13

## 原文

Cudy TR3000 before 2\.5\.42 contains a command injection vulnerability that allows authenticated administrators to execute commands as root by injecting newlines into the IPsec keyexchange field of the vpn\.set\_conf RPC method\. Attackers can append a second leftupdown directive to ipsec\.conf, which StrongSwan's updown plugin runs as root when an attacker\-controlled peer establishes the CHILD\_SA\.
