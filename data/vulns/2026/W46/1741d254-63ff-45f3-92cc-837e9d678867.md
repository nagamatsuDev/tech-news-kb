# OpenMRS module bahmnicore contains Core OpenMRS modules for Bahmni \(including ERP &amp; ELIS Atom Feed Clients\)\.

- **ID**: CVE\-2026\-63192
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-11

## 原文

OpenMRS module bahmnicore contains Core OpenMRS modules for Bahmni \(including ERP &amp; ELIS Atom Feed Clients\)\. In version 0\.93, an attacker with authenticated access could potentially exfiltrate sensitive data from the database\. This issue has been patched in version 0\.93\.1\.
