# TRENDnet TEW\-657BRM 1\.00\.1で脆弱性が検出された。

- **ID**: CVE\-2026\-129352
- **危険度**: Critical（緊急） (CVSS 9.1)
- **公開**: 2026-11-14

## 概要（機械翻訳）

TRENDnet TEW\-657BRM 1\.00\.1で脆弱性が検出された。。この問題は /usr/sbin/upgrade\_flash\.cgi ファイルに対する未知な処理に影響します。kggment境界の操作を実行すると、スタックベースのバッファオーバーフローが発生する。

## 原文

A vulnerability was detected in TRENDnet TEW\-657BRM 1\.00\.1\. This issue affects some unknown processing of the file /usr/sbin/upgrade\_flash\.cgi\. Performing a manipulation of the argument boundary results in stack\-based buffer overflow\. The attack is possible to be carried out remotely\. The exploit is now public and may be used\. The vendor explains\: ""I am not able to confirm if such vulnerability exists as the product has been EOL for more than 15 years\. We will send out an announcement letting customers know\."
