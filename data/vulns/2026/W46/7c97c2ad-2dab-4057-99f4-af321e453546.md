# OpenEMR before 8\.5\.0 contains a stored SQL injection vulnerability in getByPatientDemographics\(\) where layout\_options field\_id values are\.\.\.

- **ID**: CVE\-2026\-126491
- **危険度**: High（重要） (CVSS 7.6)
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains a stored SQL injection vulnerability in getByPatientDemographics\(\) where layout\_options field\_id values are concatenated into the patient search WHERE clause\. Attackers with Layout Editor access can plant a malicious field\_id, allowing any authenticated low\-privilege user to exfiltrate data from patient\_data and users\_secure tables\.
