# FFmpeg through 9\.0\.2 contains an off\-by\-one heap overflow vulnerability in get\_exponent\_dynamic\(\) in libavcodec/nellymoserenc\.c that allo\.\.\.

- **ID**: CVE\-2026\-125257
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-09

## 原文

FFmpeg through 9\.0\.2 contains an off\-by\-one heap overflow vulnerability in get\_exponent\_dynamic\(\) in libavcodec/nellymoserenc\.c that allows writing one element past the opt and path allocations\. Attackers can supply crafted audio to applications encoding Nellymoser with trellis enabled, causing idx to equal OPT\_SIZE and overwrite adjacent heap memory\.
