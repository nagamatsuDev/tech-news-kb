# Pagelayer 2\.1\.7 before 2\.2\.1 contains a missing authorization vulnerability in Abilities API abilities registered in main/abilitiesregist\.\.\.

- **ID**: CVE\-2026\-127094
- **危険度**: High（重要） (CVSS 7.6)
- **言語**: PHP
- **公開**: 2026-11-13

## 原文

Pagelayer 2\.1\.7 before 2\.2\.1 contains a missing authorization vulnerability in Abilities API abilities registered in main/abilitiesregister\.php that only require the edit\_posts capability\. Contributor\-level attackers can overwrite, publish, delete, or duplicate other users' private posts and pages to read them, and modify site\-wide theme templates like headers and footers\.
