# OpenEMR before 8\.5\.0 contains a missing authorization flaw in the Care Coordination CCDA and CCR import controllers, which move a documen\.\.\.

- **ID**: CVE\-2026\-126440
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains a missing authorization flaw in the Care Coordination CCDA and CCR import controllers, which move a document named by the document\_id parameter into the import category without checking access to the source document\. Authenticated non\-administrators with Care Coordination access can recategorize protected patient documents and then download them through normal ACL\-checked retrieval\.
