# The web dashboard in Coder 2\.24\.0 before 2\.29\.23, 2\.30\.0 before 2\.34\.14, 2\.35\.0 before 2\.36\.9, 2\.37\.0 before 2\.37\.6, and 2\.38\.0 before 2\.\.\.\.

- **ID**: CVE\-2026\-126308
- **危険度**: High（重要） (CVSS 7.7)
- **公開**: 2026-11-13

## 原文

The web dashboard in Coder 2\.24\.0 before 2\.29\.23, 2\.30\.0 before 2\.34\.14, 2\.35\.0 before 2\.36\.9, 2\.37\.0 before 2\.37\.6, and 2\.38\.0 before 2\.38\.2 replaces the \$SESSION\_TOKEN placeholder in external app URLs with a full\-access API key without checking whether the app belongs to a sub\-agent\. Code running in a workspace can register a disguised sub\-agent app with a custom protocol URL, so the owner's click sends their API key to an attacker\-chosen destination\.
