# Omnispace Agora Project before 26\.11\.3 contains a cross\-site request forgery vulnerability that allows remote attackers to forge privileg\.\.\.

- **ID**: CVE\-2026\-63150
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-13

## 原文

Omnispace Agora Project before 26\.11\.3 contains a cross\-site request forgery vulnerability that allows remote attackers to forge privileged actions such as administrator user creation by merging \$\_GET and \$\_POST parameters without requiring an anti\-CSRF token\. Attackers can craft a malicious link or auto\-navigating page that issues a plain GET request, exploiting the lack of CSRF protection and SameSite\=Lax cookie behavior on top\-level navigations to create unauthorized administrator accounts\.
