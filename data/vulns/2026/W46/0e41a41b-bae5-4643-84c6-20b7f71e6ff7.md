# taOS is a self\-hosted AI agent OS\.

- **ID**: CVE\-2026\-67548
- **危険度**: High（重要） (CVSS 8.3)
- **公開**: 2026-11-11

## 原文

taOS is a self\-hosted AI agent OS\. Prior to version 1\.0\.0\-beta\.25, tinyagentos \(taOS\) registers all system settings routes under a single APIRouter\(\) instance created with no admin authorization dependency\. Any authenticated user—including non\-admin invited users whose is\_admin flag is explicitly False—can read the full system configuration, overwrite it, modify platform settings, trigger a git pull \+ dependency reinstall \+ service restart, and switch the tracked update branch\. Successful exploitation of the write endpoints causes immediate configuration corruption or a denial of service for all users on the instance from a low\-privileged account\. This issue has been patched in version 1\.0\.0\-beta\.25\.
