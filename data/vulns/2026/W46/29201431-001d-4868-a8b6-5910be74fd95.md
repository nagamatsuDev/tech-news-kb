# Astro\: Image endpoint in @astrojs/node can read files from a case\-variant sibling of the output directory on case\-sensitive filesystems

- **ID**: CVE\-2026\-126364 / GHSA\-r3h5\-4585\-7x3w
- **危険度**: Medium（警告）
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/@astrojs/node &lt;\= 11\.1\.11, npm/astro &gt;\= 5\.14\.3, &lt;\= 7\.4\.6 → 7\.4\.7
- **公開**: 2026-11-13

## 原文

\#\# Summary The \`/\_image\` endpoint used by the \`@astrojs/node\` adapter checks that a requested local image is inside the build output directory before reading it from disk\. That check compared paths case\-insensitively\. On case\-sensitive filesystems \(such as Linux\), a directory whose path differs from the output directory only by letter case is a different directory, but it passed the check\.
