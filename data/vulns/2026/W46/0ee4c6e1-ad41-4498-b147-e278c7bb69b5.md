# A flaw was found in Foreman\.

- **ID**: CVE\-2026\-107443
- **危険度**: High（重要） (CVSS 7.7)
- **公開**: 2026-11-12

## 原文

A flaw was found in Foreman\. An authenticated user with view\_hosts privileges can retrieve rendered provisioning template content for a host via the hosts template API endpoint, disclosing sensitive data such as the host root password\. This is an incomplete fix of CVE\-2026\-96659, which hardened the web UI preview path but left the API host\-template render path authorized for Viewer\-level users\.
