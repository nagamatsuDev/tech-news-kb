# When independent Grafana instances share the same \[rendering\] renderer\_token, an image renderer key issued by one instance is accepted by\.\.\.

- **ID**: CVE\-2026\-102589
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-11

## 原文

When independent Grafana instances share the same \[rendering\] renderer\_token, an image renderer key issued by one instance is accepted by the others, so a user on one instance could act as the user with the same ID on another \(origin validation error\)\. This affects instances with the renderAuthJWT feature toggle enabled, the default from Grafana 13\.0\.0\.
