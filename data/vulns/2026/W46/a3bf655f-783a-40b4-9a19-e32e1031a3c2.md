# OpenEMR before 8\.5\.0 contains a SQL injection vulnerability that allows any authenticated core user to inject SQL by supplying crafted pa\.\.\.

- **ID**: CVE\-2026\-126430
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains a SQL injection vulnerability that allows any authenticated core user to inject SQL by supplying crafted patient\_data field names to the CCR revandapprove controller\. Attackers can embed scalar subqueries in the UPDATE patient\_data SET clause to read staff password hashes and portal reset values, alter arbitrary patient demographics, and take over patient\-portal accounts\.
