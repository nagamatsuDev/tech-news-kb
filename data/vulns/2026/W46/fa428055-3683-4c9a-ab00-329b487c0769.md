# NLTK dot2img runs Graphviz 'dot' without the trusted\-exec chokepoint, enabling local code execution via a writable PATH element

- **ID**: CVE\-2026\-128134 / GHSA\-7mxv\-7h3q\-9324
- **危険度**: High（重要） (CVSS 7.8)
- **言語**: Python
- **パッケージ**: PyPI/nltk &lt;\= 3\.10\.3 → 3\.10\.4
- **公開**: 2026-11-13

## 原文

\#\# Summary \`nltk\.parse\.dependencygraph\.dot2img\` invokes the Graphviz \`dot\` executable without the trusted\-execution guarantees that NLTK applies to its other native\-tool wrappers\. The function resolves \`dot\` by bare name and then runs the resolved absolute path with a raw \`subprocess\.run\`, omitting the ownership/writability check and the loader\-environment scrub that \`nltk\.pathsec\.spawn\_trusted\` provides\.
