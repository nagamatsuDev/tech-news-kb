# Huginn before 2026\.11\.09 contains an information exposure vulnerability in JqAgent that allows authenticated users to read the server pro\.\.\.

- **ID**: CVE\-2026\-127082
- **危険度**: High（重要） (CVSS 7.7)
- **公開**: 2026-11-13

## 原文

Huginn before 2026\.11\.09 contains an information exposure vulnerability in JqAgent that allows authenticated users to read the server process environment because the jq child process inherits it\. Attackers who can create, configure or dry\-run a JqAgent can supply a filter using env or \$ENV to disclose APP\_SECRET\_TOKEN, database, SMTP and OAuth secrets\.
