# Grav Login plugin before 3\.11\.0 contains an authentication bypass vulnerability that allows attackers with an account password to skip tw\.\.\.

- **ID**: CVE\-2026\-126294
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-13

## 原文

Grav Login plugin before 3\.11\.0 contains an authentication bypass vulnerability that allows attackers with an account password to skip two\-factor verification when the global twofa\_enabled setting is off\. Attackers can sign in through the /login form, remember\-me cookie, or magic link to obtain a session the API plugin accepts, gaining full account permissions including super\-admin control\.
