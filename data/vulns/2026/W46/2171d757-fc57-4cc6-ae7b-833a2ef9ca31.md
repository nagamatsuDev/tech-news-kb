# Ettercap through 0\.8\.4\.1 contains an out\-of\-bounds read vulnerability in Parse\_NTLM\_Auth\(\) in src/dissectors/ec\_http\.c due to unvalidated\.\.\.

- **ID**: CVE\-2026\-125405
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-10

## 原文

Ettercap through 0\.8\.4\.1 contains an out\-of\-bounds read vulnerability in Parse\_NTLM\_Auth\(\) in src/dissectors/ec\_http\.c due to unvalidated NTLM message offsets\. Attackers can send a crafted HTTP Authorization header observed by Ettercap to read beyond the buffer, disclosing memory or crashing the process\.
