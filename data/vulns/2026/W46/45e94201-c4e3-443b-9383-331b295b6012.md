# Dancer versions before 1\.3400 for Perl pass unvalidated session ids from the session cookie to the session engine\.

- **ID**: CVE\-2015\-10149
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-14

## 原文

Dancer versions before 1\.3400 for Perl pass unvalidated session ids from the session cookie to the session engine\.
  
read\_session\_id returns the cookie value as the session id without checking its characters, and Dancer hands it to the session engine to load the session\.
  
A remote attacker may cause path traversal or injection in a session engine that uses the id in a file path, cache command or query without checking it\.
