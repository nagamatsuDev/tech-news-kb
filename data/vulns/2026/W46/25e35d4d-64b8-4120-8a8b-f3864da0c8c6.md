# AIOHTTP is an asynchronous HTTP client/server framework for asyncio and Python\.

- **ID**: CVE\-2026\-128126 / GHSA\-xgw8\-8ccx\-rmqh
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: Python
- **公開**: 2026-11-13

## 原文

AIOHTTP is an asynchronous HTTP client/server framework for asyncio and Python\. Prior to 3\.14\.4, Request\.post\(\) does not limit the number of fields in a URL\-encoded form body, and inserting many repeated keys into MultiDict takes quadratic time on the event loop\. A remote attacker can send a form POST within client\_max\_size to a handler that calls Request\.post\(\) and block the event loop\. This issue is fixed in version 3\.14\.4\.
