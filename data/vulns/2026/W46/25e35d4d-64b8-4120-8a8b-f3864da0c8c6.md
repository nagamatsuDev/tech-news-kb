# AIOHTTP\: Too many URL\-encoded form fields block the event loop

- **ID**: CVE\-2026\-128126 / GHSA\-xgw8\-8ccx\-rmqh
- **危険度**: High（重要）
- **言語**: Python
- **パッケージ**: PyPI/aiohttp &lt;\= 3\.14\.3 → 3\.14\.4
- **公開**: 2026-11-13

## 原文

\#\#\# Summary \`Request\.post\(\)\` had no limit on the number of fields in a URL\-encoded form body\. Inserting a large number of repeated keys into a \`MultiDict\` took quadratic time on the event loop\. \#\#\# Impact An attacker could block the event loop with a form POST within the default \`client\_max\_size\` to any handler that calls \`Request\.post\(\)\`\. \-\-\- Patch\: https\://github\.com/aio\-libs/aiohttp/commit/615fec3d4f088f30d2ee72cad760152e92aa1c53
