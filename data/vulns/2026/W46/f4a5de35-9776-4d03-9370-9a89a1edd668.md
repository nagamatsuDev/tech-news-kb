# OpenEMR before 8\.5\.0 contains multiple sql injection vulnerabilities that allow authenticated users to inject payloads through ERA CLP01,\.\.\.

- **ID**: CVE\-2026\-126463
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains multiple sql injection vulnerabilities that allow authenticated users to inject payloads through ERA CLP01, form\_facility, form\_icd\_codes, and POST key names\. Attackers can perform UNION, blind, and error\-based injection to read users\_secure password hashes and patient PHI, and overwrite patient\_data fields\.
