# Cudy TR3000 before 2\.5\.42 contains an OS command injection vulnerability that allows a malicious or compromised ACS to execute commands a\.\.\.

- **ID**: CVE\-2026\-75495
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-13

## 原文

Cudy TR3000 before 2\.5\.42 contains an OS command injection vulnerability that allows a malicious or compromised ACS to execute commands as root by supplying a crafted InternetGatewayDevice\.User\.\{i\}\.Password value\. Attackers can send a SetParameterValues request with shell metacharacters that obuspa\_system\.lua concatenates into a luci\.util\.exec\(\) command string, gaining root command execution\.
