# FFmpeg through 9\.0\.2 contains a heap buffer overflow vulnerability in the APNG encoder's encode\_apng\(\) function in libavcodec/pngenc\.c wh\.\.\.

- **ID**: CVE\-2026\-125218
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-09

## 原文

FFmpeg through 9\.0\.2 contains a heap buffer overflow vulnerability in the APNG encoder's encode\_apng\(\) function in libavcodec/pngenc\.c when frame size changes mid\-stream\. Attackers can supply crafted media whose resolution grows mid\-stream, causing APNG\_DISPOSE\_OP\_BACKGROUND memset writes past prev\_frame and crashing or corrupting heap memory in transcoding applications\.
