# SvelteKit\: \`@sveltejs/adapter\-node\` crashes when proxying certain requests via \`fetch\`

- **ID**: CVE\-2026\-128123 / GHSA\-rqw3\-x7hx\-mm3p
- **危険度**: Medium（警告） (CVSS 5.9)
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/@sveltejs/adapter\-node &gt;\= 5\.5\.7, &lt; 5\.5\.8 → 5\.5\.8, npm/@sveltejs/adapter\-node &gt;\= 6\.0\.0\-next\.0, &lt; 6\.0\.1 → 6\.0\.1
- **公開**: 2026-11-13

## 原文

In affected versions, \`@sveltejs/adapter\-node\` can attempt to add a header to an immutable request in a context that causes the server to crash, denying service to any other requests routed to that server\.
