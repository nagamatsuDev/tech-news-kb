# Software installed and run as a non\-privileged user may conduct GPU system calls to trigger an integer overflow and allow OOB writes to G\.\.\.

- **ID**: CVE\-2026\-49747
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-13

## 原文

Software installed and run as a non\-privileged user may conduct GPU system calls to trigger an integer overflow and allow OOB writes to GPU buffers\.
  
The integer overflow caused when mapping a GPU buffer &gt;4GB causes corruption of array length, and can lead to kernel panics or out of bounds access\.
