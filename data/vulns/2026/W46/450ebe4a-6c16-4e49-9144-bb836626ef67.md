# BACnet Stack is a BACnet open source protocol stack C library for embedded systems\.

- **ID**: CVE\-2026\-102612
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-13

## 原文

BACnet Stack is a BACnet open source protocol stack C library for embedded systems\. Prior to versions 1\.4\.6, 1\.5\.2, and 1\.6\.1, bws\_srv\_start\(\) in ports/linux/websocket\-srv\.c builds the libwebsockets server context with a CA certificate loaded but never sets LWS\_SERVER\_OPTION\_REQUIRE\_VALID\_OPENSSL\_CLIENT\_CERT, so the hub accepts TLS connections from clients presenting no certificate at all\. Any network\-reachable host can join the BACnet/SC mesh without credentials\. This issue has been patched in versions 1\.4\.6, 1\.5\.2, 1\.6\.1, and 1\.7\.0\.
