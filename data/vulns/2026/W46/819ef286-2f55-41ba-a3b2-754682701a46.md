# Synology DiskStation Manager \(DSM\) の共有 API の制限されたディレクトリ脆弱性に対するパス名の不適切な制限。

- **ID**: CVE\-2026\-18792
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-12

## 概要（機械翻訳）

Synology DiskStation Manager \(DSM\) の共有APIにおいて、7\.3\.2\-86009\-5および7\.4\.1\-90080\-1以前の制限されたディレクトリ脆弱性に対するパス名の不適切な制限により、リモート認証されたユーザが iXiXary ファイルを読み書きし、サービス拒否攻撃を行うことができる。

## 原文

An improper limitation of a pathname to a restricted directory vulnerability in the Sharing API in Synology DiskStation Manager \(DSM\) before 7\.3\.2\-86009\-5 and 7\.4\.1\-90080\-1 allows remote authenticated users to read or write arbitrary files and conduct denial\-of\-service attacks\.
