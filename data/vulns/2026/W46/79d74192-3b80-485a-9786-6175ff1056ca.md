# Kanbanz by Softaculous plugin for WordPress before 1\.0\.3 contains a broken access control vulnerability that allows authenticated Kanban \.\.\.

- **ID**: CVE\-2026\-127215
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-13

## 原文

Kanbanz by Softaculous plugin for WordPress before 1\.0\.3 contains a broken access control vulnerability that allows authenticated Kanban Staff users to access and modify boards they are not members of by exploiting admin\-ajax handlers that fail to call kanbanz\_user\_can\_access\_board\(\) or per\-task edit checks on attacker\-supplied board\_id or task\_id parameters\. Attackers can supply arbitrary board IDs to read sensitive task data, overwrite status columns, subtasks, and labels, inject comments, upload or delete attachments, and create tasks or set WIP limits on boards owned by other teams\.
