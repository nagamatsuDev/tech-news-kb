# sqlite3\-ruby\: Possible SQL query truncation when a string is 4 GiB or larger

- **ID**: CVE\-2026\-128084 / GHSA\-4fqr\-96q8\-xrfx
- **危険度**: Medium（警告） (CVSS 4.8)
- **言語**: Ruby
- **パッケージ**: RubyGems/sqlite3 &lt;\= 2\.10\.1 → 2\.10\.2
- **公開**: 2026-11-13

## 原文

\#\#\# Summary sqlite3\-ruby cast Ruby string lengths \(\`long\`\) to \`int\` before passing them to SQLite\. On 64\-bit platforms, a string of 4 GiB \(2\^32 bytes\) or larger had its length wrap, so SQLite saw only the first \`length mod 2\^32\` bytes\. An attacker who controls the length of a SQL string could truncate the query, for example dropping a trailing \`WHERE\` clause\.
