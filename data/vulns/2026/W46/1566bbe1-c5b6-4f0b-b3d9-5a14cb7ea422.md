# On Darwin, building a malicious package that uses cgo could cause arbitrary code execution when using the Apple linker due to passing "\-l\.\.\.

- **ID**: CVE\-2026\-97036
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-11

## 原文

On Darwin, building a malicious package that uses cgo could cause arbitrary code execution when using the Apple linker due to passing "\-l to\_library &lt;path&gt;" in a "\#cgo LDFLAGS" directive\. The Apple linker recombines the separated arguments "\-l" and "to\_library" into "\-lto\_library", which loads an arbitrary LTO plugin dynamic library at link time\. The go command now disallows "\-l" followed by "to\_library" in "\#cgo LDFLAGS", rejects "\-lazy\_library", "\-lazy\_framework", "\-load\_hidden", "\-library", and "\-library\-path", and checks recombined "\-l" arguments against disallowed linker flags and patterns\.
