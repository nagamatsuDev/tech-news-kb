# BACnet Stack is a BACnet open source protocol stack C library for embedded systems\.

- **ID**: CVE\-2026\-45265
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-11-12

## 原文

BACnet Stack is a BACnet open source protocol stack C library for embedded systems\. Prior to versions 1\.4\.4 and 1\.5\.1, there is a stack\-based out\-of\-bounds write / stack\-buffer\-overflow in bacnet\-stack when the server processes a malicious Atomic\-Read\-File request in record access mode\. The bug is triggered on the real server side\. A crafted request can set an excessively large RecordCount, which is later used as the loop bound for writing record data into a stack\-allocated BACNET\_ATOMIC\_READ\_FILE\_DATA data structure\. However, the stack object only has space for one fileData element\. When the loop reaches i \= 1, the code computes &amp;data\-&gt;fileData\[1\], which is already out of bounds, and the resulting invalid pointer is passed down to memmove\(\), causing a stack\-buffer\-overflow\. This issue has been patched in versions 1\.4\.4 and 1\.5\.1\.
