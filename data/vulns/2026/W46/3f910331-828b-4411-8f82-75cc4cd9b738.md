# vLLM from 0\.10\.1 before 0\.31\.0 forwards a request\-controlled mm\_processor\_kwargs\.max\_patches value to the Hugging Face processor for Cohe\.\.\.

- **ID**: CVE\-2026\-126397
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-13

## 原文

vLLM from 0\.10\.1 before 0\.31\.0 forwards a request\-controlled mm\_processor\_kwargs\.max\_patches value to the Hugging Face processor for Cohere2 Vision models without a server\-side upper bound, causing quadratic CPU work during multimodal preprocessing\. Remote clients can send small image chat\-completion requests with large, varying max\_patches values to bypass the LRU cache, exhaust preprocessing workers, and deny service to other clients\.
