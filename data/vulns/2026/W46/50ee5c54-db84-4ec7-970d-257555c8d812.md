# 8\.5\.0以前のOpenEMRには、認証された低価格の\.NETアプリケーションに任意の認証を可能にするccdaservice/ccda\_gateway\.phpに不正がある。

- **ID**: CVE\-2026\-126472
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-13

## 概要（機械翻訳）

8\.5\.0以前のOpenEMRには、認証された低特権スタッフユーザが他の患者のC\-CDA文書を取得できるccdaservice/ccda\_gateway\.phpに欠落した承認脆弱性が含まれている。攻撃者は、連続的な睡眠値および独自の CSRF トークンを使用して、薬、問題、アレルギー、および予防接種を列挙および駆逐するために、ビューまたはアクションを要求できます。。。

## 原文

OpenEMR before 8\.5\.0 contains a missing authorization vulnerability in ccdaservice/ccda\_gateway\.php that allows any authenticated low\-privilege staff user to retrieve other patients' C\-CDA documents\. Attackers can request the view or dl action with sequential pid values and their own CSRF token to enumerate and exfiltrate medications, problems, allergies, and immunizations\.
