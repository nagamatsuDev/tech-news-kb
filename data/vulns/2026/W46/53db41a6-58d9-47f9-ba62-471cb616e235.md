# AsyncSSH is a Python package which provides an asynchronous client and server implementation of the SSHv2 protocol on top of the Python a\.\.\.

- **ID**: CVE\-2026\-102643
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: Python
- **公開**: 2026-11-09

## 原文

AsyncSSH is a Python package which provides an asynchronous client and server implementation of the SSHv2 protocol on top of the Python asyncio framework\. Prior to 2\.24\.1, SFTPServer\.map\_path\(\) uses posixpath\.normpath\(\) on a client\-supplied path and removes only one leading slash before passing the result to posixpath\.join\(\) with the configured chroot\. An authenticated SFTP user can supply a path beginning with exactly two slash characters, causing POSIX normalization to preserve the double\-leading\-slash form and the subsequent join to treat the remaining pathname as absolute\. This bypasses the SFTP chroot and permits reads and writes with the operating\-system permissions of the account running the server, which may enable code execution depending on writable targets\. This issue is fixed in version 2\.24\.1\.
