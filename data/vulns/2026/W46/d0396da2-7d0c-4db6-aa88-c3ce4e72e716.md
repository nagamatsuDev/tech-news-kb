# A security flaw has been discovered in Linksys EA8100 1\.0\.3\.216940\.

- **ID**: CVE\-2026\-127277
- **危険度**: Critical（緊急） (CVSS 10.0)
- **公開**: 2026-11-13

## 原文

A security flaw has been discovered in Linksys EA8100 1\.0\.3\.216940\. The affected element is an unknown function of the file etc/init\.d/service\_smbd\.sh of the component SMB Service\. Performing a manipulation of the argument ANON\_ACCESS results in improper initialization\. The attack can be initiated remotely\. The exploit has been released to the public and may be used for attacks\. The vendor was contacted early about this disclosure but did not respond in any way\.
