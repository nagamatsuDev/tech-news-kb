# Unauthorization vulnerability in the management of workflow definitions in OpenKM Community Edition\.

- **ID**: CVE\-2026\-112182
- **危険度**: High（重要） (CVSS 8.7)
- **言語**: Java/Kotlin
- **公開**: 2026-11-13

## 原文

Unauthorization vulnerability in the management of workflow definitions in OpenKM Community Edition\. The REST endpoints \`registerProcessDefinition\` and \`runProcessDefinition\` require authentication but do not verify roles in the WorkflowService or in lower layers\. An attacker with the \`ROLE\_USER\` role can register and execute a process definition containing BeanShell scripts, allowing them to execute Java code and operating system commands with the service’s privileges\. In the official Docker image, the process runs as root\.
