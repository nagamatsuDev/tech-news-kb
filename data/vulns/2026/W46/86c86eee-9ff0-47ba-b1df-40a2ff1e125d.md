# A improper neutralization of special elements used in an os command \('os command injection'\) vulnerability in Fortinet FortiAnalyzer 8\.0\.\.\.\.

- **ID**: CVE\-2026\-126231
- **危険度**: High（重要） (CVSS 7.2)
- **公開**: 2026-11-11

## 原文

A improper neutralization of special elements used in an os command \('os command injection'\) vulnerability in Fortinet FortiAnalyzer 8\.0\.0, FortiAnalyzer 7\.6\.0 through 7\.6\.7, FortiAnalyzer 7\.4\.0 through 7\.4\.11, FortiAnalyzer 7\.2\.0 through 7\.2\.13, FortiAnalyzer Cloud 7\.6\.0 through 7\.6\.7, FortiAnalyzer Cloud 7\.4\.1 through 7\.4\.11, FortiAnalyzer Cloud 7\.2 all versions, FortiManager 8\.0\.0, FortiManager 7\.6\.0 through 7\.6\.7, FortiManager 7\.4\.0 through 7\.4\.11, FortiManager 7\.2\.0 through 7\.2\.13, FortiManager Cloud 7\.6\.0 through 7\.6\.7, FortiManager Cloud 7\.4\.1 through 7\.4\.11, FortiManager Cloud 7\.2 all versions may allow an authenticated attacker to execute unauthorized commands via a crafted HTTP request\.
