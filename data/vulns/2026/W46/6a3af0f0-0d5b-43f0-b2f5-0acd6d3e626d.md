# Soup Sieve\: Uncontrolled recursion in CSS parser lets nested pseudo\-class selectors exhaust the Python call stack

- **ID**: CVE\-2026\-126193 / GHSA\-7g44\-g9rc\-x53w
- **危険度**: Medium（警告） (CVSS 5.3)
- **言語**: Python
- **パッケージ**: PyPI/soupsieve &gt;\= 0\.4, &lt;\= 2\.10 → 3\.0\.2
- **公開**: 2026-11-13

## 原文

\#\# Summary The Soup Sieve CSS selector parser recurses once per level of nested pseudo\-class selector \(\`\:is\(\)\`, \`\:not\(\)\`, \`\:where\(\)\`, \`\:has\(\)\`\) without any limit on nesting depth\.
