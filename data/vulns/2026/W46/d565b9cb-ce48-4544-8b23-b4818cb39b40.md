# The RegistrationMagic WordPress plugin before 6\.1\.0\.4 does not properly escape a user\-supplied value before printing it inside an inline\.\.\.

- **ID**: CVE\-2026\-110987
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: JavaScript/TypeScript, PHP
- **公開**: 2026-11-15

## 原文

The RegistrationMagic  WordPress plugin before 6\.1\.0\.4 does not properly escape a user\-supplied value before printing it inside an inline script block on several of its admin screens, allowing unauthenticated attackers to inject arbitrary JavaScript that executes in the session of an administrator who is tricked into opening a crafted link\.
