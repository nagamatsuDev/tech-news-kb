# AIOHTTP\: Base64 multipart parts bypass client\_max\_size

- **ID**: CVE\-2026\-128127 / GHSA\-24c4\-3p7v\-29cm
- **危険度**: High（重要） (CVSS 8.7)
- **言語**: Python
- **パッケージ**: PyPI/aiohttp &lt;\= 3\.14\.3 → 3\.14\.4
- **公開**: 2026-11-13

## 原文

\#\#\# Summary When reading a multipart part with \`Content\-Transfer\-Encoding\: base64\`, \`BodyPartReader\.read\_chunk\(\)\` kept reading until the chunk length was a multiple of 4, with no byte limit\. A part with a short \`Content\-Length\`, or a long run of whitespace, could cause the entire remaining body to be read into memory within a single call before any size check, or spin on the event loop\. \#\#\# Impact An attacker could bypass \`client\_max\_size\` to cause excessive memory use, or block the event loop, with a specially crafted multipart request to any handler that reads multipart data\. \-\-\- Patch\: http
