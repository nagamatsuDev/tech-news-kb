# AIOHTTP is an asynchronous HTTP client/server framework for asyncio and Python\.

- **ID**: CVE\-2026\-128127 / GHSA\-24c4\-3p7v\-29cm
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: Python
- **公開**: 2026-11-13

## 原文

AIOHTTP is an asynchronous HTTP client/server framework for asyncio and Python\. Prior to 3\.14\.4, BodyPartReader\.read\_chunk\(\) processing a multipart part with Content\-Transfer\-Encoding set to base64 keeps reading until the chunk length is a multiple of four without enforcing a byte limit\. A short Content\-Length or a long run of whitespace can cause one call to read the remaining body into memory before the size check or spin on the event loop\. A remote attacker can send such a multipart request to a handler that reads multipart data and bypass client\_max\_size\. This issue is fixed in version 3\.14\.4\.
