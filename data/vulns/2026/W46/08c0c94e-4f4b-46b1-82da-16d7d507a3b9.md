# 脆弱性はDrayTek Vigor 2960 1\.5\.1\.6に見つかっている。

- **ID**: CVE\-2026\-129452
- **危険度**: Critical（緊急） (CVSS 9.1)
- **公開**: 2026-11-15

## 原文

A vulnerability has been found in DrayTek Vigor2960 1\.5\.1\.6\. This vulnerability affects the function set\_table of the file /cgi\-bin/mainfunction\.cgi\. Such manipulation of the argument jsondata leads to command injection\. The attack can be launched remotely\. The exploit has been disclosed to the public and may be used\. Upgrading to version 1\.5\.1\.7 is able to resolve this issue\. It is suggested to upgrade the affected component\. The vendor recommends\: "1\.5\.1\.6 isn't the latest version of 2960, the latest version fixes many security issues\. And we have another one in our release plan which should solve the issues reported\."
