# A vulnerability was found in Kingston FURY CTRL RGB Control Software up to 2\.0\.66\.0\.

- **ID**: CVE\-2026\-129261
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-11-14

## 原文

A vulnerability was found in Kingston FURY CTRL RGB Control Software up to 2\.0\.66\.0\. The impacted element is an unknown function in the library NTIOLib\_X64\.sys of the component IOCTL Handler\. Performing a manipulation results in exposed ioctl with insufficient access control\. The attack is only possible with local access\.
