# D\-Link DIR\-600L 2\.17/2\.17b02 で脆弱性が検出された。

- **ID**: CVE\-2026\-129353
- **危険度**: Critical（緊急） (CVSS 10.0)
- **公開**: 2026-11-15

## 概要（機械翻訳）

D\-Link DIR\-600L 2\.17/2\.17b02 で脆弱性が検出された。この脆弱性の影響は、ファイルの認証\.cgiの機能認証cgi\_mainです。。Hgghment ID/パスワード操作を実行すると、スタックベースのバッファオーバーフローが発生する。

## 原文

A vulnerability was detected in D\-Link DIR\-600L 2\.17/2\.17b02\. Affected by this vulnerability is the function authenticationcgi\_main of the file authentication\.cgi\. Performing a manipulation of the argument id/password results in stack\-based buffer overflow\. Remote exploitation of the attack is possible\. The exploit is now public and may be used\.
