# Ettercap before 0\.8\.5\.1 contains a heap out\-of\-bounds read vulnerability in sslw\_get\_clienthello\_sni\(\) in src/ec\_sslwrap\.c that trusts th\.\.\.

- **ID**: CVE\-2026\-125402
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-10

## 原文

Ettercap before 0\.8\.5\.1 contains a heap out\-of\-bounds read vulnerability in sslw\_get\_clienthello\_sni\(\) in src/ec\_sslwrap\.c that trusts the unchecked 16\-bit SNI length field\. Network\-adjacent attackers can send crafted TLS ClientHello messages during SSL interception to leak up to 64 KB of heap memory upstream or crash Ettercap\.
