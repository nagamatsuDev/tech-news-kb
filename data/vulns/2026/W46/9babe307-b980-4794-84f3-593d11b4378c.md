# OpenEMR before 8\.5\.0には、認証された低特権ユーザがレポートにアクセスし、\.NET Coreにアクセスできる、認可されていない脆弱性が含まれている。

- **ID**: CVE\-2026\-126468
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-13

## 概要（機械翻訳）

OpenEMR before 8\.5\.0には、認証された低特権ユーザがAclMain\:\:aclCheckCore\(\)チェックが欠落しているレポート、日付リマインダ、バッチリマインダエンドポイントにアクセスするための、認証エラーの脆弱性が含まれている。\.\.\.\.コード\.コード\.攻撃者は、patient\_list\.php、amc\_full\_report\.php、dated\_reminders\_add\.php、batch\_reminders\.phpを直接要求して、患者PHIをエクスポートし、無許可のリマインダーを送信し、バッチリマインダー処理をトリガーすることができる。

## 原文

OpenEMR before 8\.5\.0 contains a missing authorization vulnerability that allows any authenticated low\-privilege user to access reports, dated reminders, and batch reminder endpoints lacking AclMain\:\:aclCheckCore\(\) checks\. Attackers can request patient\_list\.php, amc\_full\_report\.php, dated\_reminders\_add\.php, or batch\_reminders\.php directly to export patient PHI, send unauthorized reminders, and trigger batch reminder processing\.
