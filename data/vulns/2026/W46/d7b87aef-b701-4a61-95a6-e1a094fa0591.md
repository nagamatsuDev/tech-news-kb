# OpenEMR before 8\.5\.0には、認証されたユーザが患者レコードや列挙子を作成することができる、認可の脆弱性がない。

- **ID**: CVE\-2026\-126466
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-13

## 概要（機械翻訳）

8\.5\.0以前のOpenEMRには、認証されたユーザがaclCheckCore\(\)チェックを省略して患者レコードを作成して、患者を列挙できる、認可されていない脆弱性が含まれている。は、\.\.\.が\.である。攻撃者は new\_comprehensive\_save\.php に投稿して保険 PHI を持つ患者を作成するか、クエリ new\_search\_popup\.php およびPatient\_select\.php にリーク名、SSN、DOB を生成できます。

## 原文

OpenEMR before 8\.5\.0 contains a missing authorization vulnerability that allows any authenticated user to create patient records and enumerate patients by omitting aclCheckCore\(\) checks\. Attackers can POST to new\_comprehensive\_save\.php to create patients with insurance PHI, or query new\_search\_popup\.php and patient\_select\.php to leak names, SSNs and DOBs\.
