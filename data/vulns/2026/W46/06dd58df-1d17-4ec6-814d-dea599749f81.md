# ExcelJS through 4\.4\.0 contains a prototype pollution vulnerability in mergeConditionalFormattings that allows attackers to modify Object\.\.\.\.

- **ID**: CVE\-2026\-128337
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-13

## 原文

ExcelJS through 4\.4\.0 contains a prototype pollution vulnerability in mergeConditionalFormattings that allows attackers to modify Object\.prototype by supplying an x14\:cfRule id of \_\_proto\_\_\. Attackers can craft an xlsx file that, when loaded with xlsx\.load\(\), sets properties such as type, direction, border and cfvo on every object in the process until it restarts\.
