# OpenEMR before 8\.5\.0には、認証されたユーザがシステム全体のグローバル構成を上書きできる認可バイパス脆弱性が含まれている。

- **ID**: CVE\-2026\-126487
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-13

## 概要（機械翻訳）

8\.5\.0以前のOpenEMRには、認証されたユーザがlibr/ajax/user\_settings\.phpを通じてグローバルプレフィックスキーを格納することで、システム全体のグローバル構成値をオーバーライドできる認可バイパス脆弱性が含まれている。攻撃者は、グローバル\:プレフィックスされた設定名を使用してラベルまたはターゲットパラメータを送信し、監査ロギングを無効にしたり、パスワードポリシーを弱めたり、セッションにセキュリティに敏感な設定を永続的に変更できます。。

## 原文

OpenEMR before 8\.5\.0 contains an authorization bypass vulnerability that allows authenticated users to override system\-wide global configuration values by storing global\-prefixed keys through library/ajax/user\_settings\.php\. Attackers can submit lab or target parameters with global\: prefixed setting names to disable audit logging, weaken password policies, or alter security\-sensitive settings persistently for their sessions\.
