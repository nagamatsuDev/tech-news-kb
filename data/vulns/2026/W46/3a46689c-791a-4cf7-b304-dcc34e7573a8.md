# Kubero 3\.0\.0から3\.1\.1には認証バイパス脆弱性があり、認証されていないリモートアタッカーが管理者を偽装することができる。

- **ID**: CVE\-2026\-125370
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-10

## 概要（機械翻訳）

Kubero 3\.0\.0から3\.1\.1には認証バイパス脆弱性が含まれている。これにより、認証されていないリモートアタッカーは、JWT\_SECRETがリセットされたときにハードコードされたフォールバック署名シークレットを使用して管理JWTを鍛造できる。攻撃者は、JwtStrategy\.validate\(\)がデータベースのルックアップなしで信頼するJwtRaryロール、userGroup、およびパーミッションクレームを使用してトークンに署名し、パイプライン、アプリケーション、ユーザー、およびAPIトークンを制御できます。\.

## 原文

Kubero 3\.0\.0 through 3\.1\.1 contains an authentication bypass vulnerability that allows unauthenticated remote attackers to forge administrative JWTs by using a hardcoded fallback signing secret when JWT\_SECRET is unset\. Attackers can sign tokens with arbitrary role, userGroups and permissions claims, which JwtStrategy\.validate\(\) trusts without a database lookup, to take control of pipelines, applications, users and API tokens\.
