# C\-Kermit 8\.0\.200 before 11\.1\.515には、悪質なFTPサーバーが\.NET Coreで\.NET Coreで\.NET Coreで実行可能なgetresponse\(\)のバッファオーバーフロー脆弱性が含まれている。

- **ID**: CVE\-2026\-129123
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-13

## 概要（機械翻訳）

C\-Kermit 8\.0\.200 before 11\.1\.515には、ckcftp\.cのgetresponse\(\)にバッファオーバーフロー脆弱性があり、悪意あるFTPサーバーは、過度に長いセキュリティ応答を送信してクライアントメモリを上書きできる。FTPサーバーを制御またはインターセプトする攻撃者は、AUTH TLSの後、またはGSSAPI、Kerberos 4、およびSRPビルドに長いADAT応答を送信し、攻撃者によって制御されるバイトで静的応答\_bufをあふれさせる。

## 原文

C\-Kermit 8\.0\.200 before 11\.1\.515 contains a buffer overflow vulnerability in getreply\(\) in ckcftp\.c that allows malicious FTP servers to overwrite client memory by sending overlong security replies\. Attackers controlling or intercepting an FTP server can send long PBSZ replies after AUTH TLS, or long ADAT replies in GSSAPI, Kerberos 4, and SRP builds, overflowing the static reply\_buf with attacker\-controlled bytes\.
