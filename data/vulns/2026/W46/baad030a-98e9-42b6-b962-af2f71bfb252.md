# XWEB EVO 5\.6\.2 through 5\.8\.8 contains a hardcoded credential vulnerability where the Administrator web account is configured to use passw\.\.\.

- **ID**: CVE\-2026\-124012
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-12

## 原文

XWEB EVO 5\.6\.2 through 5\.8\.8 contains a hardcoded credential vulnerability where the Administrator web account is configured to use password\_mode daily\_password with no stored password, as the Users\.authenticate function in lualib\_users\.lua synthesizes the Administrator configuration without validating any stored secret\. Attackers who can derive the MAC\-based daily password can authenticate as Administrator to obtain a full admin session on the device\. This product line reached it's end of service date in March 2026\.
