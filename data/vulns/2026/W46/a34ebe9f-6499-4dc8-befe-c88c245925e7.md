# Loop with Unreachable Exit Condition \('Infinite Loop'\) vulnerability in elixir\-grpc grpc\_server and grpc allows unauthenticated attackers\.\.\.

- **ID**: CVE\-2026\-121809
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-11-13

## 原文

Loop with Unreachable Exit Condition \('Infinite Loop'\) vulnerability in elixir\-grpc grpc\_server and grpc allows unauthenticated attackers to occupy a BEAM scheduler indefinitely via a client\-streaming or bidirectional\-streaming request whose body ends inside a gRPC message\.
  
GRPC\.Server\.Adapters\.Cowboy\.read\_stream/1 \(grpc\_server/lib/grpc/server/adapters/cowboy\.ex, and the Cowboy adapter in grpc before the package split\) asks for more data whenever the buffer does not hold a complete message\. Once the request body has ended, every further read returns an empty chunk, so the buffer never changes and the function retries without end\. A single 5\-byte length prefix sent with END\_STREAM keeps one scheduler busy for as long as the connection stays open, and repeated requests exhaust all schedulers\.
  
This issue affects grpc\: from 0\.3\.1 before 1\.0\.0; grpc\_server\: from 1\.0\.0 before 1\.1\.0\.
