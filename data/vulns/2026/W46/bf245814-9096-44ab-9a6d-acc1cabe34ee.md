# Windows上のGoogle Chromeで、157\.0\.8103\.78以前の無料ブラウザでの利用により、リモート攻撃者がZbitarを実行できる可能性がある。

- **ID**: CVE\-2026\-126867
- **危険度**: High（重要） (CVSS 8.8)
- **OS**: Windows
- **公開**: 2026-11-11

## 概要（機械翻訳）

Windows上でGoogle Chromeで無料で使用した後、157\.0\.8103\.78の前にリモートアタッカーは、グラフ化されたHTMLページを介してサンドボックスの外にあるZbbaryコードを実行することができる。。\(クロムのセキュリティの重大度\:高\)\)

## 原文

Use after free in Browser in Google Chrome on on Windows prior to 157\.0\.8103\.78 allowed a remote attacker to potentially execute arbitrary code outside the sandbox via a crafted HTML page\. \(Chromium security severity\: High\)
