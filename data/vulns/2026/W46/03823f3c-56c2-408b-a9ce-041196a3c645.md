# BACnet Stack is a BACnet open source protocol stack C library for embedded systems\.

- **ID**: CVE\-2026\-52789
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-13

## 原文

BACnet Stack is a BACnet open source protocol stack C library for embedded systems\. Prior to versions 1\.4\.5, 1\.5\.1, and 1\.6\.0, a Denial of Service \(DoS\) vulnerability exists in the BACnet stack's ReadPropertyMultiple \(RPM\) handler\. When processing a malformed RPM request packet that lacks the expected closing tags, the function handler\_read\_property\_multiple enters an infinite loop\. This issue has been patched in versions 1\.4\.5, 1\.5\.1, and 1\.6\.0\.
