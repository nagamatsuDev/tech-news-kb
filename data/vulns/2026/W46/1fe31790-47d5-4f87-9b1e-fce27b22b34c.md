# OpenEMR before 8\.5\.0 contains an sql injection vulnerability in CcrTable\:\:insertApprovedData\(\) that allows authenticated users to inject \.\.\.

- **ID**: CVE\-2026\-126480
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains an sql injection vulnerability in CcrTable\:\:insertApprovedData\(\) that allows authenticated users to inject SQL through request parameter names used as column names\. Attackers can send crafted patient\_data\-\*\-sel parameters to the revandapprove route, lacking ACL and CSRF checks, to copy password hashes into patient fields or corrupt records\.
