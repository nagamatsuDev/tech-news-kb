# NLTK from 3\.10\.0 before 3\.10\.4 contains a symlink escape vulnerability in YCOECorpusReader that allows attackers to read files outside th\.\.\.

- **ID**: CVE\-2026\-126304 / GHSA\-qg35\-44qx\-7vrr
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-13

## 原文

NLTK from 3\.10\.0 before 3\.10\.4 contains a symlink escape vulnerability in YCOECorpusReader that allows attackers to read files outside the corpus root by planting psd or pos directory symlinks\. Attackers controlling a YCOE corpus can make parsed\_sents\(\) and tagged\_words\(\) return file content from other corpora or temporary files within the NLTK data sandbox\.
