# node\-fontnik is a library that delivers a range of glyphs rendered as SDFs \(signed distance fields\) in a protocol buffer\.

- **ID**: CVE\-2026\-63660
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-11

## 原文

node\-fontnik is a library that delivers a range of glyphs rendered as SDFs \(signed distance fields\) in a protocol buffer\. Prior to version 0\.7\.7, a crafted font could trigger a heap out\-of\-bounds write in RenderSDF \(include/mapbox/glyph\_foundry\_impl\.hpp\)\. RenderSDF computed the SDF bitmap allocation size as buffered\_width \* buffered\_height in 32\-bit unsigned int\. Glyph dimensions are derived from the uploaded font's outline bounding box with no upper bound, so a glyph large enough to make that product exceed 2³² wrapped to a small value\. The buffer was then under\-allocated while the render loop still wrote one byte per pixel, corrupting the heap \(CWE\-190 → CWE\-787\) and crashing the process\. A 680\-byte font is enough to drive FreeType to a 65536×65536 buffered glyph, wrapping the size to 0\. This issue has been patched in version 0\.7\.7\.
