## 原文

Cyrus SASL through 2\.1\.28 contains an authentication bypass vulnerability in the SRP server mechanism because srp\_server\_mech\_step2 does not reject client public values A that are multiples of N\. Unauthenticated network clients can send A equal to N to force a zero shared secret, authenticating as any existing user without the password and learning session keys\.
