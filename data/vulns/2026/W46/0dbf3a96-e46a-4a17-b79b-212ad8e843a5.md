# OpenEMR before 8\.5\.0 contains a missing authorization vulnerability in the FaxSMS module's utility\.php that allows read\-only demographics\.\.\.

- **ID**: CVE\-2026\-126420
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: PHP
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains a missing authorization vulnerability in the FaxSMS module's utility\.php that allows read\-only demographics users to create patient charts\. Attackers can submit the form\_create request with chosen identity fields to create fictitious or duplicate patients with employer, history, and insurance records\.
