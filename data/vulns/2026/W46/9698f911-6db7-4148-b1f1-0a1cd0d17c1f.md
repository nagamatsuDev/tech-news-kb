# Heap\-based Buffer Overflow in the io\-char library's DCMD\_CHR\_WAITINFO devctl\(\) handler could allow an attacker with local access to cause\.\.\.

- **ID**: CVE\-2026\-54436
- **危険度**: High（重要） (CVSS 7.4)
- **公開**: 2026-11-10

## 原文

Heap\-based Buffer  
Overflow in the io\-char library's DCMD\_CHR\_WAITINFO devctl\(\) handler could  
allow an attacker with local access to cause data tampering, arbitrary code  
execution, or a crash in the Character I/O device driver\.
