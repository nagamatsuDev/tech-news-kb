# OpenEMR before 8\.5\.0 contains a missing authorization vulnerability in portal/import\_template\.php, where several portal document template\.\.\.

- **ID**: CVE\-2026\-126486
- **危険度**: High（重要） (CVSS 7.6)
- **言語**: PHP
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains a missing authorization vulnerability in portal/import\_template\.php, where several portal document template modes lack admin/forms ACL and CSRF checks\. Any authenticated staff user can send mode\=save\_profiles to delete all template profile assignments, use other unguarded modes to push templates to patients or change categories, and read template bodies via mode\=get or getPdf\.
