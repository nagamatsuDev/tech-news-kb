# XWEB EVO 4\.4から5\.8\.8には、認証されていないZWBファイル書き込み脆弱性があり、リモートアタッカーはシステムを修正できる。

- **ID**: CVE\-2026\-124014
- **危険度**: Critical（緊急） (CVSS 9.1)
- **公開**: 2026-11-12

## 概要（機械翻訳）

XWEB EVO 4\.4から5\.8には認証されていないJWBの書き込み脆弱性があり、リモートアタッカーは、セッション検証を実行せず、生の未検証の要求本文を書き込むaction\=setで、postリクエストをconfig\.luaに移植することで、システム構成ファイルの/etc/xwebconfig\.jsonを修正することができる。攻撃者は、モデルやプラグインフィールドなどの構成値を変更したり、認証されていないアクション\=getおよびaction\=setオペレーションを介してSYSTEM\_NOT\_FIGUREDステートをトリガーしたりすることで、コンフィギュレーションを改ざんしてサービスの拒否を行うことができる。\.\.\.\.ファイルは、\.ファイルに格納される。

## 原文

XWEB EVO 4\.3\.0 through 5\.8\.8 contains an unauthenticated arbitrary file write vulnerability that allows remote attackers to modify the system configuration file /etc/xwebconfig\.json by sending a crafted POST request to config\.lua with action\=set, which performs no session validation and writes the raw, unvalidated request body\. Attackers can tamper with configuration values such as model and plugin fields or trigger a SYSTEM\_NOT\_CONFIGURED state via the unauthenticated action\=get and action\=set operations, resulting in configuration tampering and denial of service\. This product line reached it's end of service date in March 2026\.
