# FFmpeg through 9\.0\.2 contains an integer overflow vulnerability in hap\_parse\_frame\_header\(\) in libavcodec/hapdec\.c that allows attackers \.\.\.

- **ID**: CVE\-2026\-125222
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-09

## 原文

FFmpeg through 9\.0\.2 contains an integer overflow vulnerability in hap\_parse\_frame\_header\(\) in libavcodec/hapdec\.c that allows attackers to trigger a heap buffer overflow on 32\-bit builds\. Attackers can craft Hap video frames with Snappy length prefixes that wrap tex\_size, causing decompress\_chunks\_thread\(\) to write outside tex\_buf and crash the application or potentially execute code\.
