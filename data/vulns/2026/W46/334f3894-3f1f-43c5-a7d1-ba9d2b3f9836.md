# FFmpeg through 9\.0\.2 contains an out\-of\-bounds write vulnerability in flic\_decode\_frame\_15\_16BPP\(\) in libavcodec/flicvideo\.c that allows \.\.\.

- **ID**: CVE\-2026\-125181
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-09

## 原文

FFmpeg through 9\.0\.2 contains an out\-of\-bounds write vulnerability in flic\_decode\_frame\_15\_16BPP\(\) in libavcodec/flicvideo\.c that allows attackers to corrupt heap memory on big\-endian builds\. Attackers can supply a crafted 15/16 bpp FLIC/FLX file with an FLI\_BRUN chunk whose non\-terminating byte\-swap loop writes packet\-derived data past the frame buffer, crashing the process\.
