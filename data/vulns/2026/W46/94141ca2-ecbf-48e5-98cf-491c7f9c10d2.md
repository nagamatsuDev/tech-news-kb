# 複数のファイルに境界線チェックがないため、境界外書き込みが可能になっている。

- **ID**: CVE\-2026\-55362
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-10

## 概要（機械翻訳）

複数のファイルに境界線チェックがないため、境界外書き込みが可能になっている。。これにより、追加の実行プリビレッジが不要になるリモートコード実行につながる可能性がある。探索にはユーザのインタラクションは必要ない。\)。。

## 原文

In multiple files, there is a possible out\-of\-bounds write due to a missing bounds check\. This could lead to remote code execution with no additional execution privileges needed\. User interaction is not needed for exploitation\.
