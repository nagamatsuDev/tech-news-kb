# Hugo Blog is a tech blog site\.

- **ID**: CVE\-2026\-68905
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-11-13

## 原文

Hugo Blog is a tech blog site\. In commit 744ca15 and prior, the AI assistant proxy exposes three HTTP endpoints \(POST /api/blog\-assistant, POST /api/blog\-search\-embedding, POST /api/blog\-search\-rerank\) without any authentication check\. When deployed following the documented Nginx reverse\-proxy setup, any unauthenticated remote attacker can send arbitrary requests that the proxy forwards to the upstream LLM/embedding/rerank API using the operator's server\-side API key \(OPENAI\_API\_KEY / AI\_SEARCH\_API\_KEY\)\. This enables unlimited quota consumption, cost exhaustion, and potential service unavailability for the operator\. At time of publication, there are no publicly available patches\.
