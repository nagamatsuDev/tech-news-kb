## 原文

A flaw has been found in DrayTek Vigor2960 up to 1\.5\.1\.6\. This affects the function app\_guest\_export of the file /cgi\-bin/mainfunction\.cgi\. This manipulation of the argument filename causes path traversal\. The attack can be initiated remotely\. The exploit has been published and may be used\. Upgrading to version 1\.5\.1\.7 is able to mitigate this issue\. The affected component should be upgraded\. The vendor recommends\: "1\.5\.1\.6 isn't the latest version of 2960, the latest version fixes many security issues\. And we have another one in our release plan which should solve the issues reported\."
