# Vulnerability due to inadequate restriction of references to external XML entities in OpenKM Community Edition\.

- **ID**: CVE\-2026\-112181
- **危険度**: High（重要） (CVSS 8.3)
- **公開**: 2026-11-13

## 原文

Vulnerability due to inadequate restriction of references to external XML entities in OpenKM Community Edition\. The XML processing in FormUtils / LocalEntityResolver does not properly restrict the resolution of external resources\. An authenticated remote attacker with the ROLE\_USER role can exploit the flaw via a REST request\. In the 6\.3\.x branch, this allows the attacker to trigger HTTP requests under their control \(SSRF\); in 7\.0\.3, it allows the attacker to read local files and access internal HTTP resources from the server\.
