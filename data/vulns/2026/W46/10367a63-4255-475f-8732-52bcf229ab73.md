# OpenTelemetry JavaScript\: Insertion of Sensitive Information into Log File and Exposure of Sensitive Information to an Unauthorized Actor in @opentelemetry/instrumentation\-http

- **ID**: CVE\-2026\-128080 / GHSA\-3v2p\-hm54\-8qcq
- **危険度**: Medium（警告） (CVSS 5.8)
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/@opentelemetry/instrumentation\-http &gt;\= 0\.204\.0, &lt; 0\.222\.0 → 0\.222\.0
- **公開**: 2026-11-13

## 原文

\#\#\# Summary \`@opentelemetry/instrumentation\-http\` redacts sensitive URL query parameters on \*\*outgoing \(client\) spans\*\* but not on \*\*incoming \(server\) spans\*\*\. The server\-span path writes the raw query string verbatim into the \`url\.query\` attribute, so credentials embedded in inbound request URLs — AWS presigned\-URL signatures, Azure SAS tokens \(\`sig\`\), GCS signed\-URL signatures — are exported in plaintext to the configured tracing backend\. Configuring the \`redactedQueryParams\` option \*\*does not change this\*\*, as this applies only to outgoing \(client\) spans\. \#\#\# Impact \*\*Information disclosure
