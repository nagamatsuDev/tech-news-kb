# AIOHTTP is an asynchronous HTTP client/server framework for asyncio and Python\.

- **ID**: CVE\-2026\-128130
- **危険度**: High（重要） (CVSS 8.3)
- **言語**: Python
- **公開**: 2026-11-13

## 原文

AIOHTTP is an asynchronous HTTP client/server framework for asyncio and Python\. Prior to 3\.14\.4, when the pipelined request queue is full, the pure\-Python parser stores the unparsed remainder internally and also returns the same data to its caller\. After a handler declines an upgrade request, the caller feeds the remainder back to the parser, causing the buffer to grow with each handled request and dispatching already\-handled requests to the application again\. The issue affects deployments using AIOHTTP\_NO\_EXTENSIONS or otherwise running without the standard C\-extension wheel, and can cause excessive memory use and repeated request processing\. This issue is fixed in version 3\.14\.4\.
