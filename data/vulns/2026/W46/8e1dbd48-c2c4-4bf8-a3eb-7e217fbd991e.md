# WooCommerce PayPal Pro Payment Gateway plugin before 4\.1\.1 contains an unauthenticated payment bypass vulnerability that allows remote at\.\.\.

- **ID**: CVE\-2026\-127204
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-12

## 原文

WooCommerce PayPal Pro Payment Gateway plugin before 4\.1\.1 contains an unauthenticated payment bypass vulnerability that allows remote attackers to mark unpaid orders as paid by exploiting the pp\_capture\_order AJAX handler, which is gated only by a public checkout nonce and fails to properly validate the PayPal capture response status\. Attackers can supply a valid \_paypal\_order\_id to trigger payment\_complete\(\) without verifying the capture status or amount, causing the store to fulfill goods or services that were never paid for and resulting in direct financial loss to the merchant\.
