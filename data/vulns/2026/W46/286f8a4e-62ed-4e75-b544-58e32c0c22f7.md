# Aptabase before commit 61d4c01 contains an authentication bypass vulnerability that allows unauthenticated attackers to forge sign\-in lin\.\.\.

- **ID**: CVE\-2026\-125758
- **危険度**: High（重要） (CVSS 7.4)
- **公開**: 2026-11-10

## 原文

Aptabase before commit 61d4c01 contains an authentication bypass vulnerability that allows unauthenticated attackers to forge sign\-in links by using the publicly known example AUTH\_SECRET\. Attackers can enumerate registered e\-mails via /api/\_auth/signin, forge HS256 JWTs redeemed by /api/\_auth/continue, impersonate users, export analytics data, and transfer app ownership\.
