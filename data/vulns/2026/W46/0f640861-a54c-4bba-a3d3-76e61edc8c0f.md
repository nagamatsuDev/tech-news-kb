# zizmor is a static analysis tool for CI/CD systems\.

- **ID**: CVE\-2026\-102289
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-09

## 原文

zizmor is a static analysis tool for CI/CD systems\. In version 1\.27\.0, debug logging serializes the parsed application configuration with a derived Debug implementation for GitHubToken, causing credentials supplied through GH\_TOKEN, GITHUB\_TOKEN, ZIZMOR\_GITHUB\_TOKEN, \-\-gh\-token, \-\-github\-token, or \-\-zizmor\-github\-token to be written to stderr in cleartext\. A single \-v or \-\-verbose option or an applicable RUST\_LOG directive enables the affected logging during normal online operation and \-\-no\-online\-audits, while explicit \-\-offline clears the token first\. If another party can read a CI log, support artifact, terminal capture, or public bug report containing the output, the party can use the credential according to its scopes, repository access, and lifetime\. This vulnerability is fixed in 1\.28\.0\.
