# NLTK\: Quadratic\-time CPU denial of service in ConllCorpusReader SRL instance builder via nested span rescan

- **ID**: CVE\-2026\-126297 / GHSA\-v8f3\-6phw\-6mh9
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: Python
- **パッケージ**: PyPI/nltk &lt;\= 3\.10\.3 → 3\.10\.4
- **公開**: 2026-11-13

## 原文

\#\# Summary \`ConllCorpusReader\.srl\_instances\(\)\` builds semantic\-role\-labeling instances from a CoNLL corpus block\. For a sentence block with P predicates and P span columns, the instance builder rescans every span column \(and every span within it\) once per predicate while searching for each predicate's head, giving O\(P\^2 \* R\) work\. A single well\-formed block that places the head span in the last column forces the full scan on every predicate, so an application that reads an attacker\-supplied CoNLL SRL corpus can be driven into tens of seconds of single\-threaded CPU\.
