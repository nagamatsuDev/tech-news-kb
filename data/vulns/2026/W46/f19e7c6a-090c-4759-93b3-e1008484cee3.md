# OpenEMR before 8\.5\.0 contains an improper authorization vulnerability in patient\_tracker\_status\.php that allows low\-privilege authenticat\.\.\.

- **ID**: CVE\-2026\-126416
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: PHP
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains an improper authorization vulnerability in patient\_tracker\_status\.php that allows low\-privilege authenticated users to modify other patients' tracker entries by supplying arbitrary tracker\_id values\. Attackers can post statustype and roomnum parameters with a valid CSRF token to alter patient\-flow status, room assignments, and linked calendar appointment state\.
