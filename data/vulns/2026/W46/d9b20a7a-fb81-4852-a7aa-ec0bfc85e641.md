# FFmpeg through 9\.0\.2 contains a heap buffer overflow vulnerability in dvbsub\_encode\(\) in libavcodec/dvbsubenc\.c that undercounts each CLU\.\.\.

- **ID**: CVE\-2026\-125233
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-09

## 原文

FFmpeg through 9\.0\.2 contains a heap buffer overflow vulnerability in dvbsub\_encode\(\) in libavcodec/dvbsubenc\.c that undercounts each CLUT segment header by two bytes\. Attackers can supply a file with many bitmap subtitle rectangles that, when transcoded to the dvbsub encoder, writes past the output buffer and corrupts heap memory\.
