# Seafile SeaDoc converter 2\.0\.4 before 2\.0\.11 and 3\.0\.0 before 3\.0\.8 contains an absolute path traversal vulnerability that allows unauthe\.\.\.

- **ID**: CVE\-2026\-129167
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: Python
- **公開**: 2026-11-13

## 原文

Seafile SeaDoc converter 2\.0\.4 before 2\.0\.11 and 3\.0\.0 before 3\.0\.8 contains an absolute path traversal vulnerability that allows unauthenticated attackers holding a public share token to execute code\. Attackers supply an absolute filename to /api/v1/confluence\-to\-wiki/ to extract a ZIP from download\_url into the Python library path, then trigger the module's import via a file\-convert request\.
