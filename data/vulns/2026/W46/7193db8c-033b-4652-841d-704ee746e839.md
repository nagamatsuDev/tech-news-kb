# OpenMage magento\-lts before 20\.18\.2 and 21\.x before 21\.0\.0\-beta3 validates OAuth 1\.0a oauth\_callback URLs with a string\-prefix check and \.\.\.

- **ID**: CVE\-2026\-128044
- **危険度**: High（重要） (CVSS 7.7)
- **公開**: 2026-11-13

## 原文

OpenMage magento\-lts before 20\.18\.2 and 21\.x before 21\.0\.0\-beta3 validates OAuth 1\.0a oauth\_callback URLs with a string\-prefix check and falls back to accepting any well\-formed URL\. Attackers holding a leaked consumer key and secret can supply host\-suffix, userinfo, or arbitrary callback URLs to capture an approving administrator's or customer's request token and verifier, then obtain an access token with the victim's API privileges\.
