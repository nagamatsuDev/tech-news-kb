# WWBN AVideo 6\.5から29\.7\.1には認証バイパス脆弱性があり、認証されていない攻撃者が任意の用途でログインできます。

- **ID**: CVE\-2026\-126542
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: PHP
- **公開**: 2026-11-11

## 概要（機械翻訳）

WWBN AVideo 6\.5から29\.7\.1には認証バイパス脆弱性があり、認証されていない攻撃者はHybridauthソーシャルログインディスプレイ名を介して任意のユーザとしてログインできる。は\.\.\.\.である。は\.\.\.\.\.。攻撃者は、X、Facebook、Yahoo、LinkedIn の表示名を被害者のユーザー名に設定し、メールを保留し、login\.json\.phpまたはoauth2\.phpにパスワードなしで管理者を含むそのアカウントとしてログインさせることができる。。は、ログイン時にログインされたパスワードが含まれていない。

## 原文

WWBN AVideo 6\.5 before 29\.8\.0 contains an authentication bypass vulnerability that allows unauthenticated attackers to log in as any user via Hybridauth social login display names\. Attackers can set their X, Facebook, Yahoo or LinkedIn display name to a victim's username and withhold email, causing login\.json\.php or oauth2\.php to log them in as that account, including administrators, without a password\.
