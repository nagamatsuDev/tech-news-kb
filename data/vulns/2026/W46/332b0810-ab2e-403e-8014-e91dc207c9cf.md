# Dolibarr 20\.0\.0 through 23\.0\.4 and 24\.x before 24\.0\.2 contains an insecure direct object reference vulnerability in api\_expensereports\.cl\.\.\.

- **ID**: CVE\-2026\-125754
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: PHP
- **公開**: 2026-11-10

## 原文

Dolibarr 20\.0\.0 through 23\.0\.4 and 24\.x before 24\.0\.2 contains an insecure direct object reference vulnerability in api\_expensereports\.class\.php payment endpoints that lets authenticated users access other users' expense report payments\. Attackers with only expense report read and create rights can call getAllPayments, getPayments, addPayment, or updatePayment to read, create, or modify payments, falsifying reimbursement state\.
