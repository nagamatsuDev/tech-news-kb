# 4\.5\.0以前のZiplineは、PATCHおよび\.NET 4\.5で所有権検証が欠落していることによって引き起こされる安全でない直接オブジェクト参照脆弱性を含んでいる。

- **ID**: CVE\-2026\-126948
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-13

## 概要（機械翻訳）

4\.5\.0以前のZiplineには、PATCHおよびDELETEハンドラの/api/user/folders/\:idの所有権検証の欠如による安全でない直接オブジェクト参照脆弱性が含まれている。\.\.\.は\.認証された攻撃者は、別のユーザのフォルダIDにその名前を変更したり、公開したり、アップロードを有効にしたり、削除したりできます。。は、あるがままのフォルダIDが、別のユーザのフォルダIDに渡される。

## 原文

Zipline before 4\.5\.0 contains an insecure direct object reference vulnerability caused by missing ownership verification in the PATCH and DELETE handlers for /api/user/folders/\:id\. Authenticated attackers can supply another user's folder ID to rename it, make it public, enable uploads, or delete it\.
