# MRBS before 1\.13\.0 contains a password reset poisoning vulnerability that allows unauthenticated attackers to redirect reset links by for\.\.\.

- **ID**: CVE\-2026\-129134
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-13

## 原文

MRBS before 1\.13\.0 contains a password reset poisoning vulnerability that allows unauthenticated attackers to redirect reset links by forging the Host header when \$url\_base is unset\. Attackers can request a reset for a victim so AuthDb\:\:notifyUser\(\) emails a link pointing to their host, capturing the reset key when opened to take over accounts including administrators\.
