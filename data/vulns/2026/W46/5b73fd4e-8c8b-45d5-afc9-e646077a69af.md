# OpenEMR before 8\.5\.0 contains a missing authorization vulnerability in interface/forms/procedure\_order/common\.php that allows authenticat\.\.\.

- **ID**: CVE\-2026\-126434
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains a missing authorization vulnerability in interface/forms/procedure\_order/common\.php that allows authenticated accounts lacking patients/lab permission to read and modify other patients' procedure orders\. Attackers can request a global order id to disclose clinical history, or select the target patient in their session and submit bn\_save to falsify diagnoses, instructions, and order status\.
