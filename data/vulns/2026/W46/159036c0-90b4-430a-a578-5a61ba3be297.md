- **危険度**: High（重要） (CVSS 7.2)

## 原文

Cudy TR3000 before 2\.5\.42 contains a command injection vulnerability that allows authenticated administrators to execute commands as root via the WireGuard server private\_key option\. Attackers can save a private key containing \$\(\) command substitution, which runs when action\_wireguards\_export\(\) passes it to luci\.sys\.exec during configuration export\.
