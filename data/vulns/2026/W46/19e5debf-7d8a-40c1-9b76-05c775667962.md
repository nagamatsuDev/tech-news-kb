# Docker Sandboxes reuses existing state and configuration directories without verifying their ownership\.

- **ID**: CVE\-2026\-126329
- **危険度**: High（重要） (CVSS 7.3)
- **OS**: macOS
- **公開**: 2026-11-12

## 原文

Docker Sandboxes reuses existing state and configuration directories without verifying their ownership\. If sbx or sandboxd is run as root with HOME or, on Linux, XDG\_STATE\_HOME pointing to an attacker\-controlled location, a local unprivileged user can substitute control\-plane sockets and configuration trusted by the root process, potentially executing commands as root\. Exploitation requires a privileged invocation with an attacker\-influenced environment\. The issue affects Linux and macOS and is fixed in version 0\.53\.0\.
