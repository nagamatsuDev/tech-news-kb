# Rooxis RXR\-12 Wi\-Fi router contains an undocumented telnet backdoor daemon \(/usr/bin/telnetd\_startup\) that, upon receipt of a precomputed\.\.\.

- **ID**: CVE\-2026\-126722
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-11

## 原文

Rooxis RXR\-12 Wi\-Fi router contains an undocumented telnet backdoor daemon \(/usr/bin/telnetd\_startup\) that, upon receipt of a precomputed AES\-128\-CBC magic packet using a firmware\-wide static key and IV, enables telnet service with default credentials, providing remote root access\. Firmware 20260813\_c2169ea5 removes the UDP listener entirely, and users can update through their local web interface\.
