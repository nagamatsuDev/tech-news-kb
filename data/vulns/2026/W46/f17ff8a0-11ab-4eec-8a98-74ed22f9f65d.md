# The Reset Database plugin for WordPress is vulnerable to privilege escalation in versions up to, and including, 1\.1\.3\.

- **ID**: CVE\-2026\-119615
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-11

## 原文

The Reset Database plugin for WordPress is vulnerable to privilege escalation in versions up to, and including, 1\.1\.3\. This is due to the process\_reset\(\) function being registered on admin\_init with no capability check, a computed\-but\-unused nonce, a gating condition that passes whenever no WordPress administrator literally named 'admin' exists \(the default on modern installs\), and an identity test that verifies the ATTACKER'S OWN password rather than an administrator's\. This makes it possible for authenticated attackers, with subscriber\-level access and above, to drop every prefixed database table, re\-run wp\_install\(\) with their own credentials — making the attacker the sole site administrator — authenticate as that administrator via wp\_set\_auth\_cookie\(\), and delete the uploads directory\.
