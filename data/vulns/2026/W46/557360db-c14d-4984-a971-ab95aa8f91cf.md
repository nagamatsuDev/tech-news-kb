# In fence\_manager\_extract\_iif of fence\_manager\.c, there is a possible way to corrupt kernel memory via fence identifier reuse due to a use\.\.\.

- **ID**: CVE\-2026\-59609
- **危険度**: High（重要） (CVSS 8.4)
- **公開**: 2026-11-10

## 原文

In fence\_manager\_extract\_iif of fence\_manager\.c, there is a possible way to corrupt kernel memory via fence identifier reuse due to a use after free\. This could lead to local escalation of privilege with no additional execution privileges needed\. User interaction is not needed for exploitation\.
