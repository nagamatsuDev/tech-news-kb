# 脆弱性はDrayTek Vigor 1960 1\.5\.1\.6で検出された。

- **ID**: CVE\-2026\-129450
- **危険度**: Critical（緊急） (CVSS 9.9)
- **公開**: 2026-11-15

## 概要（機械翻訳）

DrayTek Vigor 1960 1\.5\.1\.6で脆弱性が検出された。。この問題の影響を受けているのは、/cgi\-bin/main function\.cgi?action\=doWebBackup の関数 sub\_1E084 です。HgGumentオプションの操作は経路トラバーサルをもたらす。。。 \)。 \)。 。

## 原文

A vulnerability was detected in DrayTek Vigor2960 1\.5\.1\.6\. Affected by this issue is the function sub\_1E084 of the file /cgi\-bin/mainfunction\.cgi?action\=doWebBackup\. The manipulation of the argument option results in path traversal\. It is possible to launch the attack remotely\. The exploit is now public and may be used\. Upgrading to version 1\.5\.1\.7 can resolve this issue\. You should upgrade the affected component\. The vendor recommends\: "1\.5\.1\.6 isn't the latest version of 2960, the latest version fixes many security issues\. And we have another one in our release plan which should solve the issues reported\."
