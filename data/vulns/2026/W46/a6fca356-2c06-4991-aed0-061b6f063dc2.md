# FFmpeg through 9\.0\.2 contains a heap buffer overflow vulnerability in vaapi\_hevc\_start\_frame\(\) in libavcodec/vaapi\_hevc\.c that copies unb\.\.\.

- **ID**: CVE\-2026\-125202
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-09

## 原文

FFmpeg through 9\.0\.2 contains a heap buffer overflow vulnerability in vaapi\_hevc\_start\_frame\(\) in libavcodec/vaapi\_hevc\.c that copies unbounded PPS tile counts into fixed\-size arrays\. Attackers can supply a crafted HEVC bitstream with a large picture and many tiles to write controlled 16\-bit values past heap\-allocated hwaccel data, corrupting memory in applications decoding with VAAPI\.
