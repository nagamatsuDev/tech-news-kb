# OpenEMR before 8\.5\.0には、権限のない認証ユーザによる悪意あるデータ保存を可能にする、2次sqlインジェクション脆弱性が含まれている。

- **ID**: CVE\-2026\-126492
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-13

## 概要（機械翻訳）

8\.5\.0以前のOpenEMRには、2次sqlインジェクション脆弱性があり、特権の低い認証ユーザがライブラリ/ajax/addlistitem\.php経由で悪意あるSQLを保存できる。攻撃者は、dynamic\_finder\.phpがSELECTクエリに連結してSQLとして実行される、最近の\_patient\_columnsオプション\_id値にSQLフラグメントを永続化できます。\.\.

## 原文

OpenEMR before 8\.5\.0 contains a second\-order sql injection vulnerability that allows low\-privileged authenticated users to store malicious SQL via library/ajax/addlistitem\.php\. Attackers can persist a SQL fragment in the recent\_patient\_columns option\_id value, which dynamic\_finder\.php concatenates into a SELECT query and executes as SQL\.
