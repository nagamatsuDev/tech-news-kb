# Relative path traversal vulnerability in openEuler iSulad on Linux\.

- **ID**: CVE\-2026\-111435
- **危険度**: High（重要） (CVSS 7.4)
- **公開**: 2026-11-12

## 原文

Relative path traversal vulnerability in openEuler iSulad on Linux\.
  
This vulnerability is associated with program file src/daemon/modules/image/oci/oci\_load\.c\.
  
This issue affects iSulad\: through 2\.1\.6\.
  
In oci\_load\.c, oci\_load\_process\_manifest\(\) does not sanitize the Config path of manifest\.json\. A malicious tar package can enable the isulad with the root permission to read any file on the host\.
