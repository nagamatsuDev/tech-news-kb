# An mvfst QUIC server retained CRYPTO frame data received at an encryption level \(Initial or Handshake\) that the TLS handshake had already\.\.\.

- **ID**: CVE\-2026\-119236
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-11

## 原文

An mvfst QUIC server retained CRYPTO frame data received at an encryption level \(Initial or Handshake\) that the TLS handshake had already moved past\. Because the transport treated this data as delivered, it did not count against the CRYPTO stream buffer limit\. A remote, unauthenticated client could complete a handshake, withhold its acknowledgment of the server's HANDSHAKE\_DONE frame so that Handshake keys stay in use, and keep sending Handshake\-level CRYPTO data at increasing offsets, causing unbounded memory growth on the server and leading to denial of service\. This issue affects mvfst versions prior to v2026\.11\.09\.00\.
