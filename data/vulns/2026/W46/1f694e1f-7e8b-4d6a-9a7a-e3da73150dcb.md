# pgEdge Postgres MCP Serverは、Model Context Protocol互換クライアントを通してPostgre SQLデータベースに対するSQLクエリを可能にする。

- **ID**: CVE\-2026\-126197

## 原文

pgEdge Postgres MCP Server enables SQL queries against PostgreSQL databases through Model Context Protocol compatible clients\. Prior to 1\.1\.0, custom pl\-do tools interpolated JSON arguments into a PostgreSQL DO block delimited by fixed dollar\-quote tags\. An argument containing \$mcp\_custom\_tool\$ could terminate the block and inject arbitrary SQL statements, while \$mcp\_args\$ could inject procedural code into a plpgsql block\. Because the statement used the simple query protocol, injected text could include additional statements and transaction control, bypassing read\_only and accessing data or modifying resources available to the connecting role\. The issue requires at least one pl\-do custom tool; sql and pl\-func tools pass arguments as bind parameters and are not affected by this injection mechanism\. This issue is fixed in 1\.1\.0\.
