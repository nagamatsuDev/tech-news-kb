# Control Web Panel \(CWP\) before webpanel\_version 1\.30\.6 contains an authorization bypass vulnerability in the validate\(\) function of api/v\.\.\.

- **ID**: CVE\-2026\-124021
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-13

## 原文

Control Web Panel \(CWP\) before webpanel\_version 1\.30\.6 contains an authorization bypass vulnerability in the validate\(\) function of api/v1/index\.php that allows attackers holding a password\-recovery token and a predictable legacy signature to obtain valid remote\-API authorization without a proper API key\. Attackers can exploit this flaw via the POST /cronjobsusers/ endpoint to add arbitrary cron commands and achieve command execution as the affected hosting account, and can also abuse the same token to access global account\-list and account\-detail routes exposing usernames, contact emails, and password hashes\.
