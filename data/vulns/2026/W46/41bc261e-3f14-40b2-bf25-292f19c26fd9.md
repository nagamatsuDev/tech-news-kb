# OpenEMR before 8\.5\.0 contains a persistent SQL injection vulnerability in SLEOB\:\:slInvoiceNumber\(\), where the CLP01 claim control number \.\.\.

- **ID**: CVE\-2026\-126460
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: PHP
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains a persistent SQL injection vulnerability in SLEOB\:\:slInvoiceNumber\(\), where the CLP01 claim control number from uploaded X12 835 ERA files is concatenated unescaped into a query\. Attackers with billing write access can upload a crafted \.edi file via sl\_eob\_search\.php that is stored on the server and re\-executes a time\-based payload whenever it is reprocessed through sl\_eob\_process\.php, extracting patient health information\.
