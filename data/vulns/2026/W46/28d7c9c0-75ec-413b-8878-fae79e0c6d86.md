# BACnet Stack is a BACnet open source protocol stack C library for embedded systems\.

- **ID**: CVE\-2026\-47259
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-11-12

## 原文

BACnet Stack is a BACnet open source protocol stack C library for embedded systems\. Prior to versions 1\.4\.4, 1\.5\.1, and 1\.6\.0, a RemoveListElement request targeting Notification\-Class\.recipient\-list can trigger a stack\-based out\-of\-bounds write in the current master branch when the request contains more than NC\_MAX\_RECIPIENTS valid BACnetDestination elements\. This issue has been patched in versions 1\.4\.4, 1\.5\.1, and 1\.6\.0\.
