# Vvveb through 1\.0\.8\.6 contains a missing authorization vulnerability that allows low\-privilege vendors to rename, delete, or overwrite ot\.\.\.

- **ID**: CVE\-2026\-126375
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-13

## 原文

Vvveb through 1\.0\.8\.6 contains a missing authorization vulnerability that allows low\-privilege vendors to rename, delete, or overwrite other vendors' digital\-asset files in the shared storage/digital\_assets directory\. Attackers can send rename, delete, or upload requests to product/digital\-asset with another vendor's filename to break downloads or substitute malicious content\.
