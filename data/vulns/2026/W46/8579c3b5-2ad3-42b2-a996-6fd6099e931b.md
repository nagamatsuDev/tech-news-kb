# Rooxis RXR\-12 Wi\-Fi router contains an undocumented UID\-0 backdoor account \(dg\) with a firmware\-wide default password \(ivanlee\) and inter\.\.\.

- **ID**: CVE\-2026\-126724
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-11

## 原文

Rooxis RXR\-12 Wi\-Fi router contains an undocumented UID\-0 backdoor account \(dg\) with a firmware\-wide default password \(ivanlee\) and interactive shell \(/bin/ash\), allowing authentication as root via SSH or local console without device\-specific secrets\. Firmware 20260813\_c2169ea5 removes the account from the shipped root filesystem and disables root password authentication in SSH\. Users can update their router can be through the local web interface\.
