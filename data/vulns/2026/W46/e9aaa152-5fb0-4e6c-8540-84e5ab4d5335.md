# AIOHTTP is an asynchronous HTTP client/server framework for asyncio and Python\.

- **ID**: CVE\-2026\-123817
- **危険度**: High（重要） (CVSS 8.7)
- **言語**: Python
- **公開**: 2026-11-09

## 原文

AIOHTTP is an asynchronous HTTP client/server framework for asyncio and Python\. Prior to 3\.14\.4, the WebSocket reader retains one bytes object for each transport read while reassembling an incomplete frame\. A malicious peer can split a frame into many tiny reads so per\-object overhead substantially exceeds the payload bytes allowed by max\_msg\_size\. The condition affects a server receiving frames from a malicious client and a client receiving frames from a malicious server, and can cause excessive memory consumption or denial of service\. This issue is fixed in version 3\.14\.4\.
