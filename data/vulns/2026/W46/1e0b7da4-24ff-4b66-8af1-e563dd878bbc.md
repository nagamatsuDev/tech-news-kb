# Nuxt dev server serves files from a parent directory with a stray lockfile or workspace file

- **ID**: CVE\-2026\-128070 / GHSA\-mjrq\-cffv\-q4qc
- **危険度**: Medium（警告） (CVSS 5.9)
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/@nuxt/schema &gt;\= 3\.5\.0, &lt; 4\.6\.4 → 4\.6\.4
- **公開**: 2026-11-13

## 原文

\#\#\# Summary Nuxt can pick a parent directory that does not declare a workspace as its default \`workspaceDir\`\: the farthest directory with a lockfile when the project is not inside a git repository, or the farthest directory with a \`pnpm\-workspace\.yaml\` or \`deno\.json\` file, even one that only holds settings\. The Vite dev server allows \`/\_nuxt/@fs/\` requests for any file under \`workspaceDir\`\. A stray lockfile or settings file in a parent directory, such as the home directory, therefore lets anyone who can reach the dev server read files in that directory and everything below it\. \#\#\# Impact This
