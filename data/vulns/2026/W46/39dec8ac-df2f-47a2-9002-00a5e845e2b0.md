# In multiple functions of cn\_Tai\.cpp, there is a possible way to trigger an out of bounds write due to memory corruption\.

- **ID**: CVE\-2026\-58798
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-10

## 原文

In multiple functions of cn\_Tai\.cpp, there is a possible way to trigger an out of bounds write due to memory corruption\. This could lead to remote \(proximal/adjacent\) code execution with no additional execution privileges needed\. User interaction is not needed for exploitation\.
