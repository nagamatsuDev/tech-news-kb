# Vvvebから1\.0\.8\.6はリモートコード実行脆弱性を備えており、\.sqlファイルを保存することで制限されたsite\_adminロールをPHPに注入できる。

- **ID**: CVE\-2026\-126370
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-13

## 概要（機械翻訳）

Vvvebから1\.0\.8\.6は、リモートコード実行脆弱性を含み、制限されたsite\_adminロールは、アドミンコードエディタを通して\.sqlファイルを保存することでPHPを注入できる。攻撃者は、モデルを読み込むと実行可能なPHPにコンパイルされるJJFマクロペイロードを持つ拡張リストやコンテンツの拒否リストをバイパスし、WebユーザとしてOSコマンドを実行することができる。\.

## 原文

Vvveb through 1\.0\.8\.6 contains a remote code execution vulnerability allowing restricted site\_admin roles to inject PHP by saving \.sql files through the admin code editor\. Attackers can bypass extension and content deny\-lists with an @IF macro payload that compiles into executable PHP when the model loads, running OS commands as the web user\.
