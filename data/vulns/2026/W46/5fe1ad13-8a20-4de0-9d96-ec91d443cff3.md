## 原文

XWEB EVO 5\.6\.2 through 5\.8\.8 contains an authenticated OS command injection vulnerability in the api\.lua import\_preconfiguration and restore actions, where server\_url and related server credential fields are concatenated unescaped into a root curl command executed via io\.popen\. Attackers can inject malicious shell commands through these unfiltered parameters to achieve arbitrary command execution with root privileges on the underlying system\. This product line reached it's end of service date in March 2026\.
