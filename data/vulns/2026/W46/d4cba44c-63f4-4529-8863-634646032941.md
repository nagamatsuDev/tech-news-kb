- **危険度**: High（重要） (CVSS 8.8)

## 概要（機械翻訳）

## 原文

Jadaptive Maverick Synergy Server before 3\.0\.33 and 3\.1\.x before 3\.1\.7, and Maverick Legacy Server before 1\.8\.1, contain an authentication bypass vulnerability in SSH public key authentication that reuses cached key authorization decisions across usernames\. Attackers holding a key authorized for one account can authenticate it, then send a signed SSH\_MSG\_USERAUTH\_REQUEST with a different username on the same connection to log in as that account\.
