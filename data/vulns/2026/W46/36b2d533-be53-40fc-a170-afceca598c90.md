# NLTK\: Quadratic\-time CPU denial of service in CCG lexicon parser \(fromstring\) on wide bracket bodies and operator chains

- **ID**: CVE\-2026\-126299 / GHSA\-89p3\-fcch\-88ph
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: Python
- **パッケージ**: PyPI/nltk &lt;\= 3\.10\.3 → 3\.10\.4
- **公開**: 2026-11-13

## 原文

\#\# Summary The public CCG lexicon parser \`nltk\.ccg\.lexicon\.fromstring\` parses caller\-influenced lexicon text with two pure\-Python loops whose cost is quadratic in the input width\. A service that parses an untrusted CCG lexicon string can be driven into tens of seconds of single\-threaded CPU by a few\-megabyte input, starving the request worker\. No authentication or user interaction is required\. \#\# Root Cause \`matchBrackets\` consumes a bracket body one character at a time with \`inside \= inside \+ rest\[0\]; rest \= rest\[1\:\]\`\.
