# OpenEMR before 8\.5\.0 contains a stored cross\-site scripting vulnerability in interface/billing/sl\_eob\_invoice\.php, which escapes billing \.\.\.

- **ID**: CVE\-2026\-126418
- **危険度**: High（重要） (CVSS 7.6)
- **言語**: JavaScript/TypeScript, PHP
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains a stored cross\-site scripting vulnerability in interface/billing/sl\_eob\_invoice\.php, which escapes billing codes for HTML attributes but not for JavaScript strings in an inline onkeyup handler\. Clinicians with encounter coding access can save crafted billing codes through diagnosis\.php that execute script when a Back Office user enters a payment, exposing patient and financial data or performing actions as that user\.
