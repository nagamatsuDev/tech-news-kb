# OpenEMR before 8\.5\.0 contains an authorization bypass vulnerability that allows OAuth2 clients to use unregistered grant types because oa\.\.\.

- **ID**: CVE\-2026\-126436
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains an authorization bypass vulnerability that allows OAuth2 clients to use unregistered grant types because oauth\_clients\.grant\_types is never enforced\. Attackers can request tokens with grant\_type\=password to bypass the user consent screen, and disabled clients can redeem authorization codes using JWT client assertions\.
