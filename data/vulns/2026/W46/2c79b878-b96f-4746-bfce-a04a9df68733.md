# AIOHTTP is an asynchronous HTTP client/server framework for asyncio and Python\.

- **ID**: CVE\-2026\-128131 / GHSA\-h4cc\-hm5h\-fmm9
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: Python
- **公開**: 2026-11-13

## 原文

AIOHTTP is an asynchronous HTTP client/server framework for asyncio and Python\. Prior to 3\.14\.4, aiohttp decompresses each member of a payload containing many concatenated gzip, deflate, or zstd streams by passing the entire remaining input to a new decompressor, causing quadratic CPU use\. Empty members produce no output, so client\_max\_size and output backpressure do not limit the work\. A remote attacker can block a server event loop with a crafted compressed request body or WebSocket message, and a malicious server can similarly block a client\. This issue is fixed in version 3\.14\.4\.
