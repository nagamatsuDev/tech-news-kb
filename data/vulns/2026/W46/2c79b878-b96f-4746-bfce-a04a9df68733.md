# AIOHTTP\: Concatenated compressed streams cause excessive CPU use

- **ID**: CVE\-2026\-128131 / GHSA\-h4cc\-hm5h\-fmm9
- **危険度**: High（重要） (CVSS 8.7)
- **言語**: Python
- **パッケージ**: PyPI/aiohttp &lt;\= 3\.14\.3 → 3\.14\.4
- **公開**: 2026-11-13

## 原文

\#\#\# Summary When decompressing a payload made up of many concatenated compressed members \(gzip, deflate or zstd\), each member was decoded by passing the entire remaining input to a new decompressor, resulting in quadratic CPU time\. Empty members produce no output, so \`client\_max\_size\` and output backpressure did not limit the work\. \#\#\# Impact An attacker could block the event loop of a server with a specially crafted compressed request body or WebSocket message\. A malicious server could do the same to a client\. \-\-\- Patch\: https\://github\.com/aio\-libs/aiohttp/commit/d925a80539ffd227da1d93ab4a5bf
