# NocoDB before 2026\.08\.0 contains an incorrect authorization vulnerability that lets base\-scoped API tokens act as account\-wide credential\.\.\.

- **ID**: CVE\-2026\-126283
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-13

## 原文

NocoDB before 2026\.08\.0 contains an incorrect authorization vulnerability that lets base\-scoped API tokens act as account\-wide credentials because the token's base\_id is never stored or checked\. Attackers holding a leaked token can read, write and delete records on every base the token owner belongs to, including bases joined later\.
