# Cudy TR3000 before 2\.5\.42 contains a remote code execution vulnerability that allows authenticated administrators to execute commands as \.\.\.

- **ID**: CVE\-2026\-129100
- **危険度**: High（重要） (CVSS 7.2)
- **公開**: 2026-11-13

## 原文

Cudy TR3000 before 2\.5\.42 contains a remote code execution vulnerability that allows authenticated administrators to execute commands as root by uploading crafted OpenVPN private or tls\-auth keys\. Attackers can close the inline key block with &lt;/key&gt;, inject directives such as tls\-verify that bypass the \.ovpn denylist, and have OpenVPN execute the hook as root\.
