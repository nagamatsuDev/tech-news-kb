# 脆弱性はDrayTek Vigor 1960 1\.5\.1\.6に発見された。

- **ID**: CVE\-2026\-129453
- **危険度**: Critical（緊急） (CVSS 9.9)
- **公開**: 2026-11-15

## 概要（機械翻訳）

脆弱性はDrayTek Vigor 1960 1\.5\.1\.6で発見された。。。\:ドレイテック バイガー 1\.5\.1\.6。この問題は、コンポーネントの /cgi\-bin/mainfunction\.cgi の check\_file\_exist 関数に影響します。ファイルの存在チェック。HgHgment upload\_name の操作を実行するとヒープベースのバッファオーバーフローが発生します。

## 原文

A vulnerability was found in DrayTek Vigor2960 1\.5\.1\.6\. This issue affects the function check\_file\_exist of the file /cgi\-bin/mainfunction\.cgi of the component File Existence Check\. Performing a manipulation of the argument upload\_name results in heap\-based buffer overflow\. The attack may be initiated remotely\. The exploit has been made public and could be used\. Upgrading to version 1\.5\.1\.7 is capable of addressing this issue\. Upgrading the affected component is recommended\. The vendor recommends\: "1\.5\.1\.6 isn't the latest version of 2960, the latest version fixes many security issues\. And we have another one in our release plan which should solve the issues reported\."
