# PostgreSQL pg\_dump tar\-format restore\.sql に信頼できないデータが含まれているため、 元のサーバーは\.NET ファイルとして Hglibrary コードを実行できます。

- **ID**: CVE\-2026\-116330
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-12

## 概要（機械翻訳）

PostgreSQL pg\_dump tar\-format restore\.sqlに含まれる信頼できないデータにより、 restore\.sqlの予測可能な制約キーを介して、psqlを実行しているクライアントオペレーティングシステムアカウントとして、コミットされたオリジンサーバーがHbitraryコードを実行することができる。\.sql\. の制約可能な制約キー。これはCVE\-2025\-8714の修正のギャップである。sqlは文書化されていない。は、CVE\-2025\-8714の修正のギャップである。sqlは、CVE\-2025\-8714の修正のギャップである。。。PostgreSQL 18\.7、17\.12、16\.16、15\.20、14\.25以前のバージョンが影響を受ける。\:\.\.\.\.\.\.。\: PostgreSQL 18\.7、17\.12、16\.16、15\.20、14\.25 が影響を受ける。。

## 原文

Untrusted data inclusion in PostgreSQL pg\_dump tar\-format restore\.sql allows a compromised origin server to execute arbitrary code as the client operating system account running psql, via the predictable restriction key in restore\.sql\.  This is a gap in the fix for CVE\-2025\-8714\.  restore\.sql is undocumented\.  Versions before PostgreSQL 18\.7, 17\.12, 16\.16, 15\.20, and 14\.25 are affected\.
