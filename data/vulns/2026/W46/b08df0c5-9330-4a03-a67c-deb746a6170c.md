# FFmpeg through 9\.0\.2 contains a double free vulnerability in libavcodec/cbs\_sei\.c where cbs\_sei\_delete\_message\(\) leaves a stale extension\.\.\.

- **ID**: CVE\-2026\-125269
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-09

## 原文

FFmpeg through 9\.0\.2 contains a double free vulnerability in libavcodec/cbs\_sei\.c where cbs\_sei\_delete\_message\(\) leaves a stale extension\_data reference that ff\_cbs\_sei\_add\_message\(\) reuses\. Attackers can supply a crafted H\.264 stream with a display orientation SEI message followed by payload extension data, processed by h264\_metadata with display\_orientation\=insert, to corrupt heap memory\.
