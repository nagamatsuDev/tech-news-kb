# Uncaught exceptions in PostgreSQL plperl allow an object creator to cause use of a stale sigjmp\_buf, via a tied Perl object, or a Perl ob\.\.\.

- **ID**: CVE\-2026\-116326
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-12

## 原文

Uncaught exceptions in PostgreSQL plperl allow an object creator to cause use of a stale sigjmp\_buf, via a tied Perl object, or a Perl object whose overloaded conversion throws while plperl is handling another error\.  We have not ruled out arbitrary code execution on some platform\.  Versions before PostgreSQL 18\.7, 17\.12, 16\.16, 15\.20, and 14\.25 are affected\.
