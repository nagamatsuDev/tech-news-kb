# datamodel\-code\-generator before 0\.84\.0には、攻撃者がHgbitraryコードの実行を達成できるコード注入脆弱性が含まれている。

- **ID**: CVE\-2026\-127208
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: Python
- **公開**: 2026-11-12

## 概要（機械翻訳）

データモデル\-コード\-ジェネレータ\-before 0\.84\.0にはコード注入脆弱性があり、攻撃者は、parse\_python\_Type\_annotationおよび\_python\_type\_expr\_from\_astのバリデーションをバイパスするサブスクリプトスライス位置の文字列ast\.Constantノードを含む、悪意あるx\-python\-typeアノテーションをJSON Schemaに供給することで、Hgbitraryコードの実行を実現できる。

## 原文

datamodel\-code\-generator before 0\.84\.0 contains a code injection vulnerability that allows attackers to achieve arbitrary code execution by supplying a malicious JSON Schema with a crafted x\-python\-type annotation containing a string ast\.Constant node in a subscript slice position, which bypasses validation in parse\_python\_type\_annotation and \_python\_type\_expr\_from\_ast\. Attackers can embed malicious Python expressions such as \_\_import\_\_ calls within quoted string literals in the generated source code, which Pydantic v2 evaluates as a ForwardRef via eval\(\) during model\_rebuild\(\), resulting in arbitrary code execution on developer workstations, CI/CD pipelines, or applications that generate and import the produced models at runtime\.
