# The Lightbox &amp; Modal Popup WordPress Plugin – FooBox plugin for WordPress is vulnerable to Stored DOM\-Based Cross\-Site Scripting via the \.\.\.

- **ID**: CVE\-2026\-120687
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-14

## 原文

The Lightbox &amp; Modal Popup WordPress Plugin – FooBox plugin for WordPress is vulnerable to Stored DOM\-Based Cross\-Site Scripting via the 'img alt attribute inside \.wp\-caption container' parameter in all versions up to, and including, 2\.8\.7 due to insufficient input sanitization and output escaping\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\. This is exploitable by Subscriber\-level users when bbPress is installed, as its bbp\_filter\_kses filter chain permits img and pre tags while preserving numeric character references inside attribute values, allowing encoded payloads to bypass save\-time sanitization and reach the vulnerable sink fully intact\. Exploitation by attackers with subscriber\-level access and above requires that bbPress 2\.6\.20 is installed, a public forum exists, and either the first topic has already been approved or subsequent topics clear moderation\. On a default installation, where that is not configured, the vulnerability requires attackers with contributor\-level access and above\.
