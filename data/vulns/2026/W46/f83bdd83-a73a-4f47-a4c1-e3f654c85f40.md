# Building a malicious package that uses "//go\:cgo\_import\_dynamic" or links against a crafted PE object on Windows could pass unsafe librar\.\.\.

- **ID**: CVE\-2026\-97042
- **危険度**: High（重要） (CVSS 8.8)
- **OS**: Windows
- **公開**: 2026-11-11

## 原文

Building a malicious package that uses "//go\:cgo\_import\_dynamic" or links against a crafted PE object on Windows could pass unsafe library arguments to the external linker\. The compiler only checked the first character of the library name in "//go\:cgo\_import\_dynamic" directives and skipped validation in cgo\-generated files\. In addition, on Windows, "cmd/cgo" and "cmd/link" did not validate imported DLL names extracted from PE object files before emitting "\-l&lt;name&gt;" flags for the external linker, allowing a crafted DLL name containing "\.\." path traversal or special characters to reference arbitrary files on disk\. The compiler now validates every character of the library name in "//go\:cgo\_import\_dynamic" directives \(including in cgo\-generated files on Windows\) and rejects "\.\." path traversal, and "cmd/cgo" and "cmd/link" reject PE imported DLL names containing path separators, "\.\.", "\:", or leading "\-" or "@"\.
