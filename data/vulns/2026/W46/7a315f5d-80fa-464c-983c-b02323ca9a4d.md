# OpenEMR before 8\.5\.0 contains a stored SQL injection vulnerability in which History layout field identifiers saved through edit\_layout\.ph\.\.\.

- **ID**: CVE\-2026\-126425
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains a stored SQL injection vulnerability in which History layout field identifiers saved through edit\_layout\.php, including HIS fields and LBF source\-H fields, are placed unvalidated into an INSERT statement for patients without a history\_data row\. Users with admin/super and patients/med write access can trigger history\_save\.php or LBF saves to execute SQL functions like SLEEP, tying up database workers or accessing data beyond their privileges\.
