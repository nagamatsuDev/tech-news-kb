# In thread\_free of thread\.c, there is a possible way to corrupt kernel heap metadata on thread creation failure due to memory corruption\.

- **ID**: CVE\-2026\-55319
- **危険度**: High（重要） (CVSS 8.4)
- **公開**: 2026-11-10

## 原文

In thread\_free of thread\.c, there is a possible way to corrupt kernel heap metadata on thread creation failure due to memory corruption\. This could lead to local escalation of privilege with no additional execution privileges needed\. User interaction is not needed for exploitation\.
