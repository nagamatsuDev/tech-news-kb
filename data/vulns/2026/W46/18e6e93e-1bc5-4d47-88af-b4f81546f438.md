## 原文

OpenObserve is a cloud\-native observability platform\. Prior to 1\.1\.0, the shared authentication validator in src/api/common/src/auth/validator\.rs accepts an empty or whitespace\-only HTTP Basic password for an account whose password\_ext value is missing or empty\. SSO\-provisioned and migration\-created users can have this state, allowing an unauthenticated attacker who knows an affected user's email address and organization to authenticate on protected non\-ingestion API routes with the victim's role and permissions\. A compromised privileged account can expose or modify telemetry, alerts, streams, users, and security configuration\. An account with search permission can submit a DataFusion COPY \.\.\. TO statement through the search API to create or overwrite attacker\-controlled files at service\-process\-writable locations, creating a conditional escalation to pre\-authentication remote code execution\. This issue is fixed in version 1\.1\.0\.
