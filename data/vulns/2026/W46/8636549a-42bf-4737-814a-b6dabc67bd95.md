# Vvvebから1\.0\.8\.6は、stri\.xファイルの代わりにstrpos\(\)を使用するテーマインストーラvalidFile\(\)関数にファイルアップロード脆弱性を含んでいる。

- **ID**: CVE\-2026\-126378
- **危険度**: Critical（緊急） (CVSS 9.1)
- **言語**: PHP
- **公開**: 2026-11-13

## 概要（機械翻訳）

Vvvebから1\.0\.8\.6は、厳密なパスマッチングの代わりにstrpos\(\)を使用するテーマインストーラvalidFile\(\)関数にファイルアップロード脆弱性を含んでいる。。管理者資格を持つ攻撃者は、パスに /me\.php を含む PHP ファイルを含むZIPをアップロードして、nginx デプロイメントでリモートコードを実行することができる。

## 原文

Vvveb through 1\.0\.8\.6 contains a file upload vulnerability in the theme installer validFile\(\) function that uses strpos\(\) instead of strict path matching\. Attackers with admin credentials can upload a ZIP containing a PHP file whose path includes /theme\.php to achieve remote code execution on nginx deployments\.
