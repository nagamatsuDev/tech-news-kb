# pam\_usb provides hardware authentication for Linux using removable media\.

- **ID**: CVE\-2026\-64666
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-11

## 原文

pam\_usb provides hardware authentication for Linux using removable media\. Prior to version 0\.9\.3, src/local\.c reads XRDP\_SESSION with plain getenv\(3\) at the head of pusb\_local\_login while every other env consumer in the same function uses secure\_getenv\(3\)\. When pam\_usb\.so loads into a setuid PAM host, the calling user controls the environment passed in\. Clearing XRDP\_SESSION before invoking the host bypasses the explicit XRDP\-deny rule\. Other remote\-detection signals \(rmsvc, evdev, loginctl, utmp\) may still catch the session, but the env\-based detection alone is defeated\. This issue has been patched in version 0\.9\.3\.
