# Omnispace Agora Project through 26\.10\.0 contains a predictable token generation vulnerability that allows unauthenticated attackers to ac\.\.\.

- **ID**: CVE\-2026\-63151
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-13

## 原文

Omnispace Agora Project through 26\.10\.0 contains a predictable token generation vulnerability that allows unauthenticated attackers to access private calendar data by exploiting a missing dateCrea value that causes the md5Id token to collapse to md5\(calendarId\.userId\), both small enumerable integers\. Attackers can compute valid tokens and request the misc&amp;action\=DisplayIcal endpoint with a forged md5Id to read any user's private calendar events without authentication\.
