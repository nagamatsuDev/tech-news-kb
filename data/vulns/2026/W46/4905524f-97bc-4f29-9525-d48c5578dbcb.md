# Grid Community Toolkit before 6\.2\.20261111 \(globus\-gss\-assist before 12\.9\) contains a heap out\-of\-bounds write in globus\_gss\_assist\_token\.\.\.

- **ID**: CVE\-2026\-123975
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-13

## 原文

Grid Community Toolkit before 6\.2\.20261111 \(globus\-gss\-assist before 12\.9\) contains a heap out\-of\-bounds write in globus\_gss\_assist\_token\_get\_fd\(\) triggered by SSLv2 record lengths below 3\. Remote unauthenticated clients can send a crafted GSI handshake record to services like globus\-gatekeeper and myproxy to corrupt heap memory and crash the service\.
