# C\-Kermit 6\.0\.192 before 11\.1\.515 contains a buffer overflow vulnerability in tn\_snenv\(\) in ckctel\.c that allows malicious Telnet servers \.\.\.

- **ID**: CVE\-2026\-129122
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-13

## 原文

C\-Kermit 6\.0\.192 before 11\.1\.515 contains a buffer overflow vulnerability in tn\_snenv\(\) in ckctel\.c that allows malicious Telnet servers to corrupt client memory via crafted NEW\-ENVIRON SEND subnegotiation\. Malicious or machine\-in\-the\-middle servers can send oversized variable names before authentication, overflowing a 16\-byte stack buffer and a miscomputed heap buffer to corrupt stack and heap memory\.
