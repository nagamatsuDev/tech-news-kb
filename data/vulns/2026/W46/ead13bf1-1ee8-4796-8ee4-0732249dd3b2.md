# BACnet Stack is a BACnet open source protocol stack C library for embedded systems\.

- **ID**: CVE\-2026\-62976
- **危険度**: High（重要） (CVSS 8.7)
- **公開**: 2026-11-13

## 原文

BACnet Stack is a BACnet open source protocol stack C library for embedded systems\. Prior to version 1\.5\.1, the RAMFS\-backed FILE object implementation stores appended records as NUL\-terminated strings, but its record\-counting logic later walks the buffer as if an additional terminating empty record were present\. As a result, two consecutive AtomicWriteFile\(record\-access\) append requests can cause record\_count\(\) to call bacnet\_strnlen\(\) on a pointer that is already one byte past the end of the heap allocation\. This issue has been patched in versions 1\.5\.1 and 1\.6\.0\.
