# AutoMapper\: Uncontrolled Recursion with Constructor Parameters

- **ID**: CVE\-2026\-128082 / GHSA\-6vhm\-j9h7\-f9gh
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: C\#/\.NET
- **パッケージ**: NuGet/AutoMapper &gt;\= 16\.0\.0, &lt; 16\.3\.0 → 16\.3\.0
- **公開**: 2026-11-13

## 原文

\#\#\# Summary \`MaxDepth\`, whether set explicitly or applied by default \(64\) to self\-referential type maps, was not enforced when the recursion goes through constructor parameters\. Mapping a deeply nested source to a destination built through its constructor, such as a positional \`record\`, recurses without bound and throws a \`StackOverflowException\`\. That exception can't be caught and terminates the process\. This bypasses the mitigation for CVE\-2026\-32933\. \#\#\# Details The type depth used by \`MaxDepth\` was incremented only after the destination object was created\.
