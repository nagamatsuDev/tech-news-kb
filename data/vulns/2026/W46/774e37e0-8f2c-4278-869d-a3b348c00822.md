# NLTK\: Quadratic\-time CPU denial of service in Tree\.chomsky\_normal\_form right\-factor binarization via list\.pop\(0\)

- **ID**: CVE\-2026\-126298 / GHSA\-r53h\-rw34\-8h97
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: Python
- **パッケージ**: PyPI/nltk &lt;\= 3\.10\.3 → 3\.10\.4
- **公開**: 2026-11-13

## 原文

\#\# Summary \`Tree\.chomsky\_normal\_form\(\)\` binarizes a parse tree and defaults to right factoring\. For a node with N children the right\-factor branch repeatedly removes the first element of a working list with \`list\.pop\(0\)\`, which shifts all remaining elements each time, so binarizing one wide node costs O\(N\^2\)\. An application that converts an attacker\-supplied treebank tree to Chomsky Normal Form can be forced into tens of seconds of single\-threaded CPU by one wide flat tree\. No authentication or user interaction is required\. \#\# Root Cause In the default right\-factor branch the transform execute
