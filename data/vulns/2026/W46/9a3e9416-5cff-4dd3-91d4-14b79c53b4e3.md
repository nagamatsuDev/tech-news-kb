# OpenMage magento\-lts 20\.17\.0 before 20\.18\.2 and 21\.0\.0\-beta1 before 21\.0\.0\-beta3 contains an unrestricted file upload vulnerability becau\.\.\.

- **ID**: CVE\-2026\-128046
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-13

## 原文

OpenMage magento\-lts 20\.17\.0 before 20\.18\.2 and 21\.0\.0\-beta1 before 21\.0\.0\-beta3 contains an unrestricted file upload vulnerability because the general/file/protected\_extensions blocklist omits phar, php8, and phps\. Unauthenticated attackers can upload a \.phar file through a product File custom option to a predictable media/custom\_options path and request it directly to execute code on servers that map \.phar to PHP and serve that directory\.
