# SiYuan before 3\.8\.9 contains an information disclosure vulnerability that allows authenticated Reader users to retrieve credential\-named \.\.\.

- **ID**: CVE\-2026\-126264
- **危険度**: High（重要） (CVSS 7.7)
- **公開**: 2026-11-13

## 原文

SiYuan before 3\.8\.9 contains an information disclosure vulnerability that allows authenticated Reader users to retrieve credential\-named widget files by bypassing the sensitive\-path guard in getFile\. Attackers can request paths like /data/widgets/&lt;package&gt;/credentials\.json for publish\-referenced widgets to obtain API keys, tokens, or other stored secrets\.
