# OpsTree BuildPiper before 2\.7\.0 contains an authorization bypass vulnerability that allows authenticated users to create environments on \.\.\.

- **ID**: CVE\-2026\-127077
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-13

## 原文

OpsTree BuildPiper before 2\.7\.0 contains an authorization bypass vulnerability that allows authenticated users to create environments on unassigned Kubernetes clusters by tampering with cluster\_id and namespaces values\. Attackers can modify requests to POST /api/v1/project/\{project\_id\}/env/ to target another project's cluster, then trigger builds and deployments into it, bypassing project isolation\.
