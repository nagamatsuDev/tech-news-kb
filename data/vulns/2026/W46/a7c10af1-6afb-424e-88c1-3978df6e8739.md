# PostgreSQLの外部バッチインサートでヒープベースのバッファオーバーフロー機能を使うと、外部サーバーは、Zbitraryコードを実行することができる。

- **ID**: CVE\-2026\-120149
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-12

## 概要（機械翻訳）

PostgreSQLの外部バッチインサートにおけるヒープベースのバッファオーバーフローは、外部サーバがサーバーサプライよりも多くの iXws を挿入したことを報告することで、ライブラリコードを実行することを可能にする。リモートテーブルのルールが INSERT を Hg に追加するときに、postgres\_fdw はそれと正確に遭遇する。PostgreSQL 18\.7、17\.12、16\.16、15\.20、14\.25以前のバージョンが影響を受ける。以下の通り。\: 複数 \: PostgreSQL 18\.7、17\.12、16\.16、15\.20、14\.25 が影響を受ける。\: PostgreSQL 18\.25 は、18\.

## 原文

Heap\-based buffer overflow in PostgreSQL foreign batch inserts allows a foreign server to execute arbitrary code, via reporting that it inserted more rows than the server supplied\.  postgres\_fdw can legitimately encounter this when a rule on the remote table expands an INSERT into additional rows\.  Versions before PostgreSQL 18\.7, 17\.12, 16\.16, 15\.20, and 14\.25 are affected\.
