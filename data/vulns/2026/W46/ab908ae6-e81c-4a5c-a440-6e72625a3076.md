# FFmpeg through 9\.0\.2 contains a heap buffer overflow vulnerability in the PSD decoder in libavcodec/psd\.c that allows attackers to corrup\.\.\.

- **ID**: CVE\-2026\-125213
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-09

## 原文

FFmpeg through 9\.0\.2 contains a heap buffer overflow vulnerability in the PSD decoder in libavcodec/psd\.c that allows attackers to corrupt heap memory on 32\-bit builds by supplying a crafted PSD image\. Attackers can choose dimensions and channel counts whose product exceeds 4 GB, truncating the av\_malloc allocation size so decode\_rle\(\) writes attacker\-controlled data past the buffer, causing crashes or possible code execution\.
