# JSON\:\:XS versions from 3\.0 before 4\.05 for Perl read freed stack memory when a FREEZE result's serialisation grows the Perl stack under a\.\.\.

- **ID**: CVE\-2026\-129115
- **危険度**: Critical（緊急） (CVSS 9.1)
- **公開**: 2026-11-14

## 原文

JSON\:\:XS versions from 3\.0 before 4\.05 for Perl read freed stack memory when a FREEZE result's serialisation grows the Perl stack under allow\_tags in encode\_rv\.
  
With allow\_tags, an object's FREEZE method is called in list context and each returned value is encoded through a saved Perl stack pointer\. When encoding a returned value calls back into Perl, through TO\_JSON under convert\_blessed or another FREEZE, and that callback grows the stack, the stack is reallocated while the saved pointer still refers to the freed block\.
  
Encoding such objects reads freed memory, and encode can return undef without an error\.
