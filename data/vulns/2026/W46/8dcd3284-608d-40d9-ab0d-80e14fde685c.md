# Ettercap before 0\.8\.5\.1 contains a heap buffer overflow vulnerability in gg\_get\_version\(\) in src/dissectors/ec\_gg\.c that writes up to 44 \.\.\.

- **ID**: CVE\-2026\-125401
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-10

## 原文

Ettercap before 0\.8\.5\.1 contains a heap buffer overflow vulnerability in gg\_get\_version\(\) in src/dissectors/ec\_gg\.c that writes up to 44 bytes into a 30\-byte allocation\. Remote attackers can send Gadu\-Gadu traffic on TCP port 8074 with a crafted version field through a monitored network to corrupt heap memory in the Ettercap process, which normally runs as root\.
