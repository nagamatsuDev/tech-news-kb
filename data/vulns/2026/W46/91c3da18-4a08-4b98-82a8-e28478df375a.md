# OpenBao before 2\.6\.5 and 2\.7\.2 contains a path traversal vulnerability in Transit key import that allows authenticated attackers to bypas\.\.\.

- **ID**: CVE\-2026\-126309
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-13

## 原文

OpenBao before 2\.6\.5 and 2\.7\.2 contains a path traversal vulnerability in Transit key import that allows authenticated attackers to bypass name restrictions in ACL policies\. Attackers limited by a required\_parameters name constraint can craft traversal sequences during import to write key material under arbitrary Transit key names\.
