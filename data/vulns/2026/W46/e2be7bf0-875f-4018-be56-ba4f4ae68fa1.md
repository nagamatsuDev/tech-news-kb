# カスタムブロックビルダーWordPressプラグイン3\.0\.0以前のバージョンは、RESTルートに対する無許可要求を適切に拒否していない。

- **ID**: CVE\-2026\-127048
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: PHP
- **公開**: 2026-11-15

## 概要（機械翻訳）

カスタムブロックビルダーWordPress は、3\.0\.0 以前のプラグインは、許可チェックは WordPress が助成するエラー以外のレスポンスを返すため、未承認のユーザがサーバー上で iXiXary PHP コードを実行できるようにするため、REST ルートに対する未承認の要求を適切に拒否しない。

## 原文

The Custom Block Builder  WordPress plugin before 3\.0\.0 does not properly deny unauthorised requests to its REST routes, as its permission checks return a non\-error response that WordPress treats as granted, allowing unauthenticated users to execute arbitrary PHP code on the server\.
