# Pillow is a Python imaging library\.

- **ID**: CVE\-2026\-128066
- **危険度**: High（重要） (CVSS 8.7)
- **言語**: Python
- **公開**: 2026-11-13

## 原文

Pillow is a Python imaging library\. From 1\.0 through 12\.3\.0, ImageFileDirectory\_v2\.load\(\) in src/PIL/TiffImagePlugin\.py retains a separate bytes object for each out\-of\-line IFD tag value without limiting the total data read or preventing distinct tags from referencing the same file region\. A small crafted TIFF or EXIF\-bearing JPEG, PNG, WebP, or MPO can therefore cause memory use quadratic in the input size\. TIFF and some JPEG paths trigger parsing during Image\.open\(\), while other formats are exposed when EXIF is requested, including through getexif\(\) or ImageOps\.exif\_transpose\(\)\. The declared pixel dimensions do not bound this metadata allocation, so decompression\-bomb checks do not prevent process memory exhaustion\. This issue is fixed in version 13\.0\.0\.
