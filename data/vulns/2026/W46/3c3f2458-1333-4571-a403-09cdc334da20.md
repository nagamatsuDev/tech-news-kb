# TRENDnet TEW\-657BRM 1\.00\.1ではセキュリティ脆弱性が検出されている。

- **ID**: CVE\-2026\-129351
- **危険度**: Critical（緊急） (CVSS 10.0)
- **公開**: 2026-11-14

## 概要（機械翻訳）

TRENDnet TEW\-657BRM 1\.00\.1ではセキュリティ脆弱性が検出されている。この脆弱性は、コンポーネント mini\_httpd の file/setup\.cgi の機能 sprintf に影響します。このような操作は、境界外書き込みにつながります。。

## 原文

A security vulnerability has been detected in TRENDnet TEW\-657BRM 1\.00\.1\. This vulnerability affects the function sprintf of the file /setup\.cgi of the component mini\_httpd\. Such manipulation leads to out\-of\-bounds write\. The attack can be executed remotely\. The exploit has been disclosed publicly and may be used\. The vendor explains\: ""I am not able to confirm if such vulnerability exists as the product has been EOL for more than 15 years\. We will send out an announcement letting customers know\." This vulnerability only affects products that are no longer supported by the maintainer\.
