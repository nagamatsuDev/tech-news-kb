# WWBN AVideo 14\.3 through 29\.7\.1 contains a stored cross\-site scripting vulnerability that allows uploaders to inject scripts via the vide\.\.\.

- **ID**: CVE\-2026\-126806
- **危険度**: High（重要） (CVSS 8.7)
- **言語**: PHP
- **公開**: 2026-11-11

## 原文

WWBN AVideo 14\.3 through 29\.7\.1 contains a stored cross\-site scripting vulnerability that allows uploaders to inject scripts via the videoDownloadedLink value stored unescaped through objects/aVideoEncoder\.json\.php\. Attackers can embed event\-handler payloads in the URL host rendered as a Source tag in view/managerVideos\_body\.php, executing in administrator sessions to install plugin archives containing PHP\.
