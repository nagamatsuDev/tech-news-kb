# MISPモジュールのウェブサイトコンポーネントは、外部ツール管理エンドポイント\(追加、削除、変更ステータス、および変更構成\)を公開します。

- **ID**: CVE\-2026\-127016
- **危険度**: Critical（緊急） (CVSS 9.2)
- **言語**: Python
- **公開**: 2026-11-12

## 概要（機械翻訳）

MISPモジュールのウェブサイトコンポーネントは、オプションの管理者認証ポリシーを強制しない外部ツール管理エンドポイント\(追加、削除、変更ステータス、および変更構成\)を公開します。モジュールは、外部ツール管理エンドポイントを割り当てます。モジュールは、外部ツール管理のエンドポイントは、外部ツール管理を強制しない。は、変更の構成を、追加、削除、変更、変更、変更の構成を、外部ツール管理のエンドポイントに公開します。は、外部ツール管理ポリシーを強制しないものです。アプリケーション環境において ADMIN\_PASSWORD が構成されたとき、モジュール構成のエンドポイントは正確に認証された管理者セッションを必要としますが、外部ツール管理ハンドラは承認チェックなしで匿名ユーザーからの要求を処理しました。。DMIN\_PASSWORD は、ADMIN\_PASSWORD は、承認済み管理者セッションを要求します。は、外部ツール管理プロセスで、匿名ユーザからの要求を処理します。。

## 原文

The MISP Modules website component exposes external tool management endpoints \(add, delete, change status, and change configuration\) that did not enforce the optional administrator authentication policy\. When ADMIN\_PASSWORD was configured in the application environment, the module configuration endpoints correctly required an authenticated administrator session, but the external tools management handlers processed requests from anonymous users without any authorization check\. An unauthenticated attacker with network access to the website could add arbitrary external tools, delete existing tools, toggle their active status, and modify their configurations including API keys and ingestion URLs\. This inconsistency allowed bypass of the intended access control for the external tools management functionality\. The vulnerability is conditional on ADMIN\_PASSWORD being set; installations without an admin password intentionally permit open management access by design\. The affected component is the external\_tools Flask blueprint within the MISP Modules website application\.
