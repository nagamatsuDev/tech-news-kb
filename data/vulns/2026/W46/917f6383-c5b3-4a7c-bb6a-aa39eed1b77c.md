# PLNET GS\-5220\-8P2T2S \(ハードウェアバージョン 3\.0\)ファームウェアバージョン 3\.2412b261008 以前のバージョンには、スタックベースのバッファオーバーフロー脆弱性が含まれている。

- **ID**: CVE\-2026\-109445
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-13

## 概要（機械翻訳）

PLNET GS\-5220\-8P2T2S \(ハードウェアバージョン 3\.0\) ファームウェアバージョン3\.2412b261008 以前のバージョンには、スタックベースのバッファオーバーフロー脆弱性があり、非認証された攻撃者は、長さ検証なしで固定サイズのスタックバッファにコピーされる特大Webstax\_auth HTTP Cookie値を送信することで、スタックメモリを破損させる。 。\.。 。\.\. 。\.\.\.\.\.\.\.\.\.\.\.\.\.\.\.\.\.\. 。。。。。 。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。。攻撃者は、保存されたリターンアドレスと破損したスタックメモリを上書きし、メモリの破損とデバイス上のサービスの拒否につながる、特大のクッキーを持つ、グラフ化された未認証のHTTPリクエストを送信することができる。。

## 原文

PLANET GS\-5220\-8P2T2S \(hardware version 3\.0\) firmware versions before 3\.2412b261008 contains a stack\-based buffer overflow vulnerability that allows unauthenticated attackers to corrupt stack memory by submitting an oversized webstax\_auth HTTP Cookie value that is copied into a fixed\-size stack buffer without length validation\. Attackers can send a crafted unauthenticated HTTP request with an oversized cookie to overwrite the saved return address and corrupt stack memory, leading to memory corruption and potential denial of service on the device\.
