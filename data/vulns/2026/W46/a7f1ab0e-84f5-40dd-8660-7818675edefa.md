# セキュリティ脆弱性はDrayTek Vigor2960で最大1\.5\.1\.6まで検出されている。

- **ID**: CVE\-2026\-129449
- **危険度**: Critical（緊急） (CVSS 9.9)
- **公開**: 2026-11-15

## 原文

A security vulnerability has been detected in DrayTek Vigor2960 up to 1\.5\.1\.6\. Affected by this vulnerability is the function sub\_14914 of the file /cgi\-bin/mainfunction\.cgi\. The manipulation of the argument swmconfigupload leads to command injection\. It is possible to initiate the attack remotely\. The exploit has been disclosed publicly and may be used\. Upgrading to version 1\.5\.1\.7 addresses this issue\. It is advisable to upgrade the affected component\. The vendor recommends\: "1\.5\.1\.6 isn't the latest version of 2960, the latest version fixes many security issues\. And we have another one in our release plan which should solve the issues reported\."
