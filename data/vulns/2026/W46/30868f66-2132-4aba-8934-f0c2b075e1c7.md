# FrankenPHP standalone static binaries 1\.8\.0 before 1\.13\.2 bundle the PHP brotli extension statically linked with Brotli 1\.2\.0, whose deco\.\.\.

- **ID**: CVE\-2026\-128014
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-13

## 原文

FrankenPHP standalone static binaries 1\.8\.0 before 1\.13\.2 bundle the PHP brotli extension statically linked with Brotli 1\.2\.0, whose decoder contains an out\-of\-bounds write \(CVE\-2026\-111497\)\. Unauthenticated remote attackers can send crafted data to applications that pass it to brotli\_uncompress\_add\(\) to crash the entire FrankenPHP process, and possibly cause memory disclosure or code execution\.
