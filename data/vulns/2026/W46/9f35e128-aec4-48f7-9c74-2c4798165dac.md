# Cudy TR3000 before 2\.5\.42 contains an authentication bypass vulnerability in the Mosquitto plugin auth\_plugin\_jwt\.so that accepts unsigne\.\.\.

- **ID**: CVE\-2026\-75491
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-13

## 原文

Cudy TR3000 before 2\.5\.42 contains an authentication bypass vulnerability in the Mosquitto plugin auth\_plugin\_jwt\.so that accepts unsigned JWTs using alg none\. Attackers holding any Cudy\-trusted client certificate can authenticate as admincudydevice on port 8883 and publish batchcmd requests to execute commands as root\.
