# 8\.5\.0以前のOpenEMRには、セッション認証のみに依存するいくつかのカスタム/スクリプトに、認可脆弱性がない。

- **ID**: CVE\-2026\-126469
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-13

## 概要（機械翻訳）

8\.5\.0以前のOpenEMRには、セッション認証のみに依存し、AclMain\:\:aclCheckCore\(\)を決して呼び出さないいくつかのカスタム/スクリプトに、認可脆弱性がない。は、\.\.が、\.が、\.が、\.が、\.が、\.認証された低特権ユーザは、export\_labworks\.php、chart\_tracker\.php、export\_Registry\_xml\.php を要求して、患者 SSN、DOB、および保険データ、あるいは NPI / 税金ID を開示し、チャートトラッカーレコードを偽造することができる。

## 原文

OpenEMR before 8\.5\.0 contains a missing authorization vulnerability in several custom/ scripts that rely only on session authentication and never call AclMain\:\:aclCheckCore\(\)\. Any authenticated low\-privilege user can request export\_labworks\.php, chart\_tracker\.php, or export\_registry\_xml\.php to disclose patient SSN, DOB, and insurance data or provider NPI/tax IDs, and forge chart\-tracker records\.
