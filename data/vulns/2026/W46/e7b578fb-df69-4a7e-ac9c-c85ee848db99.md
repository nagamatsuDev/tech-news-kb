# AIOHTTP\: Unbounded buffering of data received during an upgrade request

- **ID**: CVE\-2026\-128129 / GHSA\-pw86\-h8fm\-j323
- **危険度**: High（重要）
- **言語**: Python
- **パッケージ**: PyPI/aiohttp &lt;\= 3\.14\.3 → 3\.14\.4
- **公開**: 2026-11-13

## 原文

\#\#\# Summary While a request flagged as an upgrade \(e\.g\. a WebSocket handshake\) was being handled, all further data received on the connection was buffered with no size limit or flow control until the handler completed\. \#\#\# Impact An attacker could cause unbounded memory use by streaming data behind an upgrade request to any handler that does not immediately accept or reject the upgrade\. \-\-\- Patch\: https\://github\.com/aio\-libs/aiohttp/commit/3d850ee9b92573c7e913821cbcb96005beb3f4df
