# Microchip TimePictraプラットフォームで危険なタイプの脆弱性を持つファイルの無制限アップロードは、機能を適切に実行させることはできません。

- **ID**: CVE\-2026\-8331
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-12

## 概要（機械翻訳）

Microchip TimePictraプラットフォームで危険なタイプの脆弱性を持つファイルの無制限アップロードは、アクセスコントロールリストによって適切に制約されない機能を可能にし、潜在的にリモートコード実行をもたらす。

## 原文

An unrestricted upload of files with dangerous type vulnerability in the Microchip TimePictra platform allows functionality not properly constrained by access control lists, potentially resulting in remote code execution\.
