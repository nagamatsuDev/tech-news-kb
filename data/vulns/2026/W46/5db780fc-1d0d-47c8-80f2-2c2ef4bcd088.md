# Heym builds and runs agentic systems and business\-process automations on self\-hosted infrastructure\.

- **ID**: CVE\-2026\-67543
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: Python
- **公開**: 2026-11-11

## 原文

Heym builds and runs agentic systems and business\-process automations on self\-hosted infrastructure\. Prior to version 0\.0\.70, heym hardens one untrusted\-code path but not its sibling\. The Python tool executor \(python\_tool\_executor\.py\) treats user code as untrusted and mandates a Docker sandbox \(no network, read\-only fs, non\-root, no docker socket\), failing closed\. The skill executor \(skill\_python\_executor\.py\) runs skill Python via a local backend subprocess with no Docker isolation — only a 512 MB RLIMIT and a 7\-key env denylist — so a skill executes inside the backend execution context, with filesystem access, network egress, and non\-denylisted environment variables that should not be exposed to untrusted/shared skills\. In the shipped Docker config \(backend runs as root \+ /var/run/docker\.sock mounted\), this escalates to host root\. This issue has been patched in version 0\.0\.70\.
