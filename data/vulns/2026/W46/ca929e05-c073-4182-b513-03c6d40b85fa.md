# A vulnerability has been found in projectworlds Visitor Management System 1\.0\.

- **ID**: CVE\-2026\-129181
- **危険度**: High（重要） (CVSS 7.3)
- **言語**: PHP
- **公開**: 2026-11-14

## 原文

A vulnerability has been found in projectworlds Visitor Management System 1\.0\. This issue affects the function mysqli\_query of the file /img/user%20page\.php of the component Login Endpoint\. Such manipulation of the argument Username leads to sql injection\. It is possible to launch the attack remotely\. The exploit has been disclosed to the public and may be used\.
