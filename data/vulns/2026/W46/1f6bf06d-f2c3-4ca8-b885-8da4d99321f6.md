# The 6Storage Rentals plugin for WordPress is vulnerable to Authentication Bypass leading to Administrator Account Takeover in all version\.\.\.

- **ID**: CVE\-2026\-103883
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-11

## 原文

The 6Storage Rentals plugin for WordPress is vulnerable to Authentication Bypass leading to Administrator Account Takeover in all versions up to, and including, 2\.31\.0\. The vulnerability exists because the \`six\_storage\_portal\_registration\(\)\` AJAX handler — registered on \`wp\_ajax\_six\_storage\_portal\_plugin\_registration\` — performs no capability check and no nonce verification before writing the caller\-supplied \`six\_storage\_online\_api\_url\` POST parameter to the site\-wide option of the same name; the unauthenticated \`six\_storage\_create\_wp\_user\(\)\` handler then redeems a transient seeded from that attacker\-controlled URL's response and unconditionally calls \`wp\_set\_current\_user\(\)\` and \`wp\_set\_auth\_cookie\(\)\` with no ownership or credential verification\. This makes it possible for authenticated attackers, with Subscriber\-level access and above, to authenticate as any existing WordPress user — including any administrator whose email address is known or guessable — resulting in full site compromise\. This issue represents an incomplete fix for a prior vulnerability\: the 2\.29\.0 remediation moved the target email out of POST data into a server\-side transient, but because any Subscriber can still overwrite the outbound API URL that populates that transient, the full authentication bypass chain remains exploitable in three AJAX requests\.
