# C\-Kermit from 7\.0\.197 before 11\.1\.515 contains an authentication bypass vulnerability in the IKSD SSL build that leaves Telnet authentica\.\.\.

- **ID**: CVE\-2026\-129116
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-13

## 原文

C\-Kermit from 7\.0\.197 before 11\.1\.515 contains an authentication bypass vulnerability in the IKSD SSL build that leaves Telnet authentication state at AUTH\_VALID after a refused certificate login\. Attackers holding a trusted certificate mapped to a refused account can log in as any other account with any password, gaining that account's shell access\.
