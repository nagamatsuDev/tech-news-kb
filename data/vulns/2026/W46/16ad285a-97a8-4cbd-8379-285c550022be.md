# P\-Net before 1\.0\.4 does not check the number of MCR request blocks in a Connect request against the number of multicast communication rel\.\.\.

- **ID**: CVE\-2026\-127122
- **危険度**: High（重要） (CVSS 7.2)
- **公開**: 2026-11-13

## 原文

P\-Net before 1\.0\.4 does not check the number of MCR request blocks in a Connect request against the number of multicast communication relations that an Application Relationship has room for \(PNET\_MAX\_MC\_CR, 1 by default\)\. Each further block is written past the end of the array, into the rest of the Application Relationship and, with more blocks, into the following one\. The written data comes from the request\. No established Application Relationship is needed, and the attacker requires ADJACENT network access\. Builds with PNET\_OPTION\_MC\_CR disabled are not affected\.
