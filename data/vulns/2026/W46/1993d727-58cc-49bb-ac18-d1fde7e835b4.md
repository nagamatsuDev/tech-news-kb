# AIOHTTP is an asynchronous HTTP client/server framework for asyncio and Python\.

- **ID**: CVE\-2026\-128128
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: Python
- **公開**: 2026-11-13

## 原文

AIOHTTP is an asynchronous HTTP client/server framework for asyncio and Python\. Prior to 3\.14\.4, the C WebSocket reader adds a declared frame length to the size of an already buffered partial message using signed 64\-bit arithmetic\. A length near two to the power of 63 can overflow, allowing the max\_msg\_size check to pass\. A remote peer can send a small non\-final fragment followed by an oversized message and cause unbounded memory consumption\. The Python WebSocket reader is unaffected\. This issue is fixed in version 3\.14\.4\.
