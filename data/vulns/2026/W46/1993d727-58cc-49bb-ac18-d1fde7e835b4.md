# AIOHTTP\: WebSocket max\_msg\_size bypass via integer overflow

- **ID**: CVE\-2026\-128128 / GHSA\-3rp8\-rxj8\-mvjw
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: Python
- **パッケージ**: PyPI/aiohttp &lt;\= 3\.14\.3 → 3\.14\.4
- **公開**: 2026-11-13

## 原文

\#\#\# Summary The \`max\_msg\_size\` check in the WebSocket reader added the declared frame length to the size of the partial message already buffered\. In the C extension this addition is 64\-bit arithmetic, so a declared length close to 2\*\*63 overflowed and the check passed\. \#\#\# Impact An attacker could bypass \`max\_msg\_size\` and cause unbounded memory use by streaming an oversized WebSocket message after a small non\-final fragment\. \#\#\# Workaround If unable to upgrade, the Python reader is unaffected and can be used with \`AIOHTTP\_NO\_EXTENSIONS\=1\`\. \-\-\- Patch\: https\://github\.com/aio\-libs/aiohttp/commit
