# FFmpeg 7\.0 before 8\.1\.3 and 9\.x before 9\.0\.2 contains a heap out\-of\-bounds write vulnerability in vk\_av1\_decode\_slice\(\) in libavcodec/vul\.\.\.

- **ID**: CVE\-2026\-125201
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-09

## 原文

FFmpeg 7\.0 before 8\.1\.3 and 9\.x before 9\.0\.2 contains a heap out\-of\-bounds write vulnerability in vk\_av1\_decode\_slice\(\) in libavcodec/vulkan\_av1\.c because the tile\-count limit is checked only on entry\. Attackers can supply a crafted AV1 stream with more than 256 tiles decoded via the Vulkan hardware accelerator to overflow tile\_sizes and corrupt heap memory\.
