# 1300通信の管理サービス\(uavmonitor\_usbv1\)のネットワーク構成処理におけるOSコマンド注入\(CWE\-78\)。

- **ID**: CVE\-2026\-128908
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-13

## 概要（機械翻訳）

DJI AeroScope Mobile \(TP703\)ファームウェア 03\.00\.00\.26 の1300通信ボード管理サービス \(uavmonitor\_usbv1\) のネットワーク構成処理における OS コマンド注入 \(CWE\-78\) は、1300通信ボードファームウェア 02\.00\.07\.12 から 02\.00\.08\.40 の状態で、ローカルネットワーク上の未認証攻撃者が iXary コマンドをルートとして実行することができる。管理インターフェース上で認証なしで記述できる構成値は、シェルコマンドに引用なしで挿入される。は、\.メソッドの\.メソッドの\.要素の\.要素の\.要素の\.である。は、\.。は、\.が\.。。。。。。。。。。

## 原文

OS command injection \(CWE\-78\) in the network\-configuration handling of the management service \(uavmonitor\_usbv1\) of the 1300 communications board in DJI AeroScope Mobile \(TP703\) firmware 03\.00\.00\.26, with 1300 communications board firmware 02\.00\.07\.12 through 02\.00\.08\.40, allows an unauthenticated attacker on the local network to execute arbitrary commands as root\. Configuration values that can be written without authentication over the management interface are inserted unquoted into shell commands\. Exploitation requires network access to TCP port 16000 on the board and that the unit is not connected to another controlling host\. The injected command persists across reboots\. Confirmed on a physical device\.
  
NOTE\: This vulnerability only affects products that are no longer supported by the maintainer\. DJI has discontinued AeroScope Mobile and no fixed firmware is available\.
