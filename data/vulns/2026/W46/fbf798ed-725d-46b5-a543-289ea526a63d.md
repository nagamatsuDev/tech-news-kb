# JSON\:\:XS versions before 4\.05 for Perl allow stack exhaustion via nested tagged values under allow\_tags in decode\_tag\.

- **ID**: CVE\-2026\-124540
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-14

## 原文

JSON\:\:XS versions before 4\.05 for Perl allow stack exhaustion via nested tagged values under allow\_tags in decode\_tag\.
  
With allow\_tags, "\(" starts a tagged value\. Its tag and value are decoded recursively, and each can start another tagged value\. Unlike arrays and objects, this nesting is not counted against max\_depth\.
  
A run of "\(" bytes exhausts the C stack and triggers an uncatchable segmentation fault regardless of max\_depth\.
