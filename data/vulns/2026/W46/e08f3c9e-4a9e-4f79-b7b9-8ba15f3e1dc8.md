# dnspython is a DNS toolkit for Python\.

- **ID**: CVE\-2026\-128089 / GHSA\-vvf4\-9x63\-8xvv
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: Python
- **公開**: 2026-11-13

## 原文

dnspython is a DNS toolkit for Python\. Prior to version 2\.9\.2, the from\_text\(\) parser for WKS records does not require the service number to be between 0 and 65535 before using it as a bitmap offset\. An attacker\-controlled zone file can supply a larger number, causing the service bitmap to grow to an extremely large size through inefficient repeated extension, consuming excessive memory and CPU and potentially terminating the process\. Applications are affected only when they parse zone\-file text whose record type and rdata are attacker controlled\. This issue is fixed in version 2\.9\.2\.
