# The CourseCure Courses plugin for WordPress is vulnerable to Privilege Escalation in versions up to, and including, 1\.5\.1\.

- **ID**: CVE\-2026\-15309
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-12

## 原文

The CourseCure Courses plugin for WordPress is vulnerable to Privilege Escalation in versions up to, and including, 1\.5\.1\. This is due to a missing capability check in the ajax\_save\_settings\(\) function, which accepts arbitrary POST parameters and calls update\_option\(\) with attacker\-controlled keys and values without any authorization verification\. This makes it possible for authenticated attackers, with subscriber\-level access and above, to elevate their privileges to administrator by setting the default\_role WordPress option to 'administrator' and users\_can\_register to '1', then registering a new account that is automatically granted full administrator access\.
