# ag\-psd can exhaust memory when parsing crafted PSD dimensions

- **ID**: CVE\-2026\-62297 / GHSA\-qfx6\-q44v\-9qqw
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/ag\-psd &lt; 31\.0\.0 → 31\.0\.0
- **公開**: 2026-11-13

## 原文

\#\#\# Summary readPsd\(\) commits the image/layer buffers from the declared header geometry \(width x height x channels x depth, and per\-layer rectangles\) before validating those values against the actual data\. A tiny crafted PSD declaring huge geometry forces a multi\-gigabyte allocation\. \#\#\# Impact On ag\-psd 30\.2\.0, Node 24, a 52\-byte PSD makes readPsd\(buf\) commit \~3\.17 GB \(measured peak RSS\) in \~0\.45 s before throwing a catchable RangeError \("Offset is outside the bounds of the DataView"\) — about 61,000,000x amplification\.
