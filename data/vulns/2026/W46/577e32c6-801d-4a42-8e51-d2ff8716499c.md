# Rooxis RXR\-12 Wi\-Fi router contains an unauthenticated remote code execution vulnerability in /usr/bin/cloud\_manage, where a server\-contr\.\.\.

- **ID**: CVE\-2026\-126720
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-11

## 原文

Rooxis RXR\-12 Wi\-Fi router contains an unauthenticated remote code execution vulnerability in /usr/bin/cloud\_manage, where a server\-controlled JSON diagnoseParameter field is passed unsanitized to popen\(\), enabling arbitrary command execution as root over cleartext HTTP when an attacker is positioned on\-path and has access to the hard\-coded cloud endpoint\. Firmware 20260813\_c2169ea5 fixes the vulnerability, and your router can be updated through the local web interface\.
