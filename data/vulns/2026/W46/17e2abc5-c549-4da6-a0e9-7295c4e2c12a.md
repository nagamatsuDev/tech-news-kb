# OpenEMR before 8\.5\.0 contains a missing authorization vulnerability in diagnosis\_full\.php that allows authenticated users to delete or cl\.\.\.

- **ID**: CVE\-2026\-126452
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: PHP
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains a missing authorization vulnerability in diagnosis\_full\.php that allows authenticated users to delete or clear any billing record by ID\. Attackers can supply a target billing ID in the id parameter with delete or clear mode to deactivate other patients' charges and corrupt financial records\.
