# 脆弱性はLinksys EA8100 1\.0\.3\.216940で決定された。

- **ID**: CVE\-2026\-127275
- **危険度**: Critical（緊急） (CVSS 10.0)
- **公開**: 2026-11-13

## 概要（機械翻訳）

脆弱性はLinksys EA8100 1\.0\.3\.216940で決定された。。。。。この問題は、SetRemoteSetting/SetUnsecuredWiFi コンポーネントの ui\_server\.lua ファイルに対する警告に影響します。この操作は有効/有効にすると認証が切れます。

## 原文

A vulnerability was determined in Linksys EA8100 1\.0\.3\.216940\. This issue affects the function SetRemoteSetting/SetUnsecuredWiFiWarning of the file ui\_server\.lua of the component JNAP API\. This manipulation of the argument isEnabled/enabled causes missing authentication\. It is possible to initiate the attack remotely\. The exploit has been publicly disclosed and may be utilized\. The vendor was contacted early about this disclosure but did not respond in any way\.
