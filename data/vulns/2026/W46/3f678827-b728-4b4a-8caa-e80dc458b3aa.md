# SvelteKit\: DoS while parsing form data from a remote functions \`form\`

- **ID**: CVE\-2026\-128120 / GHSA\-3r8g\-jcqq\-3p5j
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/@sveltejs/kit &gt;\= 2\.42\.0, &lt;\= 3\.1\.0 → 3\.1\.1
- **公開**: 2026-11-13

## 原文

This only affects applications using the experimental remote functions flag and utilizing the \`form\`, \`query\`, or \`command\` remote functions\. A specially\-crafted request could block the event loop for extended periods of time during parsing\.
