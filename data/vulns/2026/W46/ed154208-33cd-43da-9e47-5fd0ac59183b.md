# A flaw was found in Foreman’s Api\:\:V2\:\:PersonalAccessTokensController, where Foreman\:\:Controller\:\:UserAware\#find\_user resolves the target\.\.\.

- **ID**: CVE\-2026\-86322
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-12

## 原文

A flaw was found in Foreman’s Api\:\:V2\:\:PersonalAccessTokensController, where Foreman\:\:Controller\:\:UserAware\#find\_user resolves the target account using User\.find\(params\[\:user\_id\]\) without applying the required parent\-user authorization check\. An attacker with the create\_personal\_access\_tokens permission can therefore invoke POST /api/v2/users/\:user\_id/personal\_access\_tokens with another user’s ID and create a Personal Access Token on their behalf\. The resulting plaintext token is returned in the API response, while PersonalAccessToken\#check\_permissions\_after\_save only validates create\_personal\_access\_tokens on the token and does not enforce edit\_users authorization on the target user\. The attacker can then use the forged token to authenticate as the victim, potentially resulting in complete account takeover, including administrator accounts\.
