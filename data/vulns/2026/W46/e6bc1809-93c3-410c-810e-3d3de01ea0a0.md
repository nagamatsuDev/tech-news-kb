# OpenEMR before 8\.5\.0 contains a remote code execution vulnerability that allows authenticated billing users to store attacker\-controlled \.\.\.

- **ID**: CVE\-2026\-126428
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains a remote code execution vulnerability that allows authenticated billing users to store attacker\-controlled PHP by uploading a malformed ERA file to era\_payments\.php\. Attackers with a database\-write primitive such as SQL injection can register a background\_services row whose require\_once loads the stored \.edi file, executing PHP as the web\-server user\.
