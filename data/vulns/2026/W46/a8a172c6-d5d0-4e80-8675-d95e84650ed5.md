# WordPress用のELEXワードプレスヘルプデスク&amp;カスタマーチケットシステムプラグインは、すべてのバージョンのPHPオブジェクト注入に脆弱性があります。

- **ID**: CVE\-2026\-119077
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: PHP
- **公開**: 2026-11-13

## 原文

The ELEX WordPress HelpDesk &amp; Customer Ticketing System plugin for WordPress is vulnerable to PHP Object Injection in all versions up to, and including, 3\.3\.9 via the 'form \(specifically the attacker\-controlled ticket\_label field inside the url\-encoded form string\)' parameter parameter\. This is due to missing server\-side authentication and the absence of a class allowlist on deserialization, with the only guard being a nonce publicly emitted on any page carrying the \[wsdesk\_support\] shortcode\. This makes it possible for unauthenticated attackers to execute code on the server\. A successful exploit requires a single anonymous GET to any public page carrying the \[wsdesk\_support\] shortcode to harvest the publicly emitted wsdesk\_nonce value, after which a single unauthenticated POST completes the attack\.
