# bird\-lg\-go is a BIRD looking glass in Go\.

- **ID**: CVE\-2026\-63644
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-09

## 原文

bird\-lg\-go is a BIRD looking glass in Go\. Prior to version 1\.4\.7, unsanitized input path enables arbitrary local file read, allowing an unauthenticated remote attacker to read sensitive files such as /etc/shadow and /root/\.bash\_history\. This issue has been patched in version 1\.4\.7\.
