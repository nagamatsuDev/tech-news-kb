# Cudy TR3000 before 2\.5\.42 contains an unauthenticated stack buffer overflow vulnerability in the stun\_client TR\-111 UDP Connection Reques\.\.\.

- **ID**: CVE\-2026\-75492
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-13

## 原文

Cudy TR3000 before 2\.5\.42 contains an unauthenticated stack buffer overflow vulnerability in the stun\_client TR\-111 UDP Connection Request parser that parses requests before verifying username or HMAC\. Remote attackers can send a single crafted UDP datagram lacking a space in the request line, causing strncpy\(\) to overflow a 10\-byte stack buffer and crash stun\_client for denial of service\.
