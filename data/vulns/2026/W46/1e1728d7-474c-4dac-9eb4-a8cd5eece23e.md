# Rooxis RXR\-12 Wi\-Fi router contains an authenticated command injection vulnerability in the LuCI white\_list RPC handler \(/usr/lib/lua/luc\.\.\.

- **ID**: CVE\-2026\-126723
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-11

## 原文

Rooxis RXR\-12 Wi\-Fi router contains an authenticated command injection vulnerability in the LuCI white\_list RPC handler \(/usr/lib/lua/luci/data/white\_list\_plt\.lua\), where unsanitized user\-supplied MAC addresses are concatenated into os\.execute\(\) without validation, yielding root command execution via a malformed mac parameter\. Firmware 20260813\_c2169ea5 fixes the vulnerability, and users can update their router through the local web interface\.
