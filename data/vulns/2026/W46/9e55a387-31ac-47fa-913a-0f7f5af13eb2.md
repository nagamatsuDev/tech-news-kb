# OpenEMR before 8\.5\.0 contains a stored cross\-site scripting vulnerability that allows portal patients to run JavaScript in staff sessions\.\.\.

- **ID**: CVE\-2026\-126451
- **危険度**: High（重要） (CVSS 7.3)
- **言語**: JavaScript/TypeScript
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains a stored cross\-site scripting vulnerability that allows portal patients to run JavaScript in staff sessions by injecting javascript\: URLs into document template\_data\. Attackers can submit an encounterForm value rendered unsanitized into an iframe src by DocumentTemplateRender, letting the script read PHI and CSRF tokens and call staff or admin endpoints\.
