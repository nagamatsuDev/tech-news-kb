# Dell Ansible Storage for PowerFlex, versions prior to 3\.2\.0, contains an Improper Certificate Validation vulnerability in the API client \.\.\.

- **危険度**: High（重要） (CVSS 7.4)
- **公開**: 2026-11-11

## 原文

Dell Ansible Storage for PowerFlex, versions prior to 3\.2\.0, contains an Improper Certificate Validation vulnerability in the API client component\.
