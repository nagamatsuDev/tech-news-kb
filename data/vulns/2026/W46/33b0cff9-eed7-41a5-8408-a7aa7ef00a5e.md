# An untrusted search path issue in Aurora PostgreSQL dialect detection in the AWS Advanced Go Wrapper from release 2026\-04\-06 \(awssql/v2\.0\.\.\.

- **ID**: CVE\-2026\-126793
- **危険度**: High（重要） (CVSS 8.0)
- **公開**: 2026-11-12

## 原文

An untrusted search path issue in Aurora PostgreSQL dialect detection in the AWS Advanced Go Wrapper from release 2026\-04\-06 \(awssql/v2\.0\.0\) and before release 2026\-07\-29 \(awssql/v2\.0\.3\) could allow a remote authenticated user to escalate privileges to those of another database user, including a member of the rds\_superuser role, via a crafted function that runs when that user connects to an Aurora PostgreSQL cluster through an affected version of the wrapper\.
  
To remediate this issue, users should upgrade to the AWS Advanced Go Wrapper release 2026\-07\-29 \(awssql/v2\.0\.3\) or later\.
