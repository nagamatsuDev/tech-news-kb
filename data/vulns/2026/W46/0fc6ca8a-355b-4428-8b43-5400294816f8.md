# BACnet Stack is a BACnet open source protocol stack C library for embedded systems\.

- **ID**: CVE\-2026\-45341
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-12

## 原文

BACnet Stack is a BACnet open source protocol stack C library for embedded systems\. From versions 1\.4\.0 to before 1\.4\.4, and 1\.5\.0 to before 1\.5\.1, a NULL pointer dereference can be triggered in bacnet\_device\_object\_reference\_decode\(\) when a WriteProperty request updates OBJECT\_STRUCTURED\_VIEW / PROP\_SUBORDINATE\_LIST\. This issue has been patched in versions 1\.4\.4 and 1\.5\.1\.
