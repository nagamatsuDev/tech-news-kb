# BACnet Stack is a BACnet open source protocol stack C library for embedded systems\.

- **ID**: CVE\-2026\-62973
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-13

## 原文

BACnet Stack is a BACnet open source protocol stack C library for embedded systems\. Prior to versions 1\.4\.5, 1\.5\.1, and 1\.6\.0, a remote out\-of\-bounds read exists in the official BACnet client application apps/readpropm in bacnet\-stack commit e2bdbf6\. When readpropm sends a legitimate ReadPropertyMultiple request to a malicious BACnet/IP peer, the peer can reply with a malformed but structurally valid ReadPropertyMultiple\-ACK that drives the client into a global\-buffer\-overflow read on the global receive buffer Rx\_Buf\. This issue has been patched in versions 1\.4\.5, 1\.5\.1, and 1\.6\.0\.
