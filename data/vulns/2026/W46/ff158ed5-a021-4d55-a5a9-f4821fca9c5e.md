# FFmpeg through 9\.0\.2 contains a heap buffer overflow vulnerability in libavcodec/flicvideo\.c that allows attackers to write out of bounds\.\.\.

- **ID**: CVE\-2026\-125241
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-09

## 原文

FFmpeg through 9\.0\.2 contains a heap buffer overflow vulnerability in libavcodec/flicvideo\.c that allows attackers to write out of bounds because check\_pixel\_ptr\(\) checks only one bound with negative\-stride frames\. Attackers can supply a crafted FLIC file whose RLE and delta chunks write pixel data past frame storage, corrupting heap memory to crash applications or possibly execute code\.
