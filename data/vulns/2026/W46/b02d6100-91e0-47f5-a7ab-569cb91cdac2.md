# OpenEMR before 8\.5\.0 contains an SQL injection vulnerability in the patient portal OnsiteDocument\.Query endpoint, where mass\-assigned \_Bi\.\.\.

- **ID**: CVE\-2026\-126488
- **危険度**: High（重要） (CVSS 7.7)
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains an SQL injection vulnerability in the patient portal OnsiteDocument\.Query endpoint, where mass\-assigned \_BitwiseAnd criteria parameters are placed unquoted into SQL with only quote\-character escaping\. Authenticated portal patients can inject SQL outside their per\-patient scope to read the entire database, including other patients' demographics and users\_secure password hashes\.
