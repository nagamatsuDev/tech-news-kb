# Path traversal in the certificate\.deleteCertificate JSON\-RPC method \(POST /api/rpc\) of the turbineweb web interface in Zenitel VSFF6, VSF\.\.\.

- **ID**: CVE\-2026\-95379
- **危険度**: High（重要） (CVSS 7.0)
- **公開**: 2026-11-13

## 原文

Path traversal in the certificate\.deleteCertificate JSON\-RPC method \(POST /api/rpc\) of the turbineweb web interface in Zenitel VSFF6, VSFF8, VSFF8MP, VSFF8MN, and VSFT devices with software versions from 10\.0\.3\.0 before 10\.1\.3\.0 allows authenticated administrators to delete arbitrary files as root via a relative path \(\.\./\) in the file\_name parameter\.
  
This can be used to cause denial of service or render the device inoperable by removing critical system files, and to weaken device security by removing files such as firewall rules or certificate trust stores\.
