# OpenBao before 2\.6\.5 and 2\.7\.2 contains an authentication bypass vulnerability that allows unauthenticated callers to obtain OIDC ID toke\.\.\.

- **ID**: CVE\-2026\-126310
- **危険度**: High（重要） (CVSS 8.7)
- **公開**: 2026-11-13

## 原文

OpenBao before 2\.6\.5 and 2\.7\.2 contains an authentication bypass vulnerability that allows unauthenticated callers to obtain OIDC ID tokens by abusing public clients with client\_credentials enabled\. Attackers who know a public client's client\_id can request tokens from the identity/oidc/provider/&lt;name&gt;/token endpoint to impersonate the client without any secret\.
