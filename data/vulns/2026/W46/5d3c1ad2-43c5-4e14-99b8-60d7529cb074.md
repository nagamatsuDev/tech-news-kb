# AIOHTTP is an asynchronous HTTP client/server framework for asyncio and Python\.

- **ID**: CVE\-2026\-128124 / GHSA\-jm3w\-gw2p\-xjfj
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: Python
- **公開**: 2026-11-13

## 原文

AIOHTTP is an asynchronous HTTP client/server framework for asyncio and Python\. Prior to 3\.14\.4, Application\.add\_domain\(\) converts every asterisk wildcard in a domain mask into a greedy regular\-expression fragment, so a mask containing two or more wildcards can take polynomial time to reject a long Host header that does not match\. A remote attacker can repeatedly send such headers to a server configured with a multi\-wildcard domain mask and stall the event loop\. This issue is fixed in version 3\.14\.4\.
