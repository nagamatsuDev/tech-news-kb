# AIOHTTP\: Event loop stall in add\_domain\(\) wildcard matching

- **ID**: CVE\-2026\-128124 / GHSA\-jm3w\-gw2p\-xjfj
- **危険度**: High（重要）
- **言語**: Python
- **パッケージ**: PyPI/aiohttp &lt;\= 3\.14\.3 → 3\.14\.4
- **公開**: 2026-11-13

## 原文

\#\#\# Summary \`Application\.add\_domain\(\)\` compiled each \`\*\` in a host mask to \`\[\^\:\]\*\`\. With two or more wildcards in a mask, matching a long \`Host\` header that does not match the mask took polynomial time on the event loop\. \#\#\# Impact An attacker could stall a server that registers a domain mask with more than one wildcard by sending requests with a long \`Host\` header\. \#\#\# Workaround Use at most one \`\*\` in a domain mask\. \-\-\- Patch\: https\://github\.com/aio\-libs/aiohttp/commit/c6ac0e44c3c573ff9616f4a6a532992538b31e43
