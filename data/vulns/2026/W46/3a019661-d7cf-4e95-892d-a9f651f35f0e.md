# 8\.5\.0以前のOpenEMRには、SLEOB\:\:slInvoiceNumber\(\)のSQLインジェクション脆弱性が含まれている。

- **ID**: CVE\-2026\-126482
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-13

## 概要（機械翻訳）

OpenEMR before 8\.5\.0には、SLEOB\:\:slInvoiceNumber\(\)のSQLインジェクション脆弱性が含まれている。src/Billing/SLEOB\.phpは、アップロードされたX12 835 ERAファイルからCLP01クレーム識別子を、エスケープやパラメーターバインディングなしでクエリに結合する。認証されたユーザー、またはERAファイルがクラークアップロードされる悪意ある支払い者は、 Hgsixrary SQLを実行して、 users\_secureパスワードハッシュやデータの変更を含む任意のテーブルを読み取ります。。。\.\.\.\.\.\. 認証されたユーザは、\.\. アクセス許可を持つ。

## 原文

OpenEMR before 8\.5\.0 contains an SQL injection vulnerability in SLEOB\:\:slInvoiceNumber\(\) in src/Billing/SLEOB\.php, which concatenates the CLP01 claim identifier from uploaded X12 835 ERA files into a query without escaping or parameter binding\. Authenticated users with billing permissions, or a malicious payer whose ERA file a clerk uploads, can execute arbitrary SQL to read any table, including users\_secure password hashes, and modify data\.
