# A vulnerability was found in SourceCodester Smart Attendance System with QR Code Scanner 1\.0\.

- **ID**: CVE\-2026\-125076
- **危険度**: High（重要） (CVSS 7.3)
- **言語**: PHP
- **公開**: 2026-11-10

## 原文

A vulnerability was found in SourceCodester Smart Attendance System with QR Code Scanner 1\.0\. Affected is an unknown function of the file api/attendance\_handler\.php of the component JSON Endpoint\. Performing a manipulation of the argument student\_code results in missing authentication\. It is possible to initiate the attack remotely\. The exploit has been made public and could be used\.
