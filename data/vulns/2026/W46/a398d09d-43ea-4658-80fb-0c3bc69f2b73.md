# A reachable assertion in Node\.js HTTP/2 session teardown lets any unauthenticated client abort the server, over both TLS and cleartext\.

- **ID**: CVE\-2026\-123863
- **危険度**: High（重要） (CVSS 8.2)
- **言語**: JavaScript/TypeScript
- **公開**: 2026-11-11

## 原文

A reachable assertion in Node\.js HTTP/2 session teardown lets any unauthenticated client abort the server, over both TLS and cleartext\. A client can arrange for an Http2Stream that still holds nghttp2\-allocated header buffers to outlive its session\: the stream is removed from the session's stream set but never detached, so when \~Http2Session\(\) runs the memory accounting is nonzero and the CHECK\_EQ\(current\_nghttp2\_memory\_, 0\) assertion fails, terminating the process\. The trigger needs only a default http2 server whose handler responds before the request body has ended, which is typical\. It is a variant of CVE\-2024\-27983 that the earlier fix did not cover, because that fix only detached streams still tracked in the session\. This vulnerability affects Node\.js 26\.x \(since 26\.9\.0\) and 24\.x \(since 24\.22\.0\)\.
