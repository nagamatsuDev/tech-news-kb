# OpenEMR before 8\.5\.0 contains a missing authorization vulnerability in five Module Manager InstallerController actions that lack the admi\.\.\.

- **ID**: CVE\-2026\-126479
- **危険度**: High（重要） (CVSS 7.6)
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains a missing authorization vulnerability in five Module Manager InstallerController actions that lack the admin/manage\_modules ACL check and CSRF validation\. Low\-privilege users such as Front Office accounts can POST to saveConfig or SaveHooks to overwrite any module's configuration, retarget CCDA and HIE settings, and delete module hooks\.
