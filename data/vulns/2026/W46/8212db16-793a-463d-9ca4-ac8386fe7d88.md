# OpenEMR before 8\.3\.0 contains an unsanitized deserialization vulnerability that allows authenticated attackers to control patient\-matchin\.\.\.

- **ID**: CVE\-2026\-126322
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.3\.0 contains an unsanitized deserialization vulnerability that allows authenticated attackers to control patient\-matching criteria by supplying a crafted serialized key parameter\. Attackers can send serialized arrays to interface/orders/patient\_match\_dialog\.php to enumerate patients or force matches that associate lab orders with the wrong patient\.
