# AutoMapper\: Denial of Service via uncontrolled recursion that bypasses MaxDepth

- **ID**: CVE\-2026\-128081 / GHSA\-gpwp\-5797\-mjff
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: C\#/\.NET
- **パッケージ**: NuGet/AutoMapper &gt;\= 16\.0\.0, &lt; 16\.3\.0 → 16\.3\.0
- **公開**: 2026-11-13

## 原文

\#\#\# Summary The default and explicit \`MaxDepth\` limits added for CVE\-2026\-32933 don't apply to several mapping paths\. Mapping a deeply nested source through any of them recurses without bound and throws a \`StackOverflowException\`, which can't be caught and terminates the process\. \#\#\# Affected paths \- \*\*Polymorphic maps\:\*\* derived type maps \(\`Include\` / \`IncludeBase\`\) didn't inherit the base map's \`MaxDepth\`, and the default limit for self\-referential maps was only applied to the base map\. A chain of derived objects was mapped without a limit, even with \`MaxDepth\` set on the base map\. \- \*\*Runti
