## 原文

BACnet Stack is a BACnet open source protocol stack C library for embedded systems\. Prior to versions 1\.4\.5, 1\.5\.1, and 1\.6\.0, the bsc\_node\_parse\_urls\(\) function in src/bacnet/datalink/bsc/bsc\-node\.c contains three distinct bugs when parsing space\-separated WebSocket URIs from a BACnet/SC Address Resolution ACK message\. Two bugs cause out\-of\-bounds writes past the utf8\_urls\[10\]\[129\] array in the static BSC\_ADDRESS\_RESOLUTION structure\. This issue has been patched in versions 1\.4\.5, 1\.5\.1, and 1\.6\.0\.
