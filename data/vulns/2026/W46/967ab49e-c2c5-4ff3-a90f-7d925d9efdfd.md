# The SureDash – Community, Courses &amp; Member Dashboard plugin for WordPress is vulnerable to Privilege Escalation in all versions up to, an\.\.\.

- **ID**: CVE\-2026\-123769
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-13

## 原文

The SureDash – Community, Courses &amp; Member Dashboard plugin for WordPress is vulnerable to Privilege Escalation in all versions up to, and including, 1\.13\.0 This is due to the \`save\_settings\(\)\` REST handler at \`/suredash/v1/save\-settings\` being gated only by \`admin\_permission\_callback\(\)\`, which authorizes any holder of the custom \`manage\_portal\_dashboard\` capability \(Portal Manager role\) without requiring \`promote\_users\`, \`edit\_users\`, or \`manage\_options\`, combined with \`sanitize\_settings\_data\(\)\` iterating all attacker\-supplied keys with no allow\-list, allowing arbitrary keys such as \`default\_role\` to pass through \`sanitize\_text\_field\(\)\` unchanged and be persisted into the \`portal\_settings\` option via \`update\_option\(\)\` with no role\-validity check\. This makes it possible for authenticated attackers with Portal Manager\-level access and above to poison the \`default\_role\` setting to \`administrator\`, after which any subsequent new\-user registration through the publicly accessible block\-register endpoint reads the corrupted setting and passes it directly to \`wp\_insert\_user\(\)\`, producing a full WordPress Administrator account under the attacker's control\. The exploit requires two steps\: a POST to the authenticated \`save\-settings\` endpoint to overwrite \`default\_role\`, followed by triggering a new registration through the unauthenticated block\-register endpoint to receive the escalated account\. Successful exploitation causes the attacker's own account to receive the complete administrator role\.
