# BACnet Stack is a BACnet open source protocol stack C library for embedded systems\.

- **ID**: CVE\-2026\-47710
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-11-12

## 原文

BACnet Stack is a BACnet open source protocol stack C library for embedded systems\. Prior to versions 1\.4\.4, 1\.5\.1, and 1\.6\.0, a stack\-buffer\-overflow can be triggered in the current master branch when a Loop object reads a referenced property through its default timer path and the referenced property is OBJECT\_STRUCTURED\_VIEW / PROP\_DESCRIPTION containing a long attacker\-controlled string\. This issue has been patched in versions 1\.4\.4, 1\.5\.1, and 1\.6\.0\.
