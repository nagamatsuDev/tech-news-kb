# Astro\: XSS via attribute injection in dynamic tag names

- **ID**: CVE\-2026\-126361 / GHSA\-mh32\-jxcr\-mh9f
- **危険度**: Low（注意）
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/astro &lt;\= 7\.4\.4 → 7\.4\.5
- **公開**: 2026-11-13

## 原文

\#\# Summary When a dynamic tag \(\`const Tag \= \.\.\.; &lt;Tag /&gt;\`\) resolves to a string, Astro renders it as a raw HTML element name\. The name was filtered to remove characters that could inject attributes, but the filter did not handle \`/\`\. Because HTML parsers treat \`/\` inside a tag as an attribute separator, a tag name such as \`img/src/onerror\=alert\(1\)\` was rendered as an \`&lt;img&gt;\` element with an \`onerror\` attribute\. The JSX renderer used for MDX did not filter string tag names at all\. For example\: \`\`\`astro \-\-\- const Tag \= Astro\.url\.searchParams\.get\('as'\) ?? 'div'; \-\-\- &lt;Tag&gt;hello&lt;/Tag&gt; \`\`\` rendered
