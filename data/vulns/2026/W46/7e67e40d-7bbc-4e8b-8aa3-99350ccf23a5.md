# OpenEMR before 8\.5\.0 contains an improper authorization vulnerability in interface/orders/list\_reports\.php that allows read\-only users to\.\.\.

- **ID**: CVE\-2026\-126432
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: PHP
- **公開**: 2026-11-13

## 原文

OpenEMR before 8\.5\.0 contains an improper authorization vulnerability in interface/orders/list\_reports\.php that allows read\-only users to transmit lab orders because the patients/med check ignores write permission\. Authenticated attackers can submit form\_xmit with arbitrary procedure order IDs to send HL7 orders containing SSNs, insurance, and diagnoses to laboratories and mark them transmitted\.
