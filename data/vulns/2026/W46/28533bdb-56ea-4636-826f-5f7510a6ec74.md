# Google ChromeのMediaで読まれたデータのうち、157\.0\.8103\.78以前には、リモート攻撃者が内部でHgraryコードを実行することができた。

- **ID**: CVE\-2026\-126890
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-11

## 概要（機械翻訳）

Google Chromeで読まれた境界から、リモートアタッカーがグラフ化されたHTMLページを通してサンドボックス内でHgraryコードを実行することができるようになった。。\(クロムのセキュリティレベル\:高\)\:クローム\:ハイ\)\:クローム

## 原文

Out of bounds read in Media in Google Chrome prior to 157\.0\.8103\.78 allowed a remote attacker to potentially execute arbitrary code inside the sandbox via a crafted HTML page\. \(Chromium security severity\: High\)
