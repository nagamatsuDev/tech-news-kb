# An improper authentication vulnerability has been found in the task console in the smart\_proxy\_dynflow package\.

- **ID**: CVE\-2026\-107152
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-12

## 原文

An improper authentication vulnerability has been found in the task console in the smart\_proxy\_dynflow package\. The console accepts any client certificate signed by the capsule's certificate authority\. It does not check the list of servers the capsule trusts\. A low\-privileged network attacker or user must already hold such a certificate\. They can open the console and read job details\. Those details include passwords when a job was given them\. They can also cancel a running task\.
