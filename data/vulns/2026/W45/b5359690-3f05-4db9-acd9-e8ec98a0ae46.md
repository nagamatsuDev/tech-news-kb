# IBM API Connect 10\.0\.8\.0から10\.0\.8\.12および12\.1\.0\.0から12\.1\.1\.2は、認証されていない攻撃者が認証をバイパスできるようにする。

- **ID**: CVE\-2026\-17301
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-07

## 概要（機械翻訳）

IBM API Connect 10\.0\.8\.0から10\.0\.8\.12および12\.1\.0\.0から12\.1\.1\.2は、暗号署名の不適切検証による認証を回避できる。

## 原文

IBM API Connect 10\.0\.8\.0 through 10\.0\.8\.12 and 12\.1\.0\.0 through 12\.1\.1\.2 could allow an unauthenticated attacker to bypass authentication due to improper verification of a cryptographic signature\.
