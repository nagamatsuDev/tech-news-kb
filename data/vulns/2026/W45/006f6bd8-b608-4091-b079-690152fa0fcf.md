# OpenEMR before 8\.4\.0 contains an authorization bypass vulnerability that allows low\-privileged authenticated users to read cross\-patient \.\.\.

- **ID**: CVE\-2026\-124480
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-08

## 原文

OpenEMR before 8\.4\.0 contains an authorization bypass vulnerability that allows low\-privileged authenticated users to read cross\-patient FHIR QuestionnaireResponse data by sending the APICSRFTOKEN header\. Attackers can reuse the session\-exposed api\_csrf\_token\_js value to skip FHIR scope checks and call GET /fhir/QuestionnaireResponse, exfiltrating site\-wide questionnaire answer PHI\.
