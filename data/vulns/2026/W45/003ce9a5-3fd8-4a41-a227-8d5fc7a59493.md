# rsync before 3\.5\.2 contains a denial of service vulnerability in the delta\-transfer sender's hash\_search\(\) in match\.c that allows malicio\.\.\.

- **ID**: CVE\-2026\-119741
- **危険度**: High（重要） (CVSS 7.5)
- **OS**: Windows
- **公開**: 2026-11-03

## 原文

rsync before 3\.5\.2 contains a denial of service vulnerability in the delta\-transfer sender's hash\_search\(\) in match\.c that allows malicious receivers to trigger unbounded strong\-checksum work at consecutive offsets\. Unauthenticated attackers pulling from a public daemon module can supply weak checksums colliding with consecutive rolling windows plus non\-matching strong checksums, exhausting sender CPU across concurrent connections\.
