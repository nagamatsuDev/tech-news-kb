# OpenEMR before 8\.3\.0 contains a missing authorization vulnerability in interface/billing/sl\_eob\_patient\_note\.php that allows any authenti\.\.\.

- **ID**: CVE\-2026\-124472
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-08

## 原文

OpenEMR before 8\.3\.0 contains a missing authorization vulnerability in interface/billing/sl\_eob\_patient\_note\.php that allows any authenticated user to read and modify patient billing notes\. Attackers with low\-privilege accounts can enumerate the patient\_id parameter and submit POST requests using the embedded CSRF token to view or tamper with confidential billing data\.
