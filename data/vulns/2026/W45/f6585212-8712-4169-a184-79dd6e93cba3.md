# IBM API Connect 10\.0\.8\.0から10\.0\.8\.12および12\.1\.0\.0から12\.1\.1\.2まで、リモート認証された攻撃者がアクセスし、修正することができる。

- **ID**: CVE\-2026\-17410
- **危険度**: Critical（緊急） (CVSS 9.9)
- **公開**: 2026-11-07

## 概要（機械翻訳）

IBM API Connect 10\.0\.8\.0から10\.0\.8\.12および12\.1\.0\.0から12\.1\.1\.2は、リモート認証された攻撃者が、Hgment区切り文字を適切に中立化することで、他のテナントのポータルデータにアクセスし、修正することができる。

## 原文

IBM API Connect 10\.0\.8\.0 through 10\.0\.8\.12 and 12\.1\.0\.0 through 12\.1\.1\.2 could allow a remote authenticated attacker to access and modify other tenants' portal data due to improper neutralization of argument delimiters\.
