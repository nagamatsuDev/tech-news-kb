# OpenEMR before 8\.3\.0 contains a broken access control vulnerability in portal/portal\_payment\.php that allows low\-privilege authenticated \.\.\.

- **ID**: CVE\-2026\-124489
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: PHP
- **公開**: 2026-11-08

## 原文

OpenEMR before 8\.3\.0 contains a broken access control vulnerability in portal/portal\_payment\.php that allows low\-privilege authenticated users to bypass billing ACL checks by tampering patient identifiers\. Attackers can modify the pid and form\_pid parameters to view payment pages and record fraudulent payment receipts for arbitrary patients, corrupting billing records\.
