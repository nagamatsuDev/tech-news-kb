# OpenEMR before 8\.3\.0 contains an SQL injection vulnerability in the Fee Sheet drug\-inventory lookup \(DrugSalesService\:\:sellDrug\) that int\.\.\.

- **ID**: CVE\-2026\-124469
- **危険度**: Critical（緊急） (CVSS 9.9)
- **公開**: 2026-11-08

## 原文

OpenEMR before 8\.3\.0 contains an SQL injection vulnerability in the Fee Sheet drug\-inventory lookup \(DrugSalesService\:\:sellDrug\) that interpolates the prod\[N\]\[warehouse\] POST field into an ORDER BY clause\. Low\-privileged authenticated users can submit Fee Sheet product lines with constant subqueries to run a time\-based blind oracle, extracting patient data and users\_secure bcrypt hashes\.
