# OpenEMR before 8\.3\.0 contains a missing authorization vulnerability that allows low\-privileged authenticated users to delete arbitrary pa\.\.\.

- **ID**: CVE\-2026\-124477
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-08

## 原文

OpenEMR before 8\.3\.0 contains a missing authorization vulnerability that allows low\-privileged authenticated users to delete arbitrary patient recall records via the delete\_Recall action\. Attackers can send POST requests to /interface/main/messages/save\.php with a target pid and r\_ID to remove recall data without ACL or ownership checks\.
