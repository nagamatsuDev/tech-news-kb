# In FreedomBox before 26\.15, unprivileged user accounts can read/write files for which they lack permissions by setting the authorized\_key\.\.\.

- **ID**: CVE\-2026\-123962
- **危険度**: High（重要） (CVSS 8.4)
- **OS**: Linux
- **公開**: 2026-11-06

## 原文

In FreedomBox before 26\.15, unprivileged user accounts can read/write files for which they lack permissions by setting the authorized\_keys file to be a symlink\. NOTE\: FreedomBox is a Debian Pure Blend, which means that it distributes its software through Debian repositories\.
