# OpenEMR before 8\.3\.0 contains a path traversal vulnerability in the RingCentral RCFaxClient disposeDocument\(\) method of oe\-module\-faxsms \.\.\.

- **ID**: CVE\-2026\-124490
- **危険度**: Critical（緊急） (CVSS 9.1)
- **公開**: 2026-11-08

## 原文

OpenEMR before 8\.3\.0 contains a path traversal vulnerability in the RingCentral RCFaxClient disposeDocument\(\) method of oe\-module\-faxsms that allows authenticated attackers to read and write arbitrary files via the file\_path parameter\. Attackers can use action\=download to read credentials and source code, or action\=setup with base64 content to write web\-executable files for code execution\.
