# OpenEMR before 8\.3\.0 contains a missing authorization vulnerability in the classic document controller that allows low\-privilege authenti\.\.\.

- **ID**: CVE\-2026\-124486
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-08

## 原文

OpenEMR before 8\.3\.0 contains a missing authorization vulnerability in the classic document controller that allows low\-privilege authenticated users to recategorize other patients' documents\. Attackers can invoke move\_action\_process to move a document into a patients\|demo category, then retrieve it with an empty patient\_id to exfiltrate PHI and tamper with charts\.
