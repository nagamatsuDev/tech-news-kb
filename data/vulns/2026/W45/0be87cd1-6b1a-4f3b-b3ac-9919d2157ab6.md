# OpenEMR before 8\.3\.0 contains a missing authorization vulnerability in interface/billing/sl\_eob\_invoice\.php that allows any authenticated\.\.\.

- **ID**: CVE\-2026\-124471
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-08

## 原文

OpenEMR before 8\.3\.0 contains a missing authorization vulnerability in interface/billing/sl\_eob\_invoice\.php that allows any authenticated user to read and modify billing data for any encounter\. Attackers can iterate the id parameter to read patient names and billing notes, and post payments, adjustments, deletions, or billing notes against any patient's account\.
