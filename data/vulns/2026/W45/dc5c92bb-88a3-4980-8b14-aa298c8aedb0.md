# IBM API Connect 12\.1\.0\.0から12\.1\.1\.2まで、リモート攻撃者が不正なエンド検証によって機密情報を取得できる可能性がある。

- **ID**: CVE\-2026\-17329
- **危険度**: Critical（緊急） (CVSS 9.3)
- **公開**: 2026-11-07

## 概要（機械翻訳）

IBM API Connect 12\.1\.0\.0から12\.1\.1\.2までは、エンドポイントURLの不適切な検証によって、リモートアタッカーが機密情報を取得できる。

## 原文

IBM API Connect 12\.1\.0\.0 through 12\.1\.1\.2 could allow a remote attacker to obtain sensitive information due to improper validation of endpoint URLs\.
