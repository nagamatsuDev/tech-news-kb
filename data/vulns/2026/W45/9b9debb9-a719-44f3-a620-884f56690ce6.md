# IBM API Connect 12\.1\.0\.0から12\.1\.1\.2までは、リモートアタッカーがサーバー側の要求偽造により機密情報を取得できる。

- **ID**: CVE\-2026\-17344
- **危険度**: Critical（緊急） (CVSS 9.3)
- **公開**: 2026-11-07

## 概要（機械翻訳）

IBM API Connect 12\.1\.0\.0から12\.1\.1\.2までは、リモート攻撃者がサーバー側の要求偽造により機密情報を得ることができる。認証なしでアクセスできるサービスは、意図しない宛先にリクエストを送信することができます。\)。 \) 。

## 原文

IBM API Connect 12\.1\.0\.0 through 12\.1\.1\.2 could allow a remote attacker to obtain sensitive information due to server\-side request forgery\. A service that can be reached without authentication could be made to send requests to unintended destinations\.
