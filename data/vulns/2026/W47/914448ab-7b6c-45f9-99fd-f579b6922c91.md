# ThinkPHP 2\.0 through 2\.2 and 3\.0 Lite mode contains an eval injection vulnerability in the Dispatcher PATH\_INFO parsing, which uses preg\_\.\.\.

- **ID**: CVE\-2012\-20007
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

ThinkPHP 2\.0 through 2\.2 and 3\.0 Lite mode contains an eval injection vulnerability in the Dispatcher PATH\_INFO parsing, which uses preg\_replace with the /e modifier and a double\-quoted replacement\. Unauthenticated attackers can send crafted requests to index\.php with a malicious 's' parameter containing PHP expressions to execute arbitrary code on the server\. Exploitation evidence was first observed by the Shadowserver Foundation on 2023\-10\-14\.
