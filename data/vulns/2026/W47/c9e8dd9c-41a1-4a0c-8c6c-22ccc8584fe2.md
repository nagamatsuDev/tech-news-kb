# Open Object Rexx \(ooRexx\) before 5\.2\.0において、RXAPIはXDG\_RUNTIME\_DIRが設定されていない世界書きの/tmpファイル、またはlocalhost TCPポートに依存します。

- **ID**: CVE\-2026\-130327
- **危険度**: Critical（緊急） (CVSS 9.3)
- **公開**: 2026-11-16

## 概要（機械翻訳）

5\.2\.0以前のOpen Object Rexx \(ooRexx\)では、RXAPIはXDG\_RUNTIME\_DIRが設定されていない世界書きの/tmpファイル、またはlocalhost TCP port 10010に依存しており、任意のローカルユーザがRXAPI通信を可能としており、例えばREXXスクリプトによって実行されるマクロの注入が可能である。

## 原文

In Open Object Rexx \(ooRexx\) before 5\.2\.0, RXAPI relies on a world\-writable /tmp file unless XDG\_RUNTIME\_DIR is set, or localhost TCP port 10010, allowing RXAPI communication by any local user, e\.g\., for injection of a macro that will be executed by a REXX script\.
