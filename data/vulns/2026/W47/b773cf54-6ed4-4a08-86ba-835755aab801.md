# Netatalk is a Free and Open Source file server suite for Unix\-like operating systems\.

- **ID**: CVE\-2026\-49387
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-20

## 原文

Netatalk is a Free and Open Source file server suite for Unix\-like operating systems\. From 3\.1\.0 until 4\.5\.0, the afpd FPSpotlightRPC unmarshalling handlers in etc/afpd/spotlight\_marshalling\.c trust the element count encoded in the upper 32 bits of an RPC tag without comparing it with the remaining input length\. An authenticated client with access to a Spotlight\-enabled volume can make sl\_unpack\_ints, sl\_unpack\_date, sl\_unpack\_uuid, or sl\_unpack\_floats iterate beyond dsi\-&gt;commands and read heap memory\. The read values remain in internal dalloc storage and no information\-disclosure channel was demonstrated, but the worker serving the attacker's session can be crashed\. This issue is fixed in version 4\.5\.0\.
