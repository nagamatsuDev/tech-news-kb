# In Modem, there is a possible system crash due to a missing bounds check\.

- **ID**: CVE\-2026\-20554
- **危険度**: High（重要） (CVSS 7.1)
- **OS**: Network/Firmware
- **公開**: 2026-11-02

## 原文

In Modem, there is a possible system crash due to a missing bounds check\. This could lead to remote escalation of privilege, if a UE has connected to a rogue base station controlled by the attacker, with no additional execution privileges needed\. User interaction is needed for exploitation\. Patch ID\: MOLY01911177; Issue ID\: MSV\-10122\.
