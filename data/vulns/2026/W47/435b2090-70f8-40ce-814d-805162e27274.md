# @nuxt/webpack\-builder and @nuxt/rspack\-builder dev server serves built source to DNS rebinding pages

- **ID**: CVE\-2026\-128072 / GHSA\-x2wv\-5868\-p7v2
- **危険度**: Low（注意） (CVSS 3.1)
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/@nuxt/webpack\-builder &gt;\= 4\.0\.0, &lt; 4\.6\.4 → 4\.6\.4, npm/@nuxt/webpack\-builder &gt;\= 3\.0\.0, &lt; 4\.0\.0, npm/@nuxt/rspack\-builder &gt;\= 4\.0\.0, &lt; 4\.6\.4 → 4\.6\.4, npm/@nuxt/rspack\-builder &gt;\= 3\.12\.2, &lt; 4\.0\.0
- **公開**: 2026-11-16

## 原文

\#\#\# Summary When using the webpack or rspack builder, the dev server serves built client chunks to any request whose \`Host\` header matches its \`Origin\`/\`Referer\`, or that carries \`Sec\-Fetch\-Site\: same\-origin\`\. After a DNS rebinding attack both headers name the attacker's hostname, so a malicious page opened while \`nuxt dev\` is running can read \`/\_nuxt/\*\.js\` and exfiltrate the app's source\.
