# RepoManager is a self\-hosted deb/rpm package repository\.

- **ID**: CVE\-2026\-130160
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-19

## 原文

RepoManager is a self\-hosted deb/rpm package repository\. Prior to 5\.13\.3, an authenticated user can supply a user\-controlled, array\-valued GPG key identifier to the key deletion action\. Validate\:\:string\(\) filters HTML characters but not shell metacharacters\. The user\-controlled identifier reaches the delete action without shell\-safe encoding\. controllers/Gpg\.php contains the vulnerable deletion path\. Process\:\:execute\(\) passes the command string through proc\_open\(\) and /bin/sh \-c, allowing the attacker to execute arbitrary OS commands as the web/PHP process\. This can expose secrets or poison packages\. Authentication is required, but the advisory makes an administrator\-only restriction conditional on the intended access policy and does not establish an administrator role as a prerequisite\. Fixed in 5\.13\.3\.
