# DeepAudit 2\.0\.0\-beta\.5 through 3\.8\.0 contains a server\-side request forgery vulnerability that allows registered users to leak server\-wid\.\.\.

- **ID**: CVE\-2026\-129880
- **危険度**: High（重要） (CVSS 7.7)
- **公開**: 2026-11-16

## 原文

DeepAudit 2\.0\.0\-beta\.5 through 3\.8\.0 contains a server\-side request forgery vulnerability that allows registered users to leak server\-wide GitLab or Gitea tokens via repository\_url\. Attackers can create a gitlab or gitea project pointing to a controlled host and request its branches to capture the operator's token and reach internal hosts\.
