# The Otter Blocks WordPress plugin before 3\.2\.10 does not use URL\-aware escaping when it resolves its dynamic data tags inside HTML attri\.\.\.

- **ID**: CVE\-2026\-123132
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: JavaScript/TypeScript, PHP
- **公開**: 2026-11-18

## 原文

The Otter Blocks  WordPress plugin before 3\.2\.10 does not use URL\-aware escaping when it resolves its dynamic data tags inside HTML attributes, which could allow unauthenticated users to post comments containing links that execute arbitrary JavaScript when clicked, for example by a logged\-in administrator\.
