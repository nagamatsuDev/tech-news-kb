# The Lightbox with PhotoSwipe WordPress plugin before 5\.19\.0 does not escape image link URLs before outputting them in the attributes of t\.\.\.

- **ID**: CVE\-2026\-125695
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-20

## 原文

The Lightbox with PhotoSwipe WordPress plugin before 5\.19\.0 does not escape image link URLs before outputting them in the attributes of the lightbox share menu, allowing unauthenticated users to perform Stored Cross\-Site Scripting attacks via comments when the PhotoSwipe 4 frontend is used\.
