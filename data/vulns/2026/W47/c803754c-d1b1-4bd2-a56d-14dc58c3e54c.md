# Incus before 7\.6\.0 contains a privilege escalation vulnerability\: rebuilding a never\-started unprivileged container makes it boot without\.\.\.

- **ID**: CVE\-2026\-130774
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-18

## 原文

Incus before 7\.6\.0 contains a privilege escalation vulnerability\: rebuilding a never\-started unprivileged container makes it boot without a user namespace\. Root processes inside the container run as host uid 0, keeping capabilities like sys\_module, with no device cgroup restriction, letting them load kernel modules and compromise the host\.
