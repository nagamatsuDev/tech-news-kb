# Guard Core\: Unvalidated X\-Forwarded\-For\-derived string used as a Redis key component and interpolated into a KEYS glob pattern

- **ID**: CVE\-2026\-129304 / GHSA\-gm9r\-hvc9\-96gv
- **危険度**: Medium（警告） (CVSS 5.4)
- **言語**: Python
- **パッケージ**: PyPI/guard\-core &gt;\= 1\.0\.0, &lt; 3\.13\.0 → 3\.13\.0
- **公開**: 2026-11-19

## 原文

\#\#\# Summary \`\_extract\_from\_forwarded\_header\(\)\` \(\`guard\_core/utils\.py\:172\-181\` in 3\.12\.0; \`\:179\` on master \`08780f1\`\) returns the selected \`X\-Forwarded\-For\` entry \*\*without any \`ipaddress\` validation\*\*\. When that entry is attacker\-controlled, an arbitrary string becomes \`client\_ip\` and flows into \`BehaviorTracker\` \(\`guard\_core/handlers/behavior\_handler\.py\:83\-102\`\), which interpolates it verbatim into both a Redis key name and a \`KEYS\` glob pattern\: \`\`\`python key \= f"behavior\:usage\:\{endpoint\_id\}\:\{client\_ip\}" await self\.redis\_handler\.set\_key\("behavior\_usage", f"\{key\}\:\{current\_time\}", "1", ttl\=rul
