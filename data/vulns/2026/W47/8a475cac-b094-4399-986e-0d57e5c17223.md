# NukeViet CMS is a multi Content Management System\.

- **ID**: CVE\-2026\-94567
- **危険度**: Critical（緊急） (CVSS 9.3)
- **公開**: 2026-11-20

## 原文

NukeViet CMS is a multi Content Management System\. Prior to 4\.5\.12 and 4\.6\.02, an attacker with access to an SVG upload flow can hide a script element in an internal DTD entity\. NukeViet\\Files\\Upload\:\:check\_svg\_tmpfile\(\) loads the document without entity expansion, leaving a DOMEntityReference, and sanitize\_svg\_dom\(\) inspects only element nodes, while browsers expand the entity when the stored file is served as image/svg\+xml\. The SVG path also returned before verify\_image\(\) and preserved the original bytes, so the hidden script reached disk unchanged\. Guest comment attachments make the upload unauthenticated only when a module's comment feature is open to the All or Guest group and allowattachcomm is enabled; module administrators can also use the file manager, allowing same\-origin script execution in an administrator's session\. This issue is fixed in versions 4\.5\.12 and 4\.6\.02\.
