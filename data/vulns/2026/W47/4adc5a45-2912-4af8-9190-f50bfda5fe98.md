# Dialoqbase is an application for creating chatbots\.

- **ID**: CVE\-2026\-63189
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-18

## 原文

Dialoqbase is an application for creating chatbots\. Prior to 1\.11\.5, the unauthenticated GET /api/v1/view/\* route in server/src/routes/api/v1/view/root\.ts resolves its attacker\-controlled wildcard path without normalization or containment, allowing traversal outside the intended uploads directory and arbitrary server file reads\. Reading environment files can disclose DB\_SECRET\_KEY, the application’s JWT signing key, which permits forged administrator tokens and takeover of bots, conversations, integrations, and stored third\-party credentials\. This issue is fixed in version 1\.11\.5\.
