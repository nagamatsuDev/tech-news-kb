# Open Object Rexx \(ooRexx\) before 5\.2\.0において、RXAPIはnameArgやuseridの境界チェックを誤処理し、おそらくHgJraryコードの実行につながります。

- **ID**: CVE\-2026\-130320
- **危険度**: Critical（緊急） (CVSS 9.3)
- **公開**: 2026-11-16

## 概要（機械翻訳）

5\.2\.0以前のOpen Object Rexx \(ooRexx\)では、RXAPIはnameArgやuseridの境界チェックを誤処理しており、おそらくはグラフ化されたメッセージによるHgraryコードの実行につながる。

## 原文

In Open Object Rexx \(ooRexx\) before 5\.2\.0, RXAPI mishandles nameArg and userid bounds checking, possibly leading to arbitrary code execution via crafted messages\.
