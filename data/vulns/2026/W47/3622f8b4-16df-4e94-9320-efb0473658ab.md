# djangocms\-moderation\: Moderation comments disclosed to non\-participant staff via the admin changelist

- **ID**: CVE\-2026\-69139 / GHSA\-pj7p\-238h\-76pv
- **危険度**: Medium（警告） (CVSS 4.3)
- **言語**: Python
- **パッケージ**: PyPI/djangocms\-moderation &lt;\= 2\.3\.0 → 2\.4\.0
- **公開**: 2026-11-19

## 原文

\#\# Summary The Django admin views for moderation comments \(\`CollectionCommentAdmin\` and \`RequestCommentAdmin\`\) render the full comment body but scope access only by an attacker\-controlled \`id\` in the URL and Django's model\-level \`view\_\*comment\` permission\. They perform no per\-object participant check\. As a result, any authenticated staff user who holds the comment \*view\* permission can read the comments of \*\*any\*\* collection or moderation request — including ones they are not a participant of — simply by supplying the target object's id\.
