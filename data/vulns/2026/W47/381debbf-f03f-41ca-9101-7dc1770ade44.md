# Bolt\: Prevent SSRF due to unchecked followed redirects

- **ID**: CVE\-2026\-77380 / GHSA\-3xjf\-9q55\-vxw4
- **危険度**: Medium（警告） (CVSS 5.2)
- **言語**: PHP
- **パッケージ**: Packagist/bolt/core &lt; 6\.1\.5 → 6\.1\.5
- **公開**: 2026-11-20

## 原文

\#\#\# Impact The \`/bolt/async/upload\-url\` and \`/bolt/async/embed\` endpoints validated only the \*\*submitted\*\* URL before fetching it server\-side, but the fetch then \*\*followed redirects to destinations that were never re\-validated\*\*\. This allowed an authenticated user to bypass the SSRF guard \(\`UrlSafetyChecker\`\) and make the server issue requests to internal/cloud\-metadata addresses\. \#\#\# Patches This issue has been patched with Bolt 6\.1\.5\.
