# OpenSNS 3\.2\.1 contains an unauthenticated code injection vulnerability in the shareBox method of ShareController that allows attackers to\.\.\.

- **ID**: CVE\-2021\-48025
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

OpenSNS 3\.2\.1 contains an unauthenticated code injection vulnerability in the shareBox method of ShareController that allows attackers to invoke arbitrary model methods via the query parameter\. Attackers can send crafted GET requests to /index\.php?s\=weibo/Share/shareBox abusing parse\_str and ShareModel\:\:getInfo to reach Schedule\:\:runSchedule and execute code through assert\. Exploitation evidence was first observed by the Shadowserver Foundation on 2023\-10\-14\.
