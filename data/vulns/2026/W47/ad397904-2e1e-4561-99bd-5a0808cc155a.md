# HTSlib is a library for reading and writing bioinformatics file formats\.

- **ID**: CVE\-2026\-62255
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-19

## 原文

HTSlib is a library for reading and writing bioinformatics file formats\. Prior to 1\.21\.2, 1\.22\.3, 1\.23\.2, and 1\.24, cram\_index\_load does not verify that the number of reference sequences in a CRAM \.crai index does not exceed the CRAM header reference count\. A malformed index can drive unbounded index\-array allocation, and when the number of references in the index is within two of INT\_MAX, the growth calculation can wrap, read beyond a heap buffer, and use the resulting value as a pointer for an unchecked memory write\. Any region query can trigger the flaw, causing denial of service or memory corruption\. This issue is fixed in versions 1\.21\.2, 1\.22\.3, 1\.23\.2, and 1\.24\.
