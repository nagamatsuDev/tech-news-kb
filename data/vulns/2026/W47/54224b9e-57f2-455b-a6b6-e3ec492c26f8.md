# AdminNeo before 5\.9\.1 contains an sql injection vulnerability that allows remote attackers to inject SQL by supplying crafted IN and NOT \.\.\.

- **ID**: CVE\-2026\-130374
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-17

## 原文

AdminNeo before 5\.9\.1 contains an sql injection vulnerability that allows remote attackers to inject SQL by supplying crafted IN and NOT IN search values that process\_length\(\) passes unescaped\. Attackers can send a logged\-in user a cross\-site GET link using a backslash\-escaped apostrophe to run blind SQL with that user's database rights on PostgreSQL, SQLite, MS SQL, Oracle, or MySQL in NO\_BACKSLASH\_ESCAPES mode\.
