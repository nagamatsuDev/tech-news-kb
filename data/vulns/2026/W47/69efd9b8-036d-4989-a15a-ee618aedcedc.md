# Servo is a lightweight, high\-performance web rendering engine for embedding web technologies in applications\.

- **ID**: CVE\-2026\-61715
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: JavaScript/TypeScript
- **公開**: 2026-11-17

## 原文

Servo is a lightweight, high\-performance web rendering engine for embedding web technologies in applications\. Prior to 0\.4\.0, a frame with sandbox\="" can reach and execute a javascript\: URL through declarative refresh because RefreshRedirectDue\:\:invoke\(\) in components/script/dom/document/document\.rs can reach JavaScript URL handling in components/script/script\_thread\.rs without enforcing the sandbox's script prohibition\. This gives attacker\-controlled content arbitrary JavaScript execution in a frame intended to be scriptless, including nested DOM probe creation and blind browser requests\. The frame retains an opaque origin, so the issue does not by itself provide parent DOM access\. This issue is fixed in version 0\.4\.0\.
