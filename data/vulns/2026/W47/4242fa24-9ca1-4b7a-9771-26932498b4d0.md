# The AI Puffer \- MCP Server for Claude &amp; ChatGPT, with AI Chatbot plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via AI\.\.\.

- **ID**: CVE\-2026\-130121
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The AI Puffer \- MCP Server for Claude &amp; ChatGPT, with AI Chatbot plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via AI\-generated comment replies in all versions up to, and including, 2\.5\.28 due to insufficient sanitization of the AI model's output in the insert\_comment\_reply\_logic\(\) function, which saves replies with wp\_insert\_comment\(\) and bypasses the kses filtering WordPress normally applies to comment content\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page, by submitting a comment that leads the AI model to reproduce an HTML payload in its automated reply\. This is only exploitable when an administrator has configured a Comment Auto\-Reply automation task with 'Action on reply' set to 'Approve' \(the default is 'Hold for moderation'\), and the attacker's comment has been approved\.
