# NukeViet CMS is a multi Content Management System\.

- **ID**: CVE\-2026\-94561
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-20

## 原文

NukeViet CMS is a multi Content Management System\. In 4\.6\.00, an unauthenticated attacker can place the configured domain in X\-Forwarded\-Host while choosing a different destination in the ordinary Host header\. The earlier fix validates only the forwarded value in includes/mainfile\.php, while set\_ini\_file\(\) in includes/ini\.php constructs an outbound cURL request from the separately retained NV\_SERVER\_NAME before the ordinary host is rejected\. Redirect following can carry the blind request to an attacker\-selected private host, port, and path and invoke internal HTTP endpoints\. This issue is fixed in version 4\.6\.01\.
