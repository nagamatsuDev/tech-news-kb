# In the Linux kernel, the following vulnerability has been resolved\: ceph\: clamp the inline data length in ceph\_fill\_inline\_data\(\) The M\.\.\.

- **ID**: CVE\-2026\-99590
- **危険度**: Critical（緊急） (CVSS 9.8)
- **OS**: Linux
- **公開**: 2026-11-20

## 原文

In the Linux kernel, the following vulnerability has been resolved\:
  
ceph\: clamp the inline data length in ceph\_fill\_inline\_data\(\)
  
The MDS decides how much inline data to attach to a reply, and the  
client parses inline\_len without any upper bound\: ceph\_decode\_need\(\)  
only verifies that the message actually carries that many bytes\.  
ceph\_fill\_inline\_data\(\) then copies the data into a single folio  
with no length check, so a malicious or buggy MDS returning more  
inline data than the folio can hold writes past its end\.
  
Clamp the length to folio\_size\(\) so both callers, handle\_cap\_grant\(\)  
and fill\_inode\(\), are covered\.
