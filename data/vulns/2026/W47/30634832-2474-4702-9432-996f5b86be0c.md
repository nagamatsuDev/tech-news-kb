# The Edwiser Bridge WordPress plugin before 4\.3\.5 does not correctly scope one of its REST API authentication checks, disabling WordPress\.\.\.

- **ID**: CVE\-2026\-75795
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The Edwiser Bridge  WordPress plugin before 4\.3\.5 does not correctly scope one of its REST API authentication checks, disabling WordPress's REST nonce validation for every route on the site, which allows attackers to make a logged\-in administrator perform arbitrary privileged actions, such as creating a new administrator account, via CSRF\.
