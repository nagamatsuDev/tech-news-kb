# FineReport 8\.0 contains a path traversal vulnerability that allows unauthenticated attackers to read arbitrary files through the resource\.\.\.

- **ID**: CVE\-2019\-25785
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-18

## 原文

FineReport 8\.0 contains a path traversal vulnerability that allows unauthenticated attackers to read arbitrary files through the resourcepath parameter of the /WebReport/ReportServer endpoint\. Attackers can send GET requests with op\=chart and cmd\=get\_geo\_json to read sensitive files like privilege\.xml and extract admin credentials\. Exploitation evidence was first observed by the Shadowserver Foundation on 2023\-10\-19\.
