# chcon\: recursive relabel not anchored to traversal dirfd \(TOCTOU\)

- **ID**: CVE\-2026\-35376 / GHSA\-9rv8\-9hvg\-92mq
- **危険度**: Medium（警告） (CVSS 4.5)
- **言語**: Rust
- **パッケージ**: crates\.io/uu\_chcon &lt;\= 0\.9\.0 → 0\.10\.0
- **公開**: 2026-11-20

## 原文

\`chcon\` resolved recursive targets from \`fts\_accpath\` with a fresh path lookup, so traversal and the SELinux get/set were not bound to traversal directory state\. A privileged recursive relabel can be redirected to unintended objects under rename/symlink races\. Fix opens targets with \`openat\` against the traversal cwd fd before the SELinux operation\. \*\*Fixed in 0\.10\.0\*\* \(PR \#12566, commit 7cfc74e47ffab452663be6842d788a5164d9688b\)\: recursive relabel resolution is anchored to the traversal dirfd\. \-\-\- \_Zellic private finding \(zellic\-ext/coreutils\-private PR \#120\)\. Reported in the Zellic \*uutils co
