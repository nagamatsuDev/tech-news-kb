# INTINITUM FORM Translitator サービスタにおける SQL コマンド \('SQL Injection'\) 脆弱性で使用される特殊要素の不適切な中性化

- **ID**: CVE\-2026\-39732
- **危険度**: Critical（緊急） (CVSS 9.3)
- **公開**: 2026-10-30

## 概要（機械翻訳）

SQLコマンド\('SQL Injection'\)で使われる特別な要素を、Intinitum FORMのセルビアン変換で不適切な中性化することで、Blind SQL Injectionが可能となる。

## 原文

Improper Neutralization of Special Elements used in an SQL Command \('SQL Injection'\) vulnerability in INTINITUM FORM Transliterator serbian\-transliteration allows Blind SQL Injection\.This issue affects Transliterator\: from n/a through 2\.5\.13\.
