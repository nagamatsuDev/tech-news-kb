# Stoatchat before 0\.16\.5 contains an unbounded JXL image decoding vulnerability in revolt\_files decode\_image that allows unauthenticated a\.\.\.

- **ID**: CVE\-2026\-133234
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-19

## 原文

Stoatchat before 0\.16\.5 contains an unbounded JXL image decoding vulnerability in revolt\_files decode\_image that allows unauthenticated attackers to exhaust memory via the january /proxy endpoint\. Attackers can request a small hosted JXL file declaring 12000x12000 pixels through /proxy to trigger huge allocations, OOM\-killing january and denying proxy and embed service\.
