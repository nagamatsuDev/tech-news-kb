# django\-docutils unsafe Docutils defaults allow local file disclosure, SSRF, and stored XSS

- **ID**: CVE\-2026\-59988 / GHSA\-86mf\-q4h5\-69gp
- **危険度**: High（重要） (CVSS 8.2)
- **言語**: Python
- **パッケージ**: PyPI/django\-docutils &lt; 0\.30\.0 → 0\.30\.0
- **公開**: 2026-11-19

## 原文

\#\# Summary django\-docutils before \`0\.30\.0\` rendered reStructuredText through Docutils without protected web\-safe defaults\. Public rendering paths, including \`publish\_doctree\`, \`publish\_html\_from\_source\`, \`publish\_html\_from\_doctree\`, \`publish\_parts\_from\_doctree\`, the \`\{% rst %\}\` template tag, the \`rst\` template filter, \`DocutilsTemplates\`, and \`DocutilsView\`, could process attacker\-controlled RST with Docutils directives that read local files, fetch URL\-backed content, or emit raw HTML\. The issue is fixed in \`0\.30\.0\` by disabling Docutils file insertion, raw directives, local \`docutils\.conf\` pr
