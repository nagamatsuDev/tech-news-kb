# Baidu UEditor 1\.4\.0 before 1\.4\.3\.1 contains a server\-side request forgery vulnerability that allows unauthenticated attackers to make arb\.\.\.

- **ID**: CVE\-2018\-25442
- **危険度**: High（重要） (CVSS 8.3)
- **公開**: 2026-11-18

## 原文

Baidu UEditor 1\.4\.0 before 1\.4\.3\.1 contains a server\-side request forgery vulnerability that allows unauthenticated attackers to make arbitrary requests via the source\[\] parameter in /ueditor/jsp/controller\.jsp?action\=catchimage\. Attackers can supply crafted URLs that the ImageHunter component fetches through url\.openConnection\(\) to reach internal services and bypass network restrictions\. Exploitation evidence was first observed by the Shadowserver Foundation on 2024\-07\-03\.
