# Mixed\-case HTTPS and FTPS URLs can expose data in plaintext\.

- **ID**: CVE\-2026\-128064
- **危険度**: High（重要） (CVSS 8.2)
- **言語**: PHP
- **公開**: 2026-11-19

## 原文

Mixed\-case HTTPS and FTPS URLs can expose data in plaintext\.
  
The HTTP and FTP stream wrappers recognise URL schemes case\-insensitively, but enable TLS only when the scheme contains a lowercase "s" at a fixed position\. A URL such as HTTPS\:// or FTPS\:// passed to file\_get\_contents\(\), fopen\(\) or other stream functions, or received as an HTTP redirect target, is therefore handled over unencrypted HTTP or FTP\. An attacker able to observe the network traffic can read data the application expected TLS to protect, including credentials, request bodies and transferred files\.
  
This issue affects PHP versions before 8\.2\.36, 8\.3\.\* before 8\.3\.37, 8\.4\.\* before 8\.4\.28 and 8\.5\.\* before 8\.5\.13\.
