# Kubeshark is an eBPF\-powered network observability tool for Kubernetes\.

- **ID**: CVE\-2026\-129236 / GHSA\-8vf2\-hxg5\-crqh
- **危険度**: High（重要） (CVSS 7.2)
- **公開**: 2026-11-16

## 原文

Kubeshark is an eBPF\-powered network observability tool for Kubernetes\. From 53\.1\.0 until 53\.4\.0, the start\_kubeshark MCP tool in cmd/mcpRunner\.go uses callStartKubeshark to append caller\-controlled pod\_regex as a bare positional argument to kubeshark tap without a \-\- end\-of\-options separator, allowing a value beginning with \-\-set to be parsed as a Helm value override\. An attacker who influences tool arguments against kubeshark mcp \-\-allow\-destructive can redirect the privileged worker, Hub, and front images through tap\.docker\.registry and tap\.docker\.tag to an attacker\-controlled registry\. Because the deployed worker DaemonSet runs privileged with host networking and host filesystem access, a malicious image can obtain node and cluster\-admin access when the host already has permission to deploy it\. This issue is fixed in version 53\.4\.0\.
