# cf\-manager is an all\-in\-one dashboard for managing multiple Cloudflare accounts and services\.

- **ID**: CVE\-2026\-71499
- **危険度**: Critical（緊急） (CVSS 10.0)
- **言語**: JavaScript/TypeScript
- **公開**: 2026-11-18

## 原文

cf\-manager is an all\-in\-one dashboard for managing multiple Cloudflare accounts and services\. Prior to 1\.1\.2, worker/src/routes/workers\.ts uses bare fetch\(url\) calls to retrieve user\-supplied URLs and deploys the returned content as a Worker script using stored Cloudflare credentials\. The multipart and JSON branches of POST /api/\:accountId/workers and POST /api/batch\-deploy accept URLs without protocol, destination, redirect, content\-type, or response\-size validation\. An attacker with deployment API access, or unauthenticated access when API\_SECRET is not configured, can make cf\-manager access internal resources or fetch attacker\-controlled JavaScript and execute it in the victim Cloudflare Workers account\. This issue is fixed in version 1\.1\.2\.
