# Miren Runtime\: Authentication bypass in RPC layer\: unverified TLS client certificates grant cluster superuser access

- **ID**: CVE\-2026\-75521 / GHSA\-8fh7\-7q4q\-cq52
- **危険度**: Critical（緊急）
- **言語**: Go
- **パッケージ**: Go/miren\.dev/runtime &lt; 0\.11\.1 → 0\.11\.1
- **公開**: 2026-11-18

## 原文

\#\#\# Summary The Miren Runtime RPC server \(QUIC/HTTP3, default port \`\:8443\`\) requested TLS client certificates but never verified that a presented certificate chained to the cluster Certificate Authority\. Because a client\-certificate identity is granted a blanket RBAC bypass, any party able to reach the RPC listener could present a forged, self\-signed certificate and be authenticated as a cluster \*\*superuser\*\* — no valid CA signature, credential, or prior authorization required\. \#\#\# Impact This is a complete, unauthenticated authentication bypass against the cluster control plane\.
