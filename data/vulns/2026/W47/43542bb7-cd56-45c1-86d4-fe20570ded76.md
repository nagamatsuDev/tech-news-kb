# SurrealDB from 2\.2\.0 before 4\.0\.0 contains an authorization bypass vulnerability in Document\:\:purge\_references that lets authenticated us\.\.\.

- **ID**: CVE\-2026\-134300
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-21

## 原文

SurrealDB from 2\.2\.0 before 4\.0\.0 contains an authorization bypass vulnerability in Document\:\:purge\_references that lets authenticated users bypass target table PERMISSIONS by triggering REFERENCE ON DELETE cascades\. Attackers can delete a referenced record to delete, unset, or run CUSTOM expressions on referencing records despite PERMISSIONS FOR delete or update NONE\.
