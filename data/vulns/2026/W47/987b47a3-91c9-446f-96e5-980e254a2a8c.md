# All versions of LaraDashboard contain an authentication bypass in SocialAuthService\:\:findOrCreateUser\(\), which links a social login to an\.\.\.

- **ID**: CVE\-2026\-130754
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-18

## 原文

All versions of LaraDashboard contain an authentication bypass in SocialAuthService\:\:findOrCreateUser\(\), which links a social login to an existing account by email without checking that the OAuth provider verified that email\. Unauthenticated attackers using an OAuth/OIDC provider that asserts a victim's email can log in as any user, including Superadmin, and keep persistent access through a linked social\_accounts entry\.
