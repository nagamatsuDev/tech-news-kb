# PHAR OpenSSL signature bypass via algorithm downgrade\.

- **ID**: CVE\-2026\-128090
- **危険度**: High（重要） (CVSS 7.7)
- **言語**: PHP
- **公開**: 2026-11-19

## 原文

PHAR OpenSSL signature bypass via algorithm downgrade\.
  
The Phar extension selects the signature verification method from the signature type stored in the archive, and only the OpenSSL types consult the separate \.pubkey file holding the trusted public key\. An attacker who can modify an OpenSSL\-signed Phar archive, but not its public key file, can switch the signature type to a keyless hash such as SHA\-256 with a recomputed digest, so the altered archive passes verification even with phar\.require\_hash enabled\. An application that loads the archive may then execute attacker\-controlled PHP code\. Native, tar\-based and zip\-based phars are affected\.
  
This issue affects PHP versions before 8\.2\.36, 8\.3\.\* before 8\.3\.37, 8\.4\.\* before 8\.4\.28 and 8\.5\.\* before 8\.5\.13\.
