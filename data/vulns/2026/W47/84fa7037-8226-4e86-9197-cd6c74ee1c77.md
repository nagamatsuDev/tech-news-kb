# yt through 4\.4\.4 contains a code injection vulnerability that allows attackers to execute Python code by supplying a crafted con\_args att\.\.\.

- **ID**: CVE\-2026\-132751
- **危険度**: High（重要） (CVSS 7.8)
- **言語**: Python
- **公開**: 2026-11-19

## 原文

yt through 4\.4\.4 contains a code injection vulnerability that allows attackers to execute Python code by supplying a crafted con\_args attribute in a ytdata HDF5 file\. SavedDataset\.\_parse\_parameter\_file\(\) passes con\_args to eval\(\) unrestricted, so loading a malicious \.h5 file with yt\.load\(\) runs attacker code as the user\.
