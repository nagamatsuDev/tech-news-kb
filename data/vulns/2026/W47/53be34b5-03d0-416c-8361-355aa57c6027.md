# Incorrect default permissions on the folder\-level JavaScript directory in Nitro PDF Pro before 26\.4 on Windows allow a local low\-privileg\.\.\.

- **ID**: CVE\-2026\-126675
- **危険度**: High（重要） (CVSS 7.3)
- **OS**: Windows
- **言語**: JavaScript/TypeScript
- **公開**: 2026-11-18

## 原文

Incorrect default permissions on the folder\-level JavaScript directory in Nitro PDF Pro before 26\.4 on Windows allow a local low\-privileged user to execute JavaScript in the context of another user, including an administrator, via a script planted in %ProgramData%\\Nitro\\PDF Pro\\CV\\JavaScripts that is automatically run when the victim launches the application\.
