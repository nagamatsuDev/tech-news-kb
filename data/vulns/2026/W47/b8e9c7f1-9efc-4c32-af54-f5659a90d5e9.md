# QiboCMS V7 contains an arbitrary file download vulnerability in inc/job/download\.php that allows unauthenticated attackers to read files \.\.\.

- **ID**: CVE\-2022\-51030
- **危険度**: High（重要） (CVSS 7.5)
- **OS**: Windows
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

QiboCMS V7 contains an arbitrary file download vulnerability in inc/job/download\.php that allows unauthenticated attackers to read files by supplying a base64\-encoded url parameter to /do/job\.php?job\=download\. Attackers can bypass the \.php extension check using the Windows 'ph&lt;' wildcard to download sensitive files such as configuration files containing database credentials\. Exploitation evidence was first observed by the Shadowserver Foundation on 2023\-10\-18\.
