# NLTK\: Quadratic\-time DoS in SeekableUnicodeStreamReader\.readline on an unterminated corpus line via per\-iteration full\-buffer rescan

- **ID**: CVE\-2026\-129231 / GHSA\-q4c8\-9gwf\-255x
- **危険度**: Medium（警告） (CVSS 5.3)
- **言語**: Python
- **パッケージ**: PyPI/nltk &lt;\= 3\.10\.3 → 3\.10\.4
- **公開**: 2026-11-19

## 原文

\#\# Summary \`SeekableUnicodeStreamReader\.readline\` in \`nltk/data\.py\` assembles a line by repeatedly reading a block, appending it to a growing \`chars\` buffer, and recomputing \`chars\.splitlines\(True\)\` over the entire buffer on every loop iteration\. The read block size doubles only until it caps at 8000 characters, so for a single unterminated line of N characters the loop runs about N/8000 iterations and iteration k re\-scans roughly 8000\*k characters, giving O\(N\^2\) total work\. The default \`size\=None\` used on the line\-oriented corpus\-reader read path means the early break never fires before end o
