# Zohocorp Manageengine DDI Central build below 6500 are affected by a authenticated command injection vulnerability in the Windows DDI Age\.\.\.

- **ID**: CVE\-2026\-95645
- **危険度**: Critical（緊急） (CVSS 9.1)
- **OS**: Windows
- **公開**: 2026-11-18

## 原文

Zohocorp Manageengine DDI Central build below 6500 are affected by a authenticated command injection vulnerability in the Windows DDI Agent's clear\_blocked\_domains functionality, allowing specially crafted blocked\-domain values to trigger arbitrary command execution on Windows systems\.
