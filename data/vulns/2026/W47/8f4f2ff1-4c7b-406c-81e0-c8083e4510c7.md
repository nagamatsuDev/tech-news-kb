# The httpx Ruby gem parses JSON response bodies through its transcoder layer\.

- **ID**: CVE\-2026\-129784
- **危険度**: High（重要） (CVSS 8.5)
- **言語**: Ruby
- **公開**: 2026-11-16

## 原文

The httpx Ruby gem parses JSON response bodies through its transcoder layer\. HTTPX\:\:Response\#json delegates to Transcoder\:\:JSON\.decode, and when the oj gem is loaded and multi\_json is absent, the decoder falls back to json\_load, which calls Oj\.load\(response\.to\_s\) with no mode option\. Oj\.load defaults to \:object mode, in which a response document can allocate any already\-loaded Ruby class \("\^o"\:"ClassName"\) and set its instance variables, or resolve a class or module reference \("\^c"\:"Name"\)\. An attacker who controls, or can influence, the URL an application fetches with HTTPX\.get\(url\)\.json therefore controls object instantiation in the victim process\. With a matching gadget chain, this issue can potentially cause remote code execution\. Affects httpx 1\.9\.0; fixed in 1\.9\.1\.
