# The Forminator Forms – Contact Form, Payment Form &amp; Custom Form Builder plugin for WordPress is vulnerable to Stored Cross\-Site Scripting\.\.\.

- **ID**: CVE\-2026\-120676
- **危険度**: High（重要） (CVSS 7.2)
- **OS**: Linux
- **言語**: PHP
- **公開**: 2026-11-21

## 原文

The Forminator Forms – Contact Form, Payment Form &amp; Custom Form Builder plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'upload\-1 \(the File Upload field's element\_id\)' parameter in all versions up to, and including, 1\.58\.4 due to insufficient input sanitization and output escaping\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\. This vulnerability is an incomplete fix for CVE\-2024\-1794; exploitation requires that the Forminator form's File Upload field is left at plugin defaults \(no 'custom\-files' restriction configured\) and that the server maps no Content\-Type to the \.rtx extension — the default behavior of the Debian/Ubuntu Apache package used by the official WordPress Docker image and many shared hosts\.
