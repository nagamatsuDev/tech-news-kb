# Chamilo LMS is an open\-source learning management system\.

- **ID**: CVE\-2026\-45142
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

Chamilo LMS is an open\-source learning management system\. Prior to 1\.11\.40 and 2\.0\.1, main/lp/lp\_ajax\_save\_objectives\.php and public/main/lp/lp\_ajax\_save\_objectives\.php trust the request uid parameter instead of the authenticated user identity when saving SCORM learning objectives\. Any authenticated student can replace uid with another user's identifier and overwrite that user's objectives because the endpoint performs no ownership check\. This issue is fixed in versions 1\.11\.40 and 2\.0\.1\.
