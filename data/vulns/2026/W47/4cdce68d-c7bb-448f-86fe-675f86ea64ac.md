# In the Linux kernel, the following vulnerability has been resolved\: batman\-adv\: stop originator purge worker before freeing TT batadv\_m\.\.\.

- **ID**: CVE\-2026\-99761
- **危険度**: High（重要） (CVSS 7.8)
- **OS**: Linux
- **公開**: 2026-11-20

## 原文

In the Linux kernel, the following vulnerability has been resolved\:
  
batman\-adv\: stop originator purge worker before freeing TT
  
batadv\_mesh\_free\(\) releases the translation tables via batadv\_tt\_free\(\)  
before batadv\_originator\_free\(\) stops orig\_work\. The purge worker can  
therefore still run while the TT is torn down\. When an originator times  
out, batadv\_purge\_orig\_ref\(\) calls batadv\_tt\_global\_del\_orig\(\), which  
loads tt\.global\_hash and walks all buckets while taking their locks\:
  
  CPU0                          CPU1  
  batadv\_tt\_free\(\)              batadv\_purge\_orig\(\)  
                                  batadv\_tt\_global\_del\_orig\(\)  
                                    hash \= \.\.\.tt\.global\_hash;  
    batadv\_tt\_global\_table\_free\(\)  
      batadv\_hash\_destroy\(hash\);  
                                    spin\_lock\_bh\(&amp;hash\-&gt;list\_locks\[i\]\);
  
Disable orig\_work at the beginning of batadv\_mesh\_free\(\), directly after  
the mesh was marked as deactivating\. The second  
disable\_delayed\_work\_sync\(\) in batadv\_originator\_free\(\) is harmless because  
it is free'd anyway\.
