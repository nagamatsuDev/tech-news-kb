# The WP Duplicate – WordPress Migration Plugin plugin for WordPress is vulnerable to Missing Authorization in versions up to, and includin\.\.\.

- **ID**: CVE\-2026\-85776
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-19

## 原文

The WP Duplicate – WordPress Migration Plugin plugin for WordPress is vulnerable to Missing Authorization in versions up to, and including, 1\.1\.11\. This is due to a missing capability check and missing nonce check on the start\_zip\_creation, start\_zip\_download, local\_sync\_get\_init\_root\_files, and local\_sync\_get\_files\_by\_key AJAX actions in the start\_zip\_creation\_dev\(\) and sibling functions\. This makes it possible for authenticated attackers, with subscriber\-level access and above, to overwrite the plugin's prod\_site\_url setting so it points at an attacker\-controlled host and enumerate arbitrary server directories, which when combined with a subsequent administrator\-triggered sync results in an unsigned attacker\-supplied ZIP archive being fetched, extracted via a WordPress\-independent bridge deployed under the web root, resulting in remote code execution on the affected site\.
