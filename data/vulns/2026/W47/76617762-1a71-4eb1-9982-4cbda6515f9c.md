# NukeViet CMS is a multi Content Management System\.

- **ID**: CVE\-2026\-94597
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-20

## 原文

NukeViet CMS is a multi Content Management System\. Prior to 4\.5\.12 and 4\.6\.02, an attacker who can reach an image\-upload flow can upload a valid image with appended PHP short\-tag code and a double\-extension filename\. NukeViet\\Files\\Upload\:\:save\_file\(\) relied on verify\_image\(\), which missed the &lt;? short\-open tag, while filename handling preserved embedded dots, validation inspected only the final extension, and an \.htaccess rule blocked PHP extensions only at the end of the URI\. On Apache mod\_php systems configured with short\_open\_tag and a PHP extension handler, the stored polyglot can execute as PHP and run operating\-system commands as the web\-server user; PHP\-FPM, nginx, and end\-anchored handler configurations are not exposed to the execution step\. This issue is fixed in versions 4\.5\.12 and 4\.6\.02\.
