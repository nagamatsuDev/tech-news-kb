# FreeSWITCH is a Software Defined Telecom Stack enabling the digital transformation from proprietary telecom switches to a software implem\.\.\.

- **ID**: CVE\-2026\-119292
- **危険度**: High（重要） (CVSS 8.7)
- **公開**: 2026-11-17

## 原文

FreeSWITCH is a Software Defined Telecom Stack enabling the digital transformation from proprietary telecom switches to a software implementation that runs on any commodity hardware\. Prior to 1\.11\.2, after FreeSWITCH has learned and closed source learning for an RTP peer, read\_rtp\_packet\(\) and rtp\_common\_read\(\) in src/switch\_rtp\.c reject RTP from an unrecognized source only after packet classification and, for encrypted calls, SRTP processing\. An unauthenticated attacker with UDP reachability to an active RTP or SRTP media port can sustain a foreign\-source packet flood that occupies the media read path and prevents legitimate media from entering FreeSWITCH on calls that consume incoming media for relay or echo\. The resulting one\-way audio allows the affected endpoint to continue hearing the other party, but the other party loses that endpoint's audio, leaving SIP signaling established while the call is unusable for conversation\. Transmit\-only playback was unaffected in testing\. A caller can learn the media port from the SDP answer, while a third party must first discover an active port, and no valid SRTP key is required\. This issue is fixed in version 1\.11\.2\.
