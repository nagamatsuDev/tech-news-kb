# Flagr before 1\.2\.5 contains an authentication bypass vulnerability that allows unauthenticated remote attackers to access the flag manage\.\.\.

- **ID**: CVE\-2026\-130860
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-11-17

## 原文

Flagr before 1\.2\.5 contains an authentication bypass vulnerability that allows unauthenticated remote attackers to access the flag management write API through an insecure default FLAGR\_BASIC\_AUTH\_WHITELIST\_PATHS including /api/v1/flags\. Because basicAuth\.whitelist\(\) in pkg/config/middleware\.go matches only path prefixes regardless of HTTP method, attackers can create, modify, enable, disable, and delete flags, variants, segments, constraints, and distributions\.
