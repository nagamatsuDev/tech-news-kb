# The Custom Twitter Feeds – A Tweets Widget or X Feed Widget plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'at\.\.\.

- **ID**: CVE\-2026\-116536
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The Custom Twitter Feeds – A Tweets Widget or X Feed Widget plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'atts \(JSON object, specifically the inner \`feed\` key\)' parameter in all versions up to, and including, 2\.11\.1 due to insufficient input sanitization and output escaping\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\. The injected payload is first stored in the wp\_ctf\_feed\_caches database table and later written into the ctf\_cron\_report WordPress option by the scheduled ctf\_feed\_update cron job, meaning execution is deferred until the cron runs and an administrator subsequently loads the Support page\.
