# svglib\: Exponential resource consumption via nested &lt;use&gt; references in svg2rlg

- **ID**: CVE\-2026\-132275 / GHSA\-555j\-qj3j\-c8jv
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: Python
- **パッケージ**: PyPI/svglib &lt;\= 2\.3\.0 → 2\.3\.1
- **公開**: 2026-11-20

## 原文

\# Summary \`svg2rlg\(\)\` expands \`&lt;use&gt;\` references without any limit on the total number of expansions\. Only direct cycles are rejected \(\`CircularRefError\`\)\. A group containing N \`&lt;use&gt;\` elements that point to another such group multiplies the work by N per nesting level, so an SVG of about 1\.4 KB makes svglib clone and render over 100,000 nodes, taking tens of seconds of CPU time and hundreds of MiB of memory\. Each additional level adds about 245 bytes to the document and multiplies time by \~10\. This is the SVG \`&lt;use&gt;\` variant of the XML "billion laughs" attack \(the same class as librsvg CVE\-20
