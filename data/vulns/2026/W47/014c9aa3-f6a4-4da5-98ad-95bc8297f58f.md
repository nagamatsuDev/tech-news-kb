# Filament Curator\: Cross\-tenant media metadata disclosure via Curator picker search

- **ID**: CVE\-2026\-63389 / GHSA\-828w\-6qgx\-3rcf
- **危険度**: Medium（警告） (CVSS 5.0)
- **言語**: PHP
- **パッケージ**: Packagist/awcodes/filament\-curator &gt;\= 5\.0\.0, &lt; 5\.1\.1 → 5\.1\.1, Packagist/awcodes/filament\-curator &gt;\= 4\.0\.0, &lt; 4\.1\.1 → 4\.1\.1, Packagist/awcodes/filament\-curator &gt;\= 3\.2\.4, &lt; 3\.7\.8 → 3\.7\.8
- **公開**: 2026-11-17

## 原文

Summary In multitenant Filament panels, an authenticated user could retrieve media metadata belonging to other tenants by typing in the Curator media\-picker search box\. The search query omitted the tenant ownership scope that the normal file listing applies\. Details CuratorPanel\:\:updatedSearch\(\) built its Eloquent query independently of getFiles\(\) and did not apply the filament\(\)\-&gt;hasTenancy\(\) &amp;&amp; \$isTenantAware tenant\-ownership where clause\.
