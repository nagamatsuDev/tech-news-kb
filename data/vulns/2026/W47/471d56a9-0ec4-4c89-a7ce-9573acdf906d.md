# llama\.cpp b11003 before b12556 contains an integer overflow in the hrm\_text loader load\_arch\_hparams\(\) that allows attackers to bypass th\.\.\.

- **ID**: CVE\-2026\-133710
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-20

## 原文

llama\.cpp b11003 before b12556 contains an integer overflow in the hrm\_text loader load\_arch\_hparams\(\) that allows attackers to bypass the block count check using crafted GGUF metadata\. Attackers can supply a GGUF model whose layer factors wrap modulo 2\^32, causing load\_arch\_tensors\(\) to write tensor pointers past model\.layers, corrupting heap memory and potentially enabling code execution\.
