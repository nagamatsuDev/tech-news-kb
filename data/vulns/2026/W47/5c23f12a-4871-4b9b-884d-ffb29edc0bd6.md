# Craft CMS from 5\.0\.0 before 5\.11\.4 contains a remote code execution vulnerability in ImageTransforms\:\:normalizeTransform\(\) that allows at\.\.\.

- **ID**: CVE\-2026\-130675
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

Craft CMS from 5\.0\.0 before 5\.11\.4 contains a remote code execution vulnerability in ImageTransforms\:\:normalizeTransform\(\) that allows attackers to instantiate arbitrary classes by supplying class\:null with a \_\_class key\. Attackers can reach the method through Craft Commerce's payments/pay redirect template calling customer\.photo\.getUrl\(\) with a crafted transform to instantiate classes like yii\\rbac\\PhpManager and execute PHP\.
