# obsidian\-sync\-mcp is an MCP server that gives AI agents access to Obsidian vaults\.

- **ID**: CVE\-2026\-77283
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-18

## 原文

obsidian\-sync\-mcp is an MCP server that gives AI agents access to Obsidian vaults\. Prior to 0\.5\.7, deployments running without MCP\_AUTH\_TOKEN install no serverOptions\.authenticate check for the HTTP /mcp endpoint, so requests are dispatched without validating the Host or Origin headers\. A malicious website visited by the operator can use DNS rebinding to reach loopback, LAN, VPN, or container\-published addresses, or directly issue a cross\-origin request to loopback, and invoke the MCP tool surface to read, create, overwrite, delete, or move vault notes\. Deployments using MCP\_AUTH\_TOKEN are not affected because browsers do not attach the bearer token\. This issue is fixed in version 0\.5\.7\.
