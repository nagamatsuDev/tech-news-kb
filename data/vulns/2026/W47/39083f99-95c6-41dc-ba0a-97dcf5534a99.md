# Natural Language Toolkit \(NLTK\)\: Uncontrolled recursion \(crash DoS\) in Synset\.tree\(\)/acyclic\_tree\(\) via WordNet relation traversal

- **ID**: CVE\-2026\-129223 / GHSA\-8846\-p9w9\-5frf
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: Python
- **パッケージ**: PyPI/nltk &lt;\= 3\.10\.3 → 3\.10\.4
- **公開**: 2026-11-19

## 原文

\#\#\# Summary The recursive traversal engines behind WordNetCorpusReader's Synset\.tree\(\) and Synset\.acyclic\_tree\(\) have no maximum call\-depth safeguard and default to unlimited depth\. They guard against literal cycles, but not against a long, genuinely acyclic relation chain — which exhausts the Python call stack the same way as the sibling DependencyGraph finding I reported separately\.
