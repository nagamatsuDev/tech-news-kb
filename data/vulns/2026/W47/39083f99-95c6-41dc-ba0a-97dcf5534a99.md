# NLTK \(Natural Language Toolkit\) is a suite of open source Python modules, data sets, and tutorials supporting research and development in\.\.\.

- **ID**: CVE\-2026\-129223 / GHSA\-8846\-p9w9\-5frf
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: Python
- **公開**: 2026-11-19

## 原文

NLTK \(Natural Language Toolkit\) is a suite of open source Python modules, data sets, and tutorials supporting research and development in Natural Language Processing\. Prior to 3\.10\.4, WordNet Synset\.tree and acyclic\_tree traverse relation graphs through recursive utility helpers without a depth bound\. Exploitation requires the host application to load an attacker\-influenced custom or foreign WordNet\-format lexical resource; no relation in NLTK's bundled WordNet 3\.0 corpus reaches the crash threshold\. An excessively deep relation graph in such a resource can exceed the Python recursion limit and terminate the traversal or request worker\. This issue is fixed in version 3\.10\.4\.
