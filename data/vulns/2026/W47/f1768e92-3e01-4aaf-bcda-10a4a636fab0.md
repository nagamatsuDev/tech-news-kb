# A security flaw has been discovered in SourceCodester Simple Form Builder Web App 1\.0\.

- **ID**: CVE\-2026\-132610
- **危険度**: High（重要） (CVSS 7.3)
- **言語**: PHP
- **公開**: 2026-11-19

## 原文

A security flaw has been discovered in SourceCodester Simple Form Builder Web App 1\.0\. The impacted element is the function save\_form of the file /classes/Forms\.php\. Performing a manipulation of the argument form\_code/form\_data results in code injection\. The attack may be initiated remotely\. The exploit has been released to the public and may be used for attacks\.
