# Nuxt 3\.0\.0\-rc\.1 before 3\.0\.0\-rc\.13 contains an arbitrary file read vulnerability caused by the Vite dev server default setting vite\.serve\.\.\.

- **ID**: CVE\-2023\-54418
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-18

## 原文

Nuxt 3\.0\.0\-rc\.1 before 3\.0\.0\-rc\.13 contains an arbitrary file read vulnerability caused by the Vite dev server default setting vite\.server\.fs\.strict\=false\. Unauthenticated attackers can request /\_nuxt/@fs/&lt;absolute path&gt; with a raw query to read arbitrary files like /etc/passwd from the system\. Exploitation evidence was first observed by the Shadowserver Foundation on 2023\-10\-18\.
