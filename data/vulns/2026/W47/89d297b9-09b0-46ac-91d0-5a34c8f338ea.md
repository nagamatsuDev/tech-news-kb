# The FoE DATA frame handler computes the payload length from the master\-supplied mailbox length field and passes it directly to FOE\_fwrite\.

- **ID**: CVE\-2026\-129801
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-21

## 原文

The FoE DATA frame handler computes the payload length from the master\-supplied mailbox length field and passes it directly to FOE\_fwrite\. The length is checked against the remaining file capacity but not against the physical mailbox buffer size\. A master can declare a large length while sending a short frame, causing FOE\_fwrite to read past the end of the mailbox buffer\.
