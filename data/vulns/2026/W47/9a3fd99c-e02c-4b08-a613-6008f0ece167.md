# bep/imagemeta\: Unbounded memory allocation decoding PNG \`zTXt\` "Raw profile type iptc" chunks

- **ID**: CVE\-2026\-103025 / GHSA\-7hvw\-3c2q\-45qg
- **危険度**: High（重要） (CVSS 8.7)
- **言語**: Go
- **パッケージ**: Go/github\.com/bep/imagemeta &lt; 0\.17\.3 → 0\.17\.3
- **公開**: 2026-11-19

## 原文

A crafted PNG can make \`imagemeta\.Decode\` allocate memory far in excess of the input file's size, leading to memory exhaustion\. Two separate paths in the \`zTXt\` "Raw profile type iptc" branch are affected\: the declared chunk length drives an allocation directly, and the embedded zlib stream is decompressed without an output bound\. A 42\-byte file allocated 256 MB, and a 127 KB file allocated 460 MB\. \#\#\# Impact Denial of service by memory exhaustion against any application that decodes untrusted PNG images with this library\.
