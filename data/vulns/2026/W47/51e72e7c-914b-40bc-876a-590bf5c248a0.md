# The Dokan\: AI Powered WooCommerce Multivendor Marketplace Solution – Build Your Own Amazon, eBay, Etsy plugin for WordPress is vulnerable\.\.\.

- **ID**: CVE\-2026\-119220
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The Dokan\: AI Powered WooCommerce Multivendor Marketplace Solution – Build Your Own Amazon, eBay, Etsy plugin for WordPress is vulnerable to Authorization Bypass in all versions up to, and including, 5\.3\.3\. The vulnerability exists because the \`matches\_mcp\_endpoint\(\)\` function applies an unanchored regular expression \(\`\#/\(?\:woocommerce\|dokan\)/mcp\(?\:/\|\$\)\#\`\) against the entire \`REQUEST\_URI\` including the query string, meaning any request that contains the literal substring \`/dokan/mcp/\` or \`/woocommerce/mcp/\` anywhere in its URI — including inside a query parameter value — is incorrectly treated as a trusted internal MCP context, causing \`scope\_product\_permissions\(\)\` to unconditionally return \`true\` on WooCommerce's \`woocommerce\_rest\_check\_permissions\` filter regardless of whether the caller is authenticated\. This makes it possible for unauthenticated attackers to read full authenticated WooCommerce REST product records for any published product — including private underscore\-prefixed meta, purchase notes, downloadable file URLs for paid digital products, catalog\-hidden products, and edit\-context representations — across the \`/wc/v1\`, \`/wc/v2\`, \`/wc/v3\`, and \`/wc\-analytics\` REST namespaces\. The bypass is triggered by appending a query parameter whose value contains the literal string \`/dokan/mcp/\` to any WooCommerce REST product endpoint \(e\.g\., \`/wp\-json/wc/v3/products/\{id\}?x\=/dokan/mcp/\`\); note that percent\-encoding the slashes prevents the bypass, as the unencoded literal slash characters are required for the regex to match\.
