# Session serializer mismatch can lead to remote code execution\.

- **ID**: CVE\-2026\-115560
- **危険度**: Critical（緊急） (CVSS 9.2)
- **言語**: PHP
- **公開**: 2026-11-19

## 原文

Session serializer mismatch can lead to remote code execution\.
  
Session upload progress, when enabled, can store attacker\-controlled data in a session key using the php\_binary or php\_serialize session serializer\. If the same session is later read with the php serializer, because session\.serialize\_handler is changed at runtime or differs between applications sharing a session store, bytes inside the key can be passed to the unserializer\. A remote attacker able to submit a multipart upload can inject objects, which may lead to code execution when the reading application contains a suitable gadget chain, or to session corruption or denial of service\.
  
This issue affects PHP versions before 8\.2\.36, 8\.3\.\* before 8\.3\.37, 8\.4\.\* before 8\.4\.28 and 8\.5\.\* before 8\.5\.13\.
