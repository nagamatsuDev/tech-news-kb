# Incorrect authorization in the credential loading logic in AWS Private CA Connector for Kubernetes \(aws\-privateca\-issuer\) before 1\.12\.0 m\.\.\.

- **ID**: CVE\-2026\-130622
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-17

## 原文

Incorrect authorization in the credential loading logic in AWS Private CA Connector for Kubernetes \(aws\-privateca\-issuer\) before 1\.12\.0 might allow an authenticated remote user with permission to create namespace\-scoped issuers to obtain certificates, including subordinate CA certificates, signed by another namespace's AWS Private CA with that namespace's stored AWS credentials, via a namespace\-scoped issuer that references a credentials Secret in that namespace\.
  
To remediate this issue, users should first copy any credentials Secret they intend a namespace\-scoped issuer to use into that issuer's namespace and update the issuer's secretRef\.namespace to match\. Then, upgrade aws\-privateca\-issuer to version 1\.12\.0 or the AWS Private CA Connector for Kubernetes EKS add\-on to version v1\.12\.0\-eksbuild\.1\.
