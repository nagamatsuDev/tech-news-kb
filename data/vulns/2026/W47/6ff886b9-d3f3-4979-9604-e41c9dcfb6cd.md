# MyMangaDB is a self\-hosted manga collection manager with automatic metadata, MyAnimeList import, Docker support, and collection statistics\.

- **ID**: CVE\-2026\-77297
- **危険度**: Critical（緊急） (CVSS 9.3)
- **公開**: 2026-11-18

## 原文

MyMangaDB is a self\-hosted manga collection manager with automatic metadata, MyAnimeList import, Docker support, and collection statistics\. Prior to 2\.7\.2, the unauthenticated /api/v1/database/import handler in backend/app/api/v1/endpoints/database\.py accepts a ZIP archive and moves an included database file to DATABASE\_PATH while also replacing IMAGE\_PATH content\. An attacker can supply a database containing an attacker\-controlled users table and administrative account, then authenticate as that account; invalid replacement data can also destroy application data or availability\. This issue is fixed in version 2\.7\.2\.
