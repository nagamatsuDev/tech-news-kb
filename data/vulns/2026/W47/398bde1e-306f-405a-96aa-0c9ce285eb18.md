# OpenCTI is an open source platform for managing cyber threat intelligence knowledge and observables\.

- **ID**: CVE\-2026\-121708
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-16

## 原文

OpenCTI is an open source platform for managing cyber threat intelligence knowledge and observables\. Prior to 7\.260513\.0, Draft Workspace identifiers are accepted without verifying that the authenticated user can access the referenced draft\. Any authenticated user can enumerate draftWorkspaces, use a disclosed DRAFT\_ID with draftWorkspaceEntities to read unpublished reports, descriptions, observables, and other staged intelligence, or place the identifier in the opencti\-draft\-id header and run mutations that inject entities and relationships into another user's private workspace\. The flaw permits cross\-user disclosure and tampering but does not cause a denial of service\. This issue is fixed in version 7\.260513\.0\.
