# The One to one user Chat by WPGuppy plugin for WordPress is vulnerable to generic SQL Injection via the 'userId' parameter in all version\.\.\.

- **ID**: CVE\-2026\-107654
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-21

## 原文

The One to one user Chat by WPGuppy plugin for WordPress is vulnerable to generic SQL Injection via the 'userId' parameter in all versions up to, and including, 1\.1\.6 due to insufficient escaping on the user supplied parameter and lack of sufficient preparation on the existing SQL query\. This makes it possible for unauthenticated attackers to append additional SQL queries into already existing queries that can be used to extract sensitive information from the database\. The plugin's permission callback is trivially bypassed because it validates a JWT that the plugin itself signs using an attacker\-supplied value from the guppy\_guest\_account cookie, and the guest code path \(userType\=0\) skips the get\_userdata\(\) check that would confirm the userId corresponds to a real WordPress user\.
