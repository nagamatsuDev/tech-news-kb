# Mailflare before 48957fb contains a host header injection vulnerability in the password\-reset request handler that allows unauthenticated\.\.\.

- **ID**: CVE\-2026\-134654
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-22

## 原文

Mailflare before 48957fb contains a host header injection vulnerability in the password\-reset request handler that allows unauthenticated attackers to poison reset links when APP\_URL is unset\. Attackers can submit a reset request for a victim's email with a malicious Host header, capturing the single\-use token when the victim clicks the link to take over the account\.
