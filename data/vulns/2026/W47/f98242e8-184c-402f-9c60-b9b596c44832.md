# The Everest Forms – Contact Form, Payment Form, Quiz, Survey &amp; Custom Form Builder with AI plugin for WordPress is vulnerable to Missing \.\.\.

- **ID**: CVE\-2026\-129220
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-21

## 原文

The Everest Forms – Contact Form, Payment Form, Quiz, Survey &amp; Custom Form Builder with AI plugin for WordPress is vulnerable to Missing Authorization in all versions up to, and including, 3\.6\.4 This is due to the plugin not properly verifying that a user is authorized to perform an action\. This makes it possible for authenticated attackers, with everest\_forms\_create\_forms capabilities, to activate any already\-installed inactive plugin on the server by supplying an arbitrary slug, triggering its activation hooks and escalating privileges up to administrator level\. Exploitation requires that a site administrator has delegated the everest\_forms\_create\_forms capability to a lower\-privileged role via the plugin's Role &amp; Permission feature, and that at least one inactive installed plugin whose main file follows the slug/slug\.php naming convention exists on the server\.
