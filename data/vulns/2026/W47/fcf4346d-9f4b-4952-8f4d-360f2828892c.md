# mcp\-ssh\-manager is an MCP server for managing servers over SSH with human approval, an encrypted vault, and a live audit trail\.

- **ID**: CVE\-2026\-129995
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-20

## 原文

mcp\-ssh\-manager is an MCP server for managing servers over SSH with human approval, an encrypted vault, and a live audit trail\. Prior to 3\.8\.5, ssh\_backup\_create, ssh\_backup\_restore, ssh\_backup\_schedule, and ssh\_backup\_list build remote shell commands from caller\-controlled values in src/backup\-manager\.js and inline backup handlers in src/index\.js without neutralizing shell metacharacters\. Crafted database, connection, backup directory, path, exclusion, schedule, or comment arguments can therefore execute arbitrary OS commands on managed remote servers as the configured SSH user\. ssh\_backup\_schedule can persist execution through cron\. ssh\_backup\_list does not pass through the server policy check and remains available in readonly and restricted modes, allowing command execution despite those restrictions\. Tool arguments can be supplied by a malicious or compromised MCP client or steered through indirect prompt injection; fully trusted benign arguments do not trigger the issue\. The earlier database\-helper remediation for CVE\-2026\-77383 applied shell quoting to src/database\-manager\.js but did not cover these parallel backup builders\. This issue is fixed in version 3\.8\.5\.
