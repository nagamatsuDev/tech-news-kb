# Go\-Guerrilla SMTP Daemon is a lightweight SMTP server written in Go\.

- **ID**: CVE\-2026\-115578
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-19

## 原文

Go\-Guerrilla SMTP Daemon is a lightweight SMTP server written in Go\. In 1\.6\.7 and earlier, according to the repository advisory's structured affected range, server\.go defines the seven\-byte cmdXCLIENT token, but the XCLIENT handler slices input\[8\:\] after matching only that seven\-byte verb, so a bare command causes an out\-of\-bounds panic in handleClient and terminates the daemon because that connection goroutine does not recover the panic\. The issue is reachable by an unauthenticated client when the non\-default xclient\_on setting is enabled; no HELO command is required\. The repository fix is present in version 1\.6\.7\-1\.
