# sevenz\-rust2\: decompress builds each output path as dest\.join\(entry\.name\(\)\) with no traversal guard, allowing a crafted \.7z to write files outside the destination \(Zip\-Slip\)

- **ID**: CVE\-2026\-61725 / GHSA\-qh76\-45cr\-8xrc
- **危険度**: Medium（警告） (CVSS 6.1)
- **言語**: Rust
- **パッケージ**: crates\.io/sevenz\-rust2 &lt; 0\.21\.1 → 0\.21\.1
- **公開**: 2026-11-20

## 原文

\#\#\# Summary Extracting an attacker\-supplied 7z archive can write files outside the destination directory\. The 7z header stores each entry's path as a UTF\-16 name with nothing constraining it to a relative, in\-tree path\. The extractor joins that name onto the destination and writes to the result without normalizing it or checking that it stays under the destination root, so an entry named \`\.\./\.\./etc/cron\.d/x\` or an absolute path escapes the target\. \#\#\# Details In \`src/util/decompress\.rs\`, \`decompress\_impl\` computes the per\-entry destination directly \(line 140\)\: \`\`\`rust let dest\_path \= dest\.join
