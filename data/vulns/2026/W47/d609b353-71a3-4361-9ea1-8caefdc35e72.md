# Incorrect privilege assignment in the user and group reconciliation logic in AWS ssosync before 2\.9\.5 might allow an authenticated remote\.\.\.

- **ID**: CVE\-2026\-133199
- **危険度**: High（重要） (CVSS 8.5)
- **公開**: 2026-11-20

## 原文

Incorrect privilege assignment in the user and group reconciliation logic in AWS ssosync before 2\.9\.5 might allow an authenticated remote user who is assigned a reused Google Workspace e\-mail address or group name to inherit the IAM Identity Center group memberships and permission set assignments of a previously synchronized, unrelated identity, via automatic synchronization of that Google Workspace account or group\.
  
To remediate this issue, users should upgrade to version 2\.9\.5 or later\.
