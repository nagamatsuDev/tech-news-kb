# ESP\-IDF is the Espressif Internet of Things \(IoT\) Development Framework\.

- **ID**: CVE\-2026\-113781
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-17

## 原文

ESP\-IDF is the Espressif Internet of Things \(IoT\) Development Framework\. Prior to 5\.2\.8, 5\.3\.6, 5\.5\.6, and 6\.0\.3, the Bluedroid BLE Mesh GATT server read handler bt\_mesh\_bta\_gatts\_cb in esp\_ble\_mesh stores a signed attribute\-read callback length in an unsigned 16\-bit variable\. A negative ATT error code is therefore interpreted as a very large successful length and used for a memory copy from a small stack buffer into the GATT response structure\. A remote attacker within Bluetooth LE range who can connect to an exposed PB\-GATT provisioning or Mesh Proxy service can trigger a failed attribute read with a crafted request\. On devices where the affected attributes are accessible without pairing, exploitation requires neither pairing nor user interaction; access requirements depend on device configuration\. The resulting out\-of\-bounds read and stack\-based buffer overflow corrupts the Bluetooth host task stack, causing a crash and device restart and potentially further memory corruption\. The issue affects devices built with CONFIG\_BT\_BLUEDROID\_ENABLED\=y and BLE Mesh GATT enabled; the NimBLE host path is not affected\. This issue is fixed in versions 5\.2\.8, 5\.3\.6, 5\.5\.6, and 6\.0\.3\.
