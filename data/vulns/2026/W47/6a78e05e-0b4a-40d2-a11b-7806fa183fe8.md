# The Mang Board plugin for WordPress is vulnerable to Arbitrary File Deletion via Path Traversal in versions up to, and including, 2\.4\.8 v\.\.\.

- **ID**: CVE\-2026\-125059
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-20

## 原文

The Mang Board plugin for WordPress is vulnerable to Arbitrary File Deletion via Path Traversal in versions up to, and including, 2\.4\.8 via the \`file\_path\` column handled by the \`mbw\_board\_files\_api\_body\(\)\` function\. The plugin stores an attacker\-supplied value directly into the files admin table \(no realpath, dot\-segment, or directory\-containment filtering\) and later concatenates it onto \`MBW\_UPLOAD\_PATH\` before passing the result to \`@unlink\(\)\`\. This makes it possible for unauthenticated attackers to delete arbitrary files on the affected site's server, including \`wp\-config\.
