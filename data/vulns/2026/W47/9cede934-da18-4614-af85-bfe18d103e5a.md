# In Splunk App for Payment Card Industry Compliance versions below 8\.7\.0, a user who holds the "ess\_user" Splunk Enterprise Security role \.\.\.

- **ID**: CVE\-2026\-131211
- **危険度**: High（重要） (CVSS 7.3)
- **公開**: 2026-11-19

## 原文

In Splunk App for Payment Card Industry Compliance versions below 8\.7\.0, a user who holds the "ess\_user" Splunk Enterprise Security role could add attacker\-controlled values to lookup data used by the Primary Functions report\. If another authenticated user later selects the value in the Primary Function Summary panel, the Splunk App for Payment Card Industry Compliance could run attacker\-controlled Search Processing Language \(SPL\) commands using the permissions of the user who selected the value\. With this access, the first user could expose or modify data available to the user who selected the value\.  
The vulnerability is possible because the Primary Functions report does not safely escape report values before including them in drilldown searches\.  
For more information see Users and roles for Splunk Enterprise Security \(https\://help\.splunk\.com/en/splunk\-enterprise\-security\-8/install/8\.7/installation/users\-and\-roles\-for\-splunk\-enterprise\-security\) and Reports \(https\://help\.splunk\.com/en/splunk\-enterprise\-security\-8/splunk\-app\-for\-pci\-compliance/user\-manual/8\.7/using\-the\-splunk\-app\-for\-pci\-compliance/reports\) in the Splunk documentation\.
