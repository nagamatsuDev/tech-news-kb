# コンテンツレイヤ Hgcontentlayer/source\-files through 0\.3\.4には、コンテンツのコントロールを行う攻撃者にとって、コード注入による脆弱性がある。

- **ID**: CVE\-2026\-129948
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: JavaScript/TypeScript
- **公開**: 2026-11-16

## 概要（機械翻訳）

コンテンツレイヤ Hgcontentlayer/source\-files through 0\.3\.4 にはコード注入脆弱性があり、コンテンツファイルをコントロールする攻撃者が、Markdown\(\) でグレイマターの未使用JavaScriptエンジンを悪用することでJavaScriptを実行することができる。攻撃者は、ビルド中にコードを実行するために\-\-\-jsまたは\-\-javascriptフロントマター区切り文字を使用してMarkdownまたはMDXファイルを開始し、CIビルドシークレットを公開できます。。

## 原文

Contentlayer @contentlayer/source\-files through 0\.3\.4 contains a code injection vulnerability that allows attackers who control content files to execute JavaScript by abusing gray\-matter's still\-enabled JavaScript engine in parseMarkdown\(\)\. Attackers can start a Markdown or MDX file with a \-\-\-js or \-\-\-javascript frontmatter delimiter to run code during build, exposing CI build secrets\.
