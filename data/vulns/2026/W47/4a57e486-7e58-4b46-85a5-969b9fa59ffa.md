# pympp allows excessive sponsored transaction fees through padded calldata

- **ID**: CVE\-2026\-63634 / GHSA\-v858\-xh7w\-8jr5
- **危険度**: Medium（警告）
- **言語**: Python
- **パッケージ**: PyPI/pympp &lt; 0\.9\.1 → 0\.9\.1
- **公開**: 2026-11-17

## 原文

\#\#\# Details When the server acts as the fee\_payer, \`pympp\` 0\.8\.0 validates calldata using \`eth\_abi\` decoding, which is lenient about trailing bytes\. The \`FeePayerPolicy\` caps \`gas\_limit\` \(≤ 2 M\) and \`max\_fee\_per\_gas\` \(≤ 100 Gwei\) but does \*\*not\*\* check calldata length\. Tempo uses legacy calldata gas pricing\: \*\*16 gas per non\-zero byte\*\*\. Appending \`N\` bytes of \`0x01\` padding inflates actual gas used by \`N × 16\` while keeping \`gas\_limit\` and \`max\_fee\_per\_gas\` within policy caps\.
