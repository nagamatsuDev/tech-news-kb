# The Probono Form Basic WordPress plugin before 1\.3\.3 does not validate the real type of files uploaded through its public form, trusting \.\.\.

- **ID**: CVE\-2026\-128851
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The Probono Form Basic WordPress plugin before 1\.3\.3 does not validate the real type of files uploaded through its public form, trusting the client\-declared MIME type instead, which could allow unauthenticated attackers to upload PHP files to a public directory and execute them before they are deleted, on servers that do not honour the Probono Form Basic WordPress plugin before 1\.3\.3's Apache\-only access restriction\.
