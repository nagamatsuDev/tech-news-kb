# Barracuda Networks Email Security Gateway \(ESG\) 認証バイパス \- 代替パスあるいはチャネル脆弱性の使用

- **ID**: CVE\-2026\-116606
- **危険度**: Critical（緊急） (CVSS 9.8) / 🔥 悪用確認 (CISA KEV)
- **OS**: Network/Firmware
- **公開**: 2026-11-02

## 概要（機械翻訳）

Barracuda Email Security Gatewayのバージョンでは, Hg\.4\.0\.030より早く認証バイパスによって, 認証されていないリモートアタッカーがコンフィギュレーションインポート機能を呼び出し, 互換性のあるクラフトされたバックアップを復元することができる。

## 原文

An authentication bypass in Barracuda Email Security Gateway versions earlier than 9\.4\.0\.030 allows an unauthenticated remote attacker to invoke a configuration\-import function and restore a crafted, compatible backup archive, resulting in unauthorized modification of the appliance’s global configuration\.
