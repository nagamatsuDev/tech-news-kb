# A weakness has been identified in blinkospace blinko up to 1\.8\.8\.

- **ID**: CVE\-2026\-133502
- **危険度**: High（重要） (CVSS 7.3)
- **公開**: 2026-11-20

## 原文

A weakness has been identified in blinkospace blinko up to 1\.8\.8\. Affected is an unknown function of the file /api/auth/verify\-2fa of the component 2FA Endpoint\. This manipulation of the argument userId causes improper authentication\. The attack may be initiated remotely\. The exploit has been made available to the public and could be used for attacks\. Upgrading to version 1\.8\.9 is able to address this issue\. Patch name\: 80e1c4ffaffe66a97df2b5d85fad864ff3691dc8\. Upgrading the affected component is advised\.
