# mail\-parser\: Uncaught \`OverflowError\` / \`OSError\` on an out\-of\-range \`Received\` date

- **ID**: CVE\-2026\-129300 / GHSA\-xhrq\-2mqv\-q8wx
- **危険度**: Medium（警告） (CVSS 5.3)
- **言語**: Python
- **パッケージ**: PyPI/mail\-parser &gt;\= 3\.7\.0, &lt; 4\.6\.3 → 4\.6\.3
- **公開**: 2026-11-16

## 原文

\#\#\# Impact A \`Received\` header whose trailing date carries an out\-of\-range year, or a timezone offset large enough to push the timestamp past the int64 epoch range, raises an exception that is \*\*outside the \`MailParser\*\` hierarchy\*\*\. A caller that catches only mail\-parser exceptions does not catch it, and the parse of the entire message is aborted — the same class of issue as \[GHSA\-24mq\-4vc6\-2prf\]\(https\://github\.com/SpamScope/mail\-parser/security/advisories/GHSA\-24mq\-4vc6\-2prf\), which this survives \(it is not a duplicate; 24mq is fixed in 4\.6\.2 and this reproduces on 4\.6\.2\)\.
