# The Geo Mashup plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'author \(comment form\) / display\_name \(profile f\.\.\.

- **ID**: CVE\-2026\-116519
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The Geo Mashup plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'author \(comment form\) / display\_name \(profile form\)' parameter in all versions up to, and including, 1\.13\.23 due to insufficient input sanitization and output escaping\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\. The comment\-author path requires the crafted comment to be approved before the payload is served to visitors; the subscriber\-level path requires the plugin's user\-location mapping feature to be enabled\.
