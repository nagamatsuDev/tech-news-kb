# The WP Duplicate – WordPress Migration Plugin plugin for WordPress is vulnerable to Directory Traversal in all versions up to, and includ\.\.\.

- **ID**: CVE\-2026\-14491
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-19

## 原文

The WP Duplicate – WordPress Migration Plugin plugin for WordPress is vulnerable to Directory Traversal in all versions up to, and including, 1\.1\.11 via the 'file\_name' parameter\. This makes it possible for unauthenticated attackers to read the contents of arbitrary files on the server, which can contain sensitive information\. The authentication bypass requires submitting the JSON boolean \`true\` as the \`prod\_key\_random\_id\` value, which coerces against any non\-empty stored secret so that the loose \`\!\=\` comparison evaluates to false, skipping the rejection branch entirely without knowledge of the secret\.
