# Filament Curator\: Stored XSS via unsanitized SVG upload served inline

- **ID**: CVE\-2026\-69241 / GHSA\-8vm9\-f75m\-5h2m
- **危険度**: Medium（警告） (CVSS 5.4)
- **言語**: PHP
- **パッケージ**: Packagist/awcodes/filament\-curator &gt;\= 5\.0\.0, &lt;\= 5\.1\.1 → 5\.1\.2, Packagist/awcodes/filament\-curator &gt;\= 4\.0\.0, &lt;\= 4\.1\.1 → 4\.1\.2, Packagist/awcodes/filament\-curator &gt;\= 3\.0\.0, &lt;\= 3\.7\.8 → 3\.7\.9
- **公開**: 2026-11-17

## 原文

\#\# Summary SVG files uploaded through the Curator media panel are stored and served inline without any sanitization\. An authenticated user with permission to upload media can upload an SVG containing embedded JavaScript\. When another panel user opens that file via the \*\*View\*\* action \(which opens the media as a top\-level browser document\), the embedded script executes in the origin of the Filament application\. \`image/svg\+xml\` is included in the default accepted MIME types, so a default installation is affected unless SVG uploads have been explicitly disabled\. \#\# Impact Because the SVG is serve
