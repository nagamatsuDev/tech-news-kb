# Admidio from 5\.0\.0 before 5\.0\.18 contains a path traversal vulnerability in DocumentsService\:\:renameFile\(\) that allows authenticated user\.\.\.

- **ID**: CVE\-2026\-134254
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-21

## 原文

Admidio from 5\.0\.0 before 5\.0\.18 contains a path traversal vulnerability in DocumentsService\:\:renameFile\(\) that allows authenticated users to move files outside adm\_my\_files by supplying an unvalidated adm\_new\_name value\. Attackers with folder upload permission can submit \.\./ sequences to file\_rename\_save to write files and create directories in arbitrary writable locations, including the web root\.
