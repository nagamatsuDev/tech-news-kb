# A Cross\-Site Request Forgery \(CSRF\) vulnerability in the admin panel of PHPGurukul News Portal Project V4\.1 allows remote attackers to hi\.\.\.

- **ID**: CVE\-2026\-128667
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-18

## 原文

A Cross\-Site Request Forgery \(CSRF\) vulnerability in the admin panel of PHPGurukul News Portal Project V4\.1 allows remote attackers to hijack the authentication of administrators and perform unauthorized state\-changing actions, such as adding, editing, or deleting posts and sub\-admins, or changing passwords, via crafted HTTP requests\. This occurs because the application fails to implement anti\-CSRF tokens for admin actions and permits destructive operations via HTTP GET requests\.
