# PHPGurukul Employee Leaves Management System V2\.1 contains an information disclosure vulnerability because database backup files are stor\.\.\.

- **ID**: CVE\-2026\-128662
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-18

## 原文

PHPGurukul Employee Leaves Management System V2\.1 contains an information disclosure vulnerability because database backup files are stored within the publicly accessible web root\. An unauthenticated remote attacker can download the SQL backup files and retrieve sensitive database contents, including employee personally identifiable information and password hashes\.
