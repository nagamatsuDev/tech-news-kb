# MyMangaDB is a self\-hosted manga collection manager with automatic metadata, MyAnimeList import, Docker support, and collection statistics\.

- **ID**: CVE\-2026\-77295
- **危険度**: High（重要） (CVSS 8.7)
- **公開**: 2026-11-18

## 原文

MyMangaDB is a self\-hosted manga collection manager with automatic metadata, MyAnimeList import, Docker support, and collection statistics\. Prior to 2\.7\.2, the unauthenticated /api/v1/database/export handler in backend/app/api/v1/endpoints/database\.py returns a ZIP containing the live SQLite database and the cover\-image library\. The database includes the users table and hashed\_password values, allowing a remote attacker to obtain all application data and conduct offline password attacks without a session or token\. This issue is fixed in version 2\.7\.2\.
