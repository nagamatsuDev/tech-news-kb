# Tapo provides Rust and Python APIs and an MCP server for TP\-Link Tapo smart devices\.

- **ID**: CVE\-2026\-77329
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: Python, Rust
- **公開**: 2026-11-20

## 原文

Tapo provides Rust and Python APIs and an MCP server for TP\-Link Tapo smart devices\. From 0\.3\.1 until 0\.5\.0, the Streamable HTTP implementation in tapo\-mcp/src/server\.rs calls disable\_allowed\_hosts\(\) without replacement Host or Origin validation, while TAPO\_MCP\_API\_KEY remains optional for a listener that can bind to all interfaces\. A malicious website can use DNS rebinding to send same\-origin browser requests to the victim's local or LAN Tapo MCP listener when it runs without an API key\. The attacker can invoke exposed tools including control\_device for smart\-device actuation and take\_snapshot for configured cameras\. Deployments with TAPO\_MCP\_API\_KEY set are not affected by the unauthenticated path, and exploitation requires a running listener configured with real Tapo credentials and devices, plus victim interaction with the malicious site\. This issue is fixed in version 0\.5\.0\.
