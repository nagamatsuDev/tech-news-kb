# The SendPress Newsletters plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'sp\_firstname' parameter in all versi\.\.\.

- **ID**: CVE\-2026\-96665
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The SendPress Newsletters plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'sp\_firstname' parameter in all versions up to, and including, 1\.26\.1\.20 due to insufficient input sanitization and output escaping\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\. The public subscriber\-management route uses an unsigned, forgeable base64\-encoded JSON token, allowing an unauthenticated attacker to impersonate any subscriber and obtain a valid nonce — bypassing the POST handler's only access control check\.
