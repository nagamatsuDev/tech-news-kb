# LibreChat is an enhanced ChatGPT clone that supports multiple AI providers\.

- **ID**: CVE\-2026\-54044
- **危険度**: High（重要） (CVSS 7.7)
- **公開**: 2026-11-20

## 原文

LibreChat is an enhanced ChatGPT clone that supports multiple AI providers\. Prior to 0\.8\.7, POST /api/agents/actions/\:agent\_id in api/server/routes/agents/actions\.js loads an existing action with owner credentials and merges editor\-controlled metadata\.domain and metadata\.raw\_spec while preserving metadata\.api\_key and related OAuth client secrets\. A collaborator with EDIT permission can repoint an action to an attacker\-controlled host, and a later tool invocation decrypts and sends the retained owner credential to that destination\. This issue is fixed in version 0\.8\.7\.
