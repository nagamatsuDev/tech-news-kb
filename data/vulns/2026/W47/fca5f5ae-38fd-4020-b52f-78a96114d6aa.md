# Netatalk is a Free and Open Source file server suite for Unix\-like operating systems\.

- **ID**: CVE\-2026\-49388
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-20

## 原文

Netatalk is a Free and Open Source file server suite for Unix\-like operating systems\. From 3\.1\.0 until 4\.5\.0, sl\_unpack\_loop in etc/afpd/spotlight\_marshalling\.c uses an attacker\-controlled Spotlight table\-of\-contents index during FPSpotlightRPC without checking it against the number of entries or the remaining dsi\-&gt;commands buffer\. An authenticated AFP client with access to a Spotlight\-enabled volume can choose a large toc\_index whose multiplication and addition produce an out\-of\-range address, causing an attacker\-influenced heap read and reliably crashing the worker serving that session\. The earlier CVE\-2026\-44066 remediation bounded recursion depth and toc\_offset but did not bound toc\_index\. This issue is fixed in version 4\.5\.0\.
