# contao/core\-bundle\: Non\-admin users can self\-grant permissions that implicitly make them administrators

- **ID**: CVE\-2026\-104883 / GHSA\-r9qp\-pqx5\-8369
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **パッケージ**: Packagist/contao/core\-bundle &gt;\= 5\.0\.0, &lt; 5\.3\.50 → 5\.3\.50, Packagist/contao/core\-bundle &gt;\= 5\.4\.0\-RC1, &lt; 5\.7\.12 → 5\.7\.12
- **公開**: 2026-11-20

## 原文

Commit \`2b83a60f7763\` \(5\.7\.3\) hardened the template editor\: it added \`TemplateEditorModuleVoter\` \+ \`CheckTemplateEditorSaveListener\` so a non\-admin cannot self\-grant the \`tpl\_editor\` backend module \(editable PHP\-capable templates permit server\-side code execution\)\. That voter supports only the \`modules\` field and the literal value \`tpl\_editor\`\.
