# Servo Sandbox bypass\: declarative refresh can auto\-navigate a sandboxed iframe

- **ID**: CVE\-2026\-61713 / GHSA\-pxh3\-4qqv\-58mg
- **危険度**: High（重要） (CVSS 8.3)
- **言語**: Rust
- **パッケージ**: crates\.io/servo &lt; 0\.3\.0 → 0\.3\.0
- **公開**: 2026-11-17

## 原文

A sandboxed iframe can auto\-navigate itself via declarative refresh even when automatic features should be blocked\. This allows attacker\-controlled embedded content to redirect itself without user action\. \#\#\# Summary Servo allows a sandboxed iframe to auto\-navigate itself via declarative refresh in configurations that should block automatic features\.
