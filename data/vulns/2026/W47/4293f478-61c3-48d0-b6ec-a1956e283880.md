# qbee\-agent\: Local Privilege Escalation and Arbitrary File Tampering via Symlink Following in createFile helper

- **ID**: CVE\-2026\-62336 / GHSA\-xhv5\-8fpq\-g7hf
- **危険度**: High（重要）
- **言語**: Go
- **パッケージ**: Go/go\.qbee\.io/agent &lt; 0\.0\.0\-20260615134032\-0fdf8e411de5 → 0\.0\.0\-20260615134032\-0fdf8e411de5
- **公開**: 2026-11-16

## 原文

This is a Local Privilege Escalation \(LPE\) vulnerability stemming from improper symlink handling \(CWE\-59\: Link Following\) and improper ownership management \(CWE\-282\) inside the qbee\-agent file manager logic\. \#\#\# Impact Any managed device running qbee\-agent up to the affected versions\. The impact manifests in three distinct vectors\: 1\. \*\*Primary Vector \(Full Privilege Escalation to Root \- Default Configuration\)\*\*\: If an unprivileged user's account is managed by the SSH Keys bundle, they can replace or remove their own \`\~/\.ssh\` directory and create a symlink pointing to \`/root/\.ssh\`\.
