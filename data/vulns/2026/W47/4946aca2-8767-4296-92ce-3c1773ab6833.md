# Mareforma\: verify\_bundle never checks a per\-claim signature

- **ID**: CVE\-2026\-71536 / GHSA\-hxh5\-gp44\-rc6p
- **危険度**: High（重要） (CVSS 7.0)
- **言語**: Python
- **パッケージ**: PyPI/mareforma &gt;\= 0\.3\.0, &lt; 0\.3\.8 → 0\.3\.8
- **公開**: 2026-11-18

## 原文

\#\# What's wrong \`verify\_bundle\` documents that it verifies "a bundle's DSSE envelope AND each per\-claim signature", lists "per\-claim signature failure" among its raised errors, and promises that partial verification never surfaces "an authenticated bundle that contains some invalid claims" as success\. The code does not do this\. The JSON\-LD predicate built by \`JSONLDExporter\.\_claim\_node\` carries no signature material \(there is no \`signatureBundle\` field on the node\), so the verify loop has nothing cryptographic to check per claim\.
