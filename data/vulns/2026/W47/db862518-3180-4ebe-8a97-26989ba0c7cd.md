# WeGIA is a web manager for charitable institutions\.

- **ID**: CVE\-2026\-61675
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: PHP
- **公開**: 2026-11-17

## 原文

WeGIA is a web manager for charitable institutions\. Prior to 3\.8\.7, web/html/socio/sistema/atualiza\_pagamentos\.php performs payment\-status database updates without checking whether the requester has an authenticated session\. An unauthenticated remote requester can supply a payment identifier, payment date, and paid value to mark arbitrary payment records as paid or otherwise modify payment information, causing financial record corruption\. This issue is fixed in version 3\.8\.7\.
