# Mareforma is a local verification layer for AI\-assisted research\.

- **ID**: CVE\-2026\-71535
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-18

## 原文

Mareforma is a local verification layer for AI\-assisted research\. From 0\.3\.0 until 0\.3\.7, the \_maybe\_update\_replicated\_unlocked convergence path in mareforma/db/core\.py uses generated\_by labels without requiring a valid signature\_bundle from a distinct enrolled signer, so an unsigned claim written to a shared graph can converge with a signed peer and be promoted to REPLICATED\. The forged trust state is returned by queries requiring REPLICATED support, allowing false multi\-party endorsement signals to reach downstream consumers\. This issue is fixed in version 0\.3\.7\.
