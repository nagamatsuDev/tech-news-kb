# Mareforma\: Unsigned Claims Can Be Promoted to REPLICATED via Missing Signature Enforcement in Convergence Path

- **ID**: CVE\-2026\-71535 / GHSA\-8776\-qf3h\-26r3
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: Python
- **パッケージ**: PyPI/mareforma &gt;\= 0\.3\.0, &lt; 0\.3\.7 → 0\.3\.7
- **公開**: 2026-11-18

## 原文

\#\#\# Summary \`mareforma\` 0\.3\.3 contains a critical integrity flaw in the REPLICATED convergence logic \(\`\_maybe\_update\_replicated\_unlocked\(\)\` in \`mareforma/db/core\.py\:1300\-1319\`\)\. The peer\-selection SQL query that determines whether two independent claims "agree" on the same anchor does not verify that either claim carries a valid cryptographic signature from an enrolled validator key\. Because \`rekor\_enabled\=False\` is the default and automatically sets \`transparency\_logged\=1\` at insert time, every claim — signed or not — immediately satisfies the convergence precondition\.
