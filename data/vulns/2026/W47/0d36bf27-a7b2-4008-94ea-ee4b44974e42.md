# The Trust Payments Gateway for WooCommerce \(JavaScript Library\) plugin for WordPress is vulnerable to Authentication Bypass in all versio\.\.\.

- **ID**: CVE\-2026\-110811
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: JavaScript/TypeScript, PHP
- **公開**: 2026-11-18

## 原文

The Trust Payments Gateway for WooCommerce \(JavaScript Library\) plugin for WordPress is vulnerable to Authentication Bypass in all versions up to, and including, 1\.3\.8\. The vulnerability exists because the \`new\_customer\_account\(\)\` function stores the raw return value of \`wp\_create\_user\(\)\` — including a \`WP\_Error\` object returned on username collision — into the order's \`tp\_userid\` post meta before the \`is\_wp\_error\(\)\` guard is evaluated; the \`add\_customer\_details\_to\_thankyou\_page\(\)\` callback subsequently reads that meta and casts it with \`\(int\)\`, causing PHP to coerce any object to integer \`1\`, after which \`wp\_set\_current\_user\(1\)\` and \`wp\_set\_auth\_cookie\(1\)\` are called unconditionally\. This makes it possible for unauthenticated attackers to authenticate as WordPress user ID 1 — the bootstrap site administrator or, on multisite, a network super\-admin — by supplying the \`new\_username\` parameter matching any existing login during checkout and visiting the resulting thank\-you page\. Exploitation requires the Trust Payments gateway to be active and the attacker to complete a paid order on their own account; the ID 1 administrator username is additionally enumerable via standard WordPress user enumeration techniques\.
