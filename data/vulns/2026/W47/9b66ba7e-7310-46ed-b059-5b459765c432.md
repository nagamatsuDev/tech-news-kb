# Outstatic\: Authenticated GitHub REST proxy can send OAuth token to non\-GitHub origins

- **ID**: CVE\-2026\-71425 / GHSA\-7jvc\-9xq8\-frff
- **危険度**: Medium（警告） (CVSS 6.5)
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/outstatic &lt;\= 2\.2\.0 → 2\.2\.1
- **公開**: 2026-11-18

## 原文

\#\#\# Impact Outstatic’s authenticated GitHub REST proxy accepted an unvalidated endpoint parameter and constructed an upstream GitHub API URL by string concatenation while attaching the authenticated user’s GitHub OAuth token\. A user with access to the Outstatic dashboard could craft a request that caused the server to send their own GitHub OAuth token to a non\-GitHub host\. If that token was captured, it could be used to access GitHub resources available to that same user, including private repositories depending on granted scopes\.
