# mail\-parser is a tool that parses emails by enhancing the Python standard library and extracting message details into a comprehensive obj\.\.\.

- **ID**: CVE\-2026\-129295 / GHSA\-r7w7\-vpq8\-c5vv
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: Python
- **公開**: 2026-11-16

## 原文

mail\-parser is a tool that parses emails by enhancing the Python standard library and extracting message details into a comprehensive object\. From 4\.2\.0 until 4\.6\.1, attacker\-controlled email headers can cause polynomial regular\-expression backtracking during ordinary parse\_from\_string\(\), parse\_from\_bytes\(\), or parse\_from\_file\(\) calls\. In src/mailparser/utils\.py, get\_addresses\(\) invokes the \_ADDR\_FALLBACK\_RE fallback when strict address parsing yields no usable address, and overlapping quantifiers rescan padded address headers quadratically or cubically\. In src/mailparser/const\.py, parse\_received\(\) applies \_CLAUSE\_SPLITTER to uncollapsed whitespace in a Received header, causing quadratic backtracking when a whitespace run is not followed by a clause keyword\. A small, well\-formed message can keep mail gateway, ticketing, quarantine, or archival parsing workers busy for extended periods\. This issue is fixed in version 4\.6\.1\.
