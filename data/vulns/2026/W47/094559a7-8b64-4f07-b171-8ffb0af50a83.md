# Chamilo LMS is an open\-source learning management system\.

- **ID**: CVE\-2026\-61583
- **危険度**: High（重要） (CVSS 8.7)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

Chamilo LMS is an open\-source learning management system\. Prior to 1\.11\.40, main/dropbox/dropbox\_functions\.inc\.php accepts a literal \.htaccess filename in the course dropbox and stores it in a directory served by Apache, where the file can alter handler behavior under the required AllowOverride All configuration\. Any authenticated course participant can upload \.htaccess and then upload a PHP payload disguised as a \.gif, resulting in code execution as the web\-server user when the dropbox tool is enabled\. This can expose or modify the Chamilo installation, course content, and database credentials\. This issue is fixed in version 1\.11\.40\.
