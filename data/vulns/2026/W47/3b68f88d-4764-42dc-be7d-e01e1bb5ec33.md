# codebase\-memory\-mcp provides local code intelligence for developers and AI agents through a persistent graph and MCP tools\.

- **ID**: CVE\-2026\-114495
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-20

## 原文

codebase\-memory\-mcp provides local code intelligence for developers and AI agents through a persistent graph and MCP tools\. Prior to 0\.9\.0, automatic import of a repository's \.codebase\-memory/ artifact allocated a decompression buffer using the attacker\-controlled 64\-bit original\_size value from artifact\.json but truncated that value to int when passing the destination capacity to the Zstandard decompressor\. A value with bit 31 set became negative and was sign\-extended to a large size\_t, allowing the decompressor to write frame content beyond the actual allocation\. Indexing a malicious repository containing the crafted artifact could corrupt heap memory with attacker\-controlled bytes, causing a reliable crash and potentially code execution\. This issue is fixed in version 0\.9\.0\.
