# The UpdraftPlus\: WP Backup &amp; Migration Plugin WordPress plugin before 1\.26\.10, UpdraftPlus\: WP Backup &amp; Migration Plugin WordPress plugin\.\.\.

- **ID**: CVE\-2026\-111067
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: PHP
- **公開**: 2026-11-21

## 原文

The UpdraftPlus\: WP Backup &amp; Migration Plugin WordPress plugin before 1\.26\.10, UpdraftPlus\: WP Backup &amp; Migration Plugin WordPress plugin before 2\.26\.10\.26 does not guard all execution paths of its database restore process against second\-order SQL injection, allowing a Subscriber\-level user who has stored crafted content in their own account to escalate to administrator when an administrator later restores a backup\.  
This is due to an incomplete fix of CVE\-2026\-108761 in 1\.26\.9\: the fix guards only one of the restore routine's execution paths, and a second path remains exploitable\.
