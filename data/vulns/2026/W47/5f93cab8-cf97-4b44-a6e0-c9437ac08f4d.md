# django\-tenants 3\.4\.8 before 4\.0\.1にはPostgreSQLバックエンドにSQLインジェクション脆弱性があり、攻撃者はSQLを\.NET Coreに注入できる。

- **ID**: CVE\-2026\-130082
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: Python
- **公開**: 2026-11-16

## 概要（機械翻訳）

django\-tenants 3\.4\.8 before 4\.0\.1にはPostgreSQLバックエンドにSQLインジェクション脆弱性があり、攻撃者は空きテナントスキーマ名を通じてSQLを注入できる。django\-tenants 3\.4\.8 before 4\.0\.1はSQLインジェクション脆弱性を備えている。スキーマ名の選択や影響をすることができる攻撃者は、SET search\_pathおよびCREATE、DROP、またはALTER SCHEMA文に補間される引用文字を供給し、他のテナントのデータを読み取るか、アプリケーションのデータベースユーザーとしてSQLを実行させることができる。は、\.

## 原文

django\-tenants 3\.4\.8 before 4\.0\.1 contains an SQL injection vulnerability in its PostgreSQL backend that allows attackers to inject SQL through unescaped tenant schema names\. Attackers who can choose or influence a schema name can supply quote characters that are interpolated into SET search\_path and CREATE, DROP or ALTER SCHEMA statements, letting them read other tenants' data or run SQL as the application's database user\.
