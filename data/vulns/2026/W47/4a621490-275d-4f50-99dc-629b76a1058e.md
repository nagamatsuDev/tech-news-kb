# The Soledad theme for WordPress is vulnerable to unauthenticated Remote Code Execution in versions up to, and including, 8\.7\.7 The public\.\.\.

- **ID**: CVE\-2026\-121684
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-17

## 原文

The Soledad theme for WordPress is vulnerable to unauthenticated Remote Code Execution in versions up to, and including, 8\.7\.7 The public penci\_more\_post\_ajax AJAX action feeds infeedads\[ads\_code\] \(base64\+urldecoded\) to penci\_safe\_shortcode\(\), whose allowlist regex inspects only the hyphen\-truncated outer shortcode name \(e\.g\. 'adinserter'\) and never the nested \[elementor\-element k\=\.\. data\=\.\.\] tag, so do\_shortcode\(\) renders an attacker\-chosen Elementor element\. The rendered penci\-featured\-sliders widget passes its unsanitized 'style' setting to include dirname\(\_\_FILE\_\_\)\."/\{\$style\}\.php", a path\-traversal local file inclusion\.
