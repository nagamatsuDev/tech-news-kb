# NocoBase @nocobase/plugin\-collection\-sql through 2\.2\.46 contains an SQL injection vulnerability that allows privileged users to store unv\.\.\.

- **ID**: CVE\-2026\-112306
- **危険度**: High（重要） (CVSS 7.2)
- **公開**: 2026-10-19

## 原文

NocoBase @nocobase/plugin\-collection\-sql through 2\.2\.46 contains an SQL injection vulnerability that allows privileged users to store unvalidated SQL by bypassing checkSQL\(\) through the sqlCollection\:setFields action\. Attackers holding the collection\-sql snippet can replace a benign collection query with dangerous statements executed on reload, reading pg\_shadow password hashes or calling pg\_read\_file\.
