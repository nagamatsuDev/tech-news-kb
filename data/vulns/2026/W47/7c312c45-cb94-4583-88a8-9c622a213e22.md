# テンセイから0\.11\.5は、ハードコードされたJWT署名キーにフォールバックするインテンセイローの認証バイパス脆弱性が含まれています。

- **ID**: CVE\-2026\-129552
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-16

## 概要（機械翻訳）

テンセイから0\.11\.5は、JWT\_SECRETがアンセットされたときにハードコードされたJWT署名キー'auth\-secret\-key'にフォールバックする、ノートテンセイロースの認証バイパス脆弱性を含んでいる。テンセイは、JWT\_SECRETがアンセットされたときに、"auth\-secret\-key"に偽装する。認証されていない攻撃者は、populateContextFromTokenによって受け入れられるHgBraryユーザIDを使用してトークンにサインし、管理者を含む任意のユーザを偽装することができる。。は複数ある。複数あるが、複数あるが、複数あるが、複数あるが、複数あるが、複数あるが。、複数ある。。。。

## 原文

Tensei through 0\.11\.5 contains an authentication bypass vulnerability in @tensei/auth that falls back to the hard\-coded JWT signing key 'auth\-secret\-key' when JWT\_SECRET is unset\. Unauthenticated attackers can sign tokens with arbitrary user ids accepted by populateContextFromToken to impersonate any user, including administrators\.
