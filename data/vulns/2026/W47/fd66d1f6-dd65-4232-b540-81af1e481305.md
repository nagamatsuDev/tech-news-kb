# pREST \(PostgreSQL REST\) is an API that delivers an application on top of a Postgres database\.

- **ID**: CVE\-2026\-104129
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-19

## 原文

pREST \(PostgreSQL REST\) is an API that delivers an application on top of a Postgres database\. Prior to 2\.4\.0, the vulnerable parameter is \_groupby, handled by GroupByClause in adapters/postgres/postgres\.go\. adapters/postgres/postgres\.go uses the weaker isSafeSQLExpression check for this function\-expression branch instead of the stricter single\-field validator used for \_select\. That check validates only the outer function name against a 13\-function allowlist and permits nested subqueries, trailing UNION syntax, and inner pg\_ functions\. controllers/crud\.go concatenates the GROUP BY expression while parameterizing only WHERE values, allowing attacker\-controlled SQL structure into the clause\. Default configuration permits unauthenticated access; a restricted installation may require a low\-privilege table reader\. UNION\-based extraction requires compatible column counts and types and was not verified end to end, but a delay\-producing function can cause denial of service without that alignment\. This issue is fixed in 2\.4\.0\.
