# BISHENG before 3\.0\.0 contains an authentication bypass vulnerability that allows unauthenticated remote attackers to impersonate administ\.\.\.

- **ID**: CVE\-2026\-130840
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-17

## 原文

BISHENG before 3\.0\.0 contains an authentication bypass vulnerability that allows unauthenticated remote attackers to impersonate administrators by abusing a hard\-coded default jwt\_secret used by AuthJwt\. Attackers can forge an HS256 token offline naming user\_id 1 with the admin role, send it as access\_token\_cookie, and gain full administrative access to users, workspaces, knowledge bases and workflows\.
