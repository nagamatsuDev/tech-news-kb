# Use\-after\-free after interrupted session shutdown\.

- **ID**: CVE\-2026\-129481
- **危険度**: Critical（緊急） (CVSS 9.2)
- **言語**: PHP
- **公開**: 2026-11-19

## 原文

Use\-after\-free after interrupted session shutdown\.
  
The session extension records the filename of the executing script when a session starts\. If a fatal error occurs in an application callback while the session variables are destroyed at shutdown, such as stream\_close\(\) of a user\-defined stream wrapper, the pointer is retained after the request memory is freed, and a later request handled by the same worker can free the stale string\. An attacker who can trigger such a failing cleanup may crash the worker or corrupt memory; code execution has not been demonstrated\. This requires the filename to be allocated in request memory, for example when the script is not cached by OPcache\.
  
This issue affects PHP versions 8\.3\.\* before 8\.3\.37, 8\.4\.\* before 8\.4\.28 and 8\.5\.\* before 8\.5\.13\.
