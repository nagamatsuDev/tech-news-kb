# In the Linux kernel, the following vulnerability has been resolved\: io\_uring/io\-wq\: save worker type before dropping its reference io\_w\.\.\.

- **ID**: CVE\-2026\-99804
- **危険度**: High（重要） (CVSS 7.8)
- **OS**: Linux
- **公開**: 2026-11-20

## 原文

In the Linux kernel, the following vulnerability has been resolved\:
  
io\_uring/io\-wq\: save worker type before dropping its reference
  
io\_wq\_cancel\_tw\_create\(\) inspects cb\-&gt;func after calling  
io\_worker\_cancel\_cb\(\)\. For an existing worker, that call can drop the  
last worker reference and wake io\_worker\_exit\(\)\. If the canceling task  
is preempted, the worker can be unlinked and freed by kfree\_rcu\(\) before  
the callback function is inspected\. KASAN reports a slab\-use\-after\-free  
read in this path\.
  
Save whether the callback belongs to an unpublished continuation worker  
while its reference is still held, then use the saved result for the  
conditional free\. This preserves the existing accounting and frees only  
the worker allocated for the canceled continuation\.
