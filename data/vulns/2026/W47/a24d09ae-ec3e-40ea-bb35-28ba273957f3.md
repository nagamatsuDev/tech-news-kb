# Tandoor Recipes before 2\.7\.4 contains a server\-side request forgery vulnerability that allows space admins to reach internal hosts becaus\.\.\.

- **ID**: CVE\-2026\-133235
- **危険度**: High（重要） (CVSS 7.7)
- **公開**: 2026-11-19

## 原文

Tandoor Recipes before 2\.7\.4 contains a server\-side request forgery vulnerability that allows space admins to reach internal hosts because Nextcloud\.get\_client builds WebDAV clients from Storage\.url without calling safe\_request\. Attackers can create a NEXTCLOUD storage via POST /api/storage/ pointing at internal hosts, import a file, then call GET /api/get\_recipe\_file/&lt;id&gt;/ to read internal service or cloud metadata responses\.
