# yt\-mcp is a YouTrack MCP server for Claude Code\.

- **ID**: CVE\-2026\-75612
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-18

## 原文

yt\-mcp is a YouTrack MCP server for Claude Code\. Prior to 1\.18\.1, add\_attachment in src/yt\_mcp/tools/attachments\.py accepts a caller\-controlled file\_path, checks only that the file exists, reads it without directory confinement, and uploads the bytes to a YouTrack issue\. A compromised MCP client or an LLM steered by indirect prompt injection can read any file accessible to the server process and exfiltrate secrets through an issue the caller can access\. The same release also permits get\_project\_health to interpolate a caller\-controlled project value into snapshot filenames, allowing parent\-directory traversal to write JSON files outside the snapshots directory\. This issue is fixed in version 1\.18\.1\.
