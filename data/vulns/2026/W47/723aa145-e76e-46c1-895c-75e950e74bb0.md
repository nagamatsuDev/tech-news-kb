# ZoneMinder is a free, open source closed\-circuit television software application\.

- **ID**: CVE\-2026\-28273
- **危険度**: Critical（緊急） (CVSS 9.9)
- **言語**: PHP
- **公開**: 2026-11-17

## 原文

ZoneMinder is a free, open source closed\-circuit television software application\. Prior to 1\.38\.4, any authenticated user can use the /api/configs/edit/\{name\}\.json endpoint to modify protected configuration settings because ConfigsController\:\:edit\(\) does not enforce the System\=Edit authorization requirement and its system\-variable protection is ineffective\. An attacker can set ZM\_PATH\_FFMPEG to a command\-bearing value and trigger an exec\(\) sink in web/views/image\.php or web/includes/Event\.php by requesting frame extraction\. This permits arbitrary command execution with the privileges of the web server user and can expose private camera feeds, recordings, and database data or establish persistence\. This issue is fixed in version 1\.38\.4\.
