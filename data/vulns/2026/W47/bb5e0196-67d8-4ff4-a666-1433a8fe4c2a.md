# In Eclipse versions 1\.5\-1\.6\.13, 2\.0\.0\-2\.0\.22 and 2\.1\.0\-2\.1\.2, the client library libmosquitto does not reject Will messages with payloads\.\.\.

- **ID**: CVE\-2026\-130491
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-18

## 原文

In Eclipse versions 1\.5\-1\.6\.13, 2\.0\.0\-2\.0\.22 and 2\.1\.0\-2\.1\.2, the client library libmosquitto does not reject Will messages with payloads greater than 65535 bytes when calling \`mosquitto\_will\_set\(\)\` or \`mosquitto\_will\_set\_v5\(\)\`\. This results in up to 65535 bytes of uninitialised heap memory being transmitted as the Will\.
  
This can be mitigated by only passing payloads with a maximum length of 65535 bytes\.
