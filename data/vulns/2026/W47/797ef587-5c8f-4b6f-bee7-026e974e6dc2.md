# Jane\: Instantiation RCE via header parameter name \-&gt; raw PHPDoc \*/ breakout \(jane\-php/open\-api\-3\)

- **ID**: CVE\-2026\-63413 / GHSA\-x9xr\-53qx\-9qcf
- **危険度**: Critical（緊急） (CVSS 9.3)
- **言語**: PHP
- **パッケージ**: Packagist/jane\-php/open\-api\-3 &lt; 7\.12\.0 → 7\.12\.0
- **公開**: 2026-11-18

## 原文

\#\#\# Summary jane\-php \(open\-api\-3\) builds PHP via nikic/php\-parser \(AST\), so string literals are escaped \-\- but PHPDoc comment text is emitted RAW\. The generated Client/Endpoint method docblocks embed the header parameter name verbatim in a \`@param array\{ "&lt;name&gt;"?\: \.\.\. \}\` block\. A \`\*/\` in the header name closes the \`/\*\* \.\.\. \*/\` docblock early and lands in class\-body position; because the name is a raw string key \(not identifier\-mangled\), the \`\*/\` and following PHP survive\. Injecting \`\*/ public function \_\_construct\(\)\{ &lt;code&gt; \} /\*\` adds an attacker\-controlled \_\_construct to the generated Client
