# Admidio 5\.0\.0 before 5\.0\.18 contains a stored cross\-site scripting vulnerability that allows role administrators to inject JavaScript by \.\.\.

- **ID**: CVE\-2026\-134262
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: JavaScript/TypeScript, PHP
- **公開**: 2026-11-21

## 原文

Admidio 5\.0\.0 before 5\.0\.18 contains a stored cross\-site scripting vulnerability that allows role administrators to inject JavaScript by placing quote\-breaking payloads in role names rendered unencoded in the data\-message attribute in modules/profile/roles\_functions\.php\. Attackers can execute scripts when a full administrator views an affected profile page, stealing the CSRF token to assign themselves the Administrator role\.
