# Grav before 1\.7\.53\.7 and 2\.x before 2\.2\.18 serves page media files, and rendered pages when lazy sessions are enabled, with the visitor's\.\.\.

- **ID**: CVE\-2026\-130746
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-18

## 原文

Grav before 1\.7\.53\.7 and 2\.x before 2\.2\.18 serves page media files, and rendered pages when lazy sessions are enabled, with the visitor's session cookie and a shared\-cacheable Cache\-Control header\. When a shared cache such as Apache mod\_cache stores Set\-Cookie responses, an attacker can lure a user signed in through the front\-end login to open a media URL with a unique query string, then request that URL to receive the cached session cookie and take over the session\.
