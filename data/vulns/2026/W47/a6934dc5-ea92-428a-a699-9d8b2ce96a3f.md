# Inscriptis\: Quadratic memory growth from sibling &lt;table&gt; elements in get\_text\(\)

- **ID**: CVE\-2026\-132277 / GHSA\-q87h\-c5m7\-659j
- **危険度**: Medium（警告） (CVSS 5.3)
- **言語**: Python
- **パッケージ**: PyPI/inscriptis &gt;\= 2\.0\.0, &lt;\= 2\.7\.5 → 2\.7\.6
- **公開**: 2026-11-20

## 原文

\# Summary Every sibling \`&lt;table&gt;\` adds another level of the parent's indentation, so the size of \`get\_text\(\)\` output grows quadratically with the number of tables\. In the measurements below, a 240 KB HTML document produces about 1 billion characters and uses about 1 GB of memory\. \# Details \`table\_end\_handler\(\)\` \(\`model/tag/table\_tag\.py\`\) writes the rendered table into the parent element with \`HtmlElement\.write\_verbatim\_text\(\)\` \(\`model/html\_element\.py\`\)\.
