# Daptin\: Unauthenticated SQL Injection via the \`sort\` query parameter on every entity list endpoint

- **ID**: CVE\-2026\-77367 / GHSA\-hq2p\-f2vj\-v3cm
- **危険度**: Critical（緊急） (CVSS 9.4)
- **言語**: Go
- **パッケージ**: Go/github\.com/daptin/daptin &lt;\= 0\.12\.29 → 0\.12\.30
- **公開**: 2026-11-19

## 原文

\#\#\# Summary An unauthenticated attacker can inject arbitrary SQL through the \`sort\` query parameter accepted by Daptin's generic entity list endpoint \(\`GET /api/&lt;entity&gt;\`\), which every table in a Daptin instance exposes\. The parameter is concatenated into raw SQL identifiers with no validation that the referenced column exists, unlike a sibling code path in the same file that received exactly this validation as the fix for a previously published advisory \(\[GHSA\-rw2c\-8rfq\-gwfv\]\(https\://github\.com/daptin/daptin/security/advisories/GHSA\-rw2c\-8rfq\-gwfv\)\)\. Impact ranges from unauthenticated denial
