# Jupyter MCP Server\: Browser DNS rebinding can hijack the Jupyter backend through management routes

- **ID**: CVE\-2026\-77359 / GHSA\-9x8x\-crjq\-g64h
- **危険度**: Critical（緊急） (CVSS 9.3)
- **言語**: Python
- **パッケージ**: PyPI/jupyter\-mcp\-server &lt;\= 1\.0\.2 → 1\.0\.3
- **公開**: 2026-11-19

## 原文

Standalone \`streamable\-http\` mode in \`datalayer/jupyter\-mcp\-server\` rejects forged \`Host\` and \`Origin\` headers on \`/mcp\`, but custom management routes mounted on the same application do not get the same browser\-origin protection\. A malicious website can keep an attacker origin while its hostname resolves to \`127\.0\.0\.1\` or a private target address, then send \`PUT /api/connect\` to replace the MCP server's active Jupyter backend\.
