# Grav from 2\.0\.0 before 2\.2\.18 contains a privilege escalation vulnerability that allows user managers and Flex editors to overwrite, crea\.\.\.

- **ID**: CVE\-2026\-130739
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-18

## 原文

Grav from 2\.0\.0 before 2\.2\.18 contains a privilege escalation vulnerability that allows user managers and Flex editors to overwrite, create, or delete accounts by supplying client\-controlled storage keys\. Attackers can abuse the create form username, cross\-type form flash replay, or \_\_META storage key rename to gain super\-admin accounts or delete account files\.
