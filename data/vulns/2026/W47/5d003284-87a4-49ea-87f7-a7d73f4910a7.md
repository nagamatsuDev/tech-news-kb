# The AppPresser WordPress plugin before 5\.0\.0 does not properly escape the contents of its debug log when displaying it in the admin dash\.\.\.

- **ID**: CVE\-2026\-121852
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-19

## 原文

The AppPresser  WordPress plugin before 5\.0\.0 does not properly escape the contents of its debug log when displaying it in the admin dashboard, and decodes escape sequences after sanitising input, allowing unauthenticated users to perform Stored XSS attacks against administrators when debug logging is enabled\.
