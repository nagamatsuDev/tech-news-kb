# Netatalk is a Free and Open Source file server suite for Unix\-like operating systems\.

- **ID**: CVE\-2026\-62320
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-20

## 原文

Netatalk is a Free and Open Source file server suite for Unix\-like operating systems\. From 1\.5\.0 until 4\.5\.1, dsi\_tcp\_open in libatalk/dsi/dsi\_tcp\.c silently limits the bytes read from an unauthenticated DSI frame received on TCP/548 to server\_quantum when the attacker\-controlled dsi\_len is larger, without rejecting the frame or draining the declared remainder\. The same silent dsi\_len truncation pattern exists in libatalk/dsi/dsi\_stream\.c\. The leftover bytes remain queued on the TCP connection and the next dsi\_stream\_receive call interprets them as a new DSI header and payload, allowing a remote unauthenticated attacker to smuggle one or more additional attacker\-controlled DSI frames into the same connection\. This issue is fixed in version 4\.5\.1\.
