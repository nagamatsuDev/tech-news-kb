# A vulnerability in the eXtensible ARchive \(XAR\) GZIP file parser for ClamAV could allow an unauthenticated, remote attacker to exceed the\.\.\.

- **ID**: CVE\-2026\-76516
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-18

## 原文

A vulnerability in the eXtensible ARchive \(XAR\) GZIP file parser for ClamAV could allow an unauthenticated, remote attacker to exceed the configured MaxFileSize and cause a DoS condition on an affected device\.  
    
 This vulnerability is due to inefficiencies when parsing specifically formatted files with the XAR GZIP file parser\. An attacker could exploit this vulnerability by by sending a crafted XAR GZIP file to be scanned\. A successful exploit could allow the attacker to effectively cause the ClamAV to exceed the MaxFileSize and potentially get caught in an infinite loop, causing a DoS condition\.
