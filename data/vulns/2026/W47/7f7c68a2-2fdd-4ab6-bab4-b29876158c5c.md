# NukeViet CMS is a multi Content Management System\.

- **ID**: CVE\-2026\-48118
- **危険度**: High（重要） (CVSS 8.2)
- **言語**: JavaScript/TypeScript, PHP
- **公開**: 2026-11-20

## 原文

NukeViet CMS is a multi Content Management System\. Prior to 4\.5\.09, the Comment module accepts attacker\-controlled base64 content in the status\_comment parameter through modules/comment/funcs/main\.php; modules/comment/comment\.php decodes it with nv\_base64\_decode\(\) and assigns it to STATUS\_COMMENT without output escaping\. The required checkss token was derived from the site\-wide NV\_CACHE\_PREFIX rather than NV\_CHECK\_SESSION, so a token disclosed in public comment markup could be reused across sessions in a crafted URL\. An unauthenticated attacker can therefore cause decoded HTML or JavaScript to render in a victim's browser and perform phishing or same\-origin actions\. This issue is fixed in version 4\.5\.09\.
