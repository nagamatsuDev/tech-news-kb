# Nuxt 3\.0\.0 before 3\.4\.2 contains a semi\-arbitrary file read vulnerability in the vite\-node dev server middleware that allows unauthentica\.\.\.

- **ID**: CVE\-2023\-54417
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-18

## 原文

Nuxt 3\.0\.0 before 3\.4\.2 contains a semi\-arbitrary file read vulnerability in the vite\-node dev server middleware that allows unauthenticated attackers to read files by supplying an absolute path as the moduleId\. Attackers can send GET requests to /\_\_nuxt\_vite\_node\_\_/module/ with an absolute file path to read sensitive system files\. Exploitation evidence was first observed by the Shadowserver Foundation on 2023\-10\-19\.
