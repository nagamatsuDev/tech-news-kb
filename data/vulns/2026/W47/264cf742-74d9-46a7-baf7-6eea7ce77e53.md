# OpenWrt LuCI luci\-app\-travelmate on master before 3\.0\.0\-1, on openwrt\-25\.12 before 2\.4\.9\-6, and on openwrt\-24\.10 and openwrt\-23\.05 \(no fi\.\.\.

- **ID**: CVE\-2026\-130751
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-18

## 原文

OpenWrt LuCI luci\-app\-travelmate on master before 3\.0\.0\-1, on openwrt\-25\.12 before 2\.4\.9\-6, and on openwrt\-24\.10 and openwrt\-23\.05 \(no fix available\) grants file exec permissions for state\-mutating commands in the read scope of its rpcd ACL, letting authenticated read\-only users run those commands as root\. Attackers can invoke ubus file exec on /etc/init\.d/travelmate setup, start, stop, restart, or /sbin/ifup to modify and commit network and firewall configuration or disrupt the travelmate daemon\.
