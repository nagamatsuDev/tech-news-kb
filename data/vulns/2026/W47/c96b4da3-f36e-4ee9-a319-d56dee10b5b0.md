# In the Linux kernel, the following vulnerability has been resolved\: ocfs2\: cache the mount context for dentry lock callbacks ocfs2\_drop\.\.\.

- **ID**: CVE\-2026\-99690
- **危険度**: High（重要） (CVSS 7.8)
- **OS**: Linux
- **公開**: 2026-11-20

## 原文

In the Linux kernel, the following vulnerability has been resolved\:
  
ocfs2\: cache the mount context for dentry lock callbacks
  
ocfs2\_drop\_dentry\_lock\(\) drops the inode reference before releasing the  
DENTRY lock\.  This lets inode eviction release the local inode and open  
locks before a remote unlink can proceed past the DENTRY lock\.
  
A DLM callback can still arrive before the DENTRY lock has been dropped\.  
ocfs2\_get\_dentry\_osb\(\) obtains the mount context through dl\_inode\-&gt;i\_sb,  
which can access a freed inode when the downconvert thread drops the  
last inode reference in its post\-unlock callback\:
  
  Downconvert thread                     DLM callback thread  
  \-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-                     \-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-  
  ocfs2\_process\_blocked\_lock\(\)  
    ocfs2\_dentry\_post\_unlock\(\)  
      ocfs2\_dentry\_lock\_put\(\)  
        ocfs2\_drop\_dentry\_lock\(\)  
          iput\(dl\-&gt;dl\_inode\)  
          \[inode reclaimed after RCU\]  
                                         ocfs2\_blocking\_ast\(\)  
                                           ocfs2\_get\_dentry\_osb\(\)  
                                             dl\-&gt;dl\_inode\-&gt;i\_sb  
          ocfs2\_simple\_drop\_lockres\(\)
  
Store the mount context in the DENTRY lock resource's l\_priv field and use  
the default mount\-context lookup\.  Recover the containing dentry lock with  
container\_of\(\), as already done for refcount locks, and remove  
ocfs2\_get\_dentry\_osb\(\)\.  ocfs2\_dismount\_volume\(\) shuts down the DLM before  
freeing the mount context, so callbacks can use it without accessing the  
inode\.  Preserve the existing iput\-before\-unlock order to avoid delaying  
local inode and open lock release until after the DENTRY lock is released\.
