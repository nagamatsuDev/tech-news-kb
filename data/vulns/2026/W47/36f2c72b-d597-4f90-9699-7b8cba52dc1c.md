# A maliciously crafted SBSAR file, when imported or loaded through the Substance in 3ds Max plugin in Autodesk 3ds Max, can trigger an Out\.\.\.

- **ID**: CVE\-2026\-126826
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-19

## 原文

A maliciously crafted SBSAR file, when imported or loaded through the Substance in 3ds Max plugin in Autodesk 3ds Max, can trigger an Out\-of\-Bounds Write vulnerability\. A malicious actor may leverage this vulnerability to cause an application crash, data corruption, or potentially execute arbitrary code in the context of the current process\.
