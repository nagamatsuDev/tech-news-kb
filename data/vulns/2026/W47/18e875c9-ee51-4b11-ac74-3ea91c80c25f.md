# An out\-of\-bounds write was addressed with improved input validation\.

- **危険度**: Critical（緊急） (CVSS 9.8)
- **OS**: macOS, iOS
- **公開**: 2026-11-21

## 原文

An out\-of\-bounds write was addressed with improved input validation\. This issue is fixed in iOS 26\.7\.2 and iPadOS 26\.7\.2, iOS 27\.2 and iPadOS 27\.2, macOS Golden Gate 27\.2, macOS Sequoia 15\.8\.2, macOS Tahoe 26\.7\.2, tvOS 27\.2\. A user may be able to cause unexpected app termination or arbitrary code execution\.
