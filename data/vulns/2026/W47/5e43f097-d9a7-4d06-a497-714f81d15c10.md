# Dokploy is a free, self\-hostable Platform as a Service \(PaaS\)\.

- **ID**: CVE\-2026\-129989
- **危険度**: Critical（緊急） (CVSS 9.9)
- **公開**: 2026-11-18

## 原文

Dokploy is a free, self\-hostable Platform as a Service \(PaaS\)\. Prior to 0\.31\.1, the Nixpacks publishDirectory build setting accepts shell metacharacters and is interpolated into a docker cp command executed through child\_process\.exec\. An authenticated user with access to an application can execute arbitrary commands on the Dokploy host when triggering a Nixpacks deployment, leading to host compromise through the privileged Docker environment\. This issue is fixed in version 0\.31\.1\.
