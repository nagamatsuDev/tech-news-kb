# Missing release of resource after effective lifetime vulnerability in Apache Tomcat's HTTP/2 initial connection handling leads to DoS\.

- **ID**: CVE\-2026\-116830
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-19

## 原文

Missing release of resource after effective lifetime vulnerability in Apache Tomcat's HTTP/2 initial connection handling leads to DoS\.
  
This issue affects Apache Tomcat\: from 11\.0\.0\-M1 through 11\.0\.27, from 10\.1\.0\-M1 through 10\.1\.61, from 9\.0\.20 through 9\.0\.123\.
  
Users are recommended to upgrade to version 11\.0\.29, 10\.1\.62 or 9\.0\.124, which fix the issue\.  
Note\: Tomcat 11\.0\.28 was not released
