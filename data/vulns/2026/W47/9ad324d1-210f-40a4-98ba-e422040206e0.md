# In the Linux kernel, the following vulnerability has been resolved\: smb\: server\: size directory name conversion buffer correctly A 2048\.\.\.

- **ID**: CVE\-2026\-99389
- **危険度**: High（重要） (CVSS 7.5)
- **OS**: Linux
- **公開**: 2026-11-19

## 原文

In the Linux kernel, the following vulnerability has been resolved\:
  
smb\: server\: size directory name conversion buffer correctly
  
A 2048\-byte ASCII directory name needs 4098 bytes when converted to  
UTF\-16, including the terminator\. ksmbd\_convert\_dir\_info\_name\(\) caps  
its allocation at PATH\_MAX and writes past the end of that buffer\.
  
Allocate space for one UTF\-16 code unit per input byte plus the  
terminator\. Use kmalloc\_array\(\) to check the size calculation\.
