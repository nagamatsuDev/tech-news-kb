# Sandboxie\-Plus before 1\.18\.6 contains a local privilege escalation vulnerability in SbieSvc that allows standard users to launch UpdUtil\.\.\.\.

- **ID**: CVE\-2026\-129956
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-16

## 原文

Sandboxie\-Plus before 1\.18\.6 contains a local privilege escalation vulnerability in SbieSvc that allows standard users to launch UpdUtil\.exe as SYSTEM via MSGID\_PROCESS\_RUN\_UPDATER requests\. Attackers can inject code into a signed SandMan\.exe process to bypass the signature check and write attacker\-controlled files to arbitrary paths, achieving SYSTEM code execution\.
