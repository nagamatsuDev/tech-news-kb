# In the Linux kernel, the following vulnerability has been resolved\: mm/khugepaged\: always recheck the pmd in try\_collapse\_pte\_mapped\_thp\.\.\.

- **ID**: CVE\-2026\-99667
- **危険度**: High（重要） (CVSS 7.0)
- **OS**: Linux
- **公開**: 2026-11-20

## 原文

In the Linux kernel, the following vulnerability has been resolved\:
  
mm/khugepaged\: always recheck the pmd in try\_collapse\_pte\_mapped\_thp\(\)
  
try\_collapse\_pte\_mapped\_thp\(\) drops the PTE lock after it has cleared the  
page table, and takes the PMD lock and the PTE lock to remove it\.
  
In between, MADV\_DONTNEED with CONFIG\_PT\_RECLAIM can reclaim the  
page table\. The pmd\_same\(\) check is supposed to handle this, but it is  
only done with CONFIG\_SPLIT\_PTE\_PTLOCKS\.
  
Fix it by performing the check unconditionally\.
  
Fix generated by an LLM and sent by Josef Bacik in private\.
