# In the Linux kernel, the following vulnerability has been resolved\: xfs\: cap the block count of xfs\_iomap\_write\_direct\(\) at one extent \.\.\.

- **ID**: CVE\-2026\-99678
- **危険度**: High（重要） (CVSS 7.5)
- **OS**: Linux
- **公開**: 2026-11-20

## 原文

In the Linux kernel, the following vulnerability has been resolved\:
  
xfs\: cap the block count of xfs\_iomap\_write\_direct\(\) at one extent
  
xfs\_iomap\_write\_direct\(\) reserves blocks for the whole count in an  
unsigned int\. For a pNFS layout the client chooses that count, and an  
RW LAYOUTGET for 16 TiB wraps the reservation and shuts XFS down\.
  
xfs\_bmapi\_write\(\) maps at most XFS\_MAX\_BMBT\_EXTLEN blocks here, so cap  
the count at that\. nfsd asks again for the rest\. The other callers get  
the same mapping as before\.
