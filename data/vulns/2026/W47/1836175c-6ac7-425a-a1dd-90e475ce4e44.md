# PHPGurukul Employee Leaves Management System v2\.1 contains an insufficient verification vulnerability in the password recovery functional\.\.\.

- **ID**: CVE\-2026\-128661
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

PHPGurukul Employee Leaves Management System v2\.1 contains an insufficient verification vulnerability in the password recovery functionality in forgot\-password\.php\. The application allows an unauthenticated user to access the password\-change workflow by providing a valid employee ID and corresponding email address without requiring an additional out\-of\-band verification mechanism\.
