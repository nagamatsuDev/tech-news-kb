# Prime CMS \(@primecms/core\) through 0\.4\.0\-beta\.0 contains an OS command injection vulnerability in the updateSystem GraphQL mutation that \.\.\.

- **ID**: CVE\-2026\-129943
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: JavaScript/TypeScript
- **公開**: 2026-11-16

## 原文

Prime CMS \(@primecms/core\) through 0\.4\.0\-beta\.0 contains an OS command injection vulnerability in the updateSystem GraphQL mutation that allows authenticated administrators to execute shell commands via the package version string\. Attackers can append shell metacharacters to the unvalidated version value, which is passed to child\_process\.exec\(\) in yarn add or npm install commands, executing commands as the server process\.
