# Todoist MCP Server\: Browser DNS rebinding lets websites write and delete Todoist data through local MCP server

- **ID**: CVE\-2026\-76807 / GHSA\-833v\-v58w\-294h
- **危険度**: Critical（緊急） (CVSS 9.3)
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/@doist/todoist\-mcp &lt;\= 10\.3\.2 → 10\.3\.3
- **公開**: 2026-11-18

## 原文

The self\-hosted \`todoist\-mcp\-http\` server accepts browser\-origin MCP requests with attacker\-controlled \`Host\` and \`Origin\` headers\. A malicious website can use DNS rebinding to route its own origin to a victim's local \`127\.0\.0\.1\` MCP server, then invoke Todoist MCP tools without a caller credential\. This affects \`github\.com/Doist/todoist\-mcp\` at commit \`d2903e0d945d2a559d71c091337ad6380511e62f\`, package version \`10\.3\.1\`, when the optional Streamable HTTP server is running\.
