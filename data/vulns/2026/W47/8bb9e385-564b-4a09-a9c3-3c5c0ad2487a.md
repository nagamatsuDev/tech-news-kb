# Vulnerability in the Oracle Application Object Library product of Oracle E\-Business Suite \(component\: Flexfields\)\.

- **ID**: CVE\-2026\-101552
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-10-20

## 原文

Vulnerability in the Oracle Application Object Library product of Oracle E\-Business Suite \(component\: Flexfields\)\.  Supported versions that are affected are 12\.2\.3\-12\.2\.15\. Difficult to exploit vulnerability allows low privileged attacker with network access via HTTP to compromise Oracle Application Object Library\.  Successful attacks of this vulnerability can result in takeover of Oracle Application Object Library\. CVSS 3\.1 Base Score 7\.5 \(Confidentiality, Integrity and Availability impacts\)\.  CVSS Vector\: \(CVSS\:3\.1/AV\:N/AC\:H/PR\:L/UI\:N/S\:U/C\:H/I\:H/A\:H\)\.
