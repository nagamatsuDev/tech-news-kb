# The Multi Step for Contact Form 7 plugin for WordPress is vulnerable to Insecure Direct Object Reference in all versions up to, and inclu\.\.\.

- **ID**: CVE\-2026\-115826
- **危険度**: High（重要） (CVSS 7.4)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The Multi Step for Contact Form 7 plugin for WordPress is vulnerable to Insecure Direct Object Reference in all versions up to, and including, 2\.9\.1 via the '\_cf7mls\_db\_form\_data\_id' parameter due to missing validation on a user controlled key\. This makes it possible for unauthenticated attackers to permanently delete arbitrary stored Contact Form 7 submissions from the database\. Exploitation requires the companion CF7 Database plugin to be active and the per\-form "Save every step, not just the final submission" option to be enabled\.
