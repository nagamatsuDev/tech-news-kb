# The Nexter Extension – Security, Performance, Code Snippets &amp; Site Toolkit plugin for WordPress is vulnerable to Privilege Escalation in \.\.\.

- **ID**: CVE\-2026\-125085
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-20

## 原文

The Nexter Extension – Security, Performance, Code Snippets &amp; Site Toolkit plugin for WordPress is vulnerable to Privilege Escalation in versions up to, and including, 4\.9\.0 This is due to the role\_switcher\_to\_view\_admin\_as\(\) function handling the \`reset\-view\` branch without a capability check or nonce when the caller's own login is supplied, combined with an incomplete cleanup hook \(maybe\_prevent\_switchback\_to\_administrator\) that exits early when the user's current roles equal the stored view role and that is never triggered when WordPress core's WP\_User\:\:set\_role\(\) short\-circuits because the account already has only the target role\. This makes it possible for authenticated attackers, with subscriber\-level access and above, to elevate their privileges to Administrator\.
