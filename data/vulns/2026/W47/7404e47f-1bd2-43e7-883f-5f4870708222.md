# The Unzer Payments plugin for WordPress is vulnerable to Authentication Bypass leading to Account Takeover in all versions up to, and inc\.\.\.

- **ID**: CVE\-2026\-110009
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The Unzer Payments plugin for WordPress is vulnerable to Authentication Bypass leading to Account Takeover in all versions up to, and including, 2\.2\.1\. The vulnerability exists because the Google Pay Express Checkout endpoint \(\`/?wc\-api\=google\_pay\_express\`\), handled by \`startCheckoutDataWithNormalizedCustomerData\`, accepts an attacker\-controlled \`paymentData\.email\` value and passes it to \`createOrGetGuestCustomer\(\)\`, which resolves the submitted email to any existing WordPress user via \`get\_user\_by\('email', \.\.\.\)\` and then calls \`wp\_set\_current\_user\(\)\` and \`wp\_set\_auth\_cookie\(\)\` for the resolved user ID without verifying ownership of the email address, a password, a nonce, an authentication token, or any proof of payment from the payment provider\. This makes it possible for unauthenticated attackers to log in as any existing WordPress user — including administrators — by submitting that user's known email address, receiving valid \`wordpress\_logged\_in\_\*\` session cookies for the targeted account and achieving full site takeover\. The endpoint is entirely unprotected with no capability check, nonce validation, or payment\-provider signature verification applied, and administrator email addresses are frequently discoverable via the WordPress REST API user enumeration endpoint \(\`/wp\-json/wp/v2/users\`\), author archive pages, Gravatar lookups, or site contact footers\.
