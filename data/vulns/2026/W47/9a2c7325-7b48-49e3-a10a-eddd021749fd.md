# Missing release of memory after effective lifetime vulnerability in Apache Tomcat via WebSocket\.

- **ID**: CVE\-2026\-116600
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-19

## 原文

Missing release of memory after effective lifetime vulnerability in Apache Tomcat via WebSocket\.
  
This issue affects Apache Tomcat\: from 11\.0\.0\-M1 through 11\.0\.27, from 10\.1\.0\-M1 through 10\.1\.61, from 9\.0\.22 through 9\.0\.123
  
The following versions were EOL at the time the CVE was created but are known to be affected\: from 8\.5\.0 through 8\.5\.100, from 7\.0\.43 through 7\.0\.109\. Other unsupported versions may also be affected\.
  
Users are recommended to upgrade to version 11\.0\.29, 10\.0\.62 or 9\.0\.124, which fix the issue\.  
Note\: Tomcat 11\.0\.28 was not released
