# heym before 0\.0\.142 contains a remote code execution vulnerability in the Playwright step\-mode node where \_resolve\_expressions\_in\_code su\.\.\.

- **ID**: CVE\-2026\-130753
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: Python
- **公開**: 2026-11-18

## 原文

heym before 0\.0\.142 contains a remote code execution vulnerability in the Playwright step\-mode node where \_resolve\_expressions\_in\_code substitutes workflow values directly into generated Python source\. Authenticated non\-admin users can craft step field values that break out of string literals to execute arbitrary Python as root inside the backend container\.
