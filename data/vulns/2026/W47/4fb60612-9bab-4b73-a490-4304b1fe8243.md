# Next\.js\: Cross\-client response injection and disclosure in self\-hosted Next\.js applications forwarding fetched responses

- **ID**: CVE\-2026\-119348 / GHSA\-pc58\-hwjq\-p385
- **危険度**: Medium（警告）
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/next &gt;\= 16\.0\.0, &lt;\= 16\.4\.4 → 16\.4\.5, npm/next &lt;\= 15\.5\.28 → 15\.5\.29
- **公開**: 2026-11-19

## 原文

Self\-hosted Next\.js applications \(App Router route handlers and the fetch cache\) that return a fetched upstream response unchanged can emit a response whose declared framing does not match the body actually sent\. When such an application sits behind an HTTP/1\.1 reverse proxy that permits pipelined response queueing, a crafted upstream response can desynchronize responses between clients, enabling response injection and disclosure of other clients' responses\.
