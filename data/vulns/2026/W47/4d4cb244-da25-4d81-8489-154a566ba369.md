## 原文

\#\# Summary OliveTin's \`shellAfterCompleted\` post\-execution hook injects unsanitized variables — including arbitrary command output \(\`output\`\), the authenticated username \(\`ot\_username\`\), and the exit code \(\`exitCode\`\) — directly into a shell command template processed by \`sh \-c\`\. Unlike the main action's argument handling, \*\*no \`checkShellArgumentSafety\` validation is applied\*\* to these variables\.
