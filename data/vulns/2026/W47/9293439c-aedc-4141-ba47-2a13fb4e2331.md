# A security vulnerability has been detected in SourceCodester Simple Form Builder Web App 1\.0\.

- **危険度**: High（重要） (CVSS 7.3)
- **言語**: PHP
- **公開**: 2026-11-19

## 原文

A security vulnerability has been detected in SourceCodester Simple Form Builder Web App 1\.0\. This impacts the function save\_response of the file /classes/Forms\.php\. The manipulation of the argument q\[&lt;index&gt;\] leads to unrestricted upload\. Remote exploitation of the attack is possible\. The exploit has been disclosed publicly and may be used\.
