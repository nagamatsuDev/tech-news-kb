# isomorphic\-git is a pure JavaScript implementation of Git for Node\.js and browsers\.

- **ID**: CVE\-2026\-77355
- **危険度**: High（重要） (CVSS 8.8)
- **OS**: Windows
- **言語**: JavaScript/TypeScript
- **公開**: 2026-11-20

## 原文

isomorphic\-git is a pure JavaScript implementation of Git for Node\.js and browsers\. Prior to 1\.38\.7, tree\-entry validation in src/models/GitTree\.js does not reject the Windows NTFS reserved pathname alias \.git\:\:\$INDEX\_ALLOCATION\. When clone\(\) or checkout materializes an attacker\-controlled tree containing this alias on Windows using an NTFS filesystem, the alias resolves to the active \.git directory and permits writes to trusted repository metadata instead of a normal worktree directory\. A malicious repository or object stream can therefore poison repository configuration, hooks, refs, attributes, or other gitdir state\. Strict hosting that rejects hasDotgit objects can block the crafted tree, and non\-NTFS systems do not interpret the pathname as the active gitdir\. isomorphic\-git performs the gitdir write but does not itself execute the written hook or configuration; a later native Git or compatible\-tool action, such as processing a poisoned core\.fsmonitor value, can execute configured commands as the victim developer or CI identity\. This issue is fixed in version 1\.38\.7\.
