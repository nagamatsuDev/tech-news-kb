# A flaw has been found in hankcs HanLP up to 2\.1\.6\.

- **ID**: CVE\-2026\-133835
- **危険度**: High（重要） (CVSS 7.3)
- **公開**: 2026-11-20

## 原文

A flaw has been found in hankcs HanLP up to 2\.1\.6\. Impacted is the function uncompress of the file hanlp/utils/io\_util\.py of the component TAR Archive Extraction Handler\. This manipulation causes path traversal\. The attack is possible to be carried out remotely\. The exploit has been published and may be used\. Upgrading to version 2\.1\.7 is recommended to address this issue\. Patch name\: feb0f82d12762cf4e687b9926efd90c672857780\. You should upgrade the affected component\.
