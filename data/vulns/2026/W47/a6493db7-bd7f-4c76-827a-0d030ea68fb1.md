# Bazarr is a companion application to Sonarr and Radarr\.

- **ID**: CVE\-2026\-130156
- **危険度**: Critical（緊急） (CVSS 9.4)
- **公開**: 2026-11-18

## 原文

Bazarr is a companion application to Sonarr and Radarr\. Prior to 1\.6\.3\-beta\.11, the /api/subtitles/subtitles\-info handler uses SubtitleNameContents\.get\(\) in subtitles\_contents\.py and reads the caller\-supplied subtitlePath after checking only its subtitle extension; because the resolved path is not confined to files indexed by Bazarr, traversal can read files outside the media library\. The /api/subtitles/subtitles handler in subtitles\.py passes caller\-supplied path and reference to sync and translation without per\-path authorization, allowing an out\-of\-library reference file to be read and output to overwrite a file outside the media library\. The authenticate decorator gates both endpoints when API authentication is enabled, while auth \= None allows access without credentials\. Both paths can affect only files that the Bazarr process can read or write\. This issue is fixed in version 1\.6\.3\-beta\.11\.
