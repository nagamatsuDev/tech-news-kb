# Fabio\: Access\-control bypass through unnormalized request paths

- **ID**: CVE\-2026\-104099 / GHSA\-4hrh\-34w3\-5ww8
- **危険度**: Critical（緊急） (CVSS 9.1)
- **言語**: Go
- **パッケージ**: Go/github\.com/fabiolb/fabio &lt; 1\.7\.3 → 1\.7\.3
- **公開**: 2026-11-19

## 原文

\#\# Summary Route selection uses the raw un\-normalized request path, and the per\-route ACL and basic\-auth gates hang off that selection, so a dot\-segment, encoded\-dot, or double\-slash variant of a protected path selects a different route, skips both gates, and is forwarded to the backend which normalizes and serves the protected resource\. Unauthenticated; complete bypass of the access control the operator configured\. Confirmed at HEAD b841544\. Direct peers\: Traefik CVE\-2023\-47106, Envoy CVE\-2019\-9901\. \#\# The defect fabio never normalizes the request path\. A repository\-wide search for path\.Clean
