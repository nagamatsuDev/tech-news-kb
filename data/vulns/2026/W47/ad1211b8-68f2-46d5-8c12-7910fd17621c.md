# Fabio is an HTTP\(S\) and TCP router for deploying applications managed by consul\.

- **ID**: CVE\-2026\-104099
- **危険度**: Critical（緊急） (CVSS 9.1)
- **公開**: 2026-11-19

## 原文

Fabio is an HTTP\(S\) and TCP router for deploying applications managed by consul\. Prior to 1\.7\.3, route/table\.go selects targets using raw req\.URL\.Path, while proxy/http\_proxy\.go applies per\-route ACL and basic\-auth checks to the selected target and forwards the raw path to the origin\. Dot\-segment, encoded\-dot, or repeated\-slash variants can fall through to a less restrictive route that reaches the same backend; the backend then normalizes the path and serves the protected resource without the configured access controls\. A less restrictive fallback route must reach the same backend; without one, the request returns 404\. This issue is fixed in version 1\.7\.3\.
