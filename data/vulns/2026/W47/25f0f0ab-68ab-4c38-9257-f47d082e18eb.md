# Vtiger CRM through 8\.4\.0 contains a PHP code injection vulnerability that allows authenticated administrators to inject code via the upda\.\.\.

- **ID**: CVE\-2026\-132748
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-19

## 原文

Vtiger CRM through 8\.4\.0 contains a PHP code injection vulnerability that allows authenticated administrators to inject code via the updatedFields parameter into config\.inc\.php\. Attackers can supply a crafted HELPDESK\_SUPPORT\_EMAIL\_ID value that passes email validation but closes the PHP string literal to execute arbitrary operating system commands\.
