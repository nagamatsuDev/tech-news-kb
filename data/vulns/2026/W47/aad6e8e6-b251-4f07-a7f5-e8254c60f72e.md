# Silverstripe Framework\: i18nTextCollectorTaskWriterパラメータによるRCE

- **ID**: CVE\-2026\-91115 / GHSA\-c94f\-87xg\-65wf
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **パッケージ**: Packagist/silverstripe/framework &gt;\= 6\.0\.0, &lt; 6\.2\.13 → 6\.2\.13
- **公開**: 2026-11-16

## 原文

\#\#\# Impact The writer option of the i18nTextCollectorTask dev task was passed to the injector without validation\. A crafted dev task URL could create arbitrary objects with attacker\-controlled constructor arguments and run code on the server\. Because the dev task did not ask for confirmation, an administrator could be tricked into running it by following a link\. On a site in dev mode, no login was needed\. CMS 5 is not affected\. \#\#\# Reported by Jack Wallace
