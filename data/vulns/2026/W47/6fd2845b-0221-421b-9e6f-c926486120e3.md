# October\: Media Library Crop Handler Bypasses Upload Extension Allowlist

- **ID**: CVE\-2026\-63193 / GHSA\-mqwx\-84vv\-mp26
- **危険度**: Medium（警告） (CVSS 5.5)
- **言語**: PHP
- **パッケージ**: Packagist/october/october &lt;\= 3\.7\.13, Packagist/october/october &gt;\= 4\.0\.0, &lt;\= 4\.3\.1 → 4\.3\.2
- **公開**: 2026-11-19

## 原文

The Media Library upload handler validates the destination filename against an extension allowlist \(\`default\_extensions\`\), rejecting types such as \`php\`, \`phtml\`, \`html\`, and \`htm\`\. The image crop handler \(\`MediaManager\:\:onCropImage\` / \`cropImage\`\) did not perform this check\. The destination filename was taken from user input, the extension was extracted from it, and the staged bytes were written to the public media folder under that attacker\-chosen extension\.
