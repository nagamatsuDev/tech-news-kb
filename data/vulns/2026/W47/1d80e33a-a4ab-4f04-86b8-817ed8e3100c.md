# Bolt ListFormatHelper SQL injection

- **ID**: CVE\-2026\-77378 / GHSA\-r7h9\-qx4h\-77j5
- **危険度**: Medium（警告） (CVSS 6.5)
- **言語**: PHP
- **パッケージ**: Packagist/bolt/core &lt; 6\.1\.4 → 6\.1\.4
- **公開**: 2026-11-20

## 原文

\#\#\# Impact SQL Injection in ListFormatHelper allows authenticated users with the upload permission to execute arbitrary SQL queries and exfiltrate sensitive database contents through the /async/select\-options endpoint when general/caching/list\_format is enabled\. \#\#\# Patches This has been patched in Bolt 6\.1\.4\.
