# Mitel MiCollab Unrestricted Upload of File with Dangerous Type Vulnerability

- **ID**: CVE\-2026\-133275
- **危険度**: Medium（警告） (CVSS 5.3) / 🔥 悪用確認 (CISA KEV)
- **公開**: 2026-11-19

## 原文

A vulnerability in the Audio, Web, and Video Conferencing \(AWV\) component of Mitel MiCollab through 10\.3 \(10\.3\.0\.18\) could allow an unauthenticated attacker to conduct an arbitrary file upload attack due to insufficient file type validation\. A successful exploit could allow an attacker to upload arbitrary files to the target system\. This is MTLVULN\-1861\.
