# NodePressは、認証されていないリモートアタッカーが管理者になることを可能にする認証バイパス脆弱性を含む。

- **ID**: CVE\-2026\-129952
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-16

## 概要（機械翻訳）

NodePressから8\.5\.1までの認証は、認証されていないリモートアタッカーがハードコードされた'nodepress\-secret'フォールバックキーでJWTsを偽造することで管理者アクセスを可能にする認証バイパス脆弱性を含んでいる。は、NWTsのセキュリティ保護機能を利用して、セキュリティを保護できる。攻撃者はデフォルトのイシュアー、オーディエンス、ロール'admin'でHS256ベアトークンにサインして、記事、コメント、オプション、およびファイル管理用の管理者のみのAPIにアクセスすることができる。は、\.\.\.\.\.\.\.\.\. ファイル管理。

## 原文

NodePress through 8\.5\.1 contains an authentication bypass vulnerability that allows unauthenticated remote attackers to gain administrator access by forging JWTs with the hardcoded 'nodepress\-secret' fallback key\. Attackers can sign HS256 bearer tokens with the default issuer, audience, and role 'admin' to access administrator\-only APIs for article, comment, options, and file management\.
