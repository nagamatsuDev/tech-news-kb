# OwnTracks Recorder before 1\.0\.5 contains a format string vulnerability in json\_response\(\) and related output functions that allows unauth\.\.\.

- **ID**: CVE\-2026\-131852
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-18

## 原文

OwnTracks Recorder before 1\.0\.5 contains a format string vulnerability in json\_response\(\) and related output functions that allows unauthenticated attackers to execute code by storing a malicious tid value\. Attackers can publish locations via POST /pub or MQTT with printf specifiers in tid, then read them back through GET /api/0/last to leak addresses and write memory\.
