# IO\:\:Socket\:\:SSL\:\:PublicSuffix versions through 2\.099 for Perl allow code injection via a fetched list line that closes the built\-in data \.\.\.

- **ID**: CVE\-2026\-129892
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-18

## 原文

IO\:\:Socket\:\:SSL\:\:PublicSuffix versions through 2\.099 for Perl allow code injection via a fetched list line that closes the built\-in data heredoc when update\_self\_from\_url rewrites the module's source\.
  
The rewrite copies the module's source down to the built\-in list's heredoc and appends each fetched line below it\. Nothing checks that a line looks like a domain\. A line that is not a comment loses only what follows a \`//\` and its trailing whitespace, so a line reading END\_BUILTIN\_DATA is appended as it stands and ends the data block in the rewritten file\. Every fetched line after it is Perl\.
  
Arbitrary Perl runs in every process that loads IO\:\:Socket\:\:SSL, which loads this module unconditionally, until the file is reinstalled\. The attacker must control the fetched list, through the cleartext default URL or a caller\-supplied one, and the updater must run with write access to the installed module\.
