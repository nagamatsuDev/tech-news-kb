# In Splunk Enterprise Security versions below 8\.7\.0, a user that holds a role with the mc\_investigation\_read capability could cause the Ri\.\.\.

- **ID**: CVE\-2026\-131199
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-19

## 原文

In Splunk Enterprise Security versions below 8\.7\.0, a user that holds a role with the mc\_investigation\_read capability could cause the Risk Event Timeline Representational State Transfer \(REST\) API to run arbitrary Search Processing Language \(SPL\) commands with elevated permissions\. With this access, the user could expose stored credentials and modify indexes and lookup data available to those permissions\.  
The vulnerability is possible because the affected REST API does not validate request values before including them in search macro arguments\.  
For more information see Capability reference for Splunk Enterprise Security \(https\://help\.splunk\.com/en/splunk\-enterprise\-security\-8/install/8\.7/installation/capability\-reference\-for\-splunk\-enterprise\-security\) and Risk analysis \(https\://help\.splunk\.com/en/splunk\-enterprise\-security\-8/user\-guide/8\.7/analytics/risk\-analysis\) in the Splunk documentation\.
