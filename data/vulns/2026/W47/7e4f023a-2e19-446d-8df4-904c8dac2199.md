# Git LFS may execute arbitrary commands via crafted Git LFS configurations

- **ID**: CVE\-2026\-105803 / GHSA\-x72p\-hmqp\-46hw
- **危険度**: High（重要）
- **言語**: Go
- **パッケージ**: Go/github\.com/git\-lfs/git\-lfs &gt;\= 1\.3\.0, &lt;\= 2\.13\.3, Go/github\.com/git\-lfs/git\-lfs/v3 &gt;\= 3\.0\.0, &lt; 3\.8\.1 → 3\.8\.1
- **公開**: 2026-11-19

## 原文

\#\#\# Impact When fetching objects from a malicious repository, Git LFS may execute an arbitrary command or binary after failing to sufficiently restrict the set of configuration options defined in an \`\.lfsconfig\` file in the repository\. Git LFS permits a limited set of configuration options to be defined in an \`\.lfsconfig\` file at the root of a Git repository, but does not filter these options correctly if their keys contain certain additional components, which allows an attacker to mimic options that configure Git LFS to use a custom command to transfer objects\.
