# In the Linux kernel, the following vulnerability has been resolved\: SUNRPC\: fix oversized GSS proxy token copy gss\_read\_proxy\_verf\(\) al\.\.\.

- **ID**: CVE\-2026\-99355
- **危険度**: High（重要） (CVSS 8.1)
- **OS**: Linux
- **公開**: 2026-11-19

## 原文

In the Linux kernel, the following vulnerability has been resolved\:
  
SUNRPC\: fix oversized GSS proxy token copy
  
gss\_read\_proxy\_verf\(\) allocates one page per token chunk, but it copies the  
entire linear head of an RPC request into in\_token\-&gt;pages\[0\]\. A UDP datagram  
can leave more than PAGE\_SIZE bytes in the linear head, so a large  
RPCSEC\_GSS INIT token overwrites following pages\.
  
Copy the linear head in page\-sized chunks before switching to the request  
page array\. The linear head itself can span multiple pages\.
