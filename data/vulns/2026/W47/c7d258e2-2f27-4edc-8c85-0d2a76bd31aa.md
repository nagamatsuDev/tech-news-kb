# fzf\: Predictable FIFO path in zsh completion allows local symlink attack / arbitrary file overwrite as the victim user \(\_fzf\_feed\_fifo\)

- **ID**: CVE\-2026\-121717 / GHSA\-7rj6\-7pqx\-v7rm
- **危険度**: Medium（警告） (CVSS 5.0)
- **言語**: Go
- **パッケージ**: Go/github\.com/junegunn/fzf &lt;\= 0\.74\.4 → 0\.74\.5
- **公開**: 2026-11-19

## 原文

\#\#\# Summary \`shell/completion\.zsh\` feeds every trigger\-driven zsh completion through a FIFO at a predictable, PID\-based path in shared \`/tmp\` \(\`fzf\-complete\-fifo\-\$\$\`\), without checking the failure of \`rm \-f\`/\`mkfifo\`\. On a multi\-user host, another local user can pre\-create that path as a symlink to a victim\-writable file \(e\.g\. \`\~/\.bashrc\`\), causing the victim's own completion to overwrite it with the completion stream — with attacker\-influenced content \(e\.g\. via process names in \`ps\` output\), escalating to code execution at the victim's next login\. A pre\-created plain FIFO instead leaks/blocks
