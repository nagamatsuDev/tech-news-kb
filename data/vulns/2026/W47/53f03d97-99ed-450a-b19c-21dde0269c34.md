# An out\-of\-bounds write issue was addressed with improved bounds checking\.

- **危険度**: Critical（緊急） (CVSS 9.8)
- **OS**: macOS
- **公開**: 2026-11-21

## 原文

An out\-of\-bounds write issue was addressed with improved bounds checking\. This issue is fixed in macOS Golden Gate 27\.2, macOS Sequoia 15\.8\.2, macOS Tahoe 26\.7\.2\. Connecting to a malicious NFS server may lead to kernel memory corruption\.
