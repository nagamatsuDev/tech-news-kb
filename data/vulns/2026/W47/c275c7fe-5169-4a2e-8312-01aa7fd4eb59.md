# Use\-after\-free in magic method backtraces can lead to remote code execution\.

- **ID**: CVE\-2026\-129474
- **危険度**: Critical（緊急） (CVSS 9.2)
- **言語**: PHP
- **公開**: 2026-11-19

## 原文

Use\-after\-free in magic method backtraces can lead to remote code execution\.
  
When collecting the arguments of a method call handled by \_\_call\(\) or \_\_callStatic\(\) for a backtrace, PHP can read stale values that may refer to freed memory\. If a fatal error such as exceeding memory\_limit occurs while an application enters such a call, with fatal\_error\_backtraces enabled \(the default\) and zend\.exception\_ignore\_args disabled, a remote attacker who controls enough request data to influence memory allocation may cause memory corruption, crash the PHP worker or, with knowledge of memory addresses, execute arbitrary code\. php\.ini\-production enables zend\.exception\_ignore\_args, which prevents this\.
  
This issue affects PHP versions 8\.5\.\* before 8\.5\.13\.
