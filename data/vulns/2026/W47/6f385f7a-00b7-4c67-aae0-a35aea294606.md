# VideoLAN libaacs 0\.7\.0 through 0\.12\.0 on non\-macOS, non\-Windows builds contains stack\-based buffer overflows in aacs\_resolve\_path\(\) in sr\.\.\.

- **ID**: CVE\-2026\-133306
- **危険度**: High（重要） (CVSS 7.0)
- **OS**: Windows, macOS
- **公開**: 2026-11-19

## 原文

VideoLAN libaacs 0\.7\.0 through 0\.12\.0 on non\-macOS, non\-Windows builds contains stack\-based buffer overflows in aacs\_resolve\_path\(\) in src/file/path\.c from length checks against the wrong buffer\. Local attackers can place a symlink with a long target on a disc path a user opens to overflow resolved\_path\[\] and link\[\], crashing the process or potentially executing code if mitigations are bypassed\.
