# NLTK\: Uncontrolled recursion in Toolbox settings helpers causes denial of service via deeply nested input

- **ID**: CVE\-2026\-129228 / GHSA\-f2h2\-f4fc\-p978
- **危険度**: Medium（警告） (CVSS 5.3)
- **言語**: Python
- **パッケージ**: PyPI/nltk &lt;\= 3\.10\.3 → 3\.10\.4
- **公開**: 2026-11-19

## 原文

\#\# Root Cause The Toolbox settings\-tree helpers recurse over the parsed element tree without any depth bound\. \`\_to\_settings\_string\` \(\`nltk/toolbox\.py\:418\`\), \`remove\_blanks\` \(\`nltk/toolbox\.py\:432\`\), \`add\_default\_fields\` \(\`nltk/toolbox\.py\:451\`\), \`\_sort\_fields\` \(\`nltk/toolbox\.py\:484\`\), and \`add\_blank\_lines\` \(\`nltk/toolbox\.py\:502,516\`\) each recurse once per element level with no depth counter or explicit stack\.
