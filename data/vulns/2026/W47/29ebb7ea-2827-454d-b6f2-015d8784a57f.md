# The Libreswan pluto daemon dereferences a NULL pointer when a CERT payload is received with an empty PKCS\#7 payload, causing the daemon t\.\.\.

- **ID**: CVE\-2026\-110339
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-16

## 原文

The Libreswan pluto daemon dereferences a NULL pointer when a CERT payload is received with an empty PKCS\#7 payload, causing the daemon to crash and restart\. The NSS function SEC\_PKCS7GetCertificateList\(\) was used to check whether the content was empty, but this check did not trigger if the non\-empty content of the PKCS\#7 wrapped payload was an empty list\. Continued triggering of this vulnerability can lead to a denial of service\. Remote code execution is not possible\. Authentication is not required to trigger this vulnerability\.
