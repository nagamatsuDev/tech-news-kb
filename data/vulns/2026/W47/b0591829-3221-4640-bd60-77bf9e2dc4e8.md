# HTSlib is a library for reading and writing bioinformatics file formats\.

- **ID**: CVE\-2026\-62257
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-19

## 原文

HTSlib is a library for reading and writing bioinformatics file formats\. Prior to 1\.21\.2, 1\.22\.3, 1\.23\.2, and 1\.24, the experimental CRAM v4 XPACK and XRLE decoders cache expanded block pointers at indexes beyond the 512\-element slice\-&gt;block\_by\_id array\. An array index partially controlled by data in the input file first causes an out\-of\-bounds read to determine whether a block is cached; a null value then causes allocation of a block and an out\-of\-bounds pointer write to the same element\. The invalid read may crash the process, while the write may corrupt heap state and could permit arbitrary code execution\. This issue is fixed in versions 1\.21\.2, 1\.22\.3, 1\.23\.2, and 1\.24\.
