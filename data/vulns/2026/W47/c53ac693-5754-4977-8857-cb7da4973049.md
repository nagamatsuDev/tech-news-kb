# NocoDB before 2026\.10\.0 contains an improper access control vulnerability that allows Creator\-role users to attach NocoDB's internal data\.\.\.

- **ID**: CVE\-2026\-130704
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-18

## 原文

NocoDB before 2026\.10\.0 contains an improper access control vulnerability that allows Creator\-role users to attach NocoDB's internal database by supplying is\_meta and is\_local flags\. Attackers can create sources or bases with these flags to expose user, token and integration tables, then read and modify records including user roles\.
