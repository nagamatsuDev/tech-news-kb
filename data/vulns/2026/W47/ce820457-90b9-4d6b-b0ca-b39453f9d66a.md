# Loop with Unreachable Exit Condition \('Infinite Loop'\) vulnerability in device certificate verification in nerves\-hub nerves\_hub\_web allo\.\.\.

- **ID**: CVE\-2026\-125275
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-11-17

## 原文

Loop with Unreachable Exit Condition \('Infinite Loop'\) vulnerability in device certificate verification in nerves\-hub nerves\_hub\_web allows an unauthenticated remote attacker to cause a denial of service via a TLS client certificate whose CA is not registered\. When a client certificate chains to a root in the device endpoint's trust store but no CA in the chain is registered in NervesHub, NervesHub\.SSL\.decide/2 refuses it with the reason \:unknown\_ca\. Erlang/OTP ssl reads that reason as a missing trust anchor, looks for an alternative root, finds the same root and validates again without end\. The handshake process queries the database on each pass and keeps running after the client disconnects, until the node restarts\.
  
The device endpoint trusts the public roots from CAStore unless DEVICE\_SSL\_CACERTFILE is set, so a client certificate from a public CA whose chain allows client authentication is sufficient\. A chain that ends at a root outside the trust store is refused once\.
  
This issue affects nerves\_hub\: from 1\.0\.0 before 2\.5\.4\.
