# 7\-Zip File Manager before 26\.03 fails to detect archive entry names padded with Unicode space characters, allowing attackers to bypass th\.\.\.

- **ID**: CVE\-2026\-130067
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-16

## 原文

7\-Zip File Manager before 26\.03 fails to detect archive entry names padded with Unicode space characters, allowing attackers to bypass the deceptive file name warning in CPanel\:\:IsVirus\_Message\. Attackers can craft archive entries like a PDF name followed by ideographic spaces and \.hta to hide the real extension, executing script content via ShellExecuteExW when opened\.
