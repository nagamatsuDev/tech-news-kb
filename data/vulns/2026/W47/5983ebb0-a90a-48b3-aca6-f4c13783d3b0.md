# Wavelog is web\-based amateur radio logging software\.

- **ID**: CVE\-2026\-55508
- **危険度**: Critical（緊急） (CVSS 9.4)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

Wavelog is web\-based amateur radio logging software\. Prior to 2\.5, the callsign parameter accepted by POST /oqrs/search\_log in application/controllers/Oqrs\.php search\_log\(\) reaches application/models/Oqrs\_model\.php search\_log\(\), where it is concatenated directly into a raw SQL WHERE clause without parameter binding\. An unauthenticated remote attacker can use UNION\-based SQL injection to read arbitrary application database records, including account data, password hashes, API keys, station credentials, reset tokens, QSO data, and station metadata\. Disclosure of password reset tokens can be combined with the forgot\_password workflow to take over accounts, including administrator accounts\. This issue is fixed in version 2\.5\.
