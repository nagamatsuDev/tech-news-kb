- **危険度**: High（重要） (CVSS 7.5)

## 原文

\#\#\# Summary DependencyGraph\.tree\(\)/triples\(\) walk the parsed dependency structure using plain, unbounded Python recursion — one stack frame per edge in the graph — and never use the class's own cycle detector\.
