# In the Linux kernel, the following vulnerability has been resolved\: NFSD\: copy SETXATTR data from all XDR buffer segments nfsd4\_vbuf\_fr\.\.\.

- **ID**: CVE\-2026\-99370
- **危険度**: Critical（緊急） (CVSS 9.4)
- **OS**: Linux
- **公開**: 2026-11-19

## 原文

In the Linux kernel, the following vulnerability has been resolved\:
  
NFSD\: copy SETXATTR data from all XDR buffer segments
  
nfsd4\_vbuf\_from\_vector\(\) manually copies the head followed by whole  
pages starting at offset zero\. This assumes that all remaining data  
starts at the beginning of the page array and that no data is stored  
in the tail\.
  
However, nfsd4\_decode\_setxattr\(\) passes an xdr\_buf returned by  
xdr\_stream\_subsegment\(\)\. Such a sub\-buffer can have a nonzero  
page\_base and can span its page and tail segments\. Ignoring that  
layout can copy the wrong bytes into the value passed to  
vfs\_setxattr\(\)\.
  
Use read\_bytes\_from\_xdr\_buf\(\), which observes the complete xdr\_buf  
layout\.
