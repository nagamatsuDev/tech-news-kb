- **ID**: CVE\-2026\-83816 / GHSA\-3mgh\-93r5\-r7jf
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: Rust, JavaScript/TypeScript
- **パッケージ**: crates\.io/codewhale\-tui &lt;\= 0\.8\.67 → 0\.9\.0, npm/codewhale &lt;\= 0\.8\.67 → 0\.9\.0
- **公開**: 2026-11-16

## 原文

\#\#\# Maintainer resolution The CodeWhale maintainers validated this report\. CodeWhale 0\.8\.67 and earlier are affected\. Version 0\.9\.0 contains the fix in commit 208421b9d23d81cea3311a1eeb2a2ea81d637686\. Users should upgrade to 0\.9\.0 or later\. The original reporter analysis is preserved below\. \#\# Summary The interactive Agent profile of DeepSeek\-TUI \(CodeWhale\) is explicitly documented to gate \*\*every\*\* shell command behind an approval prompt \(config\.rs\:3725\-3736\)\. However, \`ExecShellTool\:\:approval\_requirement\_for\(&amp;tool\_input\)\` downgrades the requirement from \`Required\` to \`Auto\` for any command
