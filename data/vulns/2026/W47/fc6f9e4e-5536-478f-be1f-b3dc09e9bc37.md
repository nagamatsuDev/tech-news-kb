# CodeWhale is a DeepSeek and MiMo coding agent for the terminal\.

- **ID**: CVE\-2026\-83816
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-16

## 原文

CodeWhale is a DeepSeek and MiMo coding agent for the terminal\. Prior to 0\.9\.0, the ExecShellTool\:\:approval\_requirement\_for path used is\_parallel\_readonly\_command to downgrade commands to automatic approval based on a flag\-stripped command allowlist\. The allowlist treated fd, rg, and git grep as read\-only even when fd \-x or fd \-\-exec, rg \-\-pre, or git grep \-\-open\-files\-in\-pager selected an external program\. registered\_tool\_approval\_required returned without displaying a prompt for that automatic classification, and the later command\-safety check also treated the base utilities as safe\. Attacker\-controlled content that influenced an agent tool call could therefore cause arbitrary program execution on the developer host without the approval promised by the default interactive profile, resulting in unauthorized access, modification, or disruption\. This issue is fixed in version 0\.9\.0\.
