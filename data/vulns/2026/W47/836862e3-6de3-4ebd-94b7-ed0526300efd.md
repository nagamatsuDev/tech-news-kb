# Gammapy through 2\.1 contains a code injection vulnerability in WcsGeom\.from\_header\(\) that passes the WCSSHAPE FITS header card to eval\(\)\.

- **ID**: CVE\-2026\-134694
- **危険度**: High（重要） (CVSS 7.8)
- **言語**: Python
- **公開**: 2026-11-22

## 原文

Gammapy through 2\.1 contains a code injection vulnerability in WcsGeom\.from\_header\(\) that passes the WCSSHAPE FITS header card to eval\(\)\. Attackers can supply a crafted \.fits file with a Python expression in WCSSHAPE, executing code as the user who loads it via Map\.read\(\)\.
