# mcp\-ssh\-manager is an MCP server for managing servers over SSH with human approval, an encrypted vault, and a live audit trail\.

- **ID**: CVE\-2026\-77383
- **危険度**: High（重要） (CVSS 8.7)
- **公開**: 2026-11-20

## 原文

mcp\-ssh\-manager is an MCP server for managing servers over SSH with human approval, an encrypted vault, and a live audit trail\. Prior to 3\.6\.7, ssh\_db\_list, ssh\_db\_dump, ssh\_db\_import, and ssh\_db\_restore in src/database\-manager\.js interpolate caller\-controlled database, table, collection, file path, user, host, port, and password values into shell\-evaluated command strings without neutralization\. Shell metacharacters in these arguments therefore execute arbitrary commands on the configured SSH target as the account used by the MCP server\. ssh\_db\_list is classified as read\-only and remains available in readonly and restricted server security modes, so this path bypasses the command\-execution boundary those modes are intended to enforce\. The dump and import builders are blocked in readonly mode but remain vulnerable in the default unrestricted mode\. The earlier version 3\.6\.5 hardening covered only ssh\_db\_query query text; it did not protect the list, dump, import, or restore builders, or the connection flags used by query builders\. This issue is fixed in version 3\.6\.7\.
