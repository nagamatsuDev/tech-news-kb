# Snap7 through 1\.4\.3 contains an out\-of\-bounds write vulnerability in TSnap7MicroClient\:\:opReadMultiVars\(\) that allows malicious PLCs to o\.\.\.

- **ID**: CVE\-2026\-131848
- **危険度**: High（重要） (CVSS 7.4)
- **公開**: 2026-11-18

## 原文

Snap7 through 1\.4\.3 contains an out\-of\-bounds write vulnerability in TSnap7MicroClient\:\:opReadMultiVars\(\) that allows malicious PLCs to overflow client buffers via unchecked DataLength fields\. Attackers controlling or impersonating a PLC can return crafted ReadVar responses to Cli\_ReadMultiVars\(\) callers, writing up to 65535 bytes per item to corrupt memory and crash clients\.
