# A security flaw has been discovered in D\-Link DIR\-600L 2\.17b02\.

- **ID**: CVE\-2026\-133993
- **危険度**: Critical（緊急） (CVSS 10.0)
- **公開**: 2026-11-21

## 原文

A security flaw has been discovered in D\-Link DIR\-600L 2\.17b02\. This affects the function FUN\_0040efb0 of the file gena\.cgi of the component GENA Subscription Handler\. Performing a manipulation of the argument service results in stack\-based buffer overflow\. The attack is possible to be carried out remotely\. The exploit has been released to the public and may be used for attacks\.
