# The Shortcodes and extra features for Phlox theme plugin for WordPress is vulnerable to Local File Inclusion in all versions up to, and i\.\.\.

- **ID**: CVE\-2026\-89095
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-20

## 原文

The Shortcodes and extra features for Phlox theme plugin for WordPress is vulnerable to Local File Inclusion in all versions up to, and including, 2\.17\.22 via the 'extra\_template\_path' parameter parameter\. This makes it possible for unauthenticated attackers to include and execute arbitrary \.php files on the server, allowing the execution of any PHP code in those files\. This can be used to bypass access controls, obtain sensitive data, or achieve code execution in cases where \.php file types can be uploaded and included\. The slug\-based allowlist introduced as the fix for CVE\-2023\-37888 constrains only the template\_part\_file filename suffix and does not validate the extra\_template\_path directory component, meaning path traversal sequences are fully functional against this parameter\.
