# WeGIA is a web manager for charitable institutions\.

- **ID**: CVE\-2026\-69187
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-17

## 原文

WeGIA is a web manager for charitable institutions\. Prior to 3\.9\.1, web/controle/control\.php authorizes FuncionarioControle requests only by checking whether an authenticated employee has a permission row for resource 11 or 91, while MiddlewareDAO\:\:verificarPermissao\(\) does not compare the stored id\_acao value or authorize the requested method\. An employee with any such permission and a valid CSRF token from the employee's own session can invoke FuncionarioControle\:\:adicionarPermissao, FuncionarioControle\:\:alterarPermissao, or FuncionarioControle\:\:excluirPermissao to add, change, or remove permissions for arbitrary roles\. This can grant higher action levels over sensitive resources, expose or modify protected employee, patient, configuration, and administrative data, or disrupt legitimate access by changing other roles\. This issue is fixed in version 3\.9\.1\.
