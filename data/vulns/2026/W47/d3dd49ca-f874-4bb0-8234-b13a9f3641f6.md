# An Unrestricted File Upload vulnerability in the admin panel of PHPGurukul News Portal Project V4\.1 allows authenticated attackers to upl\.\.\.

- **ID**: CVE\-2026\-128668
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

An Unrestricted File Upload vulnerability in the admin panel of PHPGurukul News Portal Project V4\.1 allows authenticated attackers to upload files with arbitrary content by bypassing weak filename extension validation in add\-post\.php and change\-image\.php\. Although files are renamed with an image extension upon storage, the lack of MIME type and content validation enables content spoofing, storage of malicious markup, and creates a vector for Remote Code Execution \(RCE\) with server misconfigurations or secondary Local File Inclusion\.
