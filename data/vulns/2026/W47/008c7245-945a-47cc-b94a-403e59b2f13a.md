# In the Linux kernel, the following vulnerability has been resolved\: mm/gup\: fix out\-of\-bounds write for nr\_pages \=\= 0 in GUP\-fast With \.\.\.

- **ID**: CVE\-2026\-99662
- **危険度**: High（重要） (CVSS 7.8)
- **OS**: Linux
- **公開**: 2026-11-20

## 原文

In the Linux kernel, the following vulnerability has been resolved\:
  
mm/gup\: fix out\-of\-bounds write for nr\_pages \=\= 0 in GUP\-fast
  
With nr\_pages \=\= 0, GUP\-fast still enters its page table walk and can  
write past the caller's page array\. The old end &lt;\= start check caught  
empty ranges, but was replaced with an overflow check\.
  
Users such as OrangeFS can pass a zero page count derived from a  
userspace\-supplied length\. So let's return zero for nr\_pages \=\= 0 before  
starting the walk, just like GUP\-slow\.
  
Fix generated by an LLM and sent by Chris Mason in private\.
