# The installer \(first installation wizard\) could be re\-enabled on an already configured instance by placing a file whose name starts with \.\.\.

- **ID**: CVE\-2026\-119623
- **危険度**: Critical（緊急） (CVSS 9.4)
- **公開**: 2026-11-17

## 原文

The installer \(first installation wizard\) could be re\-enabled on an already configured instance by placing a file whose name starts with FIRST\_INSTALL in the public web root or the project root\. The installer then became accessible without authentication, allowing for example to change the database connection and to create a new administrator and system maintainer account, which leads to remote code execution\. As demonstrated in TYPO3\-CORE\-SA\-2026\-026, such a file could be created by an authenticated, low\-privileged backend user without any further permissions\. Other ways of creating files in the web root, as well as leftover or restored marker files, could be abused in the same way\.
  
With the fixed versions, the installer can no longer be re\-enabled on an already configured instance by a marker file\. A new internal setting \$GLOBALS\['TYPO3\_CONF\_VARS'\]\['SYS'\]\['isInstalling'\] is stored in the system configuration and is only enabled while a new installation is running\. Additionally, only the exact file names FIRST\_INSTALL and FIRST\_INSTALL\.txt are accepted as marker files\.
