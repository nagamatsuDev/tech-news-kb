# diffpy\.structure before 3\.5\.1 contains a code execution vulnerability that allows attackers to run Python code by supplying crafted CIF s\.\.\.

- **ID**: CVE\-2026\-133708
- **危険度**: High（重要） (CVSS 7.8)
- **言語**: Python
- **公開**: 2026-11-20

## 原文

diffpy\.structure before 3\.5\.1 contains a code execution vulnerability that allows attackers to run Python code by supplying crafted CIF symmetry operations passed to eval\(\) in get\_symop\(\)\. Attackers can embed expressions in the \_space\_group\_symop\_operation\_xyz or \_symmetry\_equiv\_pos\_as\_xyz loop to execute code with victim privileges when the CIF file is parsed locally\.
