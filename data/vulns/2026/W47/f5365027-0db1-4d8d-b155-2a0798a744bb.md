# The WP Duplicate – WordPress Migration Plugin plugin for WordPress is vulnerable to Remote Code Execution in all versions up to, and incl\.\.\.

- **ID**: CVE\-2026\-14492
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: PHP
- **公開**: 2026-11-19

## 原文

The WP Duplicate – WordPress Migration Plugin plugin for WordPress is vulnerable to Remote Code Execution in all versions up to, and including, 1\.1\.11 via the save\_single\_batch\_file function\. This is due to a PHP type\-juggling authentication bypass via loose \!\= comparison with no is\_string\(\) guard, combined with unsanitized base64\-decoded path construction in save\_single\_batch\_file\(\) lacking any directory traversal containment\. This makes it possible for authenticated attackers, with custom\-level access and above, to execute code on the server\. Exploitation requires that the site owner has completed the plugin's initial setup so that the site\_type and prod\_key\_random\_id options are non\-empty, though any non\-empty secret value is bypassable via the type\-juggling flaw\.
