# WeGIA is a web manager for charitable institutions\.

- **ID**: CVE\-2026\-61676
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: PHP
- **公開**: 2026-11-17

## 原文

WeGIA is a web manager for charitable institutions\. Prior to 3\.8\.7, web/html/socio/sistema/cadastro\_cobranca\.php creates billing records without checking for an authenticated session\. An unauthenticated remote requester who supplies valid billing parameters can create arbitrary billing entries, enabling financial data manipulation and operational disruption\. This issue is fixed in version 3\.8\.7\.
