# The Flamix\: Bitrix24 and WooCommerce Products Sync WordPress plugin before 1\.7\.0 does not restrict or validate an unauthenticated file\-ex\.\.\.

- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The Flamix\: Bitrix24 and WooCommerce Products Sync WordPress plugin before 1\.7\.0 does not restrict or validate an unauthenticated file\-exchange request, allowing anyone to write a file with an attacker\-chosen name, extension and path to a web\-served location and thereby execute arbitrary PHP\.
