# The Video &amp; Photo Gallery for Ultimate Member plugin for WordPress is vulnerable to Arbitrary File Deletion in versions up to, and includ\.\.\.

- **ID**: CVE\-2026\-118522
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-20

## 原文

The Video &amp; Photo Gallery for Ultimate Member plugin for WordPress is vulnerable to Arbitrary File Deletion in versions up to, and including, 1\.1\.4 This is due to the um\_gallery\_add\_videos\(\) AJAX handler persisting user\-supplied videos\[\] values into the file\_name column after only esc\_url\(\) — which preserves path\-traversal sequences — and the companion um\_gallery\_delete\_photo\(\) helper passing that stored value to unlink\(\) through get\_user\_image\_path\(\) with no canonicalization or allowed\-directory check\. This makes it possible for authenticated attackers, with Subscriber\-level access and above, to delete arbitrary files on the server, which can be leveraged to achieve remote code execution when the right file \(such as wp\-config\.
