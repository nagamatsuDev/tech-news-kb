- **ID**: CVE\-2026\-121707 / GHSA\-7589\-6fvf\-x4pw

- **言語**: JavaScript/TypeScript

## 原文

\#\#\# Impact \`Schema\.TemplateLiteral\` compiles each \`Schema\.String\` span to the lazy wildcard \`\[\\s\\S\]\*?\` and decodes input by running the resulting regular expression against it\. When a template has two or more \`Schema\.String\` spans, for example\: \`\`\`ts Schema\.TemplateLiteral\(Schema\.String, "\:", Schema\.String, "\:", Schema\.String, "X"\) \`\`\` the regex contains several ambiguous wildcards\. A non\-matching input makes the backtracking engine try combinations across all of them, so matching time grows cubically with input length\.
