# AnsibleForms is a self\-hosted web application that turns automation into self\-service forms\.

- **ID**: CVE\-2026\-73969
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-18

## 原文

AnsibleForms is a self\-hosted web application that turns automation into self\-service forms\. Prior to 6\.2\.1, AnsibleForms uses a public hard\-coded fallback JWT signing secret from server/config/auth\.config\.js when ACCESS\_TOKEN\_SECRET is unset\. An unauthenticated attacker can sign a self\-contained token with privileged claims because server/src/auth/auth\_jwt\.js verifies the signature without reloading the user from the database, and server/src/lib/middleware\.js trusts the token's roles and options for authorization\. A forged token can therefore be accepted as an administrator session, resulting in authentication bypass and full privileged API access\. This issue is fixed in version 6\.2\.1\.
