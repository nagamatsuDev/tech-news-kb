# Description When an HTTP profile and an iRule containing the PSC\:\:ip\_address command are configured on a virtual server, undisclosed requ\.\.\.

- **ID**: CVE\-2026\-120285
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-18

## 原文

Description  
When an HTTP profile and an iRule containing the PSC\:\:ip\_address command are configured on a virtual server, undisclosed requests can cause the Traffic Management Microkernel \(TMM\) to terminate and may lead to remote code execution \(RCE\)\.
  
Impact  
Traffic is disrupted while the TMM process restarts\. This vulnerability allows a remote, unauthenticated attacker to cause a denial\-of\-service \(DoS\) on the BIG\-IP system and may allow the attacker to perform RCE\. There is no control plane exposure; this is a data plane issue only\.
  
Note\: Software versions which have reached End of Technical Support \(EoTS\) are not evaluated\.
