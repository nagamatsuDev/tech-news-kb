# WLA DX 9\.7 through 10\.7 contains a stack\-based buffer overflow vulnerability in parse\_data\_blocks\(\) in wlalink/analyze\.c that copies sect\.\.\.

- **ID**: CVE\-2026\-131871
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-18

## 原文

WLA DX 9\.7 through 10\.7 contains a stack\-based buffer overflow vulnerability in parse\_data\_blocks\(\) in wlalink/analyze\.c that copies section namespaces without length checks\. Attackers can supply a crafted object or library file with a namespace longer than 255 bytes or unterminated to overflow the 256\-byte stack buffer when linked\.
