# Grav from 2\.0\.0 before 2\.2\.18 contains a Twig sandbox bypass vulnerability that allows publishers to read any server file by abusing allo\.\.\.

- **ID**: CVE\-2026\-130741
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-18

## 原文

Grav from 2\.0\.0 before 2\.2\.18 contains a Twig sandbox bypass vulnerability that allows publishers to read any server file by abusing allowlisted array\_key\_value\(\) and page accessor setters such as filePath\(\)\. Attackers can repoint page objects or overwrite the assets collections to render private keys and the API signing secret, then forge a super\-admin API token\.
