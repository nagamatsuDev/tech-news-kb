# In the Linux kernel, the following vulnerability has been resolved\: xfs\: refuse a pNFS LAYOUTCOMMIT of a range without blocks A client \.\.\.

- **ID**: CVE\-2026\-99679
- **危険度**: Critical（緊急） (CVSS 9.4)
- **OS**: Linux
- **公開**: 2026-11-20

## 原文

In the Linux kernel, the following vulnerability has been resolved\:
  
xfs\: refuse a pNFS LAYOUTCOMMIT of a range without blocks
  
A client can commit a hole in a LAYOUTCOMMIT, because nfsd does not  
check the extents against its layouts\. xfs\_iomap\_write\_unwritten\(\) then  
allocates written blocks there\. A large hole overruns the block  
reservation and shuts XFS down\. A small one exposes stale data\.
  
Refuse such a range with \-EIO, using XFS\_BMAPI\_CONVERT\_ONLY\.
