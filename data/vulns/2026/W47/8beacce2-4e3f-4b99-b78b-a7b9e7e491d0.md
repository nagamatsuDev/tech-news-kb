# The FancyBox for WordPress plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via Comment Anchor 'href' Attribute in all v\.\.\.

- **ID**: CVE\-2026\-96571
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The FancyBox for WordPress plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via Comment Anchor 'href' Attribute in all versions up to, and including, 3\.4\.2 due to insufficient input sanitization and output escaping\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\. Exploitation requires the attacker to wrap the payload anchor around a smilie shortcode \(e\.g\., \:mrgreen\:\), which WordPress renders as an &amp;lt;img&amp;gt; element, satisfying the plugin's a\:has\(img\) enrollment selector and disguising the malicious link as an ordinary comment emoticon\.
