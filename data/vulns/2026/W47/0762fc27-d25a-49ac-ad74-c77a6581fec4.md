# Grav from 2\.0\.0 before 2\.2\.18 contains an insecure blueprint trust vulnerability that allows publisher accounts to read secrets and execu\.\.\.

- **ID**: CVE\-2026\-130743
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

Grav from 2\.0\.0 before 2\.2\.18 contains an insecure blueprint trust vulnerability that allows publisher accounts to read secrets and execute PHP by planting or selecting attacker\-controlled blueprint files\. Attackers can abuse the import@ directive, uploaded YAML media named as the page template, or form\.flash\_folder to leak password hashes and keys or invoke static PHP methods for code execution\.
