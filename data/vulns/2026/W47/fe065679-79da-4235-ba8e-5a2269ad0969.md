# actix\-files before 0\.7\.4 contains an information disclosure vulnerability that allows remote unauthenticated attackers to read hidden fil\.\.\.

- **ID**: CVE\-2026\-134347
- **危険度**: High（重要） (CVSS 7.5)
- **OS**: Windows
- **公開**: 2026-11-21

## 原文

actix\-files before 0\.7\.4 contains an information disclosure vulnerability that allows remote unauthenticated attackers to read hidden files by requesting Windows 8\.3 short\-name aliases\. Attackers can request short names like ENV\~1 or GIT\~1/config to bypass the leading\-dot check in actix\_files\:\:Files and retrieve \.env secrets and \.git contents\.
