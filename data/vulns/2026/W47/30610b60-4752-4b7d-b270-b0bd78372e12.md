# iDocView before 13\.10\.1\_20231115 contains an unrestricted file upload vulnerability in the /html/2word endpoint that allows unauthenticat\.\.\.

- **ID**: CVE\-2023\-54422
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-18

## 原文

iDocView before 13\.10\.1\_20231115 contains an unrestricted file upload vulnerability in the /html/2word endpoint that allows unauthenticated attackers to write arbitrary files by supplying a malicious url parameter\. Attackers can send a crafted GET request with the url parameter to download linked resources with an unsanitized path and unblocked \.jsp extension, achieving remote code execution\. Exploitation evidence was first observed by the Shadowserver Foundation on 2023\-11\-22\.
