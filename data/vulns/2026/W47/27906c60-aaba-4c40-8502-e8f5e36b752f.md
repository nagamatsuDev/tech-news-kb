# contao/newsletter\-bundle\: Contao newsletter custom actions bypass channel\-scoped authorization

- **ID**: CVE\-2026\-104881 / GHSA\-3r9g\-pfhv\-3228
- **危険度**: Medium（警告） (CVSS 4.3)
- **言語**: PHP
- **パッケージ**: Packagist/contao/newsletter\-bundle &gt;\= 5\.0\.0, &lt; 5\.3\.50 → 5\.3\.50, Packagist/contao/newsletter\-bundle &gt;\= 5\.4\.0\-RC1, &lt; 5\.7\.12 → 5\.7\.12
- **公開**: 2026-11-20

## 原文

Channel access is enforced only by the DataContainer voters \(\`NewsletterChannelAccessVoter\` / \`NewsletterRecipientsAccessVoter\`, requiring USER\_CAN\_EDIT\_CHANNEL\), whose \`supportsType\(\)\` fires exclusively for Create/Read/Update/DeleteAction subjects dispatched inside DC\_Table's create/edit/delete methods\. The newsletter custom key\-actions are dispatched directly by \`Backend\:\:getBackendModule\(\)\` \(Backend\.php\:324\-327\) after only the module\-level \`USER\_CAN\_ACCESS\_MODULE\` check; the DC\_Table constructor runs no per\-record ReadAction vote for a key\-action\. \`Newsletter\.php\` contains no \`isGranted\` /
