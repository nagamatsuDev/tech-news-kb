# Next\.js\: Information disclosure across root params when a 'use cache' function is called through unstable\_cache\(\)

- **ID**: CVE\-2026\-119790 / GHSA\-mfr8\-8qww\-v76h
- **危険度**: Medium（警告）
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/next &gt;\= 16\.3\.0, &lt;\= 16\.4\.4 → 16\.4\.5
- **公開**: 2026-11-16

## 原文

Next\.js applications with \`'use cache'\` can disclose cached data across root params when the same \`'use cache'\` function is called both directly during rendering and through \`unstable\_cache\(\)\`, and that function reads a root param\. Root params are route parameters of the root layout, and applications commonly use them to scope data, for example per locale\. During a cold process start, a cross\-request deduplication race allowed an \`unstable\_cache\(\)\` call to join the in\-flight fill of a concurrent direct call and receive its result, bypassing the root param check that would normally reject it\. \`
