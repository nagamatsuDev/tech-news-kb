# The WPvivid — Backup, Migration &amp; Staging WordPress plugin before 0\.9\.140 does not prevent serialized data it cannot safely unserialize f\.\.\.

- **ID**: CVE\-2026\-120391
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The WPvivid — Backup, Migration &amp; Staging WordPress plugin before 0\.9\.140 does not prevent serialized data it cannot safely unserialize from being re\-serialized as a PHP object during a site migration, allowing users with a role as low as Subscriber to plant a PHP object that WordPress instantiates after an administrator restores a backup onto a different URL\.
