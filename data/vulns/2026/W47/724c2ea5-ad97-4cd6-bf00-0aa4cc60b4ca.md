# Refitter allows arbitrary code execution through unescaped OpenAPI paths

- **ID**: CVE\-2026\-63345 / GHSA\-3fhm\-p725\-h3g3
- **危険度**: Critical（緊急）
- **言語**: C\#/\.NET
- **パッケージ**: NuGet/Refitter &lt; 2\.1\.2 → 2\.1\.2
- **公開**: 2026-11-20

## 原文

\#\#\# Summary Refitter emits each OpenAPI path \(the paths\-object key\) verbatim into a Refit \`\[Get\("&lt;path&gt;"\)\]\` attribute string, without escaping \`"\` or restricting characters\. A crafted single\-line, /\-prefixed path survives Refitter's default OpenAPI validation yet closes the attribute string and the enclosing interface \+ namespace, injects a top\-level \`file class\` with a \`\[ModuleInitializer\]\` method, and reopens a namespace \+ interface so the file stays valid\. \.NET runs \`\[ModuleInitializer\]\` methods when the generated assembly is loaded, so the attacker's code executes at application startup\.
