# The VidShop for WooCommerce plugin for WordPress is vulnerable to Sensitive Information Exposure in versions up to, and including, 1\.10\.0\.\.\.

- **ID**: CVE\-2026\-130055
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-20

## 原文

The VidShop for WooCommerce plugin for WordPress is vulnerable to Sensitive Information Exposure in versions up to, and including, 1\.10\.0 via the /vsfw/v1/products/\{id\} REST API endpoint\. This is due to the endpoint's permission\_callback \(check\_public\_permission\) returning true unconditionally and the get\_item\(\) handler only checking that the product and video exist — it does not check the product's post\_status or catalog visibility, nor does it verify that the product is actually linked to the supplied video\_id\. This makes it possible for unauthenticated attackers to enumerate product IDs and read private, draft, and catalog\-hidden WooCommerce products' names, short descriptions, prices, variations, attributes, and stock information that would otherwise be hidden from public view\.
