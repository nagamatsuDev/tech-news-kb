# memtomem\-stm\: Surfaced memory data can escape the Markdown compatibility boundary

- **ID**: CVE\-2026\-77332 / GHSA\-43hx\-xm7w\-3mhj
- **危険度**: Low（注意）
- **言語**: Python
- **パッケージ**: PyPI/memtomem\-stm &gt;\= 0\.1\.0, &lt;\= 0\.1\.33 → 0\.1\.34
- **公開**: 2026-11-20

## 原文

Untrusted long\-term and working\-memory fields can introduce Markdown or HTML\-compatible structure into the surfaced\-memory envelope\. A crafted memory may create misleading structural boundaries or visually conceal content\. The private fix serializes every untrusted field as inert single\-line data, validates copyable memory identifiers, and pins an explicit untrusted\-data preamble\. Ordinary natural\-language persuasion remains a residual model\-level risk\.
