# The MembershipWorks \- Membership, Events &amp; Directory plugin for WordPress is vulnerable to Stored Cross\-Site Scripting in all versions up\.\.\.

- **ID**: CVE\-2026\-119643
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-17

## 原文

The MembershipWorks \- Membership, Events &amp; Directory plugin for WordPress is vulnerable to Stored Cross\-Site Scripting in all versions up to, and including, 6\.17\. This is due to insufficient output escaping on member\-supplied data retrieved from the MembershipWorks SaaS API in the sf\_shortcode\(\), sf\_widget\_event\_do\(\), and sf\_widget\_folder\_do\(\) functions, where the 'nam' \(member name\), 'ttl' \(event title\), 'url', 'adn' \(venue name\), 'szp', and 'ezp' fields are output into page HTML without escaping, or, in sf\_widget\_folder\_do\(\), placed in an image alt attribute that an onerror handler copies into innerHTML\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\.
