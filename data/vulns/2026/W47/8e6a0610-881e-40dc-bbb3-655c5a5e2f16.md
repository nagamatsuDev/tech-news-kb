# tac\_plus\-ng before commit d8493e0 contains a stack\-based buffer overflow vulnerability that allows clients holding the TACACS\+ shared key\.\.\.

- **ID**: CVE\-2026\-130875
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-17

## 原文

tac\_plus\-ng before commit d8493e0 contains a stack\-based buffer overflow vulnerability that allows clients holding the TACACS\+ shared key to overflow a stack buffer due to an operator precedence error in author\_pak\_looks\_bogus\(\) and accounting\_pak\_looks\_bogus\(\)\. Attackers can send packets whose argument\-length table exceeds the payload, causing eval\_args\(\) to read past the packet and memcpy\(\) oversized cmd values into cmdline, crashing the daemon or executing code\.
