# The Search &amp; Replace WordPress plugin before 3\.2\.4 does not restrict one of its database tools to network administrators on multisite ins\.\.\.

- **ID**: CVE\-2026\-107740
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The Search &amp; Replace WordPress plugin before 3\.2\.4 does not restrict one of its database tools to network administrators on multisite installations, allowing administrators of a single subsite to run arbitrary SQL against the whole network's database and make themselves Super Admin\.
