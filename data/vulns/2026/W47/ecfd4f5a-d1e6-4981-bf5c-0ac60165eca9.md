# DOMShell\: domshell\_eval classified as read\-tier can execute side\-effecting JavaScript without \-\-allow\-write

- **ID**: CVE\-2026\-75518 / GHSA\-vg83\-hcp4\-5qcc
- **危険度**: Medium（警告）
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/@apireno/domshell &lt; 2\.0\.8 → 2\.0\.8
- **公開**: 2026-11-19

## 原文

\#\#\# Summary The \`domshell\_eval\` MCP tool \(and the \`eval\` command inside \`domshell\_execute\`\) was classified as \*\*read\-tier\*\*, allowing it to run without the \`\-\-allow\-write\` server flag\. However, \`eval\` and the write\-tier \`js\` command dispatch to the same handler in the extension and call CDP \`Runtime\.evaluate\` with the raw expression string and no side\-effect gate\. Any JavaScript expression could therefore mutate DOM, window, or global state through \`domshell\_eval\` without the operator's \`\-\-allow\-write\` authorization\.
