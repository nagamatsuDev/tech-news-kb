# Web\-Token jwt\-framework and jwt\-library before 3\.4\.10, 4\.0\.0 before 4\.0\.7, and 4\.1\.0 before 4\.1\.7 contain an uncontrolled resource consum\.\.\.

- **ID**: CVE\-2026\-134461
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-21

## 原文

Web\-Token jwt\-framework and jwt\-library before 3\.4\.10, 4\.0\.0 before 4\.0\.7, and 4\.1\.0 before 4\.1\.7 contain an uncontrolled resource consumption vulnerability in PBES2AESKW\:\:unwrapKey\(\), which passes the attacker\-controlled p2c JWE header value to hash\_pbkdf2\(\) without an upper bound\. Unauthenticated attackers can send a JWE using a PBES2\-HS\*\+A\*KW algorithm with a huge p2c iteration count to force lengthy PBKDF2 computations and exhaust server CPU\.
