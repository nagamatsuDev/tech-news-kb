# SurrealDB 3\.0\.0 before 4\.0\.0 contains a path traversal vulnerability in direct filesystem buckets because BucketController\:\:check\_permiss\.\.\.

- **ID**: CVE\-2026\-134295
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-21

## 原文

SurrealDB 3\.0\.0 before 4\.0\.0 contains a path traversal vulnerability in direct filesystem buckets because BucketController\:\:check\_permission evaluates key\-based ACLs against the un\-normalized object key, while FileStore\:\:to\_os\_path collapses '\.\.' sequences without a traversal check\. An authenticated tenant permitted only for certain keys can supply a key such as /public/\.\./private/confidential\.txt to read, write, or delete arbitrary files within the storage root\.
