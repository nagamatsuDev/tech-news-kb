# audio\-separator before 0\.47\.2 contains an insecure deserialization vulnerability that allows attackers to execute code by supplying malic\.\.\.

- **ID**: CVE\-2026\-134172
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-20

## 原文

audio\-separator before 0\.47\.2 contains an insecure deserialization vulnerability that allows attackers to execute code by supplying malicious Demucs \.th model files loaded via torch\.load with weights\_only\=False\. Local users writing to the shared /tmp/audio\-separator\-models/ default directory, or attackers controlling unverified model download sources, can execute code when victims run Demucs separation\.
