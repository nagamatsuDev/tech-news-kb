# The NextScripts\: Social Networks Auto\-Poster plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via 'comment\_author' and '\.\.\.

- **ID**: CVE\-2026\-84998
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-19

## 原文

The NextScripts\: Social Networks Auto\-Poster plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via 'comment\_author' and 'comment\_agent' Comment Fields in all versions up to, and including, 4\.4\.8 due to insufficient input sanitization and output escaping\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\. The injected payload executes in an administrator's browser session when the administrator views the WordPress comment moderation queue, including pending and unapproved comments, meaning no prior approval of the comment is required for exploitation\.
