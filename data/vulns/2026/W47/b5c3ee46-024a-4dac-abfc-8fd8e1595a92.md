# In the Linux kernel, the following vulnerability has been resolved\: ntfs\: don't allow compression on volumes with clusters larger than 4\.\.\.

- **ID**: CVE\-2026\-99724
- **危険度**: High（重要） (CVSS 7.8)
- **OS**: Linux
- **公開**: 2026-11-20

## 原文

In the Linux kernel, the following vulnerability has been resolved\:
  
ntfs\: don't allow compression on volumes with clusters larger than 4K
  
On a volume made with "mkntfs \-c 8192", a user can set  
FILE\_ATTR\_COMPRESSED on an empty file through system\.ntfs\_attrib\.  
Writing to the file and reading it back after dropping the page cache  
then crashes\:
  
  BUG\: KASAN\: slab\-out\-of\-bounds in ntfs\_read\_compressed\_block\+0xa2c/0x2040  
  Read of size 8192 at addr ffff88804355a000 by task dd/106
  
The read path only handles clusters up to 4K\. It copies each cluster  
out of a single page, and a compression block of 16 8K clusters does  
not fit in the 64K ntfs\_compression\_buffer\. Loading an inode already  
rejects compressed data on such volumes\.
  
Reject the flag change the same way\.
