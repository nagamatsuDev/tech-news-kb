# Philips Hue Bridge hap\_pair\_setup\_handler Heap\-based Buffer Overflow Remote Code Execution Vulnerability\.

- **ID**: CVE\-2026\-126978
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-18

## 原文

Philips Hue Bridge hap\_pair\_setup\_handler Heap\-based Buffer Overflow Remote Code Execution Vulnerability\. This vulnerability allows network\-adjacent attackers to execute arbitrary code on affected installations of Philips Hue Bridge\. Authentication is not required to exploit this vulnerability\.
  
The specific flaw exists within the HomeKit Accessory Protocol service, which listens on TCP port 8080 by default\. When parsing pairing requests, the process does not properly validate the length of user\-supplied data prior to copying it to a fixed\-length, heap\-based buffer\. An attacker can leverage this vulnerability to execute code in the context of the device\. Was ZDI\-CAN\-28434\.
