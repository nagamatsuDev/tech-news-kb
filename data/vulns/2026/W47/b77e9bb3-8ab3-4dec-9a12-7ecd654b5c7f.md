# FineCMS versions 5\.0\.4 before 5\.0\.11 contain an unauthenticated SQL injection vulnerability in the data2 API action handled by list\_tag i\.\.\.

- **ID**: CVE\-2019\-25784
- **危険度**: High（重要） (CVSS 8.2)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

FineCMS versions 5\.0\.4 before 5\.0\.11 contain an unauthenticated SQL injection vulnerability in the data2 API action handled by list\_tag in libraries/Template\.php\. Attackers can send GET requests to index\.php?c\=api&amp;m\=data2 with a valid auth hash and the param action\=sql sql\='\.\.\.' to execute arbitrary SELECT queries and extract database information\. Exploitation evidence was first observed by the Shadowserver Foundation on 2023\-10\-14\.
