# AnyShare builds through 2024\-11 contain a missing authentication vulnerability in the /api/ShareMgnt/Usrm\_GetAllUsers endpoint that expos\.\.\.

- **ID**: CVE\-2024\-58403
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-18

## 原文

AnyShare builds through 2024\-11 contain a missing authentication vulnerability in the /api/ShareMgnt/Usrm\_GetAllUsers endpoint that exposes user records including password fields\. Attackers can send unauthenticated POST requests with a \[start,limit\] body to retrieve usernames, passwords, and department information for all users\. Exploitation evidence was first observed by the Shadowserver Foundation on 2024\-12\-25\.
