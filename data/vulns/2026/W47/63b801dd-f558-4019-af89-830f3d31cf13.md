# The UpdraftPlus\: WP Backup &amp; Migration Plugin WordPress plugin before 2\.26\.16\.26, UpdraftPlus\: WP Backup &amp; Migration Plugin WordPress plu\.\.\.

- **ID**: CVE\-2026\-121153
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: PHP
- **公開**: 2026-11-21

## 原文

The UpdraftPlus\: WP Backup &amp; Migration Plugin WordPress plugin before 2\.26\.16\.26, UpdraftPlus\: WP Backup &amp; Migration Plugin WordPress plugin before 1\.26\.16 do not keep a serialized value inert when their database search and replace reaches its recursion limit, allowing users with a role as low as Subscriber to plant data in their own user meta that is rewritten into a live PHP object when an administrator later runs a search and replace or a migration restore, and is then instantiated by WordPress on a later read\.
  
This is distinct from CVE\-2024\-10957, whose fix restricted the unserialize call but left this path in place\. No gadget chain is present in WordPress core or the UpdraftPlus\: WP Backup &amp; Migration Plugin WordPress plugin before 2\.26\.16\.26, UpdraftPlus\: WP Backup &amp; Migration Plugin WordPress plugin before 1\.26\.16 themselves; further impact depends on a suitable class from another installed UpdraftPlus\: WP Backup &amp; Migration Plugin WordPress plugin before 2\.26\.16\.26, UpdraftPlus\: WP Backup &amp; Migration Plugin WordPress plugin before 1\.26\.16 or \.
