# Zyrabit Platform provides sovereign AI infrastructure for enterprise retrieval\-augmented generation\.

- **ID**: CVE\-2026\-130154
- **危険度**: Critical（緊急） (CVSS 9.1)
- **公開**: 2026-11-18

## 原文

Zyrabit Platform provides sovereign AI infrastructure for enterprise retrieval\-augmented generation\. Prior to 2\.4\.4, import\_to\_vault\(source\_path, destination\_name\) accepts both caller\-controlled paths, but the content\-pattern guard does not confine destination\_name\. The vulnerable tool is implemented in zyrabit\-slm/api\-rag/app/domain/services/mcp\_service\.py, where Path\(DOCS\_DIR\) / destination\_name is passed to shutil\.copy2, allowing traversal or an absolute destination to write outside the vault\. An unrestricted source\_path can be copied into the vault and retrieved through secure\_query, disclosing files readable by the service; files that do not match the executable\-pattern filter pass that filter\. When ENABLE\_LEGACY\_EXTENSIONS\=true, zyrabit\-slm/api\-rag/app/main\.py registers POST /mcp/rpc without get\_current\_user, allowing unauthenticated network tool calls; this optional exposure is disabled by default and is not required for local invocation\. If an attacker can stage chosen source content and write to an execution\-triggered destination, the advisory describes conditional process execution\. This issue is fixed in version 2\.4\.4\.
