# Doorkeeper\: When using public clients, any client can revoke any access token

- **ID**: CVE\-2026\-115472 / GHSA\-h5m9\-42h9\-vcq6
- **危険度**: Medium（警告） (CVSS 6.5)
- **言語**: Ruby
- **パッケージ**: RubyGems/doorkeeper &lt; 5\.9\.1 → 5\.9\.1
- **公開**: 2026-11-19

## 原文

\#\#\# Summary An improper authorization issue affects Doorkeeper's OAuth token revocation flow when public \(non\-confidential\) clients are in use\. This vulnerability can lead to tokens being revoked without correct authorization\. The issue is fixed in Doorkeeper 5\.9\.1\.
