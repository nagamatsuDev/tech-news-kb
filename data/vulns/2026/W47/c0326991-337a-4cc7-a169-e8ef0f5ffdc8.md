# NodePressは、認証されていない攻撃者が管理者アクセスを獲得できる認証バイパス脆弱性を含む。

- **ID**: CVE\-2026\-129955
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-16

## 概要（機械翻訳）

NodePress through 8\.5\.1には認証バイパス脆弱性があり、未認証の攻撃者はハードコードされたデフォルトパスワード'root'を使用して管理者にアクセスすることができる。は無効である。は無効である。は無効である。攻撃者は NP\_ADMIN\_DEFAULT\_PASSWORD がアンセットされたときに base64 でエンコードされた ‘root’ を Post /admin/login に送信し、管理トークンを取得し、サイトを完全に制御できます。

## 原文

NodePress through 8\.5\.1 contains an authentication bypass vulnerability that allows unauthenticated attackers to gain administrator access by using the hardcoded default password 'root'\. Attackers can send base64\-encoded 'root' to POST /admin/login when NP\_ADMIN\_DEFAULT\_PASSWORD is unset to obtain admin tokens and fully control the site\.
