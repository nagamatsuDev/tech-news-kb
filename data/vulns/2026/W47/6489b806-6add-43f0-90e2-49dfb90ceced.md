# Refitter allows code execution through unescaped OpenAPI header parameter names

- **ID**: CVE\-2026\-63346 / GHSA\-58x9\-vjvp\-6mx8
- **危険度**: Critical（緊急）
- **言語**: C\#/\.NET
- **パッケージ**: NuGet/Refitter &lt; 2\.1\.2 → 2\.1\.2
- **公開**: 2026-11-20

## 原文

\#\#\# Summary Refitter emits the spec's header parameter name \(parameters\[\]\.name with in\: header\) verbatim into a Refit \`\[Header\("&lt;name&gt;"\)\]\` attribute string without escaping \`"\`\. A crafted value survives Refitter's default OpenAPI validation, breaks out of the attribute and the enclosing interface \+ namespace, injects a top\-level \`file class\` with a \`\[ModuleInitializer\]\` method, and reopens so the file stays valid\. \.NET runs \`\[ModuleInitializer\]\` methods at assembly load, so the attacker's code executes at application startup\. Verified on Refitter 2\.0\.0 / \.NET 8\. Notable\: the breakout starts fr
