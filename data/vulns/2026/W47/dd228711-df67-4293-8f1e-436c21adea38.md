# Incus before 7\.6\.0 contains an authorization bypass that allows restricted project users to create resources in the unrestricted default \.\.\.

- **ID**: CVE\-2026\-130773
- **危険度**: Critical（緊急） (CVSS 9.9)
- **公開**: 2026-11-18

## 原文

Incus before 7\.6\.0 contains an authorization bypass that allows restricted project users to create resources in the unrestricted default project by targeting projects lacking features\.\* flags\. Attackers can create bridge networks with raw\.dnsmasq dhcp\-script injection to run scripts as root, or custom volumes with block\.create\_options mkfs arguments to read host files\.
