# アドミンネオは5\.9\.1より前のOtpLoginPluginで認証バイパス脆弱性を含んでいる。

- **ID**: CVE\-2026\-130382
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-17

## 概要（機械翻訳）

アドミンネオは5\.9\.1より前のOtpLoginPluginに認証バイパス脆弱性があり、データベースパスワードを知っている攻撃者が永続ログインのクッキーを悪用することでTOTP検証をスキップできる。攻撃者は間違った OTP と Permanent\=1 を持つログインを送信して newo\_permanent のクッキーを取得し、それを再生して完全な認証済みデータベースアクセスを得ることができる。は\.\.\.

## 原文

AdminNeo before 5\.9\.1 contains an authentication bypass vulnerability in OtpLoginPlugin that allows attackers knowing the database password to skip TOTP verification by abusing the permanent\-login cookie\. Attackers can submit a login with a wrong OTP and permanent\=1 to obtain a neo\_permanent cookie, then replay it to gain full authenticated database access\.
