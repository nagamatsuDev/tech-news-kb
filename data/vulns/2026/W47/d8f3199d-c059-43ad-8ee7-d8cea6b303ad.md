# The wpForo Forum plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'data\[display\_name\]' parameter in all versions\.\.\.

- **ID**: CVE\-2026\-123830
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-21

## 原文

The wpForo Forum plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'data\[display\_name\]' parameter in all versions up to, and including, 3\.2\.4 due to insufficient input sanitization and output escaping\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\. This requires public user registration to be enabled \(users\_can\_register\=1\) and a valid \_wpfnonce fetched from the public sign\-up page, but is otherwise fully unauthenticated\.
