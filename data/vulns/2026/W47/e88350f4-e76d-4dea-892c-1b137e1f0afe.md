# FreeSWITCH is a Software Defined Telecom Stack enabling the digital transformation from proprietary telecom switches to a software implem\.\.\.

- **ID**: CVE\-2026\-119293
- **危険度**: Critical（緊急） (CVSS 9.3)
- **公開**: 2026-11-17

## 原文

FreeSWITCH is a Software Defined Telecom Stack enabling the digital transformation from proprietary telecom switches to a software implementation that runs on any commodity hardware\. In 1\.11\.2 and earlier, rtp\_common\_read\(\) in src/switch\_rtp\.c uses one session\-wide autoadj\_tally to learn RTP sources that differ from the address negotiated in SDP\. An unauthenticated remote attacker who sends plaintext RTP during call setup can make packets from one or more non\-advertised sources reach the threshold before the legitimate endpoint, causing FreeSWITCH to adopt the source of the threshold\-crossing packet as the media peer\. The attacker can then receive call audio, inject media, and deny media to the legitimate endpoint without being on the media path\. FreeSWITCH 1\.11\.2 adds two opt\-in controls, but both default to zero and the release remains affected unless both are configured before RTP session creation\. This vulnerability is fixed in 1\.11\.2\.
