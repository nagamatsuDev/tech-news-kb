# code\-review\-mcp\-server\: Command injection via unsanitized folderPath/baseBranch parameters

- **ID**: CVE\-2026\-68934 / GHSA\-jq3q\-62jc\-fqq9
- **危険度**: High（重要） (CVSS 8.7)
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/code\-review\-mcp\-server &lt; 1\.5\.3 → 1\.5\.3
- **公開**: 2026-11-16

## 原文

\#\#\# Impact \`code\-review\-mcp\-server\` exposes MCP tools \(\`getLocalGitDiff\`, \`codeReview\`, \`createPR\`, \`getPRTemplate\`\) that accept \`folderPath\` and \`baseBranch\` string parameters\. These caller\-controlled values were interpolated directly into shell command strings executed via \`child\_process\.execSync\(\)\`, which runs commands through \`/bin/sh\`\. A crafted value such as \`baseBranch \= "main; &lt;arbitrary command&gt; \#"\` \(or a \`\$\(\.\.\.\)\` command substitution, or a \`folderPath\` that breaks out of the surrounding quotes\) results in \*\*arbitrary command execution\*\* on the host running the MCP server\. \#\#\# Patches
