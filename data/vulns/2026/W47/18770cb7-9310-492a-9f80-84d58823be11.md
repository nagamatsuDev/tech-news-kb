# RepoManager is a self\-hosted deb/rpm package repository\.

- **ID**: CVE\-2026\-130157
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-19

## 原文

RepoManager is a self\-hosted deb/rpm package repository\. Prior to 5\.13\.3, an attacker who controls an upstream RPM repository mirrored by a RepoManager instance can provide a package filename through the primary\.xml &lt;location href&gt; field; the mirror passes that filename into a shell\-interpreted RPM query, allowing shell metacharacters to execute commands as the www\-data service account\. The target must mirror an upstream repository controlled by the attacker, and the default "Check GPG signatures" option triggers the vulnerable call\. The command executes before a later signature\-verification failure, so a valid signed package is not required\. Fixed in 5\.13\.3\.
