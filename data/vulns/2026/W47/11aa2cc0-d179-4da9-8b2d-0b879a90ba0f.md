# A vulnerability was determined in EyouCMS up to 1\.8\.6\.

- **ID**: CVE\-2026\-116094
- **危険度**: High（重要） (CVSS 7.3)
- **言語**: PHP
- **公開**: 2026-10-25

## 原文

A vulnerability was determined in EyouCMS up to 1\.8\.6\. This impacts the function remote\_file\_to\_local of the file application/function\.php\. Executing a manipulation can lead to server\-side request forgery\. It is possible to launch the attack remotely\. The exploit has been publicly disclosed and may be utilized\. Upgrading to version 1\.8\.7 will fix this issue\. Upgrading the affected component is advised\.
