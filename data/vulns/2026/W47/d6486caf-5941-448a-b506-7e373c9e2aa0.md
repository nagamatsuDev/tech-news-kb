# OpenRemote\: Cross\-realm MQTT session disconnect without authorization

- **ID**: CVE\-2026\-104885 / GHSA\-3h6w\-xcw3\-9xjj
- **危険度**: Medium（警告）
- **言語**: Java/Kotlin
- **パッケージ**: Maven/io\.openremote\:openremote\-manager &lt; 1\.31\.0 → 1\.31\.0
- **公開**: 2026-11-20

## 原文

\#\#\# Summary Cross\-realm MQTT session disconnect without authorization \#\# Vulnerability The \`disconnectUserSession\` endpoint in \`UserResourceImpl\.java\` \(line 443\) accepts a \`realm\` path parameter but ignores it entirely, performing no authorization or realm\-boundary check before force\-disconnecting an MQTT session\. Any authenticated user from any realm can disconnect MQTT broker sessions belonging to users in other realms by supplying the target session ID\.
