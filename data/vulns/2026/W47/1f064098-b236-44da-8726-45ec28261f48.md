# SiYuan before 3\.8\.10 uses an incomplete deny\-list in IsSensitivePath that omits shell\-initialization files such as \.zshenv and \.bash\_prof\.\.\.

- **ID**: CVE\-2026\-130683
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-11-18

## 原文

SiYuan before 3\.8\.10 uses an incomplete deny\-list in IsSensitivePath that omits shell\-initialization files such as \.zshenv and \.bash\_profile, as well as \~/\.local\. Authenticated administrators can call /api/file/copyFile with an absolute destination outside the workspace to write payloads there, which execute as the user on the next shell or login\.
