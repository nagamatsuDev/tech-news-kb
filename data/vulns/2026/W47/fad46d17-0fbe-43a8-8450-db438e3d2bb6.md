# Netatalk is a Free and Open Source file server suite for Unix\-like operating systems\.

- **ID**: CVE\-2026\-62318
- **危険度**: Critical（緊急） (CVSS 9.3)
- **公開**: 2026-11-20

## 原文

Netatalk is a Free and Open Source file server suite for Unix\-like operating systems\. From 2\.0\.0 until 4\.5\.1, the DHX2 and DHX2\-PAM authentication state machine in etc/uams/uams\_dhx2\_pam\.c permits logincont1 to be invoked again with the same FPLoginCont retID after it has released the global gcry\_mpi\_t Ra object\. When DHX2 or DHX2PAM is enabled in the UAM list, a remote attacker without valid AFP credentials can repeat the first continuation step, causing gcry\_mpi\_powm to dereference the freed Ra value and gcry\_mpi\_release to free it again in a privileged afpd worker\. The demonstrated result is a repeatable pre\-authentication worker crash, and the use\-after\-free and double\-free provide a plausible allocator exploitation primitive although code execution was not demonstrated\. This issue is fixed in version 4\.5\.1\.
