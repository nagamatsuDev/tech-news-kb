# In the Linux kernel, the following vulnerability has been resolved\: cipso\: fix optlen corruption in cipso\_v4\_delopt\(\) cipso\_v4\_delopt\(\)\.\.\.

- **ID**: CVE\-2026\-99725
- **危険度**: High（重要） (CVSS 7.0)
- **OS**: Linux
- **公開**: 2026-11-20

## 原文

In the Linux kernel, the following vulnerability has been resolved\:
  
cipso\: fix optlen corruption in cipso\_v4\_delopt\(\)
  
cipso\_v4\_delopt\(\) recomputes the option length by walking the option  
buffer after the CIPSO option has been moved out\.  The walk then reads  
the stale bytes at the tail of the buffer as option data, and a crafted  
setsockopt\(IP\_OPTIONS\) buffer can make it treat one of them as an option  
length, increasing opt\-&gt;opt\.optlen beyond the valid option data\.
  
The corrupted length stays on the socket and is later used as the copy  
length by getsockopt\(IP\_OPTIONS\) and by the udp/raw/ping sendmsg paths,  
where it exceeds the size of the buffers they copy into\.
  
Compute the new length from the intact options before the move and  
subtract the CIPSO length, and fill the padding with IPOPT\_END\.
