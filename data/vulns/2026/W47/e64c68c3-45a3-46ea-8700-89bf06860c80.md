# SvelteKit\: Private \`query\.batch\` functions could collide, producing unexpected parameter / function combinations

- **ID**: CVE\-2026\-128119 / GHSA\-6cf5\-gc4q\-fm3x
- **危険度**: Medium（警告） (CVSS 5.9)
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/@sveltejs/kit &gt;\= 2\.60\.1, &lt;\= 3\.1\.0 → 3\.1\.1
- **公開**: 2026-11-16

## 原文

Under certain circumstances, private \(non\-exported\) \`query\.batch\` functions could end up sharing a batch, resulting in the arguments from one function being passed to another\. This only affects apps using the experimental remote functions flag and non\-exported \`query\.batch\` functions\.
