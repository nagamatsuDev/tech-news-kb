# The NextGEN Gallery plugin for WordPress is vulnerable to Stored Cross\-Site Scripting in versions up to, and including, 4\.5\.5 via the 'aj\.\.\.

- **ID**: CVE\-2026\-119611
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-20

## 原文

The NextGEN Gallery plugin for WordPress is vulnerable to Stored Cross\-Site Scripting in versions up to, and including, 4\.5\.5 via the 'ajax\_pagination\_referrer' request parameter used on the /ngg\_tag/&lt;tag&gt;/ taxonomy page\. This is due to the plugin reading the pagination base URL from \$\_REQUEST, preserving the attacker\-supplied host on the tag route \(where ngg\_wprouting\_add\_post\_permalink is forced to false so the plugin does not re\-base the links to the site's own permalink\), and caching the fully rendered page in a transient keyed only on the request URI \(not the request body\) for 1800 seconds via NGG\_RENDERING\_CACHE / PHOTOCRATI\_CACHE\. This makes it possible for unauthenticated attackers to poison the cached /ngg\_tag/&lt;tag&gt;/ page so that its pagination links point to an attacker\-controlled host; the plugin's own ajax\_pagination\.
