# The Unbounce Landing Pages plugin for WordPress is vulnerable to Stored Cross\-Site Scripting in versions up to, and including, 1\.1\.6\.

- **ID**: CVE\-2026\-107632
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-21

## 原文

The Unbounce Landing Pages plugin for WordPress is vulnerable to Stored Cross\-Site Scripting in versions up to, and including, 1\.1\.6\. This is due to insufficient input sanitization and output escaping on the proxy error message that is persisted to the 'ub\-proxy\-error\-message' option\: unauthenticated attacker\-controlled REQUEST\_URI data is concatenated into the error string in UBHTTP\:\:stream\_request\_curl\(\)/stream\_request\_wp\_remote\(\) and stored via update\_option\(\), then later echoed inside a &lt;textarea&gt; on the Unbounce Pages Diagnostics admin page without any escaping\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user \(an administrator viewing the Diagnostics screen\) accesses an injected page\.
