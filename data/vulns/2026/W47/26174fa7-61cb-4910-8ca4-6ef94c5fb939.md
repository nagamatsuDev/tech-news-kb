# Mistune is a Python Markdown parser with renderers and plugins\.

- **ID**: CVE\-2026\-97698
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: Python
- **公開**: 2026-11-17

## 原文

Mistune is a Python Markdown parser with renderers and plugins\. Prior to 3\.3\.4, parse\_link\_href performs an unbounded parenthesis\-balancing scan to the end of the document for each unmatched opening parenthesis reached through an empty \[\] link label\. In src/mistune/helpers\.py and src/mistune/inline\_parser\.py, the empty label bypasses no\_close\_bracket\_before, and no\_link\_before advances only past the short label, so successive \[\] \( candidates repeatedly scan the remaining document\. Rendering untrusted Markdown with the default HTML renderer and no plugins can perform quadratic CPU work and keep a worker at 100 percent utilization\. This issue is fixed in version 3\.3\.4\.
