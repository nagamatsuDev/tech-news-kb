# Refitter allows arbitrary code execution through unescaped OpenAPI content\-type values

- **ID**: CVE\-2026\-63344 / GHSA\-p32v\-8v8j\-j534
- **危険度**: Critical（緊急）
- **言語**: C\#/\.NET
- **パッケージ**: NuGet/Refitter &lt; 2\.1\.2 → 2\.1\.2
- **公開**: 2026-11-20

## 原文

\#\#\# Summary Refitter emits the spec's content\-type key \(content map key in requestBody/responses\) verbatim into a Refit \`\[Headers\("Accept\: &lt;ct&gt;", "Content\-Type\: &lt;ct&gt;"\)\]\` attribute string without escaping \`"\`\. A crafted value survives Refitter's default OpenAPI validation, breaks out of the attribute and the enclosing interface \+ namespace, injects a top\-level \`file class\` with a \`\[ModuleInitializer\]\` method, and reopens so the file stays valid\. \.NET runs \`\[ModuleInitializer\]\` methods at assembly load, so the attacker's code executes at application startup\. Verified on Refitter 2\.0\.0 / \.NET 8\.
