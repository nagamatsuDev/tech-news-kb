# Improper neutralization of special elements used in an OS command in the package broker in Devolutions Agent 2026\.3\.0 and 2026\.2\.4 on Win\.\.\.

- **ID**: CVE\-2026\-131157
- **危険度**: Critical（緊急） (CVSS 9.8)
- **OS**: Windows
- **公開**: 2026-11-17

## 原文

Improper neutralization of special elements used in an OS command in the package broker in Devolutions Agent 2026\.3\.0 and 2026\.2\.4 on Windows allows a local authenticated user to execute arbitrary commands with elevated privileges via crafted custom package parameters\.
