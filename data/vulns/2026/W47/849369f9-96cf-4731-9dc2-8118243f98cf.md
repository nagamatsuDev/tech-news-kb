# appium allows unauthenticated arbitrary file/directory deletion in @appium/storage\-plugin

- **ID**: CVE\-2026\-58192 / GHSA\-jwgx\-mp9m\-jwcr
- **危険度**: High（重要） (CVSS 8.6)
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/@appium/storage\-plugin &lt; 1\.1\.6 → 1\.1\.6
- **公開**: 2026-11-20

## 原文

\#\# Summary The Appium storage plugin exposes an HTTP endpoint \`POST /storage/delete\` that takes a user\-supplied \`name\` and deletes it from the server storage folder\. The handler passes \`name\` straight into \`path\.join\(storageRoot, name\)\` and then \`fs\.rimraf\(\)\` \*\*without any path sanitization\*\*\. By sending a \`name\` containing \`\.\./\` sequences, an unauthenticated remote client can escape the storage root and \*\*recursively delete arbitrary files and directories\*\* that the Appium process user can write, anywhere on the host filesystem\.
