# A flaw was found in dnsmasq, where a memory handling issue exists in its Dynamic Host Configuration Protocol for IPv6 \(DHCPv6\) relay proc\.\.\.

- **ID**: CVE\-2026\-133730
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-20

## 原文

A flaw was found in dnsmasq, where a memory handling issue exists in its Dynamic Host Configuration Protocol for IPv6 \(DHCPv6\) relay processing\. A remote attacker can exploit this vulnerability by sending a sequence of network packets to a system configured as a DHCPv6 relay\. This causes the service to write data to previously freed memory and crash, resulting in a Denial of Service \(DoS\)\.
