# 53AIHub before 0\.5\.5 contains a missing authentication vulnerability that allows unauthenticated attackers to read files by requesting /a\.\.\.

- **ID**: CVE\-2026\-130591
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-17

## 原文

53AIHub before 0\.5\.5 contains a missing authentication vulnerability that allows unauthenticated attackers to read files by requesting /api/files/\:file\_id/preview and /api/file\-version/\:file\_body\_id without UserTokenAuth\. Attackers can enumerate sequential numeric ids to read raw knowledge\-base files and stored file versions belonging to any enterprise tenant\.
