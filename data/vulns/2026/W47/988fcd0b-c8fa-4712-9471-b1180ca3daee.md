# aMQTT is an open source MQTT broker and client\.

- **ID**: CVE\-2026\-104199
- **危険度**: High（重要） (CVSS 8.7)
- **公開**: 2026-11-19

## 原文

aMQTT is an open source MQTT broker and client\. From 0\.11\.0 until 0\.11\.4, add\_subscription\(\) in amqtt/broker\.py accepts malformed single\-level \+ wildcard placement because it checks substrings instead of validating each slash\-delimited level\. The \_matches\(\) function converts each \+ into a greedy regular\-expression fragment and evaluates it with re\.fullmatch\(\), allowing a filter containing many adjacent \+ characters to trigger catastrophic backtracking when compared with a topic that partially matches but ultimately fails\. Because matching runs synchronously in \_run\_broadcast\(\), one subscription followed by a publish can block the broker event loop, stopping message delivery and new connection processing until restart\. Anonymous clients can trigger the issue with the default configuration\. Any authenticated client permitted to create arbitrary subscriptions and publish messages may still exploit it when authentication is enabled\. This issue is fixed in version 0\.11\.4\.
