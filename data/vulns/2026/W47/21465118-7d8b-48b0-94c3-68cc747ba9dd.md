# NLTK \(Natural Language Toolkit\) is a suite of open source Python modules, data sets, and tutorials supporting research and development in\.\.\.

- **ID**: CVE\-2026\-128139 / GHSA\-j8g8\-j4j7\-8j54
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: Python
- **公開**: 2026-11-19

## 原文

NLTK \(Natural Language Toolkit\) is a suite of open source Python modules, data sets, and tutorials supporting research and development in Natural Language Processing\. From 3\.6 to 3\.10\.3, XMLCorpusView\.\_read\_xml\_fragment accumulates 1 KiB blocks and repeatedly applies whole\-buffer XML validation while a comment or CDATA terminator remains ahead\. A large comment in an attacker\-controlled corpus file causes quadratic CPU consumption through documented XML corpus readers across the affected range\. On 3\.6 and 3\.9\.2, a large CDATA section incurs the quadratic scan before rejection, while on 3\.10\.3 both comment and CDATA documents are read successfully\. This vulnerability is fixed in 3\.10\.4\.
