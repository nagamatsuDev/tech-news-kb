# Iceburg CRM through 5\.0\.0 contains an incorrect authorization vulnerability in Module\:\:saveRecord\(\) that allows authenticated users to wr\.\.\.

- **ID**: CVE\-2026\-133874
- **危険度**: High（重要） (CVSS 8.1)
- **公開**: 2026-11-20

## 原文

Iceburg CRM through 5\.0\.0 contains an incorrect authorization vulnerability in Module\:\:saveRecord\(\) that allows authenticated users to write to unauthorized modules by prefixing request body keys with another module id\. Attackers with write access to one module can submit crafted requests to POST /data/save or PUT /api/crm/\{id\} to set their role\_id to Admin and access administrative data\.
