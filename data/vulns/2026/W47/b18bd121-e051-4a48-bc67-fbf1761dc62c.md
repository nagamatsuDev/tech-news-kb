# NocoDB before 2026\.10\.0 contains an account takeover vulnerability that allows users with the base creator role to hijack other accounts \.\.\.

- **ID**: CVE\-2026\-130702
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-18

## 原文

NocoDB before 2026\.10\.0 contains an account takeover vulnerability that allows users with the base creator role to hijack other accounts by resending base invitations\. Attackers can trigger baseUserInviteResend to mint a new invite\_token, read it from the base member list, and reset the victim's password through signup, taking over owner or super admin accounts\.
