# SiYuan 3\.8\.0 before 3\.8\.10 contains an incorrect authorization vulnerability in the serveAssets route that allows unauthenticated attacke\.\.\.

- **ID**: CVE\-2026\-134245
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-21

## 原文

SiYuan 3\.8\.0 before 3\.8\.10 contains an incorrect authorization vulnerability in the serveAssets route that allows unauthenticated attackers to read password\-protected document assets via name collisions\. Attackers can request GET /assets/&lt;name&gt; when a visible document references the same relative asset name, retrieving the protected file's contents on public\-publish instances with Basic Auth disabled\.
