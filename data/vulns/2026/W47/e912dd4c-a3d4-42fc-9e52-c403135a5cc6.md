# The WPO365 \| SEAMLESS WORDPRESS \+ MICROSOFT INTEGRATION \(WPO365 \| LOGIN\) WordPress plugin before 45\.4 does not ensure the signature valid\.\.\.

- **ID**: CVE\-2026\-129446
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-19

## 原文

The WPO365 \| SEAMLESS WORDPRESS \+ MICROSOFT INTEGRATION \(WPO365 \| LOGIN\) WordPress plugin before 45\.4 does not ensure the signature validated on a SAML response covers the element the user identity is read from, allowing unauthenticated attackers to forge a response via signature wrapping and log in as any user, including administrators, when they can supply a single artifact signed by the configured identity provider\.
