# The UpdraftPlus\: WP Backup &amp; Migration Plugin WordPress plugin before 2\.26\.16\.26, UpdraftPlus\: WP Backup &amp; Migration Plugin WordPress plu\.\.\.

- **ID**: CVE\-2026\-121150
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: PHP
- **公開**: 2026-11-21

## 原文

The UpdraftPlus\: WP Backup &amp; Migration Plugin WordPress plugin before 2\.26\.16\.26, UpdraftPlus\: WP Backup &amp; Migration Plugin WordPress plugin before 1\.26\.16 do not correctly handle comment\-like content found in the middle of a long SQL statement when restoring a database backup, allowing users with a role as low as Subscriber who have stored crafted content in their own profile to have SQL executed when an administrator later restores a backup, and so escalate their account to administrator\.
  
This is a different code path from the backup restore issue fixed in 1\.26\.10, and it does not depend on the database server's maximum packet size\.
