# A vulnerability was detected in eigent\-ai eigent up to 1\.0\.2\.

- **ID**: CVE\-2026\-133983
- **危険度**: High（重要） (CVSS 7.3)
- **公開**: 2026-11-21

## 原文

A vulnerability was detected in eigent\-ai eigent up to 1\.0\.2\. Affected by this vulnerability is an unknown functionality of the file backend/app/controller/chat\_controller\.py of the component Local Agent Control API\. Performing a manipulation results in missing authentication\. The attack may be initiated remotely\. Upgrading to version 1\.0\.3 addresses this issue\. The patch is named 59f43afcb1b0ba7b2de8c65d585124f196c4aa17\. It is recommended to upgrade the affected component\.
