# Jane is a set of PHP libraries that generates models and API clients from JSON Schema and OpenAPI specifications\.

- **ID**: CVE\-2026\-63412
- **危険度**: Critical（緊急） (CVSS 9.3)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

Jane is a set of PHP libraries that generates models and API clients from JSON Schema and OpenAPI specifications\. Prior to 7\.12\.0, the Jane open\-api\-3 generator emits an OpenAPI query parameter name verbatim as an array key in generated Client/Endpoint method docblocks\. A query parameter name containing a PHPDoc closing delimiter can terminate the comment early and place attacker\-controlled PHP in class\-body position, including an \_\_construct method that runs when the generated Client is instantiated\. Exploitation requires generating a client from an attacker\-influenced OpenAPI document and then using the generated SDK, and can execute arbitrary PHP with the consuming application's privileges\. This issue is fixed in version 7\.12\.0\.
