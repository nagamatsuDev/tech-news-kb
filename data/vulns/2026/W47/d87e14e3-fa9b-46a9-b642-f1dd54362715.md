# Netatalk is a Free and Open Source file server suite for Unix\-like operating systems\.

- **ID**: CVE\-2026\-45356
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-20

## 原文

Netatalk is a Free and Open Source file server suite for Unix\-like operating systems\. Prior to 4\.4\.3, the afpd Spotlight RPC unmarshalling loop in etc/afpd/spotlight\_marshalling\.c subtracts an attacker\-controlled subcount from the unsigned count variable in sl\_unpack\_loop without verifying that subcount is not larger\. An authenticated AFP client can place an excessive element count in the sl\_unpack\_ints, sl\_unpack\_uuid, sl\_unpack\_floats, or sl\_unpack\_date handler, or in a null element, so the subtraction wraps near UINT\_MAX and the loop continues reading heap memory at increasing offsets up to toc\_offset, which is capped at 65000\. The out\-of\-bounds values can be stored in dalloc structures and returned in the Spotlight RPC response, disclosing heap contents\. This issue is fixed in version 4\.4\.3\.
