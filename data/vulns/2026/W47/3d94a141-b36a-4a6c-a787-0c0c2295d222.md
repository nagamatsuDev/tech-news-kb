# Git LFS may execute arbitrary commands via crafted Git configurations

- **ID**: CVE\-2026\-105802 / GHSA\-xrgv\-7vx6\-5vx6
- **危険度**: High（重要） (CVSS 8.6)
- **言語**: Go
- **パッケージ**: Go/github\.com/git\-lfs/git\-lfs &gt;\= 0\.6\.0, &lt;\= 2\.13\.3, Go/github\.com/git\-lfs/git\-lfs/v3 &gt;\= 3\.0\.0, &lt; 3\.8\.1 → 3\.8\.1
- **公開**: 2026-11-19

## 原文

\#\#\# Impact When fetching objects from a malicious repository, Git LFS may execute an arbitrary command or binary after incorrectly parsing the Git configuration options defined for a submodule\. Git LFS reads Git configuration options without checking for embedded line\-ending control characters\. By inserting control characters such as line feed \(LF\) into certain values, an attacker may be able to mimic options that cause Git LFS to execute an arbitrary command when fetching or adding objects\.
