# wcmatch\: Polynomial\-time ReDoS when matching untrusted names against multi\-star patterns \(default flags\)

- **ID**: CVE\-2026\-132276 / GHSA\-53pm\-wgxf\-c6qf
- **危険度**: Medium（警告） (CVSS 5.9)
- **言語**: Python

## 原文

\# Summary With default flags, a pattern that contains several \`\*\` wildcards takes polynomial time, O\(n\^k\) for k stars, to reject a crafted file name\. The pattern is an ordinary developer constant such as \`\*\_\*\_\*\_\*\_\*\.csv\`; only the string being matched comes from the attacker\. A 255\-byte file name \(the maximum on common filesystems\) takes 73 s with \`fnmatch\.fnmatch\(\)\` and 86 s with \`glob\.globmatch\(\)\`\. The standard library's \`fnmatch\` handles the same input in under a millisecond\.
