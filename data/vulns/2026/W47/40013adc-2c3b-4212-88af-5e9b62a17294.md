# node\-soap before 1\.14\.1 contains a prototype pollution vulnerability in WSDL\.xmlToObject that allows unauthenticated attackers to pollute\.\.\.

- **ID**: CVE\-2026\-133243
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-11-19

## 原文

node\-soap before 1\.14\.1 contains a prototype pollution vulnerability in WSDL\.xmlToObject that allows unauthenticated attackers to pollute Object\.prototype via an XML element with id\="\_\_proto\_\_"\. Attackers can send a single crafted SOAP request to a soap\.listen\(\) server, or return a malicious response to a client, causing all subsequent SOAP parsing to fail until process restart\.
