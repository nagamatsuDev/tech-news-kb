# The Toocheke Companion plugin for WordPress is vulnerable to Missing Authorization leading to arbitrary post and attachment deletion in v\.\.\.

- **ID**: CVE\-2026\-120556
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-20

## 原文

The Toocheke Companion plugin for WordPress is vulnerable to Missing Authorization leading to arbitrary post and attachment deletion in versions up to, and including, 2\.38\. This is due to a missing object\-level capability check in the toocheke\_tapas\_ajax\_cleanup\_start\(\) and toocheke\_tapas\_ajax\_cleanup\_step\(\) AJAX handlers; the toocheke\_tapas\_cleanup\_ajax\_guard\(\) method only verifies the primitive delete\_posts capability \(held by every Contributor\) and never calls current\_user\_can\('delete\_post', \$post\_id\) or delete\_others\_posts before passing the attacker\-supplied series\_post\_id to wp\_delete\_post\(\) and wp\_delete\_attachment\(\) with force\-delete enabled\. The required nonce is emitted on the Import\: Tapas admin page, which is gated only by edit\_posts, so a Contributor can read it\. This makes it possible for authenticated attackers, with Contributor\-level access and above, to permanently delete any importer\-created series post, every child 'comic' post attached to it, and every Media Library attachment belonging to those posts — regardless of which user originally created them\.
