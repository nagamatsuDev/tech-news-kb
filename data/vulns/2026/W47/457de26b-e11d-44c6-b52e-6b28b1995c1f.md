# The Advanced Country Blocker plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'REQUEST\_URI' parameter in all ver\.\.\.

- **ID**: CVE\-2026\-116758
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The Advanced Country Blocker plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'REQUEST\_URI' parameter in all versions up to, and including, 2\.3\.2 due to insufficient input sanitization and output escaping\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\. The injected script is stored via the advcb\_live\_activity transient on the init hook and executed when an administrator views the Live Monitor page, as the stored URI is unsafely concatenated into a double\-quoted HTML title attribute and inserted into the DOM via jQuery \.html\(\)\.
