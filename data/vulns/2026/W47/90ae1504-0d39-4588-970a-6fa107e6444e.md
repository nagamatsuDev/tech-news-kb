# ioBroker\.lovelace before 7\.0\.0 contains a path traversal vulnerability in the onCards\(\) request handler that allows unauthenticated remot\.\.\.

- **ID**: CVE\-2026\-130841
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-17

## 原文

ioBroker\.lovelace before 7\.0\.0 contains a path traversal vulnerability in the onCards\(\) request handler that allows unauthenticated remote attackers to read arbitrary files via unsanitized dot\-dot segments\. Attackers can send crafted requests to the /cards/\_static\_/, /hacsfiles/, or /local/custom\_ui/ routes to read files including ioBroker configuration and stored credentials\.
