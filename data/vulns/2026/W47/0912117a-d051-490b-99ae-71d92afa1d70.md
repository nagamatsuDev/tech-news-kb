# k8s\-mcp\-server manages Kubernetes clusters through the Model Context Protocol\.

- **ID**: CVE\-2026\-130007 / GHSA\-m932\-63jc\-4jqq
- **危険度**: High（重要） (CVSS 7.9)
- **公開**: 2026-11-18

## 原文

k8s\-mcp\-server manages Kubernetes clusters through the Model Context Protocol\. Prior to 1\.1\.0, SERVER\_MODE defaults to SSE, with the listener on 0\.0\.0\.0\:8080, but main\.go creates the SSE server without an authentication option or context function\. The GET /sse handler creates a sessionId that is only a correlation value, and the POST /message handler accepts a loadable sessionId without an authorization or Origin check before dispatching tools/call; consequently, any client able to reach the port can enumerate and invoke registered Kubernetes tools without credentials\. Read\-only mode is disabled by default, leaving write\-capable Kubernetes tools available to run with the server's configured cluster privileges\. This issue is fixed in version 1\.1\.0\.
