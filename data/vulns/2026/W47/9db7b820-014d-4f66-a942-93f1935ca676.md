# fzf\: Arbitrary command execution via bash arithmetic expansion on unvalidated layout size in fzf\-tmux \(\-l/\-u attached value\)

- **ID**: CVE\-2026\-121716 / GHSA\-w6x2\-f5m4\-xw82
- **危険度**: High（重要） (CVSS 7.0)
- **言語**: Go
- **パッケージ**: Go/github\.com/junegunn/fzf &lt;\= 0\.74\.4 → 0\.74\.5
- **公開**: 2026-11-17

## 原文

\#\#\# Summary \`bin/fzf\-tmux\` fails to validate layout size values given in the \*attached\* form \(e\.g\. \`\-l50\`\)\. For \`\-l\`/\`\-u\` these values reach bash arithmetic expansion \(\`\$\(\( max \- size \)\)\`\), where an operand like \`a\[\$\(cmd\)\]\` executes \`cmd\` as the invoking user during option parsing — before any tmux interaction and even outside tmux\. A second sink embeds unvalidated popup geometry \(\`\-x/\-y/\-w/\-h/\-p\`\) into an unquoted \`tmux popup \.\.\. \$opt \.\.\.\` invocation, allowing injection of tmux flags such as \`\-e BASH\_ENV\=&lt;path&gt;\` \(command execution via non\-interactive bash sourcing \`\$BASH\_ENV\`\)\. \#\#\# Reporter /
