# Issue summary\: The QUIC stack queues a RETIRE\_CONNECTION\_ID frame also for retransmitted NEW\_CONNECTION\_ID frames\.

- **ID**: CVE\-2026\-107494
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-18

## 原文

Issue summary\: The QUIC stack queues a RETIRE\_CONNECTION\_ID frame also for  
retransmitted NEW\_CONNECTION\_ID frames\. This allows a remote malicious  
QUIC stack to queue an unlimited number of RETIRE\_CONNECTION\_ID frames\.
  
Impact summary\: A malicious remote QUIC peer can trigger an out\-of\-memory  
condition causing a Denial of Service\.
  
CWE\: CWE\-770\: Allocation of Resources Without Limits or Throttling
  
Description\: The earlier fix for CVE\-2026\-84784 was not complete\. It  
failed to ignore retransmissions of the NEW\_CONNECTION\_ID frame\. The QUIC  
implementation created and inserted a RETIRE\_CONNECTION\_ID frame for every  
retransmitted NEW\_CONNECTION\_ID frame it received and there was no limit  
on how many RETIRE\_CONNECTION\_ID frames were queued\.  
This allows a malicious remote QUIC stack to trigger an out\-of\-memory \(OOM\)  
condition\.
  
FIPS impact\: no  
The FIPS module is not affected as the QUIC implementation is outside the  
OpenSSL FIPS module boundary\.
