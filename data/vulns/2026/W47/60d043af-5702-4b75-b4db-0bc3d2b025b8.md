# In Splunk Enterprise Security versions below 8\.7\.0, a user that holds a role with the mc\_view\_im\_data capability could cause the Mission \.\.\.

- **ID**: CVE\-2026\-131198
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-19

## 原文

In Splunk Enterprise Security versions below 8\.7\.0, a user that holds a role with the mc\_view\_im\_data capability could cause the Mission Control incident mapping Representational State Transfer \(REST\) API to run arbitrary Search Processing Language \(SPL\) commands with elevated permissions\. With this access, the user could expose all data in Splunk indexes and all stored credentials and modify protected indexes and lookup data\.  
The vulnerability is possible because the Mission Control incident mapping REST API does not validate incident identifiers before including them in SPL searches\.  
For more information see Capability reference for Splunk Enterprise Security \(https\://help\.splunk\.com/en/splunk\-enterprise\-security\-8/install/8\.7/installation/capability\-reference\-for\-splunk\-enterprise\-security\) and Overview of Mission Control in Splunk Enterprise Security \(https\://help\.splunk\.com/en/splunk\-enterprise\-security\-8/user\-guide/8\.7/mission\-control/overview\-of\-mission\-control\-in\-splunk\-enterprise\-security\) in the Splunk documentation\.
