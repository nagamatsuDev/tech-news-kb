# Netatalk is a Free and Open Source file server suite for Unix\-like operating systems\.

- **ID**: CVE\-2026\-45355
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-20

## 原文

Netatalk is a Free and Open Source file server suite for Unix\-like operating systems\. Prior to 4\.4\.3, the afpd Spotlight RPC string unmarshalling path in etc/afpd/spotlight\_marshalling\.c uses sl\_unpack\_cpx to calculate slen from qlen and the attacker\-controlled used\_in\_last\_block value without preventing a negative result\. An authenticated AFP client can send a complex string or UTF\-16 string element that makes slen negative, and the implicit conversion to size\_t causes dalloc\_strndup or convert\_string\_allocate to read beyond the heap buffer\. The out\-of\-bounds read can expose heap data through the RPC response or crash the worker process\. This issue is fixed in version 4\.4\.3\.
