# The UpdraftPlus\: WP Backup &amp; Migration Plugin WordPress plugin before 2\.26\.16\.26, UpdraftPlus\: WP Backup &amp; Migration Plugin WordPress plu\.\.\.

- **ID**: CVE\-2026\-121155
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-21

## 原文

The UpdraftPlus\: WP Backup &amp; Migration Plugin WordPress plugin before 2\.26\.16\.26, UpdraftPlus\: WP Backup &amp; Migration Plugin WordPress plugin before 1\.26\.16 do not preserve the escaping of JSON\-formatted database values when they rewrite the database during a restore to a new address or server, which could allow unauthenticated attackers to plant harmless\-looking escaped markup, for example in a comment author name, that becomes Stored Cross\-Site Scripting once an administrator performs such a restore\.
