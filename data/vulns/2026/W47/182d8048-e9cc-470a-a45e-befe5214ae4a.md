# Convert\:\:ASN1 versions before 0\.37 for Perl allow CPU exhaustion via exponent\-notation string in INTEGER encoding\.

- **ID**: CVE\-2026\-126682
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-20

## 原文

Convert\:\:ASN1 versions before 0\.37 for Perl allow CPU exhaustion via exponent\-notation string in INTEGER encoding\.
  
The encoder routes any value with abs &gt;\= 2\*\*31 to i2osp without validating that it is an integer\. A string in exponent notation such as "1e8000" passes that threshold\. Math\:\:BigInt expands it to an 8001\-digit integer, and i2osp's per\-octet conversion loop is quadratic in that size\.
  
An attacker who controls encoded INTEGER values can exhaust CPU with a short exponent\-notation string\.
