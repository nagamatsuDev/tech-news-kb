# mssql\-mcp\-core\: SQL injection in mssql\-mcp write tools via unparameterized table names and WHERE clauses

- **ID**: CVE\-2026\-63129 / GHSA\-2m9m\-6cr5\-9x25
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/@connorbritain/mssql\-mcp\-core &lt;\= 0\.5\.0 → 0\.6\.0, npm/@connorbritain/mssql\-mcp\-reader &lt;\= 0\.4\.2 → 0\.5\.0, npm/@connorbritain/mssql\-mcp\-writer &lt;\= 0\.4\.2 → 0\.5\.0, npm/@connorbritain/mssql\-mcp\-server &lt;\= 0\.5\.2 → 0\.6\.0
- **公開**: 2026-11-18

## 原文

Several tools in \`mssql\-mcp\-core\` built T\-SQL by string\-interpolating caller\-supplied identifiers and predicates directly into the statement passed to the node\-mssql \`Request\.query\(\)\` batch API\. Only data values were parameterized\. Affected tools and inputs\: \- \`update\_data\`, \`delete\_data\`\: \`tableName\` and the free\-form \`whereClause\` were interpolated raw\. \- \`insert\_data\`\: \`tableName\` and column names \(object keys\) were interpolated raw\. \- \`execute\_transaction\`\: the same raw \`tableName\`/\`whereClause\` interpolation per operation\. \- \`create\_table\`, \`create\_index\`, \`drop\_table\`\: table/column/index
