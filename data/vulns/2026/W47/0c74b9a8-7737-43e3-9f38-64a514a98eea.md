# The Dynific Addons for Elementor \(formerly Anywhere Elementor\) WordPress plugin before 1\.3\.1 does not perform a capability check on an AJ\.\.\.

- **ID**: CVE\-2026\-117520
- **危険度**: High（重要） (CVSS 8.0)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The Dynific Addons for Elementor \(formerly Anywhere Elementor\) WordPress plugin before 1\.3\.1 does not perform a capability check on an AJAX action that stores a configuration value, allowing any authenticated user, including Subscribers, to store a value that is later output without proper escaping in a quoted attribute on an administrator settings page, resulting in Stored Cross\-Site Scripting that executes in the administrator's session\.
