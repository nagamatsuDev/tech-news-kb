# Snap7 through 1\.4\.3 contains a heap\-based buffer overflow in TSnap7MicroClient\:\:opReadSZL\(\) that allows malicious PLCs to overwrite clien\.\.\.

- **ID**: CVE\-2026\-131849
- **危険度**: High（重要） (CVSS 7.4)
- **公開**: 2026-11-18

## 原文

Snap7 through 1\.4\.3 contains a heap\-based buffer overflow in TSnap7MicroClient\:\:opReadSZL\(\) that allows malicious PLCs to overwrite client memory by sending oversized multi\-slice SZL responses\. A rogue or impersonated PLC can keep flagging more data with attacker\-controlled DLen slices, overflowing the 65536\-byte opData buffer via Cli\_ReadSZL\(\) and Cli\_ReadSZLList\(\), crashing the client and corrupting heap memory\.
