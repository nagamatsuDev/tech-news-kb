# Next\.js\: Cache leak across root param values in nested 'use cache' functions via delayed inner stream metadata

- **ID**: CVE\-2026\-119351 / GHSA\-vc7v\-qv4w\-wrv8
- **危険度**: Medium（警告）
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/next &gt;\= 16\.2\.0, &lt;\= 16\.4\.4 → 16\.4\.5
- **公開**: 2026-11-17

## 原文

With Cache Components enabled, an outer \`'use cache'\` function can be keyed incorrectly even when its inner \`'use cache'\` call generates a fresh entry\. If the inner function reads a root param \(via \`next/root\-params\`\) and returns a value that still contains pending promises — for example an object with data that is ready immediately alongside slower data — React Flight delivers the ready portion to the outer function before the inner entry has finished publishing its root param dependencies\.
