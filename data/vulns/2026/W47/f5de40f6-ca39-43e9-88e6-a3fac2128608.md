# Mareforma\: invalidated claims still promote to REPLICATED

- **ID**: CVE\-2026\-71500 / GHSA\-rgg9\-956j\-3378
- **危険度**: Medium（警告）
- **言語**: Python
- **パッケージ**: PyPI/mareforma &gt;\= 0\.3\.0, &lt; 0\.3\.8 → 0\.3\.8
- **公開**: 2026-11-19

## 原文

\#\# What's wrong \`\_maybe\_update\_replicated\_unlocked\` never checks \`t\_invalid\`, so a claim that a signed contradiction verdict has marked invalid can still climb to REPLICATED through convergence detection, and it pulls an honest peer up with it\. Three gaps line up\: \- The new\-claim short\-circuit reads only \`status\` and \`asserter\_keyid\` \(\`core\.py\:1339\-1352\`\); an invalidated but still\-\`open\` new claim passes\. \- The candidate\-peer SELECT filters \`status \= 'open'\`, \`unresolved \= 0\`, and \`transparency\_logged \= 1\` but has no \`t\_invalid\` predicate \(\`core\.py\:1390\-1410\`\), so an invalidated existing claim
