# contao/core\-bundle\: Improper access control in the CSV import wizard

- **ID**: CVE\-2026\-104882 / GHSA\-23w9\-4pg3\-xwm3
- **危険度**: Medium（警告） (CVSS 6.5)
- **言語**: PHP
- **パッケージ**: Packagist/contao/core\-bundle &gt;\= 5\.0\.0, &lt; 5\.3\.50 → 5\.3\.50, Packagist/contao/core\-bundle &gt;\= 5\.4\.0\-RC1, &lt; 5\.7\.12 → 5\.7\.12
- **公開**: 2026-11-20

## 原文

Custom backend module "key" actions are dispatched in \`Backend\:\:getBackendModule\(\)\` \(Backend\.php\:322\-327\) after only the module\-level \`USER\_CAN\_ACCESS\_MODULE\` check \- no per\-record voter runs\. \#\# Impact A non\-admin editor scoped to certain pages/forms can overwrite the tableitems/listitems/options of arbitrary tl\_content / tl\_form\_field records outside their scope, defeating the per\-record access control\. Integrity IDOR \(blind content overwrite; the value written is \`serialize\(\)\` of a plain string array from the CSV \- not object injection\)\. \#\# Credits This security vulnerability was found by @
