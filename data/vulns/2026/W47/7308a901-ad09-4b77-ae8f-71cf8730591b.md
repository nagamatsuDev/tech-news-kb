# A flaw has been found in Microweber up to 2\.0\.20\.

- **ID**: CVE\-2026\-134623
- **危険度**: High（重要） (CVSS 7.3)
- **言語**: PHP
- **公開**: 2026-11-22

## 原文

A flaw has been found in Microweber up to 2\.0\.20\. This impacts the function UserManager\:\:make\_logged of the file src/MicroweberPackages/App/Http/Controllers/ApiController\.php of the component Generic API Dispatcher\. This manipulation causes improper access controls\. Remote exploitation of the attack is possible\. The exploit has been published and may be used\. Upgrading to version 2\.0\.21 will fix this issue\. Patch name\: e639d26e61b989b100f8b6f6bb78c0cecca79b99\. You should upgrade the affected component\.
