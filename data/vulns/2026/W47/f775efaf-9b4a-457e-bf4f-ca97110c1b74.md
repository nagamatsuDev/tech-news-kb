# The targets R package before 1\.12\.1 contains a code execution vulnerability that allows attackers to run arbitrary R code by planting for\.\.\.

- **ID**: CVE\-2026\-133707
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-20

## 原文

The targets R package before 1\.12\.1 contains a code execution vulnerability that allows attackers to run arbitrary R code by planting format functions in the data store metadata file\. Attackers can supply a crafted \_targets data store whose custom format or CAS repository functions are passed to eval\(parse\(\)\), executing code when victims call tar\_read\(\), tar\_load\(\) or tar\_workspace\(\)\.
