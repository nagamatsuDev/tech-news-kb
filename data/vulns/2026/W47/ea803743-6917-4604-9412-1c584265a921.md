# Poste\.io is vulnerable to remote code execution in DMARC report processing\.

- **ID**: CVE\-2026\-127027
- **危険度**: Critical（緊急） (CVSS 9.2)
- **公開**: 2026-11-20

## 原文

Poste\.io is vulnerable to remote code execution in DMARC report processing\. Email sent to dmarc\-reports@&lt;domain&gt; is saved without sender verification\. Script that runs as root unpacks the attachments using unsafe shell commands, allowing command injection through crafted attachments \(e\.g\. file names or archive contents\)\. A remote unauthenticated attacker who can send an email to the server's port 25 can execute arbitrary commands as root within the Poste\.io container\.
  
This issue was fixed in version 2\.5\.22\.
