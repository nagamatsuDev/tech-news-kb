# Mistune is a Python Markdown parser with renderers and plugins\.

- **ID**: CVE\-2026\-97699
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: Python
- **公開**: 2026-11-17

## 原文

Mistune is a Python Markdown parser with renderers and plugins\. Prior to 3\.3\.4, inline image parsing sends nested \!\[ openers through precedence\_scan because the no\_link\_before and \_label\_contains\_link linearization guards are gated by not is\_image\. In src/mistune/inline\_parser\.py, each outer image opener can therefore search the remaining image body, while max\_image\_depth does not apply because the failed scans do not produce image tokens\. Rendering untrusted Markdown with the default HTML renderer and no plugins can perform quadratic CPU work and keep a worker at 100 percent utilization\. This issue is fixed in version 3\.3\.4\.
