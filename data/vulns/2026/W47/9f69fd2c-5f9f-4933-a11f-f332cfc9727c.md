# The WPvivid — Backup, Migration &amp; Staging WordPress plugin before 0\.9\.140 does not limit its table prefix rewrite to table names when res\.\.\.

- **ID**: CVE\-2026\-120390
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The WPvivid — Backup, Migration &amp; Staging WordPress plugin before 0\.9\.140 does not limit its table prefix rewrite to table names when restoring a database backup, which corrupts the length of stored serialized values and allows users with a role as low as Subscriber to plant a PHP object that WordPress instantiates after an administrator restores a backup\.
