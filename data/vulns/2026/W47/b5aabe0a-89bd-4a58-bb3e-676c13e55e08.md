# Radicale 3\.3\.0 before 3\.8\.3 contains an authorization bypass vulnerability that allows unauthenticated attackers to inherit group\-based r\.\.\.

- **ID**: CVE\-2026\-130838
- **危険度**: High（重要） (CVSS 7.4)
- **公開**: 2026-11-17

## 原文

Radicale 3\.3\.0 before 3\.8\.3 contains an authorization bypass vulnerability that allows unauthenticated attackers to inherit group\-based rights by reusing group memberships never reset between requests\. Attackers can send credential\-less requests after a group member logs in to read and write group\-shared calendar and address book collections evaluated by the from\_file rights backend\.
