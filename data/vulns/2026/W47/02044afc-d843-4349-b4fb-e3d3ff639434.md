# In the Linux kernel, the following vulnerability has been resolved\: mptcp\: pm\: kernel\: use RCU to free endpoint listeners mptcp\_pm\_nl\_c\.\.\.

- **ID**: CVE\-2026\-99603
- **危険度**: High（重要） (CVSS 7.8)
- **OS**: Linux
- **公開**: 2026-11-20

## 原文

In the Linux kernel, the following vulnerability has been resolved\:
  
mptcp\: pm\: kernel\: use RCU to free endpoint listeners
  
mptcp\_pm\_nl\_create\_listen\_socket\(\) starts the TCP listener directly  
instead of going through mptcp\_listen\(\)\. It consequently misses setting  
SOCK\_RCU\_FREE on the parent MPTCP socket\.
  
tcp\_child\_process\(\) can invoke the listener's subflow\_data\_ready\(\)  
callback without holding the MPTCP parent lock or a reference to the  
parent\. An authenticated MP\_JOIN racing with endpoint teardown can  
therefore access the parent after its last reference has been dropped\.  
The ADD\_ADDR error path can also close an already published listener\.
  
Set SOCK\_RCU\_FREE before \_\_inet\_listen\_sk\(\) publishes the TCP listener,  
matching mptcp\_listen\(\)\. This protects the parent on every subsequent  
close path, including a failed endpoint addition\.
