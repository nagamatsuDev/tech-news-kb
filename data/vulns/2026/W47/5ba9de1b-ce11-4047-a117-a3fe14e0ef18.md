# DeepAudit 2\.0\.0\-beta\.1から3\.8\.0までにはパストラバーサル脆弱性があり、認証されたユーザが\.NETでJJbraryファイルを記述できる。

- **ID**: CVE\-2026\-129879
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-16

## 概要（機械翻訳）

DeepAudit 2\.0\.0\-beta\.1から3\.8\.0まではパストラバーサル脆弱性を備えており、認証されたユーザが、グラフ化されたIDを持つプロジェクトをインポートすることで、Hgbitraryファイルを記述できる。は、\.が\.\.が\.である。である。攻撃者は /api/v1/database/import で絶対または\./ プロジェクト ID を設定し、クローンされたシンボリックリンクに続いて /api/v1/scan/upload\-zip で ZIP をアップロードして、リモートコード実行用に app/main\.py を上書きできます。

## 原文

DeepAudit 2\.0\.0\-beta\.1 through 3\.8\.0 contains a path traversal vulnerability that allows authenticated users to write arbitrary files by importing projects with crafted IDs\. Attackers can set absolute or \.\./ project IDs via /api/v1/database/import, then upload ZIPs through /api/v1/scan/upload\-zip following cloned symlinks to overwrite app/main\.py for remote code execution\.
