# Forge, also called node\-forge, is a native implementation of Transport Layer Security in JavaScript\.

- **ID**: CVE\-2026\-119192
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: JavaScript/TypeScript
- **公開**: 2026-11-17

## 原文

Forge, also called node\-forge, is a native implementation of Transport Layer Security in JavaScript\. Prior to 1\.4\.1, publicKey\.verify\(\) with the default RSASSA\-PKCS1\-V1\_5 scheme in lib/rsa\.js parses the recovered DigestInfo with the lenient BER parser asn1\.fromDer\(\) and validates its structure with digestInfoValidator without requiring canonical DER bytes\. Non\-minimal or indefinite lengths, malformed parameter values, and non\-canonical object identifier encodings with padded subidentifiers or trailing bytes can leave attacker\-controlled data inside an accepted DigestInfo\. When the verifying RSA public key uses a low exponent such as e\=3, an attacker can use that encoding slack to forge a signature without the private key\. The same path is used by X\.509 certificate and PKCS\#7 signature verification\. This issue is fixed in version 1\.4\.1\.
