# NotrinosERP is an open\-source web\-based enterprise resource planning system written in PHP and MySQL\.

- **ID**: CVE\-2026\-76913
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

NotrinosERP is an open\-source web\-based enterprise resource planning system written in PHP and MySQL\. From 1\.0\.0 until 1\.1\.0, the employee document handler in hrm/manage/employees\.php allows an authenticated user with SA\_EMPLOYEE permission to submit doc\_file through tab\_documents\(\) and stores the raw client filename, including an executable extension, under company/0/documents/employees/ without extension, MIME, or content validation\. Uploading a PHP file places executable content beneath the web root, where requesting the stored file results in server\-side code execution\. This issue is fixed in version 1\.1\.0\.
