# aMQTT is an open source MQTT broker and client\.

- **ID**: CVE\-2026\-130176
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-19

## 原文

aMQTT is an open source MQTT broker and client\. From 0\.11\.0 until 0\.12\.1, the QoS 2 transaction handler in amqtt/mqtt/protocol/handler\.py, \_handle\_qos2\_message\_flow\(\), can retain transaction state and packet identifiers when a client disconnects before the handshake completes, unlike QoS 1 flows that expire after the default five\-second timeout\. A remote client can repeatedly begin QoS 2 flows and disconnect without maintaining long\-lived connections; anonymous clients can do this with the default configuration, while authenticated deployments remain affected when a client may initiate QoS 2 flows\. The retained state grows broker memory until resource exhaustion can terminate the process; no confidentiality or integrity impact is identified\. This issue is fixed in version 0\.12\.1\.
