# aMQTT\: Denial of Service \(DoS\) via Memory Leak in Unmanaged QoS 2 Session Handshakes

- **ID**: CVE\-2026\-130176 / GHSA\-wcqj\-wx85\-c75p
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: Python
- **パッケージ**: PyPI/amqtt &gt;\= 0\.11\.0, &lt;\= 0\.12\.0 → 0\.12\.1
- **公開**: 2026-11-19

## 原文

\#\#\# Impact \`amqtt\` is vulnerable to a remote denial of service caused by incomplete MQTT QoS 2 transactions remaining allocated after the associated client disconnects\. MQTT QoS 2 uses a four\-step handshake to provide exactly\-once delivery\. If a client begins a QoS 2 transaction but disconnects before the handshake completes, \`amqtt\` retains the associated transaction state and packet identifier without an expiration mechanism to remove it\. QoS 1 transactions are protected by a timeout mechanism, which defaults to 5 seconds, allowing abandoned state to be released\. Equivalent timeout handling
