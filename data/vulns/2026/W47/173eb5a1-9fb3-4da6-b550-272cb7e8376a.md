# mini\-snmpd is a minimal SNMP agent implementation\.

- **ID**: CVE\-2026\-59961
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-11-18

## 原文

mini\-snmpd is a minimal SNMP agent implementation\. Prior to 1\.7, the ASN\.1 BER parser in protocol\.c does not verify that an attacker\-controlled field length is no greater than the remaining packet size before decode\_str\(\), decode\_oid\(\), and decode\_ptr\(\) evaluate size \- len \+ 1\. When len exceeds size, unsigned size\_t arithmetic wraps and bypasses the bounds check, allowing the decoder to read beyond the 2048\-byte packet buffer\. Parsing occurs before the SNMP community string is checked, so a remote unauthenticated attacker can send one crafted request to UDP port 161 to crash the process and potentially disclose adjacent heap memory\. This issue is fixed in version 1\.7\.
