# ModelScope 1\.11\.0 to before 1\.40\.1 contains an unsafe reflection vulnerability in the image\-to\-3D SyncDreamer pipeline that allows remote\.\.\.

- **ID**: CVE\-2026\-130839
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-17

## 原文

ModelScope 1\.11\.0 to before 1\.40\.1 contains an unsafe reflection vulnerability in the image\-to\-3D SyncDreamer pipeline that allows remote attackers to execute code via crafted model configuration\. Attackers can publish a model whose syncdreamer\.yaml target field makes instantiate\_from\_config\(\) import and instantiate any class with controlled params, without an allowlist or trust\_remote\_code check, executing code when victims load it\.
