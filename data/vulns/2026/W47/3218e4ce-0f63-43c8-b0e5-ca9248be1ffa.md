# WP File Manager before 8\.0\.7 contains a file upload restriction bypass vulnerability that allows authenticated administrators to upload a\.\.\.

- **ID**: CVE\-2026\-82025
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-17

## 原文

WP File Manager before 8\.0\.7 contains a file upload restriction bypass vulnerability that allows authenticated administrators to upload arbitrary PHP files by exploiting a misconfigured elFinder connector in file\_folder\_manager\.php where an empty uploadDeny list causes allowPutMime\(\) to unconditionally return true, bypassing the uploadAllow restriction\. Attackers can upload a \.php file directly or upload it under an allowed filename and then rename it via the rename connector command, achieving remote code execution as the web server user\.
