# flowintel contains an authorization bypass in the browser\-based admin user editing interface\.

- **ID**: CVE\-2026\-133847
- **危険度**: High（重要） (CVSS 8.4)
- **公開**: 2026-11-20

## 原文

flowintel contains an authorization bypass in the browser\-based admin user editing interface\. The edit\_user view in the admin panel verified that a non\-platform\-admin user could only edit accounts belonging to their own organization, but it did not verify that the target account was not a platform\-admin account\. As a result, an authenticated user holding an organization\-admin role could open the edit form for any platform\-admin account and submit modifications, including changes to credentials, roles, or other account attributes\.
  
The API layer already enforced a restriction preventing non\-admin users from targeting admin accounts, but the browser\-based admin view lacked the equivalent check, creating an inconsistent authorization boundary\.
  
Impact\:  
\- Unauthorized modification of platform\-admin account data \(integrity\)  
\- Potential lockout or privilege manipulation of platform administrators \(availability\)  
\- Escalation of an organization\-admin role to effectively control platform\-level administration
  
Affected versions\: flowintel prior to 4\.1\.0\.
