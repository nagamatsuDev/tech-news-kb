# modified eCommerce Shopsoftware through 3\.3\.0 contains a local file inclusion vulnerability that allows administrators to include arbitra\.\.\.

- **ID**: CVE\-2026\-133246
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-19

## 原文

modified eCommerce Shopsoftware through 3\.3\.0 contains a local file inclusion vulnerability that allows administrators to include arbitrary server files by storing \.\./ sequences in the content manager file name\. Unauthenticated requests to shop\_content\.php then pass the stored path to include\(\), executing embedded PHP in uploaded content files or images as the web server user\.
