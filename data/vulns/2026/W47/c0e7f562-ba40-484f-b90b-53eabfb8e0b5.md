# DeepAudit 2\.0\.0\-beta\.1 through 3\.8\.0 contains an HTML injection vulnerability in ReportGenerator\.generate\_task\_report that allows registe\.\.\.

- **危険度**: High（重要） (CVSS 7.7)
- **公開**: 2026-11-16

## 原文

DeepAudit 2\.0\.0\-beta\.1 through 3\.8\.0 contains an HTML injection vulnerability in ReportGenerator\.generate\_task\_report that allows registered users to read server files and perform SSRF\. Attackers can create a project whose name contains a link attachment element and download the task PDF report to retrieve local files or internal network responses\.
