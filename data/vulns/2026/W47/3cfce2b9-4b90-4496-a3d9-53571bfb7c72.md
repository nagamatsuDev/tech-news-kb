# devpi\-web before 5\.2\.0 contains an unauthenticated path traversal vulnerability in the \+doc documentation route because docs\_file\_exists \.\.\.

- **ID**: CVE\-2026\-134167
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-20

## 原文

devpi\-web before 5\.2\.0 contains an unauthenticated path traversal vulnerability in the \+doc documentation route because docs\_file\_exists and docs\_file\_path in doczip\.py never confine relpath to the documentation directory\. Attackers can request a relpath with a leading // or percent\-encoded \.\. segments to read server files, including the keyfs sqlite database holding password hashes\.
