# VB\-Audio VB\-CABLE before 3\.5\.2\.0 contains out\-of\-bounds read and write vulnerabilities in the vbaudio\_cable64\_win10\.sys kernel streaming \.\.\.

- **ID**: CVE\-2026\-124019
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-16

## 原文

VB\-Audio VB\-CABLE before 3\.5\.2\.0 contains out\-of\-bounds read and write vulnerabilities in the vbaudio\_cable64\_win10\.sys kernel streaming driver's KSPROPSETID\_Audio MUTE, VOLUMELEVEL, and PEAKMETER2 property handlers that allow a local standard user to supply an all\-channels sentinel value improperly used as a loop terminator or array index instead of being bounds\-checked\. Attackers can exploit the accessible low\-integrity KS filter device object to write attacker\-controlled values sequentially into kernel memory, corrupting kernel globals and object pointers, or read past an array boundary to leak kernel memory, resulting in local privilege escalation or denial of service via a kernel bug check\.
