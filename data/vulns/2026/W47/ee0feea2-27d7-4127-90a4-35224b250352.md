# Pi\-hole FTL is the core engine of the Pi\-hole network\-level advertisement and tracker blocker\.

- **ID**: CVE\-2026\-65963
- **危険度**: High（重要） (CVSS 7.2)
- **公開**: 2026-11-17

## 原文

Pi\-hole FTL is the core engine of the Pi\-hole network\-level advertisement and tracker blocker\. From 6\.6\.2 until 6\.7, PATCH /api/config accepts unfiltered CivetWeb lua\_\* options through webserver\.advancedOpts, while POST /api/teleporter writes attacker\-controlled content from a dhcp\.leases archive entry through src/zip/teleporter\.c without content validation\. An authenticated administrator can place controlled file content on disk, point a Lua execution option at that file, and rely on the advancedOpts configuration change to restart FTL\. CivetWeb then executes the file as Lua through the processing in src/webserver/webserver\.c, allowing arbitrary commands to run as the pihole operating\-system user and persist across restarts while the configuration and file remain\. This issue is fixed in version 6\.7\.
