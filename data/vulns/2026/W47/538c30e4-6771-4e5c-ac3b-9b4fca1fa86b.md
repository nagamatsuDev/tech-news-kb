# GreaterWMS through 2\.1\.54 contains an unauthenticated path traversal vulnerability in the css, js, statics and fonts routes in greaterwms\.\.\.

- **ID**: CVE\-2026\-130867
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-17

## 原文

GreaterWMS through 2\.1\.54 contains an unauthenticated path traversal vulnerability in the css, js, statics and fonts routes in greaterwms/views\.py, which concatenate raw request\.path\_info without normalization\. Attackers can send URL\-encoded \.\./ sequences to read db\.sqlite3 and obtain user openid tokens, enabling impersonation of any account\.
