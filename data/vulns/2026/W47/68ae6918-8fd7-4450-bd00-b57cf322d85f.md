# Netatalk is a Free and Open Source file server suite for Unix\-like operating systems\.

- **ID**: CVE\-2026\-45354
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-20

## 原文

Netatalk is a Free and Open Source file server suite for Unix\-like operating systems\. Prior to 4\.4\.3, libatalk/dsi/dsi\_stream\.c interprets the dsi\_code and dsi\_doff union field as a data offset for all DSI command types instead of limiting that interpretation to DSIWrite\. An unauthenticated client can send a non\-WRITE DSIFUNC\_CMD packet with a nonzero dsi\_code smaller than dsi\_len, causing dsi\_stream\_receive to consume only the dsi\_code number of payload bytes and leave attacker\-controlled bytes in the readahead buffer\. The residual bytes become the next DSI header, allowing protocol desynchronization that can close sessions, corrupt protocol state, or trigger an infinite\-read denial of service\. This issue is fixed in version 4\.4\.3\.
