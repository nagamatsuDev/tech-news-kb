# In the Linux kernel, the following vulnerability has been resolved\: ASoC\: SOF\: Intel\: hda\-sdw\-bpt\: Stop active DMA before closing BPT st\.\.\.

- **ID**: CVE\-2026\-99746
- **危険度**: High（重要） (CVSS 7.0)
- **OS**: Linux
- **公開**: 2026-11-20

## 原文

In the Linux kernel, the following vulnerability has been resolved\:
  
ASoC\: SOF\: Intel\: hda\-sdw\-bpt\: Stop active DMA before closing BPT streams
  
When sdw\_enable\_stream\(\) fails in intel\_ace2x\_bpt\_send\_async\(\) after  
hda\_sdw\_bpt\_send\_async\(\) has already started the TX and RX DMA streams,  
intel\_ace2x\_bpt\_close\_stream\(\) invokes hda\_sdw\_bpt\_close\(\) directly  
without calling hda\_sdw\_bpt\_wait\(\)\.  As a result,  
hda\_sdw\_bpt\_dma\_deprepare\(\) tears down the DMA buffers and BDL while  
the DMA hardware is still running\.
  
Disable any running TX or RX BPT DMA stream at the start of  
hda\_sdw\_bpt\_close\(\) before unmapping channels and depreparing DMA  
resources\.
