# install\-artifact\-from\-github loads downloaded native artifacts without integrity verification

- **ID**: CVE\-2026\-73864 / GHSA\-88q3\-gch3\-5396
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/install\-artifact\-from\-github &lt;\= 1\.6\.0 → 1\.7\.0
- **公開**: 2026-11-18

## 原文

\#\# Description \`bin/install\-from\-cache\.js\` downloads a prebuilt native addon \(\`\*\.node\`\) over the network and writes it directly to the artifact path \*\*with no cryptographic integrity verification of any kind\*\* — no checksum manifest, no signature, no SRI\. A scan of the whole package for \`createHash\|sha256\|checksum\|integrity\|digest\|signature\` finds nothing\. The file is then \`require\(\)\`\-loaded by the consumer, which executes the addon's native module\-init code\.
