# install\-artifact\-from\-github installs prebuilt native artifacts hosted by GitHub without compiling them locally\.

- **ID**: CVE\-2026\-73864 / GHSA\-88q3\-gch3\-5396
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-18

## 原文

install\-artifact\-from\-github installs prebuilt native artifacts hosted by GitHub without compiling them locally\. Prior to 1\.7\.0, bin/install\-from\-cache\.js downloads a native \.node artifact, allows RE2\_DOWNLOAD\_MIRROR to select a source, follows HTTP redirects including HTTPS\-to\-HTTP downgrades, and writes the decompressed response to the artifact path without cryptographic integrity verification before writing or loading it\. An attacker who controls a configured mirror, replaces a release asset, or can modify plaintext transport can supply native code that executes when the consumer loads the artifact\. Version 1\.7\.0 adds SHA\-256 verification for default\-GitHub\-source downloads when the consuming package publishes an artifactHashes bag; configured mirrors and packages without a bag remain outside that verification\.
