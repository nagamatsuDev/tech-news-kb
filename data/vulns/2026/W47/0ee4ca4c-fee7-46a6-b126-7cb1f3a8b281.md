# Insertion of Sensitive Information into Log File vulnerability in the Apache Iggy server\.

- **ID**: CVE\-2026\-118493
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-18

## 原文

Insertion of Sensitive Information into Log File vulnerability in the Apache Iggy server\. If Apache Iggy 0\.9\.0 started without IGGY\_ROOT\_USERNAME and IGGY\_ROOT\_PASSWORD, it generated a root password and wrote it to the server log file, which is enabled by default\. The system snapshot command \(GetSnapshot on the binary transports and POST /snapshot on HTTP\) let a user with only the read\_servers permission download the server log files\. That user could read the generated root password and log in as root\.
  
This issue affects Apache Iggy\: 0\.9\.0\.
  
Users are recommended to upgrade to version 0\.10\.0, which fixes the issue\. Version 0\.10\.0 never generates a root password, and the snapshot requires the manage\_servers permission\. If a 0\.9\.0 server generated its root password, change that password\.
