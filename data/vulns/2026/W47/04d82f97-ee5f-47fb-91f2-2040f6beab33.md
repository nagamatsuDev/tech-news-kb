# In Postgres Enterprise Manager \(PEM\), the SQL Profiler save and load functions in the PEM web application do not keep the client\-supplied\.\.\.

- **ID**: CVE\-2026\-132662
- **危険度**: High（重要） (CVSS 7.2)
- **公開**: 2026-11-20

## 原文

In Postgres Enterprise Manager \(PEM\), the SQL Profiler save and load functions in the PEM web application do not keep the client\-supplied file name inside the user's storage directory\. A user with the SQL Profiler role \(pem\_comp\_sqlprofiler\) can read JSON files, and overwrite files that the PEM web server account can write, outside their own storage directory\. Overwriting the PEM web application's configuration database stops the web console for all users\.  
From PEM 10\.6\.1, the SQL Profiler only reads and writes files inside the user's storage directory\.
