# commit c731cdfからcommit 672dfecまでのメインブランチのmumeeb141によるゴーストは、WWで認証バイパス脆弱性を含む。

- **ID**: CVE\-2026\-130070
- **危険度**: Critical（緊急） (CVSS 9.1)
- **公開**: 2026-11-16

## 概要（機械翻訳）

commit c731cdfからcommit 672dfecまでのメインブランチのmumeeb141によるゴーストは、クライアントが提供したbypass\_otpパラメータを設定することで、認証されていない攻撃者がOTP検証をスキップできる白リストのghost\.api\.ghost\.convert\_real\_userメソッドに認証バイパス脆弱性を含む。攻撃者はゲストがアクセス可能なcreate\_ghost\_sessionエンドポイントからゴーストセッションを取得し、 convert\_to\_real\_user withan Hgrary real\_email と bypass\_otp\=1 を呼び出して、既存のアカウントから OAuth トークンを受け取り、引き継ぐことができる。は、アタッカーは、アタッカーがアタックする。

## 原文

Ghost by muneeb141 on the main branch from commit c731cdf through commit 672dfec contains an authentication bypass vulnerability in the whitelisted ghost\.api\.ghost\.convert\_to\_real\_user method that allows unauthenticated attackers to skip OTP verification by setting the client\-supplied bypass\_otp parameter\. Attackers can obtain a ghost session from the guest\-accessible create\_ghost\_session endpoint, then call convert\_to\_real\_user with an arbitrary real\_email and bypass\_otp\=1 to receive OAuth tokens for existing accounts and take them over\.
