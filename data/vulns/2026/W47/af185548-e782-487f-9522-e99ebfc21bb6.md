# The Groundhogg plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'post\_title' merge\-tag of the \[ghr\] shortcode in\.\.\.

- **ID**: CVE\-2026\-119635
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The Groundhogg plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'post\_title' merge\-tag of the \[ghr\] shortcode in versions up to, and including, 4\.10 The post\_title replacement is registered with 'nested' \=&gt; true, so the nested branch of Replacements\:\:do\_replacement\(\) returns the merge value through tackle\_replacements\(\) without passing it through escape\_merge\_tags\(\)/escape\_shortcodes\(\); the callback single\_post\(\) calls html\_entity\_decode\(get\_the\_title\(\), ENT\_QUOTES\), converting the entity\-encoded text that wp\_filter\_kses leaves intact on a Contributor's post title back into raw HTML, which is then emitted into the rendered post\. This makes it possible for authenticated attackers, with Contributor\-level access and above, to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\.
