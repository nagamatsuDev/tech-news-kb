# sqlite\-mcp is a Model Context Protocol server for SQLite\.

- **ID**: CVE\-2026\-130008
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-11-18

## 原文

sqlite\-mcp is a Model Context Protocol server for SQLite\. Prior to 0\.1\.2, the default read\-only mode can be bypassed through execute\_query, which accepts a leading SELECT while the SQLite driver executes trailing statements, and through describe\_table, which interpolates the caller\-controlled table\_name into PRAGMA table\_info\. Either path can issue ATTACH DATABASE, which opens an attached file read\-write despite mode\=ro and can make the protected database writable, read other SQLite database files, or create a SQLite\-format file at a path writable by the server process\. Existing non\-empty files that are not SQLite databases are refused and left unchanged\. The server has no built\-in authentication and listens on all interfaces at \:8080 by default, so any client that can reach the port can invoke these tools unless an authenticating proxy is in place\. This issue is fixed in version 0\.1\.2\.
