# Nuxt payload URL generation has quadratic cost for repeated slashes in the request path

- **ID**: CVE\-2026\-128074 / GHSA\-r9jc\-w898\-3fv6
- **危険度**: Medium（警告）
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/nuxt &gt;\= 4\.6\.0, &lt; 4\.6\.4 → 4\.6\.4
- **公開**: 2026-11-16

## 原文

\#\#\# Summary Nuxt strips trailing slashes from the request path with a regular expression whose cost grows quadratically with the length of a run of consecutive slashes\. A single unauthenticated request with a long run of slashes can occupy the server's event loop for a noticeable time, delaying every other request handled by the same process\. \#\#\# Impact When a page is rendered with payload extraction \(any route covered by an \`isr\`, \`swr\` or \`cache\` route rule\), Nuxt builds the \`\_payload\.json\` URL from the raw request path\.
