# WeGIA is a web manager for charitable institutions\.

- **ID**: CVE\-2026\-61677
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: PHP
- **公開**: 2026-11-17

## 原文

WeGIA is a web manager for charitable institutions\. Prior to 3\.8\.7, web/html/socio/sistema/processa\_edicao\_socio\.php updates member information without validating an authenticated session\. An unauthenticated remote requester who supplies a target member identifier and replacement member fields can modify arbitrary member records, corrupt personal information, and cause loss of data integrity\. This issue is fixed in version 3\.8\.7\.
