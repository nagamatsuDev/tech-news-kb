# contao/core\-bundle\: Cross\-site scripting in the frontend search results

- **ID**: CVE\-2026\-104884 / GHSA\-h57j\-5f5m\-789v
- **危険度**: Medium（警告） (CVSS 5.4)
- **言語**: PHP
- **パッケージ**: Packagist/contao/core\-bundle &gt;\= 4\.9\.0, &lt; 5\.3\.50 → 5\.3\.50, Packagist/contao/core\-bundle &gt;\= 5\.4\.0\-RC1, &lt; 5\.7\.12 → 5\.7\.12
- **公開**: 2026-11-20

## 原文

Commit \`23e8cca3136a\` hardened the search\-result title against insert\-tag/XSS by setting \`\$objTemplate\-&gt;title \= StringUtil\:\:specialchars\(StringUtil\:\:stripInsertTags\(\$arrResult\[\$i\]\['title'\]\)\)\`\. But the legacy HTML5 template does not use that \`title\` variable \- it prints the raw \`link\` variable, which is assigned without escaping\. \#\# Impact Affected configuration \(important\)\: on 5\.7\.9 the default search template is the Twig \`search\_default\.html\.twig\`, which does not use the raw \`link\` variable and auto\-escapes \- so a default Twig install is not affected\.
