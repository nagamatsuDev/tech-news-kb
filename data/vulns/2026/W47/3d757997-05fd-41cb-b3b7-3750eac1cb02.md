# The UpdraftPlus\: WP Backup &amp; Migration Plugin for WordPress is vulnerable to second\-order SQL Injection via the user profile description \.\.\.

- **ID**: CVE\-2026\-108761
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The UpdraftPlus\: WP Backup &amp; Migration Plugin for WordPress is vulnerable to second\-order SQL Injection via the user profile description field in all Free versions up to, and including, 1\.26\.15 and all Premium versions up to, and including, 2\.26\.15\. This makes it possible for authenticated attackers, with subscriber\-level access and above, to store a malicious payload that is written into a database backup and executed as SQL when an administrator later restores that backup\. Successful exploitation can modify sensitive WordPress data and, on sites where plugin installation is available, lead to remote code execution through the installation and activation of an attacker\-controlled plugin\.
