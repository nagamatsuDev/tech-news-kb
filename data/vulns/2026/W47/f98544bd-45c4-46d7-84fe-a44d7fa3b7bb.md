# Git LFS may attempt arbitrary remote commands via crafted SSH URLs

- **ID**: CVE\-2026\-69260 / GHSA\-w3f2\-pr6x\-wwjc
- **危険度**: High（重要）
- **言語**: Go
- **パッケージ**: Go/github\.com/git\-lfs/git\-lfs &gt;\= 0\.5\.0, &lt;\= 2\.13\.3, Go/github\.com/git\-lfs/git\-lfs/v3 &gt;\= 3\.0\.0, &lt; 3\.8\.1 → 3\.8\.1
- **公開**: 2026-11-19

## 原文

\#\#\# Impact When Git LFS makes object transfer or authentication requests to a remote host via SSH, it passes the path component of the remote's SSH URL as part of a command to be executed, but does not properly format the URL's path component as a single argument\. By inserting shell meta\-characters into the SSH URL, an attacker may be able to execute arbitrary commands on the remote host, if the host passes the commands to a shell without sanitizing them first\.
