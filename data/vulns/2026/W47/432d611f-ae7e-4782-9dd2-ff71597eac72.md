# The GiveWP – Donation Plugin and Fundraising Platform plugin for WordPress is vulnerable to donor account account takeover in all version\.\.\.

- **ID**: CVE\-2026\-82675
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-20

## 原文

The GiveWP – Donation Plugin and Fundraising Platform plugin for WordPress is vulnerable to donor account account takeover in all versions up to, and including, 4\.17\.0\. This is due to the plugin not properly validating a donor's identity prior to updating the password of a linked WordPress account\. The donation receipt processes an attacker\-controlled first name through the V3 template engine and then reprocesses the result through the legacy \`\{meta\_donor\_\*\}\` engine, which can disclose the donor's email\-access bearer token\. The donor\-dashboard password endpoint accepts that token by itself and calls \`wp\_set\_password\(\)\` for the WordPress user linked to the donor\. This makes it possible for unauthenticated attackers to reset the password of any WordPress account linked to a GiveWP donor record and gain access to that account\. If the linked account is an administrator, the attacker can achieve full site compromise and remote code execution through standard administrator functionality\. A published GiveWP form with a usable gateway, enabled donor email access \(enabled by default\), knowledge of the donor email address, and an account already linked to the targeted donor record are required\. NOTE\: This vulnerability can be chained with CVE\-2026\-82676 to satisfy the administrator donor pre\-requisite for a targeted administrator user attack\.
