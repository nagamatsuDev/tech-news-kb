# Next\.js\: Cache poisoning of shared fallback shells in Cache Components via request\-supplied placeholder route params

- **ID**: CVE\-2026\-119350 / GHSA\-vvgp\-ww4w\-46vf
- **危険度**: Medium（警告）
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/next &gt;\= 16\.4\.0, &lt;\= 16\.4\.4 → 16\.4\.5
- **公開**: 2026-11-19

## 原文

Self\-hosted Next\.js applications served with \`next start\` and built with \`cacheComponents\: true\` but without Partial Prefetching accept a request\-supplied route param value as a prerender placeholder\. One unauthenticated GET request can poison the fallback shell cache entry that a family of routes shares\. Such a route is served from a shell that keeps its never\-prerenderable params as placeholders, so every value of those params shares one cache entry\. A path segment equal to the percent\-encoded, bracketed name of its own route param is treated as an unresolved placeholder, and only that param
