# Azon Dominator releases through 2024\-06\-03 contain an SQL injection vulnerability that allows unauthenticated attackers to manipulate dat\.\.\.

- **ID**: CVE\-2024\-58402
- **危険度**: High（重要） (CVSS 8.2)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

Azon Dominator releases through 2024\-06\-03 contain an SQL injection vulnerability that allows unauthenticated attackers to manipulate database queries through the cid parameter in /fetch\_products\.php\. Attackers can send crafted POST requests with boolean\-based or time\-based blind payloads to extract sensitive database information\. Exploitation evidence was first observed by the Shadowserver Foundation on 2024\-07\-30\.
