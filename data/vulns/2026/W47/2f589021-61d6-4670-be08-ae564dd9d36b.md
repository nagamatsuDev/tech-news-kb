# NLTK\: StreamBackedCorpusView constructor os\.stat leaks out\-of\-root file existence, size, and mtime bypassing pathsec ENFORCE

- **ID**: CVE\-2026\-129233 / GHSA\-w674\-vqhw\-g3pg
- **危険度**: Medium（警告） (CVSS 5.3)
- **言語**: Python
- **パッケージ**: PyPI/nltk &gt;\= 3\.10\.0, &lt;\= 3\.10\.3 → 3\.10\.4
- **公開**: 2026-11-19

## 原文

\#\# Summary \`StreamBackedCorpusView\`, a public API in \`nltk/corpus/reader/util\.py\`, applies the pathsec sandbox to the file content it reads but not to the file metadata it probes in its constructor\. When the view is created with a plain string fileid, \`\_\_init\_\_\` calls \`os\.stat\(self\.\_fileid\)\.st\_size\` with no pathsec validation, so an application that passes an attacker influenced path to the constructor discloses whether an arbitrary out of root file exists and, if it does, its exact byte size and modification time, even when \`nltk\.pathsec\.ENFORCE\` is \`True\`\.
