# djangocms\-versioning\: Authorization Bypass Through User\-Controlled Key and Missing Authorization

- **ID**: CVE\-2026\-69138 / GHSA\-5g9x\-qwh5\-33x4
- **危険度**: Medium（警告） (CVSS 6.5)
- **言語**: Python
- **パッケージ**: PyPI/djangocms\-versioning &lt;\= 2\.6\.0 → 2\.6\.1
- **公開**: 2026-11-18

## 原文

\#\# Summary The \`discard\` and \`edit\_redirect\` version transitions did not enforce a per\-object change\-permission check, while the sibling transitions \(\`archive\`, \`publish\`, \`unpublish\`, \`revert\`\) all did\. As a result a low\-privileged staff user could \*\*discard \(delete\) any draft version — and thereby the underlying content object — of content they have no change permission on\*\*, and could create an editable draft off any published version, by supplying a version primary key they should not have access to \(an insecure direct object reference\)\. \#\# Details Version state transitions are guarded by
