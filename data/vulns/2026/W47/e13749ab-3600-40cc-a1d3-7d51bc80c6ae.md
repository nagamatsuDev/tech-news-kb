# AIOHTTP\: Unbounded cookie storage in client CookieJar

- **ID**: CVE\-2026\-128125 / GHSA\-5pv8\-vvhc\-h7jv
- **危険度**: Medium（警告）
- **言語**: Python
- **パッケージ**: PyPI/aiohttp &lt;\= 3\.14\.3 → 3\.14\.4
- **公開**: 2026-11-16

## 原文

\#\#\# Summary \`Set\-Cookie\` parsing created additional cookies from unrecognised \`name\=value\` attributes, and \`CookieJar\` had no limit on the number of cookies stored or sent\. A server could make the client store a very large number of cookies and generate very large \`Cookie\` headers\. \#\#\# Impact A malicious server could cause excessive memory and CPU use in a client, repeated on every redirect, and cause later requests to the same domain to build an excessively large \`Cookie\` header\. \-\-\- Patch\: https\://github\.com/aio\-libs/aiohttp/commit/6963ee0befec1502b6bb7b4db6c72d044c08f4fa
