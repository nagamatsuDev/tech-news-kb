# Admidio 5\.0\.0 before 5\.0\.18 contains a path traversal vulnerability in the Documents &amp; Files renameFile\(\) action that allows authenticate\.\.\.

- **ID**: CVE\-2026\-134258
- **危険度**: High（重要） (CVSS 8.7)
- **公開**: 2026-11-21

## 原文

Admidio 5\.0\.0 before 5\.0\.18 contains a path traversal vulnerability in the Documents &amp; Files renameFile\(\) action that allows authenticated users with folder upload rights to move files outside adm\_my\_files by supplying \.\./ sequences in adm\_new\_name\. Attackers can relocate an uploaded SVG containing script to the web root, where it is served inline and executes stored cross\-site scripting against administrators for account takeover\.
