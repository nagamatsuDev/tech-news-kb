# Incorrect authorization in the credential handling for namespace\-scoped issuers in AWS Private CA Connector for Kubernetes \(aws\-privateca\.\.\.

- **ID**: CVE\-2026\-130623
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-17

## 原文

Incorrect authorization in the credential handling for namespace\-scoped issuers in AWS Private CA Connector for Kubernetes \(aws\-privateca\-issuer\) before 1\.12\.0 might allow an authenticated remote user with permission to create namespace\-scoped issuers to obtain certificates, including subordinate CA certificates, from every AWS Private CA and certificate template reachable by the controller's own AWS identity or by any IAM role that identity can assume\. This happens because a namespace\-scoped issuer that supplies no credentials, or sets only a role, falls back to the controller's own identity\.
  
To remediate this issue, users should first update any namespace\-scoped issuers that rely on the controller's identity to use their own credentials\. Then, upgrade aws\-privateca\-issuer to version 1\.12\.0 or the AWS Private CA Connector for Kubernetes EKS add\-on to version v1\.12\.0\-eksbuild\.1\.
