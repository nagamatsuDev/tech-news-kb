# In the Linux kernel, the following vulnerability has been resolved\: media\: hackrf\: fix use\-after\-free in hackrf\_alloc\_urbs\(\) error path \.\.\.

- **ID**: CVE\-2026\-99510
- **危険度**: High（重要） (CVSS 7.0)
- **OS**: Linux
- **公開**: 2026-11-19

## 原文

In the Linux kernel, the following vulnerability has been resolved\:
  
media\: hackrf\: fix use\-after\-free in hackrf\_alloc\_urbs\(\) error path
  
hackrf\_alloc\_urbs\(\) frees the URBs it allocated so far when one  
allocation fails, but leaves the entries in dev\-&gt;urb\_list\[\] and  
dev\-&gt;urbs\_initialized untouched\. The caller, hackrf\_start\_streaming\(\),  
then calls hackrf\_free\_urbs\(\) on the error path, which walks  
dev\-&gt;urbs\_initialized entries and calls usb\_free\_urb\(\) a second time on  
the already\-freed URBs, causing a use\-after\-free \(slab\-use\-after\-free  
Write in usb\_free\_urb\(\)\)\.
  
Drop the redundant cleanup loop inside hackrf\_alloc\_urbs\(\) and let  
hackrf\_free\_urbs\(\), which the caller already invokes on error, own the  
cleanup of the successfully allocated URBs\.
