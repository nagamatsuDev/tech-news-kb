# Gortex is a high\-performance code\-intelligence engine for AI agents and integrated development environments\.

- **ID**: CVE\-2026\-62964
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-18

## 原文

Gortex is a high\-performance code\-intelligence engine for AI agents and integrated development environments\. Prior to 0\.55\.0, resolveFilePath in internal/mcp/tools\_fileops\.go accepts absolute paths without checking indexed repository roots, while write\_file, edit\_file, and move\_inline in internal/mcp/tools\_move\_inline\.go omit guardSymlinkWithinRepo before reaching AtomicWriteFile and related write sinks\. A caller that can influence MCP tool arguments can therefore create or overwrite files anywhere the daemon user can access, including startup or hook files that execute code on a later trigger\. The flaw violates Gortex's repository\-confinement invariant and can lead to arbitrary host code execution\. This issue is fixed in version 0\.55\.0\.
