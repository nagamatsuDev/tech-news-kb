# The WPvivid — Backup, Migration &amp; Staging plugin for WordPress is vulnerable to Arbitrary File Deletion in version up to, and including, \.\.\.

- **ID**: CVE\-2026\-84693
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-20

## 原文

The WPvivid — Backup, Migration &amp; Staging plugin for WordPress is vulnerable to Arbitrary File Deletion in version up to, and including, 0\.9\.134\. This is due to a timing side channel in the bundled RSA decryption path, insufficient validation of migration receiver backup records, and missing path validation in the cleanup\_local\_backup\(\) function\. This makes it possible for unauthenticated attackers to recover an active migration receiver's RSA modulus, inject a backup record containing path traversal, and cause a later scheduled cleanup to delete an attacker\-selected file writable by the web server\. Exploitation requires an unexpired receiver key generated by an administrator and a subsequent manual or scheduled backup lifecycle\.
