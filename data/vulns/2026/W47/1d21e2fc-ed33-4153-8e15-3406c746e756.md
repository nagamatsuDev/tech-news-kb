# The WP Abstracts plugin for WordPress is vulnerable to Privilege Escalation in all versions up to, and including, 2\.7\.6\.

- **ID**: CVE\-2026\-12239
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: PHP
- **公開**: 2026-11-17

## 原文

The WP Abstracts plugin for WordPress is vulnerable to Privilege Escalation in all versions up to, and including, 2\.7\.6\. This is due to a missing capability check on the wpabs\_save\_regform AJAX action and the use of a static, frontend\-exposed nonce that allows any authenticated user to persist attacker\-controlled form schemas with arbitrary wpSync mappings that are later used as user meta keys in the wpabstracts\_sync\_wpfields function\. This makes it possible for authenticated attackers, with subscriber\-level access and above, to elevate their privileges to administrator\.
