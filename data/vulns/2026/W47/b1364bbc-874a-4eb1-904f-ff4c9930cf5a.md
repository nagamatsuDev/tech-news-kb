# ThinkPHP 5\.0\.0 before 5\.0\.24 contains a code injection vulnerability that allows unauthenticated attackers to execute commands by setting\.\.\.

- **ID**: CVE\-2019\-25782
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-18

## 原文

ThinkPHP 5\.0\.0 before 5\.0\.24 contains a code injection vulnerability that allows unauthenticated attackers to execute commands by setting \_method\=\_\_construct in POST data to overwrite the Request filter property\. Attackers can send POST requests to endpoints reached via ?s\=captcha or ?s\=index/index/index with filter\[\]\=system and server\[REQUEST\_METHOD\] values to execute arbitrary system commands\. Exploitation evidence was first observed by the Shadowserver Foundation on 2023\-10\-14\.
