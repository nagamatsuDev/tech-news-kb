# In Postgres Enterprise Manager \(PEM\), the pem\_agent role, which every PEM agent login inherits, is a member of the PostgreSQL pg\_read\_ser\.\.\.

- **ID**: CVE\-2026\-132658
- **危険度**: Critical（緊急） (CVSS 9.4)
- **公開**: 2026-11-20

## 原文

In Postgres Enterprise Manager \(PEM\), the pem\_agent role, which every PEM agent login inherits, is a member of the PostgreSQL pg\_read\_server\_files and pg\_write\_server\_files roles on the PEM backend database\. An attacker who controls any monitored host, and so its PEM agent certificate, can read and write files on the PEM server host as the postgres operating system user\. This includes the PEM certificate authority key, which lets the attacker issue certificates for other agents and act as them\.  
From PEM 10\.6\.1, PEM agents no longer hold these roles\.
