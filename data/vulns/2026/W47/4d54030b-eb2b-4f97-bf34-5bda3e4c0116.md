# The VikBooking Hotel Booking Engine &amp; PMS plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'vbf&lt;field\_id&gt;' param\.\.\.

- **ID**: CVE\-2026\-119061
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-21

## 原文

The VikBooking Hotel Booking Engine &amp; PMS plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'vbf&lt;field\_id&gt;' parameter in all versions up to, and including, 1\.8\.20 due to insufficient input sanitization and output escaping\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\.
