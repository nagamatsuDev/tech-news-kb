# NocoDB before 2026\.10\.0 contains an sql injection vulnerability that allows authenticated users with the Creator role to inject SQL by su\.\.\.

- **ID**: CVE\-2026\-130689
- **危険度**: High（重要） (CVSS 8.8)
- **公開**: 2026-11-18

## 原文

NocoDB before 2026\.10\.0 contains an sql injection vulnerability that allows authenticated users with the Creator role to inject SQL by supplying a crafted formula parsed\_tree during table creation\. Attackers can set a malicious binary\-expression operator that is interpolated into a knex\.raw fragment, reading user and token tables and escalating to super administrator on SQLite installs\.
