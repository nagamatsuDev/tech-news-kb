# Axon is an agent\-agnostic context engine that gives AI coding agents continuous memory across sessions, tools, and machines\.

- **ID**: CVE\-2026\-76818
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-18

## 原文

Axon is an agent\-agnostic context engine that gives AI coding agents continuous memory across sessions, tools, and machines\. Prior to 0\.1\.1, rtk\-install in src/axon/context/rtk\_bootstrap\.py uses \_http\_download\(\) to fetch a prebuilt rtkx release archive and \_extract\_binary\(\) to mark it executable, after which compress\_text\_with\_rtk\(\) invokes it without verifying a checksum, signature, or build attestation\. If the sammyjdev/rtkx release pipeline or maintainer release credentials are compromised, an attacker can supply a modified binary that executes with the Axon process privileges when a user installs or automatically bootstraps rtkx\. This issue is fixed in version 0\.1\.1\.
