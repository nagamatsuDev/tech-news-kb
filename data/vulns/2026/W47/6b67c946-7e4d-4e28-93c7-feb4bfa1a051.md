# Axon\: Download of Code Without Integrity Check in axon\-mcp

- **ID**: CVE\-2026\-76818 / GHSA\-r7wg\-f7r2\-8wf7
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: Python
- **パッケージ**: PyPI/axon\-mcp &lt;\= 0\.1\.0
- **公開**: 2026-11-18

## 原文

\#\#\# Summary axon rtk\-install downloads a pre\-built rtkx binary from GitHub releases and executes it via subprocess\.run\(\) on every text\-compression call, without verifying its integrity — no checksum, signature, or attestation check anywhere in the download/install path\. If the release pipeline or a maintainer token for sammyjdev/rtkx were ever compromised, every axon user who installs or auto\-bootstraps rtkx would silently download and execute an unverified binary with the same privileges as the axon process\. \#\#\# Details The download path lives in src/axon/context/rtk\_bootstrap\.py\: \- \_http\_dow
