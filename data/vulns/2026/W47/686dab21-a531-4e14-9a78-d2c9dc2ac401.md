# The The GDPR Framework By Data443 plugin for WordPress is vulnerable to authorization bypass in all versions up to, and including, 2\.5\.2\.

- **ID**: CVE\-2026\-116764
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The The GDPR Framework By Data443 plugin for WordPress is vulnerable to authorization bypass in all versions up to, and including, 2\.5\.2\. This is due to the plugin not properly verifying that a user is authorized to perform an action\. This makes it possible for authenticated attackers, with subscriber\-level access and above, to delete all postmeta rows for every Easy Digital Downloads payment order on the site, destroying order metadata belonging to all customers\. Exploitation requires that Easy Digital Downloads 2\.x is active and the GDPR Framework's EDD compatibility option is enabled with a delete or delete\_and\_notify action configured\.
