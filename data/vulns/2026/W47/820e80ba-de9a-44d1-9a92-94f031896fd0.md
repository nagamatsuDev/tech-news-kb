# Vulnerability in the Oracle EDI Gateway product of Oracle E\-Business Suite \(component\: EDI\)\.

- **ID**: CVE\-2026\-101534
- **危険度**: High（重要） (CVSS 8.5)
- **公開**: 2026-10-20

## 原文

Vulnerability in the Oracle EDI Gateway product of Oracle E\-Business Suite \(component\: EDI\)\.  Supported versions that are affected are 12\.2\.3\-12\.2\.15\. Easily exploitable vulnerability allows low privileged attacker with network access via HTTP to compromise Oracle EDI Gateway\.  While the vulnerability is in Oracle EDI Gateway, attacks may significantly impact additional products \(scope change\)\.  Successful attacks of this vulnerability can result in  unauthorized access to critical data or complete access to all Oracle EDI Gateway accessible data as well as  unauthorized update, insert or delete access to some of Oracle EDI Gateway accessible data\. CVSS 3\.1 Base Score 8\.5 \(Confidentiality and Integrity impacts\)\.  CVSS Vector\: \(CVSS\:3\.1/AV\:N/AC\:L/PR\:L/UI\:N/S\:C/C\:H/I\:L/A\:N\)\.
