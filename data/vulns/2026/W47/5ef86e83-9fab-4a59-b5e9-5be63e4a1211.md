# Atomic Server\: Unauthenticated \`/setup\` invite grants write access to the entire Drive

- **ID**: CVE\-2026\-69157 / GHSA\-pfwx\-xjp4\-qxcj
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: Rust
- **パッケージ**: crates\.io/atomic\-server &gt;\= 0\.29\.0, &lt;\= 0\.40\.1
- **公開**: 2026-11-17

## 原文

\#\# Summary atomic\-server provisions a well\-known invite at \`\{server\}/setup\` with \`write \= true\`, \`target\` \= the Drive root, and \`usagesLeft \= 1\`\. Invite redemption \*\*ignores the redeemer's identity\*\* \(\`for\_agent\: \_\` in \`server/src/plugins/invite\.rs\:22\`\), so possession of the URL is the only requirement\. An \*\*unauthenticated\*\* attacker who sends \`GET /setup?public\-key\=&lt;attacker\_key&gt;\` has the server create a new Agent and grant it \*\*write access to the entire Drive\*\*\. On a freshly deployed \(not\-yet\-claimed\) instance this is a full server takeover with no credentials\. \#\# Severity \*\*Critical — CVS
