# Atomic Server is an open source headless CMS and real\-time database\.

- **ID**: CVE\-2026\-69157
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-17

## 原文

Atomic Server is an open source headless CMS and real\-time database\. From 0\.29\.0 to 0\.40\.2, Atomic Server provisions a well\-known /setup invite with write enabled, the Drive root as its target, and usagesLeft set to one\. construct\_invite\_redirect in server/src/plugins/invite\.rs discards the redeemer identity, so an unauthenticated request containing an attacker\-controlled public\-key can create a new Agent and grant it write access to the entire Drive\. On a fresh, unclaimed deployment, this permits reading, modifying, or deleting resources, changing permissions, and creating or altering Agents\. No complete fixed version was verified as of this review\.
