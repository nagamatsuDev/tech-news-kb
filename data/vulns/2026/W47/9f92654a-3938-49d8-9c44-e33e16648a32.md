# Convert\:\:ASN1 versions before 0\.37 for Perl allow memory exhaustion via unbounded MSG\_PEEK buffer doubling in asn\_recv\.

- **ID**: CVE\-2026\-126568
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-20

## 原文

Convert\:\:ASN1 versions before 0\.37 for Perl allow memory exhaustion via unbounded MSG\_PEEK buffer doubling in asn\_recv\.
  
asn\_recv peeks the socket in a loop, doubling the buffer size on each pass until a tag and length can be decoded\. An inverted boolean guard \(\$tb \|\| rather than \$tb &amp;&amp;\) prevents the need\-more\-data exit from firing once a tag byte has been decoded\. When asn\_decode\_length returns no value because the length is absent or incomplete, no exit fires for that case either\. MSG\_PEEK leaves socket data unconsumed, so each re\-peek returns at once while the buffer size doubles\.
  
A single truncated BER header sent to a process calling asn\_recv doubles the peek buffer until memory is exhausted\. Perl's realloc failure is fatal and not catchable with eval\.
