# OpenCTI is an open source platform for managing cyber threat intelligence knowledge and observables\.

- **ID**: CVE\-2026\-76823
- **危険度**: High（重要） (CVSS 8.7)
- **公開**: 2026-11-16

## 原文

OpenCTI is an open source platform for managing cyber threat intelligence knowledge and observables\. Prior to 7\.260706\.0, the logsWorkerConfig GraphQL query is authorized with the broad CONNECTORAPI capability and returns Elasticsearch connection details including elasticsearch\_username, elasticsearch\_password, elasticsearch\_api\_key, the URL, index, proxy, and TLS\-verification setting\. A holder of any connector API bearer token can retrieve this credential material\. If the returned credentials are valid and Elasticsearch is reachable, the caller can directly read, modify, or delete OpenCTI indices and audit history outside application\-layer role, marking, organization, and audit controls, with the practical impact bounded by the credentials' privileges and network reachability\. This issue is fixed in version 7\.260706\.0\.
