# codebase\-memory\-mcp provides local code intelligence for developers and AI agents through a persistent graph and MCP tools\.

- **ID**: CVE\-2026\-114494
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-20

## 原文

codebase\-memory\-mcp provides local code intelligence for developers and AI agents through a persistent graph and MCP tools\. Prior to 0\.9\.0, the Cypher parser accepted an unbounded number of projection items in RETURN and WITH clauses while projection executors indexed fixed 32\-element stack arrays using the parsed count\. A query\_graph query with more than 32 projection items could therefore write beyond those arrays, and a related result\-column path could read uninitialized stack slots even when no node matched\. Any caller of query\_graph, including an agent whose query is influenced by untrusted content, could cause a reliable server crash and potentially compromise process confidentiality and integrity\. This issue is fixed in version 0\.9\.0\.
