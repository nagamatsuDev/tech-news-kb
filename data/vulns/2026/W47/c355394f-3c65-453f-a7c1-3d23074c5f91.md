# The immonex Kickstart plugin for WordPress is vulnerable to Local File Inclusion in all versions up to, and including, 1\.19\.0 via the 'in\.\.\.

- **ID**: CVE\-2026\-123419
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The immonex Kickstart plugin for WordPress is vulnerable to Local File Inclusion in all versions up to, and including, 1\.19\.0 via the 'inx\-r\-cidata \(JSON blob containing 'template' and 'template\_folders'\)' parameter parameter\. This makes it possible for unauthenticated attackers to include and execute arbitrary \.php files on the server, allowing the execution of any PHP code in those files\. This can be used to bypass access controls, obtain sensitive data, or achieve code execution in cases where \.php file types can be uploaded and included\. The filename\-level sanitization that strips dot\-slash sequences applies only to the template filename component, not to the attacker\-supplied template\_folders directory paths, rendering it ineffective against directory traversal via that parameter\.
