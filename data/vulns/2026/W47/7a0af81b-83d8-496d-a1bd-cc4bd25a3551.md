# nginxWebUI 3\.0\.0 before 3\.5\.8 contains an authentication bypass vulnerability that allows unauthenticated attackers to reach the /AdminPa\.\.\.

- **ID**: CVE\-2023\-54419
- **危険度**: Critical（緊急） (CVSS 9.8)
- **公開**: 2026-11-18

## 原文

nginxWebUI 3\.0\.0 before 3\.5\.8 contains an authentication bypass vulnerability that allows unauthenticated attackers to reach the /AdminPage/conf/runCmd endpoint by using a case\-variant path that evades the case\-sensitive /adminPage/ login filter\. Attackers can pass OS commands through the cmd parameter, which are executed via /bin/sh with insufficient filtering of &amp; and \$\(\) characters, achieving remote code execution\. Exploitation evidence was first observed by the Shadowserver Foundation on 2023\-10\-14\.
