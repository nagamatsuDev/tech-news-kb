# Netatalk is a Free and Open Source file server suite for Unix\-like operating systems\.

- **ID**: CVE\-2026\-62321
- **危険度**: High（重要） (CVSS 8.7)
- **公開**: 2026-11-20

## 原文

Netatalk is a Free and Open Source file server suite for Unix\-like operating systems\. From 3\.1\.0 until 4\.5\.1, the afpd Spotlight RPC fetchQueryResultsForContext\: reply path in etc/afpd/spotlight\_marshalling\.c calls the top\-level sl\_pack function from sl\_pack\_filemeta on a shifted sub\-buffer without passing the remaining capacity of the outer DSI reply buffer\. An authenticated AFP client can request an amplified nested file\-metadata tree so the nested packer applies MAX\_SLQ\_DAT relative to the shifted pointer and writes beyond struct DSI\:\:data\. The out\-of\-bounds write corrupts heap memory beyond the DSI reply buffer\. This issue is fixed in version 4\.5\.1\.
