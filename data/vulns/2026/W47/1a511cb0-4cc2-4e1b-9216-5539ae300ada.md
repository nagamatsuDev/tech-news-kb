# OpenShot Video Editor \(openshot\-qt\) through 4\.1\.1 contains an unsafe deserialization vulnerability in ProjectDataStore\.load\(\) and read\_le\.\.\.

- **ID**: CVE\-2026\-134704
- **危険度**: High（重要） (CVSS 7.8)
- **公開**: 2026-11-22

## 原文

OpenShot Video Editor \(openshot\-qt\) through 4\.1\.1 contains an unsafe deserialization vulnerability in ProjectDataStore\.load\(\) and read\_legacy\_project\_file\(\) that passes non\-JSON project files to pickle\.load\(\) without restriction\. Attackers can trick users into opening a crafted \.osp project file containing a pickle \_\_reduce\_\_ gadget to execute code with the user's privileges\.
