# keystore\-go\: Keystore integrity and password verification bypass via stripped trailing digest in Decode\(\)

- **ID**: CVE\-2026\-76101 / GHSA\-j282\-pjg5\-j643
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: Java/Kotlin, Go
- **パッケージ**: Go/github\.com/pavel\-v\-chernykh/keystore\-go &lt;\= 2\.1\.0, Go/github\.com/pavel\-v\-chernykh/keystore\-go/v3 &lt; 3\.0\.0 → 3\.0\.0
- **公開**: 2026-11-18

## 原文

\#\#\# Summary \`keystore\.Decode\(\)\` fails to check the error returned when reading the trailing SHA\-1 integrity digest of a JKS keystore\. If an attacker removes the final 20 bytes from a \`\.jks\` file, the digest read returns an empty slice and the byte\-comparison loop never executes, so \`Decode\(\)\` returns the parsed keystore with \`err \=\= nil\`\.
