# SurrealKV before 1\.1\.0 contains an out\-of\-bounds read vulnerability in the safe InternalKeyRef\:\:from\_encoded constructor, which only chec\.\.\.

- **ID**: CVE\-2026\-134303
- **危険度**: High（重要） (CVSS 7.9)
- **公開**: 2026-11-21

## 原文

SurrealKV before 1\.1\.0 contains an out\-of\-bounds read vulnerability in the safe InternalKeyRef\:\:from\_encoded constructor, which only checks key length with a debug\-only assertion\. Callers passing keys shorter than 16 bytes, or crafted or corrupted SSTable blocks, trigger unchecked length underflow in timestamp\(\), seq\_num\(\) and trailer\(\), reading heap bytes before the allocation or panicking\.
