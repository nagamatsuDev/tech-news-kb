# NukeViet CMS is a multi Content Management System\.

- **ID**: CVE\-2026\-94598
- **危険度**: High（重要） (CVSS 8.2)
- **言語**: JavaScript/TypeScript
- **公開**: 2026-11-20

## 原文

NukeViet CMS is a multi Content Management System\. From 4\.5\.08 until 4\.5\.12 and 4\.6\.02, an attacker can place NukeViet's internal \{@\[, \]@\}, \[@\{, and \}@\] sanitizer markers in an iframe srcdoc value by encoding square brackets as HTML entities\. Recursive NukeViet\\Core\\Request\:\:filterTags\(\) processing decodes the characters, accepts the forged marker, and later converts it to real markup without normal tag or attribute filtering\. Because an unsandboxed srcdoc iframe shares the parent origin and iframe is enabled by default through NV\_ALLOWED\_HTML\_TAGS, stored Contact messages, comments with the editor enabled, or submitted articles can execute JavaScript with the viewer's session\. This issue is fixed in versions 4\.5\.12 and 4\.6\.02\.
