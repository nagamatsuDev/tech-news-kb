# MLflow before 3\.18\.0 contains a path traversal vulnerability in the FileStore tracking backend that allows unauthenticated attackers to c\.\.\.

- **ID**: CVE\-2026\-53995
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-10-19

## 原文

MLflow before 3\.18\.0 contains a path traversal vulnerability in the FileStore tracking backend that allows unauthenticated attackers to control filesystem paths by submitting a crafted trace ID containing traversal sequences to the POST /api/3\.0/mlflow/traces endpoint\. Attackers can exploit FileStore\.start\_trace\(\) to write trace\_info\.yaml, request\_metadata, and tag files with attacker\-controlled metadata outside the intended experiment trace directory, subject to the server process's filesystem permissions\. FileStore is the default tracking backend before MLflow 3\.7\.0 and opt\-in thereafter \(the default changed to a SQLite database\), so deployments in the earlier part of the affected range are vulnerable without special configuration while later ones are affected only when FileStore is explicitly selected\.
