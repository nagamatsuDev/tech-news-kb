# CodeWhale is a DeepSeek and MiMo coding agent for the terminal\.

- **ID**: CVE\-2026\-83817
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-16

## 原文

CodeWhale is a DeepSeek and MiMo coding agent for the terminal\. Prior to 0\.9\.0, DEFAULT\_AUTOMATION\_AUTO\_APPROVE caused AutomationRecord\:\:task\_auto\_approve to resolve an omitted setting to true, and the automation\_create schema advertised the same insecure default\. enqueue\_run\_task converted that omission into an explicit true value, bypassing the safer task\-path fallback and selecting ApprovalMode\:\:Bypass for each scheduled run\. After a user approved creation of an apparently benign recurring automation, subsequent executions could silently authorize mutating tools without a human present, and an automation created with shell access could repeatedly execute commands\. This issue is fixed in version 0\.9\.0\.
