# LinkAce is a self\-hosted archive to collect website links\.

- **ID**: CVE\-2026\-104184
- **危険度**: High（重要） (CVSS 7.1)
- **言語**: PHP
- **公開**: 2026-11-20

## 原文

LinkAce is a self\-hosted archive to collect website links\. Prior to 2\.6\.0, LinkController\:\:update\(\) in app/Http/Controllers/API/LinkController\.php passes \$request\-&gt;all\(\) to the repository update method even though user\_id is fillable and is not an allowed field in the validated update request\. An authenticated API user who is authorized to update a link can therefore assign an arbitrary or nonexistent user\_id, transferring the link into another user's bookmark collection or orphaning it from any real account\. The web update controller is unaffected because it passes only validated fields\. This issue is fixed in version 2\.6\.0\.
