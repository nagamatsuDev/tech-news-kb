# NUUO NVRmini 2 through 3\.0\.8 contains a file disclosure vulnerability that allows unauthenticated attackers to read web\-root files by pas\.\.\.

- **ID**: CVE\-2016\-20106
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

NUUO NVRmini 2 through 3\.0\.8 contains a file disclosure vulnerability that allows unauthenticated attackers to read web\-root files by passing a filename to the 'css' parameter of css\_parser\.php\. Attackers can retrieve PHP source files confined to the document root, exposing hardcoded credentials and sensitive application logic\. Exploitation evidence was first observed by the Shadowserver Foundation on 2023\-10\-17\.
