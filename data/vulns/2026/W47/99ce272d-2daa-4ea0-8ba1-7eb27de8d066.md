# Next\.js\: HttpOnly cookie exposure through internal response header on Next\.js Edge runtime routes

- **ID**: CVE\-2026\-119346 / GHSA\-f3mh\-rxg3\-f5g2
- **危険度**: Medium（警告）
- **言語**: JavaScript/TypeScript
- **パッケージ**: npm/next &gt;\= 15\.0\.0, &lt;\= 15\.5\.28 → 15\.5\.29, npm/next &gt;\= 16\.0\.0, &lt;\= 16\.4\.4 → 16\.4\.5
- **公開**: 2026-11-19

## 原文

Next\.js applications that set cookies through \`NextResponse\` on Edge runtime routes — App Router route handlers and Pages Router Edge API routes — send an internal \`x\-middleware\-set\-cookie\` header in the public response, duplicating the cookie value and its attributes\. This makes HttpOnly cookies, such as session tokens, readable by JavaScript running on the same origin when an application sets a sensitive cookie on an affected response\.
