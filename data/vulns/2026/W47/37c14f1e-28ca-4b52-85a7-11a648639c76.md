# Hysteria from 2\.0\.0 before 2\.9\.2 contains an ACL bypass vulnerability that allows authenticated clients to reach blocked UDP destinations\.\.\.

- **ID**: CVE\-2026\-134454
- **危険度**: High（重要） (CVSS 7.4)
- **公開**: 2026-11-21

## 原文

Hysteria from 2\.0\.0 before 2\.9\.2 contains an ACL bypass vulnerability that allows authenticated clients to reach blocked UDP destinations by reusing an established UDP session\. Attackers can open a session to an allowed destination, then send later packets to localhost or private\-network addresses to access internal\-only UDP services\.
