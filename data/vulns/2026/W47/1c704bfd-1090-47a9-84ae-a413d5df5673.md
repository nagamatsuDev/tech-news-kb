# A vulnerability in the Ultimate Packer for eXecutables \(UPX\) unpacker of ClamAV could allow an unauthenticated, remote attacker to cause \.\.\.

- **ID**: CVE\-2026\-76430
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-18

## 原文

A vulnerability in the Ultimate Packer for eXecutables \(UPX\) unpacker of ClamAV could allow an unauthenticated, remote attacker to cause a DoS condition on an affected device\.  
    
 This vulnerability is due to improper length checks, when unpacking the UPX files, which may result in an out\-of\-bounds read of heap memory\. An attacker could exploit this vulnerability by submitting a crafted UPX for decode\. A successful exploit could allow the attacker to cause the ClamAV decode process to terminate, resulting in a DoS condition on the affected software\.
