# The AppPresser – Mobile App Framework plugin for WordPress is vulnerable to generic SQL Injection via the 'appp\_cam\_file\[name\]' parameter\.\.\.

- **ID**: CVE\-2026\-127921
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The AppPresser – Mobile App Framework plugin for WordPress is vulnerable to generic SQL Injection via the 'appp\_cam\_file\[name\]' parameter in all versions up to, and including, 5\.0\.0 due to insufficient escaping on the user supplied parameter and lack of sufficient preparation on the existing SQL query\. This makes it possible for unauthenticated attackers to append additional SQL queries into already existing queries that can be used to extract sensitive information from the database\. Although the AJAX handler is registered for unauthenticated users, the only authorization gate is a nonce check, and the required nonce is only emitted to logged\-in users viewing a page containing the \[app\-camera\] shortcode, making Subscriber\-level access the effective minimum requirement for exploitation\.
