# Chamilo LMS 1\.11\.10 before 1\.11\.16 contains an unauthenticated SQL injection vulnerability in the searchOptionsFromTags function through \.\.\.

- **ID**: CVE\-2021\-48021
- **危険度**: High（重要） (CVSS 8.2)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

Chamilo LMS 1\.11\.10 before 1\.11\.16 contains an unauthenticated SQL injection vulnerability in the searchOptionsFromTags function through the options parameter of extra\_field\.ajax\.php\. Attackers can send POST requests with a malicious JSON options array to inject SQL into the IN clause and extract database information\. Exploitation evidence was first observed by the Shadowserver Foundation on 2023\-10\-14\.
