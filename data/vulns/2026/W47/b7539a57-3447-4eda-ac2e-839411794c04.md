# AIT\-GUI route chain allows unauthenticated Python execution in server process

- **ID**: CVE\-2026\-77309 / GHSA\-jrjx\-9jjw\-747m
- **危険度**: High（重要） (CVSS 8.8)
- **言語**: Python
- **パッケージ**: PyPI/ait\-gui &gt;\= 1\.0\.0, &lt;\= 2\.5\.0 → 2\.5\.1
- **公開**: 2026-11-20

## 原文

\#\# Summary A security issue exists where unauthenticated callers can instruct the AIT\-GUI server to execute arbitrary Python scripts\. The attack vector involves obtaining a session cookie through GET /, followed by a malicious POST /script/run request containing an absolute file path that bypasses the configured script directory restrictions\. \#\#\# Patches \* 2\.5\.1 \#\#\# Impact This vulnerability allows unauthenticated remote code execution on the AIT\-GUI server\. Any attacker with network access can execute arbitrary Python code with daemon privileges\. \#\# Details \_Chain\:\_ 1\. \`POST /tlm/query\` write
