# AdminNeo before 5\.9\.1 contains a remote code execution vulnerability that allows authenticated SQLite users to bypass the check\_sqlite\_na\.\.\.

- **ID**: CVE\-2026\-130375
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-17

## 原文

AdminNeo before 5\.9\.1 contains a remote code execution vulnerability that allows authenticated SQLite users to bypass the check\_sqlite\_name\(\) extension guard using PDO\_SQLite file\: URI database names\. Attackers can select the PDO driver with ext\=pdo and submit names like file\:/webroot/x\.php?x\=\.db to create a \.php file, then store PHP source as table data for code execution\.
