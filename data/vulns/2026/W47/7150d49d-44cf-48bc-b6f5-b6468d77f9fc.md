# NukeViet CMS is a multi Content Management System\.

- **ID**: CVE\-2026\-54065
- **危険度**: High（重要） (CVSS 8.7)
- **言語**: PHP
- **公開**: 2026-11-20

## 原文

NukeViet CMS is a multi Content Management System\. Prior to 4\.5\.09, an authenticated administrator can submit a crafted attach value to modules/comment/admin/edit\.php\. The handler removed a fixed\-length upload prefix without validating containment, allowing padding followed by a traversal path to be stored in the database\. When the comment is deleted, modules/comment/admin/del\.php joins the stored path to NV\_UPLOADS\_REAL\_DIR and passes it to nv\_deletefile\(\), whose realpath\(\) check restricts deletion only to NV\_ROOTDIR rather than the upload directory, permitting deletion of application files such as config\.php and causing an outage\. This issue is fixed in version 4\.5\.09\.
