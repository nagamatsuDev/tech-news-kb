# SurrealDB 3\.1\.0 before 4\.0\.0 contains an SQL injection vulnerability in its Model Context Protocol \(MCP\) server because the identifier va\.\.\.

- **ID**: CVE\-2026\-134293
- **危険度**: High（重要） (CVSS 8.2)
- **公開**: 2026-11-21

## 原文

SurrealDB 3\.1\.0 before 4\.0\.0 contains an SQL injection vulnerability in its Model Context Protocol \(MCP\) server because the identifier validator \(consume\_backtick\_ident and validate\_identifier\) treats the first backtick as the closing delimiter, ignoring escape characters that the SurrealQL parser honors\. Attackers can supply MCP tool arguments containing an escaped backtick to break out of the quoted identifier and execute arbitrary SurrealQL statements\.
