# lightsaml allows Signature wrapping bypass

- **ID**: CVE\-2026\-63182 / GHSA\-w553\-pwx6\-3mg9
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **パッケージ**: Packagist/litesaml/lightsaml &gt;\= 5\.0\.0, &lt; 5\.0\.1 → 5\.0\.1, Packagist/litesaml/lightsaml &gt;\= 4\.0\.0, &lt; 4\.7\.1 → 4\.7\.1
- **公開**: 2026-11-16

## 原文

\#\#\# Summary LightSaml 5\.0\.0 \(latest release; also confirmed on 4\.6\.1\) validates an inbound \`samlp\:Response\` by collecting its direct\-child \`saml\:Assertion\` elements and validating each one's \`ds\:Signature\` via robrichards/xmlseclibs\. The two layers disagree on which element a signature actually covers\: LightSaml reads claims from the assertion node it collected, while xmlseclibs resolves the signed \`Reference URI\="\#id"\` with a document\-wide \`//\*\[@Id\]\` XPath that returns the first ID\-bearing element anywhere in the document\.
