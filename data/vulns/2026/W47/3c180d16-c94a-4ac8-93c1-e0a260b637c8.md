# The SAML SSO Login WordPress plugin through 1\.5\.2 does not verify that the SAML assertion whose signature it validates is the same asser\.\.\.

- **ID**: CVE\-2026\-108687
- **危険度**: High（重要） (CVSS 8.1)
- **言語**: PHP
- **公開**: 2026-11-19

## 原文

The SAML SSO Login  WordPress plugin through 1\.5\.2 does not verify that the SAML assertion whose signature it validates is the same assertion it reads the user identity from, allowing unauthenticated attackers who hold a validly signed assertion for any identity to authenticate as any existing user, including an administrator, through XML signature wrapping\.
