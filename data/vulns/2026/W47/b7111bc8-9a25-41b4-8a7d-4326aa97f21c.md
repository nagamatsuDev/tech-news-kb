- **ID**: CVE\-2026\-129232 / GHSA\-cj8f\-5fp3\-6m88
- **危険度**: Medium（警告） (CVSS 5.3)
- **言語**: Python
- **パッケージ**: PyPI/nltk &lt;\= 3\.10\.3 → 3\.10\.4

## 原文

\#\# Summary NLTK's \`XMLCorpusView\.read\_block\` rebuilds the full root\-to\-node context path with \`"/"\.join\(context\)\` on every start tag while it is still searching for a matching element\.
