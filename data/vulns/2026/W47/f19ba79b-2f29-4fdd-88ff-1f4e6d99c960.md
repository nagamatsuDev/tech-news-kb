# matrix\-hookshot is a Matrix bot for connecting to external services like GitHub, GitLab, JIRA, and more\.

- **ID**: CVE\-2026\-62267
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-17

## 原文

matrix\-hookshot is a Matrix bot for connecting to external services like GitHub, GitLab, JIRA, and more\. Prior to 7\.3\.3, Hookshot can crash in src/Bridge\.ts while processing a modern Matrix reply whose m\.relates\_to\.m\.in\_reply\_to\.event\_id identifies an event that the bot cannot read\. Bridge event handling calls botClient\.getEvent\(\) for the parent event without catching the resulting M\_NOT\_FOUND error, allowing the rejected request to escape reply processing and terminate the service\. This issue is fixed in version 7\.3\.3\.
