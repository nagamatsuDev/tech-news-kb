# WeGIA is a web manager for charitable institutions\.

- **ID**: CVE\-2026\-61680
- **危険度**: Critical（緊急） (CVSS 9.8)
- **言語**: PHP
- **公開**: 2026-11-17

## 原文

WeGIA is a web manager for charitable institutions\. Prior to 3\.8\.6, web/html/socio/sistema/cadastro\_cobrancas\_geracao\.php performs privileged charge\-generation operations without checking for an authenticated session\. An unauthenticated remote requester who supplies valid charge\-generation parameters can create arbitrary charge records, enabling financial record manipulation and large\-scale billing corruption\. This issue is fixed in version 3\.8\.6\.
