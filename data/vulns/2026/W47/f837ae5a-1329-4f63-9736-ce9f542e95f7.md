# SGLang through 0\.5\.23, fixed in commit 7b5fb39, contains a missing authorization vulnerability in the POST /load\_lora\_adapter\_from\_tensor\.\.\.

- **ID**: CVE\-2026\-127222
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-18

## 原文

SGLang through 0\.5\.23, fixed in commit 7b5fb39, contains a missing authorization vulnerability in the POST /load\_lora\_adapter\_from\_tensors HTTP endpoint, which lacks the @auth\_level\(AuthLevel\.ADMIN\_OPTIONAL\) decorator applied to its sibling admin endpoints, allowing unauthenticated network\-reachable attackers to invoke it without an API key\. Attackers can load a LoRA adapter from attacker\-supplied serialized tensors to manipulate the served model, and when combined with a separately documented deserialization bypass, achieve unauthenticated remote code execution as root\.
