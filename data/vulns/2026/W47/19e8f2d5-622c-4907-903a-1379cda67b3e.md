# NocoDB before 2026\.09\.0 contains an sql injection vulnerability that allows authenticated Creator or Owner users to inject raw SQL by per\.\.\.

- **ID**: CVE\-2026\-130706
- **危険度**: Critical（緊急） (CVSS 9.1)
- **公開**: 2026-11-18

## 原文

NocoDB before 2026\.09\.0 contains an sql injection vulnerability that allows authenticated Creator or Owner users to inject raw SQL by persisting a crafted formula parsed\_tree reused without revalidation\. Attackers can bypass the SQLite metadata path guard with an alias to plant the tree, escalating to super administrator or executing OS commands on external PostgreSQL hosts\.
