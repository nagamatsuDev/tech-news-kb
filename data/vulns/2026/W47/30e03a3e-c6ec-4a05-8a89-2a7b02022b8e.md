# In Open Object Rexx \(ooRexx\) before 5\.2\.0, RXAPI has a heap buffer over\-read in a QueueManager DataQueue\:\:addmethod\.

- **ID**: CVE\-2026\-130290
- **危険度**: High（重要） (CVSS 7.9)
- **公開**: 2026-11-16

## 原文

In Open Object Rexx \(ooRexx\) before 5\.2\.0, RXAPI has a heap buffer over\-read in a QueueManager DataQueue\:\:addmethod\. In particular, the code blindly trusts the message\.parameter1 value provided by the client as the size used to fill the data from the queueData heap buffer\. An attacker sends a large parameter1 value in an ADD\_TO\_SESSION\_QUEUE or ADD\_TO\_NAMED\_QUEUE message and then retrieves data with a PULL\_FROM\_SESSION\_QUEUE message\. \(A very large value causes a process crash\.\)
