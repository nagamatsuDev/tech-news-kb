# Netatalk is a Free and Open Source file server suite for Unix\-like operating systems\.

- **ID**: CVE\-2026\-62319
- **危険度**: High（重要） (CVSS 7.2)
- **公開**: 2026-11-20

## 原文

Netatalk is a Free and Open Source file server suite for Unix\-like operating systems\. From 1\.5\.0 until 4\.5\.1, dsi\_stream\_receive in libatalk/dsi/dsi\_stream\.c independently clamps dsi\_doff and dsi\_len for DSIWrite requests without enforcing that the data offset is no greater than the declared frame length\. An authenticated AFP client can send dsi\_doff greater than dsi\_len, causing the receiver to consume bytes from a queued subsequent frame before libatalk/dsi/dsi\_write\.c detects the inconsistency\. The irreversible stream desynchronization lets the attacker control the next parsed DSI header and payload and corrupts protocol framing for the connection\. This issue is fixed in version 4\.5\.1\.
