# The Check &amp; Log Email – Easy Email Testing &amp; Mail logging plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'auth\.\.\.

- **ID**: CVE\-2026\-116530
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-18

## 原文

The Check &amp; Log Email – Easy Email Testing &amp; Mail logging plugin for WordPress is vulnerable to Stored Cross\-Site Scripting via the 'author' parameter in all versions up to, and including, 2\.0\.17 due to insufficient input sanitization and output escaping\. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that will execute whenever a user accesses an injected page\. Exploitation requires an administrator to approve the comment carrying the shortcode payload, and the target page must render the core Latest Comments block, which passes comment author names through do\_shortcode via the\_content\.
