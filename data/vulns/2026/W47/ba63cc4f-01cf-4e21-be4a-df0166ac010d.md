# llama\.cpp b2877 before b11935 contains an uncaught exception vulnerability in the ggml\-rpc server that allows unauthenticated remote atta\.\.\.

- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-10-29

## 原文

llama\.cpp b2877 before b11935 contains an uncaught exception vulnerability in the ggml\-rpc server that allows unauthenticated remote attackers to crash the rpc\-server by sending oversized message lengths\. After the HELLO handshake, attackers can send a command such as SET\_TENSOR with a length above std\:\:vector\:\:max\_size\(\), triggering an uncaught std\:\:length\_error that aborts the process and denies service to all clients\.
