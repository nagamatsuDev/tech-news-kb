# NLTK\: Path Traversal in save\_maxent\_params / load\_maxent\_params Allow Arbitrary File READ/WRITE

- **ID**: CVE\-2026\-126296 / GHSA\-59f9\-gqg8\-mqpj
- **危険度**: Medium（警告）
- **言語**: Python
- **パッケージ**: PyPI/nltk &lt;\= 3\.10\.3 → 3\.10\.4
- **公開**: 2026-11-16

## 原文

\#\#\# Summary Path traversal in NLTK's save\_maxent\_params\(\) and load\_maxent\_params\(\) allows arbitrary file write and arbitrary file read outside the directories permitted by NLTK's pathsec security mechanism\. This vulnerability was previously reported through Huntr, accepted by the NLTK project, and assigned CVE\-2026\-15367\. A \$750 bounty was paid through Huntr \(i didnt get the fix bounty\)\. Huntr subsequently shut down its OSS vulnerability program, so I am submitting this report through GitHub to continue the existing disclosure process and preserve the original CVE assignment and researcher cre
