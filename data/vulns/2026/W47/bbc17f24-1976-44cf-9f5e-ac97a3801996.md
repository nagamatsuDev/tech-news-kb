# Music Assistant is an open\-source media library manager that integrates streaming services with connected speakers\.

- **ID**: CVE\-2026\-73971
- **危険度**: High（重要） (CVSS 8.0)
- **言語**: Python
- **公開**: 2026-11-18

## 原文

Music Assistant is an open\-source media library manager that integrates streaming services with connected speakers\. Prior to 2\.8\.0, parse\_arguments\(\) passes the caller\-controlled return\_type parameter for config/core/get\_value, config/providers/get\_value, and config/players/get\_value to parse\_value\(\) and Python eval\(\) when resolving type parameters in music\_assistant/helpers/api\.py\. Any authenticated user, regardless of role, can reach these commands through the WebSocket /ws endpoint or the REST JSON\-RPC /api endpoint, causing arbitrary Python code to run with the Music Assistant server process privileges before command\-handler validation, even if the request later fails\. A default installation requires no special configuration, and compromise can expose secrets and configuration, alter library data, and control the application container\. This issue is fixed in version 2\.8\.0\.
