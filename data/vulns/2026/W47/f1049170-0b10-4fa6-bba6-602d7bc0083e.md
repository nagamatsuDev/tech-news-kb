# When NGINX Plus or NGINX Open Source is configured to use HTTP/2 for client connections and proxy client requests to a backend, a special\.\.\.

- **ID**: CVE\-2026\-123633
- **危険度**: High（重要） (CVSS 8.1)
- **OS**: Linux
- **公開**: 2026-11-18

## 原文

When NGINX Plus or NGINX Open Source is configured to use HTTP/2 for client connections and proxy client requests to a backend, a specially crafted request can result in use\-after\-free in the worker process, if this process is running low on worker\_connections\. Additionally, attackers can execute code on systems with Address Space Layout Randomization \(ASLR\) disabled or when the attacker can bypass ASLR\.
  
Impact\:
  
This vulnerability may allow remote attackers to cause a denial\-of\-service \(DoS\) on the NGINX system or may allow a code execution\. There is no control plane exposure; this is a data plane issue only\.
  
Note\: Software versions which have reached End of Technical Support \(EoTS\) are not evaluated\.
