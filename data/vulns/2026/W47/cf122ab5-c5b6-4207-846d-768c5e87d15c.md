# TeamPass is a self\-hosted collaborative password manager\.

- **ID**: CVE\-2026\-103035
- **危険度**: High（重要） (CVSS 8.3)
- **言語**: PHP
- **公開**: 2026-11-19

## 原文

TeamPass is a self\-hosted collaborative password manager\. Prior to 3\.2\.1\.2, the update\_folder action in app/sources/folders\.queries\.php allowed an authenticated, non\-read\-only user to re\-parent a folder without checking whether the target folder or submitted parentId belonged to the caller's user\-accessible\_folders set\. Selecting a personal folder as the new parent passed the personal\-folder guard and set personal\_folder on the target, transferring the credential subtree into the attacker's accessible space after the next login and hiding it from the organization, including administrators\. The change exposed credential labels, logins, URLs, email addresses, and descriptions, while sharekey\-protected passwords remained protected; hiding the subtree also denied other users access\. This issue is fixed in version 3\.2\.1\.2\.
