# In Eclipse Mosquitto versions 2\.1\.0 to 2\.1\.2, using the mosquitto\_ctrl utility in interactive shell mode to interact with a malicious ser\.\.\.

- **ID**: CVE\-2026\-129149
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-18

## 原文

In Eclipse Mosquitto versions 2\.1\.0 to 2\.1\.2, using the mosquitto\_ctrl utility in interactive shell mode to interact with a malicious server could result in a crash of the utility if the server sent a hostile response\.
