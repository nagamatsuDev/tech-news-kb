# In the Linux kernel, the following vulnerability has been resolved\: media\: em28xx\: fix double free in em28xx\_alloc\_urbs When allocation\.\.\.

- **ID**: CVE\-2026\-99297
- **危険度**: High（重要） (CVSS 7.8)
- **OS**: Linux
- **公開**: 2026-11-16

## 原文

In the Linux kernel, the following vulnerability has been resolved\:
  
media\: em28xx\: fix double free in em28xx\_alloc\_urbs
  
When allocation of usb\_bufs\-&gt;buf\[i\] fails, em28xx\_alloc\_urbs\(\)  
explicitly frees all items within usb\_bufs\-&gt;buf before calling  
em28xx\_uninit\_usb\_xfer\(\), which also frees these items, causing them to be  
freed twice\.
