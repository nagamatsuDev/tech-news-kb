# NukeViet CMS is a multi Content Management System\.

- **ID**: CVE\-2026\-49259
- **危険度**: High（重要） (CVSS 8.7)
- **言語**: JavaScript/TypeScript
- **公開**: 2026-11-20

## 原文

NukeViet CMS is a multi Content Management System\. From the 4\.x release line until 4\.5\.09, a low\-privileged authenticated user can store script\-breaking content in the first\_name and last\_name profile fields used to form a comment display name\. Both reply links in themes/default/modules/comment/comment\.tpl interpolate \{COMMENT\.post\_name\} into the inline onclick call to nv\_commment\_feedback\(\)\. HTML numeric references produced by Request\:\:\_get\_title\(\) are decoded by the browser before JavaScript parsing, so clicking Reply can terminate the string and execute attacker\-controlled JavaScript in the visitor's origin, including an administrator's session\. This issue is fixed in version 4\.5\.09\.
