# Atomic Server is an open source headless CMS and real\-time database\.

- **ID**: CVE\-2026\-69158
- **危険度**: High（重要） (CVSS 8.6)
- **公開**: 2026-11-17

## 原文

Atomic Server is an open source headless CMS and real\-time database\. Prior to 0\.40\.3, unauthenticated requests to /bookmark can supply a url that server/src/plugins/bookmark\.rs passes through fetch\_data to fetch\_body\. Endpoint dispatch in lib/src/db\.rs invokes the handler before check\_read, and lib/src/client/helpers\.rs previously checked only that the URL began with HTTP, without restricting loopback, private, link\-local, DNS\-rebinding, or redirect targets\. The handler reflects fetched content in returned resource fields, making this a full\-response server\-side request forgery that can expose internal services and plain\-GET cloud metadata\. The short request timeout limits slow targets, and metadata services requiring a separate token request are outside the demonstrated GET\-only path\. This issue is fixed in version 0\.40\.3\.
