# Atomic Server\: Unauthenticated full\-response SSRF in Atomic\-Server /bookmark endpoint

- **ID**: CVE\-2026\-69158 / GHSA\-ff87\-73jp\-f3v4
- **危険度**: High（重要） (CVSS 8.6)
- **言語**: Rust
- **パッケージ**: crates\.io/atomic\-server &lt;\= 0\.40\.1
- **公開**: 2026-11-17

## 原文

\#\# Summary Atomic\-Server exposes a \`GET /bookmark\` endpoint that fetches an attacker\-supplied URL server\-side, parses the response, and reflects the fetched content back to the caller\. The endpoint requires no authentication and performs no authorization of its own, and the underlying fetch helper applies no allow\-list or private\-IP deny\-list\. An unauthenticated attacker with network reach to the server can force it to issue arbitrary outbound HTTP GET requests to internal\-only hosts \(loopback services, internal admin panels, link\-local cloud\-metadata\) and read the response body back\.
