# In the Linux kernel, the following vulnerability has been resolved\: mm/huge\_memory\: fix zapping migration entries for device\-private THP\.\.\.

- **ID**: CVE\-2026\-99668
- **危険度**: High（重要） (CVSS 7.8)
- **OS**: Linux
- **公開**: 2026-11-20

## 原文

In the Linux kernel, the following vulnerability has been resolved\:
  
mm/huge\_memory\: fix zapping migration entries for device\-private THPs
  
A PMD migration entry can refer to a device\-private folio\.  
zap\_huge\_pmd\_folio\(\) checks the folio type instead of the entry type,  
so it treats such a migration entry as a device\-private entry\.
  
Installing the migration entry already removed the reverse mapping and  
dropped the mapping reference\. Zapping it must not repeat those  
operations\. Concurrent MADV\_DONTNEED during migration back to system  
memory can trigger this\.
  
Check the PMD entry type using pmd\_is\_device\_private\_entry\(\)\.
  
Fix generated by an LLM and sent by Chris Mason in private\.
