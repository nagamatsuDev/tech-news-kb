# qbee\-agent\: Docker Compose build context Zip Slip writes outside context directory

- **ID**: CVE\-2026\-129237 / GHSA\-vx32\-xf7g\-9ghr
- **危険度**: Medium（警告） (CVSS 5.4)
- **言語**: Go
- **パッケージ**: Go/go\.qbee\.io/agent &lt; 0\.0\.0\-20260908095235\-eb7875f0a849 → 0\.0\.0\-20260908095235\-eb7875f0a849

## 原文

\#\# Summary \`qbee\-agent\` contains a Zip Slip vulnerability in \`app/utils/tar\.go\`\. The tar extractor checks whether an entry remains inside the destination directory with\: \`\`\`go strings\.HasPrefix\(targetPath, destdirClean\) \`\`\` This does not enforce a path separator boundary\. If the destination directory is \`/tmp/\.\.\./context\`, a tar entry such as \`\.\./context\-outside/payload\.txt\` cleans to \`/tmp/\.\.\./context\-outside/payload\.txt\` and still passes the prefix check\. qbee\-agent then creates the outside directory and writes the payload outside the intended extraction root\.
