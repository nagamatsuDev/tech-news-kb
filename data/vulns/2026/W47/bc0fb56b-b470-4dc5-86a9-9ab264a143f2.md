# In Postgres Enterprise Manager \(PEM\), webhook URLs are not validated, and the PEM agent does not restrict the URL schemes it uses to deli\.\.\.

- **ID**: CVE\-2026\-132663
- **危険度**: High（重要） (CVSS 7.1)
- **公開**: 2026-11-20

## 原文

In Postgres Enterprise Manager \(PEM\), webhook URLs are not validated, and the PEM agent does not restrict the URL schemes it uses to deliver webhooks\. A user with the alert configuration role \(pem\_config\_alert\) can set up a webhook with a file\:// URL\. When the webhook is sent, the agent on the PEM server, which runs as root by default, reads the local file and stores its contents in the webhook error record in the PEM database, where any PEM user can read it\.  
From PEM 10\.6\.1, PEM accepts and sends only http and https webhook URLs\.
