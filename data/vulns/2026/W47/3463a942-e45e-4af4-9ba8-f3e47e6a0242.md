## 原文

\#\#\# Summary An unauthenticated path‑traversal / arbitrary file read vulnerability in Etherpad's /static/\* handler allows any remote, unauthenticated user to read any file on the server's filesystem \(e\.g\. GET /static/plugins/ep\_etherpad\-lite/static/\.\.%5C\.\.%5C\.\.%5C\.\.%5C\.\.%5C\.\.%5C\.\.%5Cetc/passwd returns /etc/passwd\) available to the user running the etherpad software\. Because the endpoint is mounted before the authentication middleware, no credentials, session, or configuration change are required\.
