# Atomic Server is an open source headless CMS and real\-time database\.

- **ID**: CVE\-2026\-69155 / GHSA\-x277\-3wcg\-g9r2
- **危険度**: High（重要） (CVSS 8.7)
- **言語**: JavaScript/TypeScript
- **公開**: 2026-11-17

## 原文

Atomic Server is an open source headless CMS and real\-time database\. From 0\.30\.0 until 0\.40\.3, an authenticated Agent with folder write access can use POST /upload to store HTML or SVG content that GET /download/\{path\} serves from the application origin through server/src/handlers/download\.rs\. The response sets Content\-Disposition\: inline and lacks forced attachment handling and X\-Content\-Type\-Options\: nosniff, allowing the browser to render the uploaded active content as the application\. When a victim opens the link, the script can access the JavaScript\-readable atomic\_session cookie and the Agent private key in same\-origin IndexedDB, enabling persistent account impersonation\. This issue is fixed in version 0\.40\.3\.
