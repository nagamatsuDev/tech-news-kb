# SurrealDB 3\.0\.0 before 4\.0\.0 contains a path traversal vulnerability in its bucket storage layer on Windows, where ObjectKey\:\:check\_no\_tr\.\.\.

- **ID**: CVE\-2026\-134294
- **危険度**: High（重要） (CVSS 7.5)
- **OS**: Windows
- **公開**: 2026-11-21

## 原文

SurrealDB 3\.0\.0 before 4\.0\.0 contains a path traversal vulnerability in its bucket storage layer on Windows, where ObjectKey\:\:check\_no\_traversal splits object keys only on forward slashes while FileStore\:\:to\_os\_path treats backslashes as directory separators\. Attackers can supply object keys such as /\.\.\\bucket2\\secret to bypass the traversal check and read or modify files in other buckets\.
