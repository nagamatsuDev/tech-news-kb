# A vulnerability was identified in D\-Link DIR\-600L 2\.17b02\.

- **ID**: CVE\-2026\-133493
- **危険度**: Critical（緊急） (CVSS 10.0)
- **公開**: 2026-11-20

## 原文

A vulnerability was identified in D\-Link DIR\-600L 2\.17b02\. Affected is the function genacgi\_main of the file gena\.cgi of the component GENA Handler\. Such manipulation leads to os command injection\. The attack can be launched remotely\. The exploit is publicly available and might be used\.
