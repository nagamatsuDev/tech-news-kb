# NukeViet CMS is a multi Content Management System\.

- **ID**: CVE\-2026\-94562
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-20

## 原文

NukeViet CMS is a multi Content Management System\. Prior to 4\.6\.01, a super\-administrator satisfying the NV\_IS\_SPADMIN gate can use modules/users/admin/fields\.php to store an arbitrary existing PHP function in the func\_callback setting for a custom profile field because the callback name is checked only with function\_exists\(\) and no allowlist restricts which function may be selected\. modules/users/fields\.check\.php later invokes that function through call\_user\_func\(\) when the field is validated through registration, profile editing, or administrator editing\. Selecting a command\-execution function crosses the super\-administrator to operating\-system boundary and executes commands as the web\-server account, while ordinary users can trigger the stored callback after it is configured\. Because the remediation validates callbacks only when they are written, upgrading does not remove a malicious callback already stored in the database, which must be cleaned manually\. This issue is fixed in version 4\.6\.01\.
