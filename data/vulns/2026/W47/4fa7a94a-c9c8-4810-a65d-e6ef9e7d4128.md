# HtmlSanitizer\: CSS Removal DoS

- **ID**: CVE\-2026\-102529 / GHSA\-464h\-4j8h\-q5mf
- **危険度**: High（重要） (CVSS 7.5)
- **言語**: C\#/\.NET
- **パッケージ**: NuGet/HtmlSanitizer &lt; 9\.0\.967 → 9\.0\.967, NuGet/HtmlSanitizer &gt;\= 9\.1\.878\-beta, &lt; 9\.1\.968\-beta → 9\.1\.968\-beta
- **公開**: 2026-11-17

## 原文

\#\#\# Impact An unauthenticated request can occupy one synchronous application worker for seconds\. Concurrent requests add CPU cost and can keep all workers busy, sustaining denial of service without user interaction\. \#\#\# Patches The issue has been patched in versions 9\.0\.967 and 9\.1\.968\-beta\. \#\#\# Workarounds Disallow the style attribute\.
