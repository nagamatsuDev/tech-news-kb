# NukeViet CMS is a multi Content Management System\.

- **ID**: CVE\-2026\-55372
- **危険度**: High（重要） (CVSS 7.2)
- **言語**: PHP
- **公開**: 2026-11-20

## 原文

NukeViet CMS is a multi Content Management System\. Prior to 4\.5\.09, an unauthenticated attacker can submit the \_\_serverInfoUpdate\=1 field while controlling X\-Forwarded\-Host and X\-Forwarded\-Proto\. NukeViet\\Core\\Server\:\:standardizeHost\(\) did not validate the forwarded host against my\_domains, and a trailing slash could preserve an attacker\-selected port that server\_info\_update\(\) used to construct a cURL request in includes/ini\.php before authentication\. The blind, HEAD\-only request uses a fixed path, but it permits internal host and port discovery and can poison cached server\_headers\. This issue is fixed in version 4\.5\.09\.
