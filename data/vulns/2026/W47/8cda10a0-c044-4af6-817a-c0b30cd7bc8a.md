# In Eclipse Mosquitto versions 2\.1\.0 to 2\.1\.2, the mosquitto\_ctrl utility would crash if attempting to interact with a hostile broker and \.\.\.

- **ID**: CVE\-2026\-126706
- **危険度**: High（重要） (CVSS 7.5)
- **公開**: 2026-11-18

## 原文

In Eclipse Mosquitto versions 2\.1\.0 to 2\.1\.2, the mosquitto\_ctrl utility would crash if attempting to interact with a hostile broker and the broker sent a non\-string "error" value\.
